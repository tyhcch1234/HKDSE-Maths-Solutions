Equations — Guards in an Exhibition Centre

There are 132 guards in an exhibition centre consisting of 6 zones. Each zone has the same number of guards. In each zone, there are 4 more female guards than male guards.

Find the number of male guards in the exhibition centre. [4 marks]

Step-by-step Solution

Step 1 · Define the unknown

Let $x$ be the number of male guards in the exhibition centre.

Always start by naming the quantity the question asks for with a single letter.

Step 2 · Express the female guards

Each of the 6 zones has 4 more female guards than male guards, so across the whole centre the female guards exceed the male guards by $6 \times 4 = 24$.

Hence the number of female guards is $(x + 24)$.

The “per-zone” difference must be multiplied by the number of zones (6) to obtain the total difference.

Step 3 · Form the equation

Total number of guards $= 132$:

$$x + (x + 24) = 132$$

Male guards + female guards = total guards.

Equation from a Sum Condition \((\text{part}_{1})+(\text{part}_{2})=\text{total}\) The two groups of guards together make up all 132 guards.
Step 4 · Solve the equation

$$x + x + 24 = 132$$

$$2x = 132 - 24 = 108$$

$$x = \frac{108}{2} = 54$$

Collect like terms, then divide both sides by 2.

Balancing Method for a Linear Equation \(ax+b=c\;\Longrightarrow\;x=\dfrac{c-b}{a}\quad(a\neq 0)\) Collect like terms first, then divide both sides by the coefficient of the unknown.
Step 5 · Check & conclude

Male $= 54$, female $= 54 + 24 = 78$, and $54 + 78 = 132$. ✓

The number of male guards in the exhibition centre is 54.

Answer:   The number of male guards is $\boxed{54}$.

Question. There are \(150\) students in a school consisting of \(5\) classes. Each class has the same number of students. In each class, there are \(6\) more girls than boys. Find the number of boys in the school.

Show the worked solution
Step 1. Let \(x\) be the number of boys. Each class has 6 more girls than boys, so across 5 classes the girls exceed the boys by \(5\times6=30\); there are \((x+30)\) girls.
Step 2. Form the equation: \(x+(x+30)=150\).
Step 3. \(2x=150-30=120\), so \(x=60\).
Step 4. Check: 60 boys and 90 girls give 150 students; each class has \(90\div5=18\) girls and \(60\div5=12\) boys, a difference of 6 ✓.
Answer: \(60\) boys.
