Guards in an exhibition centre

There are 132 guards in an exhibition centre consisting of 6 zones. Each zone has the same number of guards. In each zone, there are 4 more female guards than male guards. Find the number of male guards in the exhibition centre.

#linear equation #word problem #let x

🧩 Step‑by‑Step Solution

Tap any step to expand / collapse

Let \(x\) be the number of male guards in the exhibition centre.

💡 Hint: Choosing a variable that matches what we want to find (male guards) simplifies the final equation.

There are 6 zones, and each zone has 4 more female guards than male guards.

In each zone: if there are \(m\) male guards, female guards = \(m + 4\).

So for the whole exhibition centre, the extra female guards = \(6 \times 4 = 24\).

Number of female guards = \(x + 24\).

(Alternatively: females in one zone = \(x/6 + 4\) → total = \(x + 24\))

Total guards = male + female = 132.

\(x + (x + 24) = 132\)

Simplify and solve:

\(2x + 24 = 132\)

\(2x = 108\)

\(x = 54\)

Number of male guards = 54.

Check: female guards = \(54 + 24 = 78\). Total = \(54 + 78 = 132\) ✓

✅ Answer: 54 male guards
