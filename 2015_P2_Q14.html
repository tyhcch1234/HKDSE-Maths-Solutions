HKDSE 2015 · Paper 2 · Q14
There is a bag of white sugar. The weight of white sugar in the bag is measured as $5$ kg correct to the nearest kg. If the bag of white sugar is packed into $n$ packets such that the weight of white sugar in each packet is measured as $10$ g correct to the nearest g, find the greatest possible value of $n$.
A. 429
B. 500
C. 578
D. 579

SOLUTION Step by step

1
Write the maximum possible total weight Let $W$ kg be the true weight of the sugar in the bag. Measured $5$ kg correct to the nearest kg means \[4.5 \le W < 5.5\] Converting to grams (multiply by 1000): \[4500 \le 1000W < 5500\] Hint: “correct to the nearest kg” gives the range $\pm 0.5$ kg, and the upper end is strictly below 5500 g.
Maximum Absolute Error \(x-\tfrac{1}{2}d\le \text{true value} A reading of \(5\ \text{kg}\) to the nearest kg means \(d=1\), giving \(4.5\le W<5.5\).
2
Range of each packet Let $w_i$ g be the true weight in the $i$-th packet ($i=1,2,\dots,n$). Measured $10$ g correct to the nearest g means \[9.5 \le w_i < 10.5\] Hint: each packet weighs at least 9.5 g — this is the key to making $n$ large.
3
Add up the packets The total weight is conserved, so \[1000W = w_1 + w_2 + \cdots + w_n\] Using the lower bound of each packet: \[9.5n \le w_1 + w_2 + \cdots + w_n = 1000W < 5500\] Hint: use the smallest allowed packet weight to maximise the number of packets.
4
Solve the inequality for n \[9.5n < 5500\] \[n < \frac{5500}{9.5} = 578.947\ldots\] Hint: the upper limit is strict, so $n$ cannot equal 579.
Greatest Integer Satisfying an Inequality \(n<\dfrac{5500}{9.5}=578.947\ldots\ \Longrightarrow\ n_{\max}=578\) The bound is strict, so \(579\) is excluded and the answer is rounded down.
5
Take the greatest integer Since $n$ is a positive integer and $n < 578.947\ldots$, the greatest possible value is \[n = 578\] (Check: $578 \times 9.5 = 5491 \text{ g} < 5500$ ✔; while $579 \times 9.5 = 5500.5 \text{ g} \not< 5500$ ✘.)
Answer: C — the greatest possible value of $n$ is 578. Total weight $< 5500$ g and each packet $\ge 9.5$ g, so $n < 5500/9.5 = 578.95\ldots$
Hint: watch the strict inequality — always round down to an integer.

Question. A bag of flour weighs \(8\ \text{kg}\), correct to the nearest kg. It is packed into \(n\) packets such that each packet weighs \(25\ \text{g}\), correct to the nearest g. Find the greatest possible value of \(n\).

Show the worked solution
Step 1. The true total weight \(W\) satisfies \(7.5\le W<8.5\ \text{kg}\), i.e. \(7500\le 1000W<8500\ \text{g}\).
Step 2. Each packet weighs at least \(25-0.5=24.5\ \text{g}\), so the total is at least \(24.5n\ \text{g}\).
Step 3. Hence \(24.5n<8500\), so \(n<\dfrac{8500}{24.5}=346.94\ldots\)
Step 4. Since \(346\times24.5=8477<8500\) but \(347\times24.5=8501.5>8500\), the greatest possible value is \(n=346\).
Answer: \(n=346\)
