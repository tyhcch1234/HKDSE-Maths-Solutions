Range of Values from a Rounded Number

If $y = 73.8$ (correct to 3 significant figures), find the range of values of $y$.

A. $73.75 \le y < 73.85$
B. $73.75 < y \le 73.85$
C. $73.7 < y \le 73.9$
D. $73.7 \le y < 73.9$
Key idea: When a number is rounded, the true value lies within half a unit of the place value of the last significant figure.

The number is given correct to 3 significant figures. The third significant figure of $73.8$ is 8, which is in the tenths place.

Place value of the last significant figure = 0.1

Hint: The rounding unit is $0.1$, so the maximum rounding error is half of $0.1$, i.e. $0.05$.

The true value $y$ can be as low as (but not below) $73.8 - 0.05 = 73.75$ and as high as (but not including) $73.8 + 0.05 = 73.85$.

Formula for rounding interval

$73.8 - \frac{0.1}{2} \le y < 73.8 + \frac{0.1}{2}$

Hint: The lower bound is included (because $73.75$ rounds up to $73.8$), while the upper bound is excluded (because $73.85$ rounds up to $73.9$).

Combining the bounds gives:

$73.75 \le y < 73.85$

Therefore, the correct option is A.

Quick Recap

  • When a value is rounded to $n$ significant figures, the rounding unit is the place value of the $n$-th significant figure.
  • The true value lies within half a rounding unit of the rounded value.
  • Lower bound is inclusive (the value rounds up to the given number).
  • Upper bound is exclusive (the value would round up to the next number).
