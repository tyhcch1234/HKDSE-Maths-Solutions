Inequalities

Compound inequalities · Number line representation

Question

The solution of \( x < -7 \) and \( x < 3 \) is

A. \( x < -7 \)
B. \( x < 3 \)
C. \( -7 < x < 3 \)
D. \( x < -7 \) or \( x > 3 \)
Inequality Intersection Number line "and" = common region

Visualize on the Number Line

Red = \( x < -7 \), Blue = \( x < 3 \). The overlapping region shows the solution.

\( x < -7 \)    \( x < 3 \)    Overlap

? Step-by-step Solution

1

Understand the meaning of "and"

The word "and" means the solution must satisfy both inequalities at the same time. So we need the intersection (common part) of the two solution sets.

Hint: Think of two conditions: \( x < -7 \) and \( x < 3 \). A number must be less than both.
2

Analyze each inequality separately

Inequality 1: \( x < -7 \) means \( x \) is any number strictly less than \(-7\).

Inequality 2: \( x < 3 \) means \( x \) is any number strictly less than \(3\).

3

Test a few numbers to build intuition

Pick a number and check if it satisfies both:

  • ✔ \( x = -8 \): Is \(-8 < -7\)? Yes. Is \(-8 < 3\)? Yes. → Works.
  • ✘ \( x = -5 \): Is \(-5 < -7\)? No. (Fails inequality 1)
  • ✘ \( x = 0 \): Is \(0 < -7\)? No. (Fails inequality 1)
  • ✘ \( x = 4 \): Is \(4 < -7\)? No. Is \(4 < 3\)? No. (Fails both)

Only numbers that are less than \(-7\) satisfy both conditions.

4

Determine the intersection on the number line

On the number line, \( x < -7 \) is the region to the left of \(-7\). \( x < 3 \) is the region to the left of \(3\).

The overlap (common region) is everything to the left of \(-7\) (since \(-7 < 3\), the stricter condition dominates).

5

Write the final solution

The solution is simply: \( x < -7 \).

✅ Conclusion: The correct option is A.

Quick Check

Why is option D (\( x < -7 \) or \( x > 3 \)) incorrect?

Answer: Option D uses "or", which means we take the union of the two solution sets. Also, "\( x > 3 \)" is not even part of the given inequalities. The correct operation is "and" (intersection), giving only \( x < -7 \).
