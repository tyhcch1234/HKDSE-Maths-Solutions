Q37 · Linear Programming & Inequalities

Linear Programming Feasible Region Corner Points Maximisation

Question

Consider the following system of inequalities:

\[ \begin{cases} x + 3 \ge 0 \\ 2x + 3y - 12 \le 0 \\ 5x - 3y + 12 \le 0 \end{cases} \]

Let \(D\) be the region which represents the solution of the above system of inequalities. Find the range of values of \(\beta\) such that the greatest value of \(\beta x + 6y\) is \(24\), where \((x, y)\) is a point lying in \(D\).

A. \(\beta \le -10\)
B. \(\beta \ge -10\)
C. \(\beta \le 4\)
D. \(\beta \ge 4\)

Visualisation of Region \(D\)

Step-by-Step Solution

1

Identify the feasible region \(D\)

The three inequalities define a triangular region \(D\).

Boundary lines:

  • \(x = -3\) (vertical line)
  • \(2x + 3y = 12\) (line with slope \(-2/3\))
  • \(5x - 3y = -12\) (line with slope \(5/3\))
2

Find the corner points of \(D\)

Solve the intersecting lines pairwise.

Lines Intersection
\(2x+3y=12\) & \(5x-3y=-12\) \((0, 4)\)
\(2x+3y=12\) & \(x=-3\) \((-3, 6)\)
\(5x-3y=-12\) & \(x=-3\) \((-3, -1)\)

These are the only candidates for the maximum of a linear function.

3

Evaluate \(\beta x + 6y\) at each corner

At \((0, 4)\): \(\beta(0) + 6(4) = 24\)
At \((-3, 6)\): \(\beta(-3) + 6(6) = -3\beta + 36\)
At \((-3, -1)\): \(\beta(-3) + 6(-1) = -3\beta - 6\)
Hint: The greatest value must be \(24\). Since \(24\) is already achieved at \((0,4)\), the other two values must be \(\le 24\).
4

Set up inequalities for \(\beta\)

We require:

1) \(-3\beta + 36 \le 24\)

\(\Rightarrow -3\beta \le -12\)

\(\Rightarrow \beta \ge 4\)

2) \(-3\beta - 6 \le 24\)

\(\Rightarrow -3\beta \le 30\)

\(\Rightarrow \beta \ge -10\)

Since both conditions must hold, we take the more restrictive one.

5

Combine the conditions

From \(\beta \ge 4\) and \(\beta \ge -10\), the intersection is \(\beta \ge 4\).

\(\beta \ge 4\)

Thus the correct choice is D.

Verification: When \(\beta = 4\), maximum = 24 (attained at both \((0,4)\) and \((-3,6)\)). When \(\beta > 4\), maximum is 24 at \((0,4)\).
💡

Exam Tip

In linear programming, the maximum/minimum of a linear function over a convex polygon occurs at a vertex (corner point). For DSE, always test all corner points and solve the resulting inequalities carefully.
