HKDSE Math 2016 Paper 2 Q32

Linear relation between \(x\) and \(\log_9 y\)

Laws of Indices Exponential & Log Functions Linear Graph / Slope

Question

The graph in the figure shows the linear relation between \(x\) and \(\log_9 y\). If \(y = ab^{\,x}\), then \(b =\)
The graph of \(\log_9 y\) against \(x\) is a straight line passing through \((0,-2)\) and \((4,0)\).
\(y = ab^{\,x}\)
A\(-2\)
B\(\dfrac{1}{81}\)
C\(\dfrac{1}{2}\)
D\(3\)

Guided Solution — Tap each step

1
Take \(\log_9\) on both sides of \(y = ab^{\,x}\)
▶

The graph plots \(\log_9 y\) against \(x\), so we must convert the exponential equation into logarithmic form.

\(y = ab^{\,x}\ \Longrightarrow\ \log_9 y = \log_9\!\left(ab^{\,x}\right)\)
Hint: Applying the same logarithm to both sides keeps the equation balanced. We choose base \(9\) because the graph's vertical axis is \(\log_9 y\).
2
Use the product and power laws of logarithms
▶

Split the product \(ab^{\,x}\) and bring down the power \(x\).

\(\log_9 y = \log_9 a + \log_9\!\left(b^{\,x}\right)\)
\(\log_9 y = \log_9 a + x\log_9 b\)
Hint — the two laws used:
• Product law: \(\log(MN)=\log M+\log N\)
• Power law: \(\log M^{\,n}=n\log M\)
3
Recognise the form \(Y = mX + c\)
▶

Compare with the equation of a straight line, where \(Y = \log_9 y\) and \(X = x\):

\(\underbrace{\log_9 y}_{Y} = \underbrace{\log_9 b}_{m}\,x + \underbrace{\log_9 a}_{c}\)
Key insight: The equation is now linear in \(x\) — exactly matching the straight-line graph.
• Slope \(m = \log_9 b\)
• Intercept \(c = \log_9 a\)
4
Read the slope from the graph
▶

The line passes through the two points \((0,-2)\) and \((4,0)\).

\(m = \frac{y_2-y_1}{x_2-x_1} = \frac{0-(-2)}{4-0} = \frac{2}{4} = \frac{1}{2}\)
Hint: Slope \(=\dfrac{\text{rise}}{\text{run}}\). Here the line rises \(2\) units while running \(4\) units to the right.
\(x\)-coordinates are read from the horizontal axis; the \(\log_9 y\) values are read from the vertical axis.
5
Solve for \(b\) using \(\log_9 b = \tfrac{1}{2}\)
▶

Since the slope equals \(\log_9 b\):

\(\log_9 b = \frac{1}{2}\)

Convert to exponential form: if \(\log_a N = k\), then \(N = a^{k}\).

\(b = 9^{\frac{1}{2}} = \sqrt{9} = 3\)
Hint: \(9^{\frac{1}{2}}\) means the positive square root of \(9\). \(3\times 3 = 9\), so \(b = 3\).

Final Answer

\(b = 3\)  →  Option D
