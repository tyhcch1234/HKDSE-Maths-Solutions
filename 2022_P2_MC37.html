Geometric Sequence — Finding the 4th Term

2022 Paper 2 · Q37 · MC

i What is this question testing?

Geometric Sequence Common Ratio \(r\) General Term \(a_n = a_1 r^{\,n-1}\) Solving for \(p\) Exponent Laws

1 The Question

Let \(a_n\) be the \(n\)th term of a geometric sequence. It is given that \[a_1 = 8p^2, \qquad a_2 = 1, \qquad a_3 = 27p,\] where \(p\) is a real number. Find \(a_4\).

1st term\(a_1 = 8p^2\)
2nd term\(a_2 = 1\)
3rd term\(a_3 = 27p\)

2 Step-by-Step Solution

Tap each step to reveal it. Try to predict the next line before you open it!

In a geometric sequence, each term is obtained by multiplying the previous term by the same constant, called the common ratio \(r\).

Working definition \[ \frac{a_2}{a_1} = \frac{a_3}{a_2} = r \] So the ratio of any two consecutive terms is constant.

Apply the ratio property to the three given terms:

\[ \frac{a_2}{a_1} = \frac{a_3}{a_2} \]

Substitute the given expressions:

\[ \frac{1}{8p^2} = \frac{27p}{1} \]
Why this works Both fractions equal the same common ratio \(r\), so they must be equal to each other.

Cross-multiply:

\[ 1 = 8p^2 \cdot 27p = 216p^3 \]

Hence

\[ p^3 = \frac{1}{216} = \left(\frac{1}{6}\right)^3 \]

Since \(p\) is a real number and \(p^3 = \dfrac{1}{216}\):

\[ p = \frac{1}{6} \]
Hint — real cube root Taking the cube root is valid here because \(p\) is real. \(\sqrt[3]{\frac{1}{216}} = \frac{1}{6}\).

Now that \(p = \dfrac{1}{6}\), compute \(a_1\):

\[ a_1 = 8p^2 = 8\left(\frac{1}{6}\right)^2 = 8 \cdot \frac{1}{36} = \frac{8}{36} = \frac{2}{9} \]

Then the common ratio is

\[ r = \frac{a_2}{a_1} = \frac{1}{2/9} = \frac{9}{2} \]
Sanity check \(a_3 = a_2 \cdot r = 1 \cdot \frac{9}{2} = \frac{9}{2}\). Also \(27p = 27 \cdot \frac{1}{6} = \frac{27}{6} = \frac{9}{2}\).

Each new term is the previous term multiplied by \(r = \dfrac{9}{2}\):

\[ a_4 = a_3 \cdot r = \frac{9}{2} \cdot \frac{9}{2} = \frac{81}{4} \]

Therefore, the answer is D.

Alternative check Using \(a_4 = a_1 r^{3}\): \[ a_4 = \frac{2}{9}\left(\frac{9}{2}\right)^3 = \frac{2}{9} \cdot \frac{729}{8} = \frac{1458}{72} = \frac{81}{4} \] Same result.

Answer & Key Takeaways

Correct choice
D. \(\dfrac{81}{4}\)
  • In a geometric sequence, \(\dfrac{a_{n+1}}{a_n} = r\) is constant — use it to build an equation.
  • Consecutive ratio equality: \(\dfrac{a_2}{a_1} = \dfrac{a_3}{a_2}\), which gives \(216p^3 = 1\).
  • Take the real cube root to get \(p = \dfrac{1}{6}\), then find \(a_1 = \dfrac{2}{9}\).
  • Common ratio \(r = \dfrac{9}{2}\), so \(a_4 = a_3 \cdot r = \dfrac{9}{2} \cdot \dfrac{9}{2} = \dfrac{81}{4}\).
  • Always verify with the general term \(a_n = a_1 r^{\,n-1}\).
