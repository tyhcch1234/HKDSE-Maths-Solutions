Question

In the figure, ABCD is a circle. AD produced and BC produced meet at the point E. It is given that BD = DE, $\angle BAC = 66^\circ$ and $\angle ABD = 30^\circ$. Find $\angle CED$.

Given: $BD = DE$  ·  $\angle BAC = 66^\circ$  ·  $\angle ABD = 30^\circ$
A. $18^\circ$
B. $20^\circ$
C. $22^\circ$
D. $28^\circ$

Solution

Step 1 · Name the unknown

Let $\angle CED = x$.

$E$ lies on both produced lines $AD$ and $BC$,
so $\angle CED$ is exactly the angle at $E$ in $\triangle ABE$ (and in $\triangle BDE$).

Step 2 · Isosceles triangle BDE
Base Angles of an Isosceles Triangle \(BD=DE\ \Longrightarrow\ \angle EBD=\angle BED\) \\(BD=DE\\) makes \\(\triangle BDE\\) isosceles, so the angle at \\(B\\) equals the required angle \\(x\\) at \\(E\\).

In $\triangle BDE$, $BD = DE$ (given).

$$\therefore \angle EBD = \angle BED = x \quad (\text{base } \angle\text{s, isos. } \triangle)$$

Since $D$ lies on $AE$ and $C$ lies on $BE$,
the angle at $E$ in $\triangle BDE$ is the same $x$.

Step 3 · Angles in the same segment
Angles in the Same Segment \(\angle CAD=\angle CBD\) \\(A,B,C,D\\) are concyclic and both angles stand on the chord \\(CD\\), so \\(\angle CAD=\angle CBD=x\\).

$A$, $B$, $C$, $D$ are concyclic, and $\angle CAD$ and $\angle CBD$ both stand on the chord $CD$.

$$\therefore \angle CAD = \angle CBD = x \quad (\angle\text{s in the same segment})$$

$\angle EBD = \angle CBD$ because $E$, $C$, $B$ are collinear.

Step 4 · Angle sum in triangle ABE
Angle Sum of a Triangle \(\angle A+\angle B+\angle C=180^\circ\) In \\(\triangle ABE\\) the three angles are \\(x+30^\circ\\), \\(x+66^\circ\\) and \\(x\\), which must add to \\(180^\circ\\).

In $\triangle ABE$:

$$\angle ABE + \angle BAE + \angle AEB = 180^\circ \quad (\angle \text{ sum of } \triangle)$$

$$\angle ABE = \angle ABD + \angle DBE = 30^\circ + x$$

$$\angle BAE = \angle BAC + \angle CAE = 66^\circ + x$$

$$\angle AEB = x$$

Step 5 · Solve for x

$$(x + 30^\circ) + (x + 66^\circ) + x = 180^\circ$$

$$3x + 96^\circ = 180^\circ$$

$$3x = 84^\circ \quad\Rightarrow\quad x = 28^\circ$$

Check: $\angle ABE = 58^\circ$, $\angle BAE = 94^\circ$, $\angle AEB = 28^\circ$ → sum $= 180^\circ$ ✓ (and $\angle DBE = \angle DEB = 28^\circ$ is consistent with $BD = DE$).
Answer: $\angle CED = 28^\circ$ — choice D
