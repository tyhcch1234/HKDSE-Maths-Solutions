Q24 The Question

The straight line \(L\) is perpendicular to the straight line \[ 9x - 5y + 45 = 0. \] If the \(x\)-intercept of \(L\) is \(-3\), then the equation of \(L\) is
  1. \(5x + 9y + 15 = 0\)
  2. \(5x + 9y + 27 = 0\)
  3. \(9x - 5y + 15 = 0\)
  4. \(9x - 5y + 27 = 0\)

Part A Find the slope of the given line

Rewrite \(9x - 5y + 45 = 0\) in slope-intercept form and read off its slope. Drag the slider / use the toggles to see how the given line and the perpendicular direction relate to each other.

1.8
Given line: \(9x-5y+45=0\) Slope \(m_1 = 9/5 = 1.8\) Perp. slope \(m_2 = -1/m_1 = -5/9 \approx -0.556\)
Step 11M

Make \(y\) the subject of the equation of the given line:

\[ 9x - 5y + 45 = 0 \;\Longrightarrow\; 5y = 9x + 45 \;\Longrightarrow\; y = \tfrac{9}{5}x + 9. \]
The coefficient of \(x\) after rearranging is the slope — no need to guess.
Step 21A

Hence the slope of the given line is

\[ m_1 = \frac{9}{5} = 1.8. \]
Slope of \(9x-5y+45=0\) is \(\dfrac{9}{5}\).

Part B Find the slope of \(L\) (perpendicular condition)

Two perpendicular lines satisfy \(m_1 \cdot m_2 = -1\). Use the slider to change \(m_1\) and watch how the perpendicular slope \(m_2\) changes.

1.8
\(m_1 \cdot m_2 = \left(\tfrac{9}{5}\right)\left(-\tfrac{5}{9}\right) = -1\) So \(m_2 = -\dfrac{1}{m_1} = -\dfrac{5}{9}\)
Step 11M

Since \(L \perp\) the given line, the product of their slopes is \(-1\):

\[ m_1 \cdot m_2 = -1 \;\Longrightarrow\; m_2 = -\frac{1}{m_1}. \]
Perpendicular lines "flip and negate" the slope: \(m_2 = -1/m_1\).
Step 21A

Substitute \(m_1 = \dfrac{9}{5}\):

\[ m_2 = -\frac{1}{9/5} = -\frac{5}{9}. \]
Slope of \(L\) is \(-\dfrac{5}{9}\).
0 / 2

Part C Write the equation of \(L\) using the \(x\)-intercept

The \(x\)-intercept of \(L\) is \(-3\), so the point \((-3,\,0)\) lies on \(L\). Drag the slider to shift the point and see how the line changes; the perpendicular condition is always kept.

-3
Point: \((-3,\,0)\) Slope of \(L = -\tfrac{5}{9}\) \(5x + 9y + 15 = 0\)
Step 11M

The \(x\)-intercept of \(L\) is \(-3\), so \(L\) passes through \((-3,\,0)\). Use the point–slope form:

\[ y - 0 = -\frac{5}{9}\bigl[x - (-3)\bigr]. \]
Point–slope form: \(y - y_1 = m(x - x_1)\). Be careful with the double negative \(-(-3)\).
Step 21M

Simplify:

\[ 9y = -5(x + 3) \;\Longrightarrow\; 9y = -5x - 15. \]
Step 31A

Rearrange into the general form:

\[ 5x + 9y + 15 = 0. \]
\(\boxed{5x + 9y + 15 = 0}\) — this is option A.
0 / 3

📘 Summary of Answers

  • Slope of the given line \(9x - 5y + 45 = 0\): \(m_1 = \dfrac{9}{5}\)
  • Perpendicular condition: \(m_1 m_2 = -1 \Rightarrow\) slope of \(L\): \(m_2 = -\dfrac{5}{9}\)
  • Point on \(L\): \(x\)-intercept \(= -3 \Rightarrow (-3,\,0)\)
  • Equation of \(L\) via point–slope form: \(y = -\dfrac{5}{9}(x + 3)\)
  • Final answer: \(5x + 9y + 15 = 0\) — Option A
