2016 MC #1

Simplify the following expression.

\[ 8^{222}\cdot 5^{666} = \; ? \]

  • A. \(10^{666}\)
  • B. \(10^{888}\)
  • C. \(40^{666}\)
  • D. \(40^{888}\)
1

Change the base to prime factors

\[ 8 = 2^{3} \quad\text{and}\quad 5 \text{ is already prime.} \] So rewrite the first factor: \[ 8^{222} = \left(2^{3}\right)^{222}. \]
Hint: Always look for a common base — here both 8 and 5 can be linked through 2 and 5, giving 10.
2

Apply the power-of-a-power law

\[ \left(2^{3}\right)^{222} = 2^{\,3\times 222} = 2^{666}. \] So the expression becomes \[ 2^{666}\cdot 5^{666}. \]
Hint: \((a^m)^n = a^{mn}\). Multiply the exponents \(3\times 222 = 666\).
3

Same exponent — combine the bases

Both factors now share the exponent \(666\): \[ 2^{666}\cdot 5^{666} = (2\cdot 5)^{666} = 10^{666}. \]
Hint: \(a^n b^n = (ab)^n\). This is the "common index" law.
4

Match with the options

The result \(10^{666}\) corresponds to option A.
Hint: Check the exponent carefully — it stays 666, not 888.
Answer: A  ·  \(8^{222}\cdot 5^{666} = 10^{666}\)
