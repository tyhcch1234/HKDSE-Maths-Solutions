Question

If \(a\), \(b\) and \(c\) are non-zero constants such that

\(a(x+3) + b(3x+1) \equiv c(x+2)\),

then \(a : b =\)

🔍 Visual: Compare Coefficients

Expand the left side and match coefficients with the right side. Use the slider to see the structure clearly.

LHS: \((a + 3b)x\) \(+\) \((3a + b)\)
≡
RHS: \(c\,x\) \(+\) \(2c\)

x term

\(a + 3b = c\)

Constant term

\(3a + b = 2c\)

These two equations hold for all values of \(x\) because the expressions are identical.

📝 Step-by-Step Solution

Distribute \(a\) and \(b\):

\(a(x+3) + b(3x+1)\)

\(= ax + 3a + 3bx + b\)

Group the \(x\)-terms and constant terms:

\(= (a + 3b)x + (3a + b)\)

💡 Hint: The symbol \(\equiv\) means the two expressions are identical for all \(x\). So their \(x\)-coefficients and constant terms must match.

The RHS is \(c(x+2) = cx + 2c\).

Matching the \(x\) and constant terms:

x coefficient

\(a + 3b = c\) ……(1)

Constant term

\(3a + b = 2c\) ……(2)

💡 Hint: These two equations come from the fact that the two expressions are identical. We can solve them simultaneously.

Since the identity holds for all \(x\), we can choose a value that simplifies the equation.

Put \(x = -2\):

\(a(-2 + 3) + b(3(-2) + 1) = c(-2 + 2)\)
\(a(1) + b(-5) = c(0)\)

\(a - 5b = 0\)

\(a = 5b\)

Therefore:

\(\frac{a}{b} = 5\)

So \(a : b = 5 : 1\).

💡 Hint: Choosing \(x = -2\) makes the \(c\)-term become zero, leaving a simple equation in \(a\) and \(b\).

From Step 2:

\(a + 3b = c\) ……(1)
\(3a + b = 2c\) ……(2)

Multiply (1) by 2:

\(2a + 6b = 2c\) ……(3)

Subtract (2) from (3):

\((2a + 6b) - (3a + b) = 0\)
\(2a + 6b - 3a - b = 0\)
\(-a + 5b = 0\)

\(a = 5b\)

\(\frac{a}{b} = 5\)

So \(a : b = 5 : 1\).

💡 Hint: Both methods lead to the same result. The key is to eliminate either \(c\) or to substitute a clever value of \(x\).

Final Answer

D. \(5 : 1\)

✅ Key Takeaway

  • • An identity (\( \equiv \)) means the equation holds for all values of \(x\).
  • • Compare coefficients of like terms to form equations.
  • • You can substitute a strategic value (like \(x = -2\)) to simplify quickly.
  • • The ratio \(a : b\) is found by solving \(a = 5b\), giving \(5 : 1\).
