📝 Step-by-Step Solution

Let \(T(n)\) be the number of dots in the \(n\)th pattern.

\[ T(1) = 1 \]
🔑 Hint: We name the quantity we want to find. \(T\) stands for "total dots".

The rule says: "the \((n+1)\)th pattern is formed by adding \(n\) dots to the \(n\)th pattern."

\[ T(n+1) = T(n) + n \quad \text{for any positive integer } n \]
🔑 Hint: This is a recursive formula — each term is built from the previous one.

Apply the recursive rule with \(n = 1, 2, 3, 4, 5, 6, 7\):

\[ \begin{aligned} T(2) &= T(1) + 1 = 1 + 1 = 2 \\ T(3) &= T(2) + 2 = 2 + 2 = 4 \\ T(4) &= T(3) + 3 = 4 + 3 = 7 \\ T(5) &= T(4) + 4 = 7 + 4 = 11 \\ T(6) &= T(5) + 5 = 11 + 5 = 16 \\ T(7) &= T(6) + 6 = 16 + 6 = 22 \\ T(8) &= T(7) + 7 = 22 + 7 = 29 \end{aligned} \]
🔑 Hint: You only need 7 steps to reach the 8th pattern. Be careful — this is a common place for careless mistakes.

Substitute repeatedly to express \(T(8)\) directly from \(T(1)\):

\[ \begin{aligned} T(8) &= T(7) + 7 \\ &= \big(T(6) + 6\big) + 7 \\ &= \big(T(5) + 5\big) + 6 + 7 \\ &\;\;\vdots \\ &= T(1) + 1 + 2 + 3 + 4 + 5 + 6 + 7 \end{aligned} \]
🔑 Hint: Every intermediate term cancels out, leaving only \(T(1)\) and the sum of added dots.

Use the formula for the sum of the first \(m\) positive integers:

\[ 1 + 2 + \cdots + m = \frac{m(m+1)}{2} \]

Here \(m = 7\):

\[ 1 + 2 + \cdots + 7 = \frac{7 \times 8}{2} = 28 \]
🔑 Hint: The pattern shows a triangular number — recognizable by the formula \(\frac{m(m+1)}{2}\).
\[ T(8) = T(1) + 28 = 1 + 28 = 29 \]

Correct Answer

B · 29

⚠️ Common trap: Choice C (36) is \(T(7) + 8\) — adding 8 instead of 7, or mistakenly treating the 8th additional step as adding 8. The number of dots added in the 8th step is \(n = 7\).

💡 Key Takeaway

  • Recursive definition: \(T(n+1) = T(n) + n\) means each step adds \(n\) new dots.
  • Unrolling: \(T(8) = T(1) + (1 + 2 + \cdots + 7)\).
  • Arithmetic sum: \(1 + 2 + \cdots + m = \frac{m(m+1)}{2}\).
  • Result: \(T(8) = 1 + 28 = 29\).
