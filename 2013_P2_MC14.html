Coordinate Geometry — Reading signs & intercepts from a straight line
Straight Line Equation Slope x-intercept & y-intercept Inequalities from a Graph

Q14 The Question

Multiple Choice — choose the correct combination of statements.

The figure shows the graph of the straight line

\[ x + ay + b = 0 . \]

Which of the following are true?

  1. \( a < 0 \)
  2. \( b < 0 \)
  3. \( a < b \)
  • A. I and II only
  • B. I and III only
  • C. II and III only
  • D. I, II and III  ✓

(Answer: D)

I Statement I — Is \( a < 0 \) ?

Key idea: the slope of the line tells us the sign of \( -\tfrac{1}{a} \).

Drag \(a\): -1.0
slope \(= -\frac{1}{a} =\)
Step 11M

Rearrange the equation into slope–intercept form:

\[ x + ay + b = 0 \;\Longrightarrow\; ay = -x - b \;\Longrightarrow\; y = -\frac{1}{a}x - \frac{b}{a} \]
Hint: The coefficient of \(x\) after rearranging is the slope \(m\). Here \(m = -\dfrac{1}{a}\).
Step 21A

From the graph, the line rises from left to right, so the slope is positive:

\[ -\frac{1}{a} > 0 \]

Multiplying both sides by \(a^2 > 0\) (or simply noting \(1/a < 0\)) gives:

\[ a < 0 \]
Hint: A positive slope means numerator and denominator have opposite signs. Since the numerator \(-1\) is already negative, the denominator \(a\) must be negative.
Statement I is TRUE.
0 / 2

II Statement II — Is \( b < 0 \) ?

Key idea: the \(x\)-intercept is positive, and \(x\)-intercept \(= -b\) (when \(x\) has coefficient 1).

Drag \(b\): -1.0
x-intercept \(= -b =\) y-intercept \(= -\frac{b}{a}\)
Step 11M

Put \(y = 0\) to find the \(x\)-intercept:

\[ x + a(0) + b = 0 \;\Longrightarrow\; x = -b \]

The graph clearly shows the \(x\)-intercept is to the right of the origin, i.e. positive.

Hint: Reading a graph is a legitimate mathematical step: the point where the line cuts the \(x\)-axis lies on the positive \(x\)-axis.
Step 21A

Since the \(x\)-intercept is positive:

\[ -b > 0 \;\Longrightarrow\; b < 0 \]
Hint: Don’t confuse the \(x\)-intercept with \(b\). The intercept is \(-b\); if \(-b > 0\), then \(b < 0\).
Statement II is TRUE.
0 / 2

III Statement III — Is \( a < b \) ?

Key idea: the \(y\)-intercept is greater than \(-1\) (it lies above the point \((0,-1)\) labelled on the axis).

Drag \(a\): -1.0
Drag \(b\): -1.5
y-intercept \(= -\frac{b}{a} =\)
Step 11M

Put \(x = 0\) to find the \(y\)-intercept:

\[ a\,y + b = 0 \;\Longrightarrow\; y = -\frac{b}{a} \]

From the graph, the \(y\)-intercept is above the marked point \((0,-1)\):

\[ -\frac{b}{a} > -1 \]
Hint: The mark “\(-1\)” on the \(y\)-axis is a reference point. The line crosses the \(y\)-axis higher than that mark.
Step 21M

Multiply both sides by \(a\). Since Part (a) established \(a < 0\), the inequality sign flips:

\[ -b < -a \]
Hint: This is the classic trap! Multiplying an inequality by a negative number reverses the direction of the inequality. We already know \(a < 0\).
Step 31A

Multiply by \(-1\) once more (which flips the sign again):

\[ b > a \quad\text{or equivalently}\quad a < b \]
Hint: Both \(a\) and \(b\) are negative, but \(b\) is “less negative” than \(a\), so \(b\) is the larger number.
Statement III is TRUE.
0 / 3

✓ Summary of Answers

  • Statement I — Slope \(= -\frac{1}{a} > 0\) (line rises), hence \(a < 0\). TRUE
  • Statement II — \(x\)-intercept \(= -b > 0\) (cuts right of origin), hence \(b < 0\). TRUE
  • Statement III — \(y\)-intercept \(= -\frac{b}{a} > -1\) and \(a < 0\) flips the sign, giving \(a < b\). TRUE

All three statements hold, so the correct option is D. I, II and III.

Exam strategy: translate every visual feature (slope direction, intercept positions) into an inequality on \(a\) and \(b\), then solve carefully remembering to flip the inequality sign when multiplying by a negative value.
