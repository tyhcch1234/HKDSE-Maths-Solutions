Binary to Grouped Decimal Powers

Convert the binary numeral into the form \(a\times 2^{m}+b\times 2^{n}+c\) by spotting the repeated digit pattern.

Question
Express the binary number in terms of powers of 2:
10110010110010112 =
A \(11\times 2^{11}+11\times 2^{5}+11\)
B \(11\times 2^{12}+11\times 2^{6}+11\)
C \(11\times 2^{13}+11\times 2^{7}+11\)
D \(11\times 2^{14}+11\times 2^{8}+11\)
Key Concepts
Base-2 place values Index laws: \(a^m \times a^n = a^{m+n}\) Factorisation of powers Repeating bit blocks Answer: B

Step-by-Step Solution
1 Write the number with place-value positions ›

The binary string 10110010110010112 has 16 digits. Counting from the right, the rightmost digit sits at position \(0\), and the leftmost at position \(15\).

\[ 1011001011001011_2 = \sum_{k=0}^{15} d_k\,2^{k} \]
💡
Place value rule: each digit \(d_k\) multiplies \(2^{k}\). The leftmost bit of a 16-bit string always weights \(2^{15}\).
2 Expand into a sum of powers of 2 ›

Read off every position that holds a 1:

\[ \begin{aligned} &1011001011001011_2 \\[4pt] ={}& 2^{15}+2^{13}+2^{12}+2^{9}+2^{7}+2^{6}+2^{3}+2^{1}+2^{0} \end{aligned} \]

Notice there are 9 terms — one for each "1" in the string.

💡
Positions of the 1s are: 15, 13, 12, 9, 7, 6, 3, 1, 0. Test each with the visualizer above!
3 Group the powers into identical triplets ›

Look for a way to split the indices into groups that share the same "shape":

\[ \underbrace{(2^{15}+2^{13}+2^{12})}_{\text{group }A} \;+\; \underbrace{(2^{9}+2^{7}+2^{6})}_{\text{group }B} \;+\; \underbrace{(2^{3}+2^{1}+2^{0})}_{\text{group }C} \]

All three groups contain the same pattern \(2^{a+2}+2^{a}+2^{a-1}\) — just shifted by a different amount.

💡
Why group? The options all have the form \(11\times 2^{m}+11\times 2^{n}+11\). We want to pull out the common factor 11 from each group.
4 Factorise group A: \(2^{15}+2^{13}+2^{12}\) ›

The smallest index in group A is 12, so factor out \(2^{12}\):

\[ \begin{aligned} 2^{15}+2^{13}+2^{12} &= 2^{12}\bigl(2^{15-12}+2^{13-12}+2^{12-12}\bigr) \\[4pt] &= 2^{12}\bigl(2^{3}+2^{1}+2^{0}\bigr) \\[4pt] &= 2^{12}\bigl(8+2+1\bigr) \\[4pt] &= 2^{12}\times 11 \end{aligned} \]
💡
Key identity: \(2^{m}\times 2^{n}=2^{m+n}\). Subtracting exponents when factoring is just using this in reverse.
5 Factorise group B: \(2^{9}+2^{7}+2^{6}\) ›

The smallest index here is 6, so factor out \(2^{6}\):

\[ \begin{aligned} 2^{9}+2^{7}+2^{6} &= 2^{6}\bigl(2^{3}+2^{1}+2^{0}\bigr) \\[4pt] &= 2^{6}\times 11 \end{aligned} \]
💡
The bracket is again \((8+2+1)=11\) — exactly the same as group A!
6 Factorise group C: \(2^{3}+2^{1}+2^{0}\) ›

The smallest index is 0, so \(2^{0}\) is already the common factor:

\[ \begin{aligned} 2^{3}+2^{1}+2^{0} &= 2^{0}\bigl(2^{3}+2^{1}+2^{0}\bigr) \\[4pt] &= 1 \times 11 = 11 \end{aligned} \]
💡
Remember \(2^{0}=1\) and \(a^{0}=1\).
7 Combine to get the answer ›

Put the three factorised groups back together:

\[ \begin{aligned} &1011001011001011_2 \\[4pt] &= (2^{15}+2^{13}+2^{12}) + (2^{9}+2^{7}+2^{6}) + (2^{3}+2^{1}+2^{0}) \\[4pt] &= 2^{12}\cdot 11 + 2^{6}\cdot 11 + 1\cdot 11 \\[4pt] &= 11\times 2^{12}+11\times 2^{6}+11 \end{aligned} \]

➡ This matches option B.

Correct Option
B  —  \(11\times 2^{12}+11\times 2^{6}+11\)

The key insight is that the binary string contains the pattern "1011" repeated three times (in an overlapping way), which corresponds to \(2^{k+2}+2^{k}+2^{k-1}=2^{k-1}\times 11\).

Fast check: \(2^{12}\times 11 = 45056,\; 2^{6}\times 11 = 704,\; +11 = 45771\).
