HKDSE 2015 Paper 2 — Q30

Statistics: mean, median, mode

Consider the following integers:
2   2   3   3   3   3   3   5   5   6   8   8   9   10   m
Let $p$, $q$ and $r$ be the mean, the median and the mode of the above integers respectively. If $3 \le m \le 5$, which of the following must be true?
I.   $p > q$
II.  $p > r$
III. $q > r$
A. I only
B. II only
C. I and III only
D. II and III only

Solution

1
Mode of a Data Set \(\text{mode}=\text{value with the highest frequency}\) The 14 given numbers already contain five \(2\)s, so adding one more value cannot change the mode.
Read the data; fix what does not change.

There are $15$ integers in total ($14$ given numbers plus $m$). The $14$ given numbers are fixed, so the mode of the whole set is always $3$ (there are five $3$'s, more than any other value — and $m\in\{3,4,5\}$ cannot change this, since it adds at most one more copy of $3$).

Hence $$r = 3 .$$

Hint: the mode is the most frequent value — count the repeats first.

2
Mean of a Data Set \(\bar{x}=\dfrac{\sum x}{n}\) The sum of the 14 given numbers is \(56\), so \(p=\dfrac{56+m}{15}\).
Compute the sum and the mean $p$.

The sum of the $14$ given numbers is $$2+2+3+3+3+3+3+5+5+6+8+8+9+10 = 70.$$ So the sum of all $15$ integers is $70+m$, and $$p=\frac{70+m}{15}.$$

Hint: sum of all values ÷ number of values.

3
Median of a Data Set \(n=15\ \text{odd}:\ \text{median}=\text{the }8\text{th value}\) The position of \(m\) decides whether the 8th value is \(2\), \(3\) or \(4\).
Find the median $q$.

With $15$ numbers the median is the $8$th value when arranged in order.

  • $m=3$: ordered list $2,2,3,3,3,3,3,3,5,5,6,8,8,9,10$ → $8$th $=3$, so $q=3$.
  • $m=4$: $2,2,3,3,3,3,3,\underbrace{4}_{8\text{th}},5,5,6,8,8,9,10$ → $q=4$.
  • $m=5$: $2,2,3,3,3,3,3,\underbrace{5}_{8\text{th}},5,5,6,8,8,9,10$ → $q=5$.

Hint: a new value $m$ is inserted near the middle, so it pushes the median up as $m$ grows.

4Test each statement for $m=3,4,5$.

Hint: "must be true" means true for every allowed value of $m$.

5Combine the results and choose.

I is false when $m=5$ (there $p=q=5$, not $p>q$).
II is true in all three cases ($p>3$ always).
III is false when $m=3$ (there $q=r=3$).

Therefore only II must be true → option B.

Hint: a single counter-example is enough to kill a "must be true" statement.

Answer: B (II only)

Question. The 14 integers \(1,1,2,2,2,2,2,4,4,5,7,7,8,9\) together with one more integer \(m\), where \(m\in\{2,3,4\}\), form a set of 15 integers. Let \(p\), \(q\) and \(r\) be the mean, the median and the mode of the 15 integers respectively. Which of the following must be true? I. \(p>q\) II. \(p>r\) III. \(q>r\)

Show the worked solution
Step 1. The mode \(r\) is always \(2\), since five \(2\)s are already present and \(m\in\{2,3,4\}\) adds at most one more.
Step 2. The sum of the 14 given numbers is \(56\), so \(p=\dfrac{56+m}{15}\): \(p\approx3.87,\ 3.93,\ 4.00\) for \(m=2,3,4\).
Step 3. With 15 numbers the median is the 8th value: \(q=2,3,4\) for \(m=2,3,4\).
Step 4. I fails at \(m=4\) (there \(p=q=4\));
III fails at \(m=2\) (there \(q=r=2\));
II holds in all three cases since \(p>2\). So only II must be true.
Answer: II only
