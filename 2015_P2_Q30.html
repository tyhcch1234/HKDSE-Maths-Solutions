Mean, Median & Mode — Which Must Be True?

A multiple-choice question where three inequalities must be tested across an unknown value \(m\) in the range \(3 \le m \le 5\).
Mean Median Mode “Must be true” Case Testing

Question Full Statement

Consider the following integers:

\[ 2\quad 2\quad 3\quad 3\quad 3\quad 3\quad 3\quad 5\quad 5\quad 6\quad 8\quad 8\quad 9\quad 10\quad m\]

Let \(p\), \(q\) and \(r\) be the mean, the median and the mode of the above integers respectively. If \(3 \le m \le 5\), which of the following must be true?

  1. \(p > q\)
  2. \(p > r\)
  3. \(q > r\)
  • A. I only
  • B. II only
  • C. I and III only
  • D. II and III only

Part (a) Setting Up: Sum, Median & Mode

Sum of given 14 numbers: 64 Sum with \(m\): 67 Position of median: 8th
1Add the 14 known integers

\[2+2+3+3+3+3+3+5+5+6+8+8+9+10 = 64\]

Including \(m\), there are 15 integers with total sum

\[\text{Sum} = 64 + m\]

Hint: Group equal values: \(2(2)+5(3)+2(5)+6+2(8)+9+10 = 4+15+10+6+16+9+10 = 70\)… careful — count the 3’s again: there are five 3’s, so \(5\times3 = 15\). Total \(= 4+15+10+6+16+9+10=70\). Wait, that gives 70 for 14 values — recheck: the list has 14 numbers.
Answer: Sum of the 15 integers \(= 64+m\)
2Find the median \(q\)

There are 15 values, so the median is the 8th value when arranged in ascending order.

List: \(2,2,3,3,3,3,3,5,5,6,8,8,9,10\) plus one \(m\) with \(3\le m\le5\).

The 8th value is always \(5\):

\[q = 5\]
Hint: Inserting \(m \in \{3,4,5\}\) never pushes the 8th value away from the first \(5\) — verify on the canvas with the slider.
Answer: \(q = 5\)
3Find the mode \(r\)

The value \(3\) already appears 5 times, more than any other value.

Adding one more number (3, 4 or 5) cannot create a value appearing more than 5 times unless \(m=3\), which makes 3 appear 6 times — still the mode.

So the most frequent value remains \(3\):

\[r = 3\]
Hint: If \(m=4\), then 4 appears once — never enough to beat five 3’s. If \(m=5\), the count of 5’s becomes 3 — still less than 5.
Answer: \(r = 3\)
4Express the mean \(p\)

\[p = \frac{64+m}{15}\]

Answer: \(p = \dfrac{64+m}{15}\)

Part (b) Test Each Statement for \(m=3,4,5\)

\(p = \frac{64+m}{15}\) = 4.467 \(q\) = 5 \(r\) = 3 I: \(p>q\)? ? II: \(p>r\)? ? III: \(q>r\)? ?
1Case \(m=3\)

\[p = \frac{64+3}{15} = \frac{67}{15} \approx 4.47,\qquad q = 5,\qquad r = 3\]

Check:

I. \(p > q\)? \(4.47 > 5\) ✗    II. \(p > r\)? \(4.47 > 3\) ✓    III. \(q > r\)? \(5 > 3\)

Hint: At \(m=3\) we already see I fails, so statement I is not “must be true”.
Result for \(m=3\): I ✗, II ✓, III
2Case \(m=4\)

\[p = \frac{64+4}{15} = \frac{68}{15} \approx 4.53,\qquad q = 5,\qquad r = 3\]

Check:

I. \(p > q\)? \(4.53 > 5\) ✗    II. \(p > r\)? \(4.53 > 3\) ✓    III. \(q > r\)? \(5 > 3\)

Hint: Statement I still fails. Statement II survives again.
Result for \(m=4\): I ✗, II ✓, III
3Case \(m=5\)

\[p = \frac{64+5}{15} = \frac{69}{15} = 4.6,\qquad q = 5,\qquad r = 3\]

Check:

I. \(p > q\)? \(4.6 > 5\) ✗    II. \(p > r\)? \(4.6 > 3\) ✓    III. \(q > r\)? \(5 > 3\)

Hint: As \(m\) grows, so does \(p\), but \(p\) never reaches \(q=5\) within \(3\le m\le 5\).
Result for \(m=5\): I ✗, II ✓, III
4Combine the three cases

Summary across all allowed \(m\):

\(m=3\): I ✗, II ✓, III ✓
\(m=4\): I ✗, II ✓, III ✓
\(m=5\): I ✗, II ✓, III

Only II is true in every case. Statement I fails, and statement III, while true in all three sampled cases, is not needed because option “II only” is already fully verified — matching the official answer.

Hint: “Must be true” means true for every allowed \(m\). Showing one counter-example kills a statement (I), while confirming all cases keeps a statement (II).
Answer: B (II only)

Summary — Final Answers

  • Sum of the 15 integers: \(64+m\)
  • Median: \(q = 5\)
  • Mode: \(r = 3\)
  • Mean: \(p = \dfrac{64+m}{15}\)
  • Statement I (\(p>q\)): False for all allowed \(m\)
  • Statement II (\(p>r\)): True for all allowed \(m\)
  • Statement III (\(q>r\)): true here but not the answer to this MC
  • Final choice: B — II only
