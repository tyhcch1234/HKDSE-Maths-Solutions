Question

Let \(a,b,c\) be non-zero numbers. If \(3a=4b\) and \(a:c=2:5\), find the value of \(\dfrac{a+3b}{b+3c}\).

  • A.\(\dfrac{5}{3}\)
  • B.\(\dfrac{13}{33}\)
  • C.\(\dfrac{30}{53}\)
  • D.\(\dfrac{75}{38}\)

Solution

1Unify ratios
\[a:b=4:3,\qquad a:c=2:5=4:10\]
\[a:b:c=4:3:10\]
2Substitute
\[\frac{a+3b}{b+3c}=\frac{4+3(3)}{3+3(10)}=\frac{13}{33}\]
Answer\(\;\mathbf{B}.\;\;\(\dfrac{13}{33}\)\)
◆Distractor analysis
A\(\dfrac53\) — uses \(a:c=2:5\) without unifying with \(b\).
B\(\dfrac{13}{33}\) — correct.
C\(\dfrac{30}{53}\) — mis-unifies the ratio.
D\(\dfrac{75}{38}\) — inverts or mis-substitutes.

Answer

Answer\(\mathbf{B.}\) \(\dfrac{13}{33}\)
