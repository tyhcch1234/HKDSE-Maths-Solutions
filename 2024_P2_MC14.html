Q14 The Question

Which of the following statements about the graph of \[ y = 2(6-x)^2 - 7 \] is true?

  • A. The graph opens upwards.
  • B. The graph does not cut the \(x\)-axis.
  • C. The \(y\)-intercept of the graph is \(-7\).
  • D. The graph passes through the point \((-6,\,7)\).

We examine each statement one by one, using the completed-square (vertex) form of the quadratic.

A Statement A — Does the graph open upwards?

A quadratic \(y=ax^2+bx+c\) opens upwards exactly when \(a>0\). Let us rewrite the function and check the sign of the leading coefficient.

Write the given function in the standard completed-square form. Note that \((6-x)^2=(x-6)^2\):

\[ y = 2(6-x)^2 - 7 = 2(x-6)^2 - 7 \]
Hint: Squaring removes the sign, so \((6-x)^2\) and \((x-6)^2\) are identical expressions.
21A

Expanding the completed-square form gives the leading coefficient:

\[ y = 2(x^2-12x+36)-7 = 2x^2-24x+65 \]

So the coefficient of \(x^2\) is \(a=2\).

Hint: In the vertex form \(y=a(x-h)^2+k\), the value of \(a\) is exactly the multiplier in front of the bracket.
31A

Since \(a=2>0\), the parabola opens upwards (a "smile").

∴ Statement A is TRUE.

B Statement B — Does the graph cut the \(x\)-axis?

The graph cuts the \(x\)-axis when \(y=0\) has real solutions. Since the vertex is at \((6,-7)\) which lies below the \(x\)-axis and the parabola opens upwards, it must cross the axis twice.

From Part A, the vertex form is

\[ y = 2(x-6)^2 - 7 \]

so the vertex is \((6,\,-7)\). The vertex lies below the \(x\)-axis.

Hint: The vertex is the lowest point because \(a=2>0\).
21M

Check the discriminant of \(2x^2-24x+65=0\):

\[ \Delta = (-24)^2 - 4(2)(65) = 576 - 520 = 56 > 0 \]
Hint: \(\Delta>0\) → two distinct real roots; \(\Delta=0\) → one repeated root; \(\Delta<0\) → no real roots.
31A

Since \(\Delta = 56 > 0\), the equation \(y=0\) has two distinct real roots, so the graph cuts the \(x\)-axis at two points.

∴ Statement B is FALSE.

Substitute \(x=0\) into \(y=2(6-x)^2-7\):

\[ y\text{-intercept} = 2(6-0)^2 - 7 = 2(36)-7 = 72-7 = 65 \]
Hint: Don't confuse the constant term of the expanded form with the constant in vertex form. Here \(c=65\).
21A

Therefore the \(y\)-intercept is \(65\), not \(-7\). The number \(-7\) is the minimum value (the \(y\)-coordinate of the vertex), not the \(y\)-intercept.

∴ Statement C is FALSE.

Substitute \(x=-6\) into the equation:

\[ y = 2\bigl(6-(-6)\bigr)^2 - 7 = 2(12)^2 - 7 = 2(144) - 7 = 288 - 7 = 281 \]
Hint: Carefully compute \(6-(-6)=12\), then square before multiplying by 2.
21A

The curve gives \(y=281\) when \(x=-6\), but the point \((-6,\,7)\) has \(y=7\). Since \(281 \ne 7\), the point is not on the graph.

∴ Statement D is FALSE.

Summary of Answers

  • Given: \(y = 2(6-x)^2 - 7 = 2(x-6)^2 - 7 = 2x^2 - 24x + 65\)
  • A. Opens upwards — TRUE (\(a=2>0\))
  • B. Does not cut \(x\)-axis — FALSE (vertex below axis; \(\Delta=56>0\), two roots)
  • C. \(y\)-intercept is \(-7\) — FALSE (actual \(y\)-intercept is \(65\))
  • D. Passes through \((-6,7)\) — FALSE (\(y(-6)=281\ne 7\))
  • Correct option: A
