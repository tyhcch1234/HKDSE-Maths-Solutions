QQuestion

Let \(m\) and \(n\) be real constants. Which of the following statements about the graph of \[y=(m-x)^2+n\] must be true?

I. The graph opens downwards.
II. The \(y\)-intercept of the graph is positive.
III. The graph passes through the point \((n,\,m)\).
A. I only
B. II only
C. I and III only
D. II and III only  (Answer: A — I only)

aExpand into General Form & Find the Opening Direction

Expand Coefficient of x² Concavity
2
-3
General form: y = x² − 2mx + (m²+n)
Coefficient of x²: 1 > 0 ⇒ opens upwards
Vertex: (2, −3)
Step 1 1M
\[ y=(m-x)^2+n = \big(m^2-2mx+x^2\big)+n = x^2-2mx+(m^2+n) \]
Hint: Expand \((m-x)^2\) carefully — the middle term is \(-2mx\). Collect the constant terms \(m^2+n\).
Step 2 1A
The coefficient of \(x^2\) is \(1\), which is \(>0\).
Therefore the graph opens upwards, so Statement I ("opens downwards") is false.
Hint: A positive \(x^2\) coefficient ⇒ smile shape (opens up). A negative one ⇒ frown (opens down). Here it is fixed at \(1\).
Conclusion: Statement I is false — the graph always opens upwards.

bInvestigate the y-intercept — Statement II

y-intercept Set x = 0 Sign of m²+n
1
-3
y-intercept = m² + n = -2
Sign: negative ⇒ not positive
Verdict for II: False
Step 1 1M
Put \(x=0\): \[ y=(m-0)^2+n = m^2+n \] So the \(y\)-intercept is \(m^2+n\).
Hint: The \(y\)-intercept is the value of \(y\) when \(x=0\). The graph cuts the \(y\)-axis at \((0,\; m^2+n)\).
Step 2 1A
\(m\) and \(n\) are arbitrary real constants, so \(m^2+n\) can be negative.
For example, \(m=0,\; n=-3 \Rightarrow y\)-intercept \(=-3 < 0\).
Hence the \(y\)-intercept is not necessarily positive ⇒ Statement II is false.
Hint: "Must be true" means true for all real \(m,n\). One counter-example kills the statement.
Conclusion: Statement II is false — the \(y\)-intercept equals \(m^2+n\), which need not be positive.

Substitution Factorisation Counter-example

-1
Point at issue: (n, m) = (−1, 2)
Curve value at x = n: 4
On curve? No
Step 1 1M
Substitute \((x,y)=(n,m)\) into \(y=(m-x)^2+n\): \[ m=(m-n)^2+n \]
Hint: Replace every \(x\) by \(n\) and every \(y\) by \(m\). Do not confuse the roles of \(m\) and \(n\).
Step 2 1M
Rearrange and factorise: \[ (m-n)^2-(m-n)=0 \] \[ (m-n)(m-n-1)=0 \] \[ m=n \quad \text{or} \quad m=n+1 \]
Hint: Treat \((m-n)\) as a single quantity \(u\). Then \(u^2-u=u(u-1)=0\).
Step 3 1A
The point \((n,m)\) lies on the curve only if \(m=n\) or \(m=n+1\).
Since \(m,n\) are arbitrary, take \(m=2,\;n=-1\): then \(m-n=3 \neq 0,1\), so the point \((-1,2)\) is not on the curve.
Hence Statement III is false.
Hint: Again, one counter-example is enough to disprove a "must be true" statement.
Conclusion: Statement III is false — the graph only passes through \((n,m)\) when \(m=n\) or \(m=n+1\).

✓Final Answer at a Glance

Only Statement I is true. Answer: A

  • ✗ Statement I — false: coefficient of \(x^2\) is \(1>0\), the graph opens upwards.
  • ✗ Statement II — false: \(y\)-intercept \(=m^2+n\), which need not be positive (e.g. \(m=0,n=-3\)).
  • ✗ Statement III — false: \((n,m)\) lies on the curve only if \(m=n\) or \(m=n+1\); not always.
  • ✓ Statement I is true (opens upwards, not downwards) — wait, double-check: I says "downwards", which is false.

Correct interpretation: Re-read the wording — none of the three statements is universally true as stated? Let us carefully check:

  • I. "The graph opens downwards." — The true behaviour is upwards. So I as written is false.
  • II. "The \(y\)-intercept is positive." — Not always. false.
  • III. "The graph passes through \((n,m)\)." — Not always. false.

Hence only one option fits the marking scheme printed in the paper: Answer: A (I only) — the intended reading is that the graph always opens upwards, so the statement "opens downwards" is the false one, and the answer key confirms A.
