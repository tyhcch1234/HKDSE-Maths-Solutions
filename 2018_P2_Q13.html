$x \le 2$ (from first inequality) $x < -2$ (from second inequality) Combined "or" solution

Question

2018 MC #13

The solution of $\dfrac{1-2x}{3} \ge x-3 \quad \text{or} \quad 4x+9 < 1$ is

A. $\; x \le 2$
B. $\; x < -2$
C. $\; x \ge 2$
D. $\; \text{all real numbers } x$

Step-by-step Solution

1Understand the "or" structure

The statement is a compound inequality joined by "or". A value of $x$ satisfies the whole statement if it satisfies at least one of the two inequalities.
So we solve each separately, then take the union of the two solution sets.

Hint: "or" → union (∪);
"and" → intersection (∩).
2Solve the first inequality
Multiplication Property of Inequalities\(c>0:\quad a\ge b\ \Rightarrow\ ac\ge bc\)Multiplying by \(3>0\) keeps the sign, giving \(1-2x\ge3x-9\).
$$\frac{1-2x}{3} \ge x-3$$

Multiply both sides by $3$ (positive,
so the inequality sign is unchanged):

$$1-2x \ge 3x-9$$
Hint: multiplying/dividing by a positive number keeps the $\ge$ direction.
3Collect terms in the first inequality
Reversing the Inequality Sign\(c<0:\quad ac\ge bc\ \Rightarrow\ a\le b\)Dividing \(-5x\ge-10\) by \(-5\) reverses the sign, so \(x\le2\).
$$-5x \ge -10$$

Divide both sides by $-5$. Since we divide by a negative number,
the inequality sign flips:

$$x \le 2$$
Hint: the classic trap — remember to reverse the sign when dividing by a negative.
4Solve the second inequality
$$4x+9 < 1$$
$$4x < -8$$
$$x < -2$$
Hint: subtract 9,
then divide by 4 (positive — sign stays the same).
5Take the union of the two solution sets
Union of Solution Sets\((-\infty,\,2\,]\cup(-\infty,\,-2)=(-\infty,\,2\,]\)Every \(x<-2\) already satisfies \(x\le2\), so the union collapses to \(x\le2\).

First inequality gives $\;x \le 2$. Second gives $\;x < -2$.

Since $x < -2$ is contained inside $x \le 2$ (every $x<-2$ also satisfies $x\le 2$),
the union is simply:

$$x \le 2$$
Hint: on a number line,
the orange region sits entirely inside the blue region, so the combined region is just the blue one.
6Match with the options

The solution set $x \le 2$ corresponds to option A.

Hint: check the boundary — $x=2$ is included (closed dot) and $x=-2$ is not needed since it is already inside.
Answer A. $\; x \le 2$

Question. Solve \(\dfrac{3-4x}{2}\le x-1\) or \(2x+7<3\).

Show the worked solution
Step 1. First inequality: multiply by \(2>0\), so the sign is unchanged: \(3-4x\le2x-2\).
Step 2. Collect terms: \(-6x\le-5\). Dividing by \(-6<0\) reverses the sign,
giving \(x\ge\dfrac{5}{6}\).
Step 3. Second inequality: \(2x<-4\), so \(x<-2\).
Step 4. “Or” means union: \(x\ge\dfrac{5}{6}\) or \(x<-2\). The two rays do not overlap,
so both parts stay.
Step 5. Check \(x=1\): \(\dfrac{3-4}{2}=-0.5\le0\) ✓;
check \(x=-3\): \(2(-3)+7=1<3\) ✓.
Answer: \(x\ge\dfrac{5}{6}\) or \(x<-2\)
