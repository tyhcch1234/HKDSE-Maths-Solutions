Statistics — Finding the inter-quartile range from a bar chart

Bar Chart Median & Quartiles Inter-quartile Range Ordered Data

Question Multiple Choice

1 mark

The bar chart below shows the distribution of the numbers of pens owned by some students. Find the inter-quartile range of the distribution.

Number of pens: \(4,\;5,\;6,\;7,\;8\).   Frequency (number of students): \(6,\;8,\;8,\;4,\;2\).

A. \(1\)
B. \(2\)
C. \(4\)
D. \(6\)

Read the heights of the bars and total the number of data values. Use the slider to “walk” through the students and watch the cumulative count grow.

Step 11M

Read each bar height (the number of students) from the chart:

\[ \text{pens }4:6,\quad \text{pens }5:8,\quad \text{pens }6:8,\quad \text{pens }7:4,\quad \text{pens }8:2 \]
Hint: The horizontal axis lists number of pens owned; the vertical axis lists number of students. Each bar height is a frequency.
Step 21M

Add the frequencies to get the total number of data values:

\[ n = 6+8+8+4+2 = 28 \]
Hint: The total number of students is the total number of data values. Always find \(n\) first — the position of the quartiles depends on it.
Step 31A

The distribution has \(28\) data values, so the ordered data can be written as a list of 28 numbers.

\(n = 28\)  →  there are 28 students in total.

Step 11M

Arrange the 28 values in ascending order. Counting from the left, the first 6 values are \(4\) and the next 8 values are \(5\):

\[ \underbrace{4,\ldots,4}_{6\text{ values}},\ \underbrace{5,\ldots,5}_{8\text{ values}},\ \underbrace{6,\ldots,6}_{8\text{ values}},\ \underbrace{7,\ldots,7}_{4\text{ values}},\ \underbrace{8,\ldots,8}_{2\text{ values}} \]
Hint: The cumulative counts are \(6,\ 14,\ 22,\ 26,\ 28\). This tells you exactly which positions hold which value.
Step 21M

The lower quartile is the \(\dfrac{n}{4}=\dfrac{28}{4}=7\)th ordered value… but since \(n\) is even, take the mean of the 7th and 8th values.

Hint: For \(n\) data values, the lower quartile uses position \(\frac{n+1}{4}\) in the “smooth” convention; with a discrete frequency table the DSE convention is to average the two middle values of the lower half when \(\frac{n}{4}\) is an integer.
Step 31A

Locate the values using the cumulative counts: positions \(1\text{–}6\) are \(4\); positions \(7\text{–}14\) are \(5\). So the 7th and 8th values are both \(5\):

\[ Q_1 = \frac{5+5}{2} = 5 \]
\(Q_1 = 5\) pens
Step 41A

Check with the diagram: the highlighted 7th and 8th bars both sit on the “5” column.

Hint: Both values are the same, so averaging them simply returns \(5\). A common error is to use the 6th value (\(4\)) or the 14th value.

Step 11M

Use cumulative counts to find where the 21st and 22nd values sit:

\[ 6+8=14,\quad 14+8=22 \] So positions \(15\text{–}22\) all hold the value \(6\).
Hint: The upper quartile position is \(\frac{3n}{4}=\frac{3\times28}{4}=21\). Again we take the mean of the 21st and 22nd values.
Step 21A

Both the 21st and 22nd ordered values are \(6\):

\[ Q_3 = \frac{6+6}{2} = 6 \]
Step 31A
\(Q_3 = 6\) pens
Hint: Do not confuse \(Q_3\) with the maximum value (\(8\)) or the 3rd quartile position \(21\). The quartile is the value, not the position.

Part (b)(iii) Inter-quartile range

The inter-quartile range measures the spread of the middle 50% of the data: \( \mathrm{IQR} = Q_3 - Q_1 \). Drag the slider to change the assumed \(Q_1\) and \(Q_3\) and see the IQR update live.

Step 11M

Use the quartiles found earlier:

\[ Q_1 = 5,\qquad Q_3 = 6 \]
Hint: The inter-quartile range always uses \(Q_3 - Q_1\) (upper minus lower).
Step 21A

Substitute into the formula:

\[ \mathrm{IQR} = Q_3 - Q_1 = 6 - 5 = 1 \]
Step 31A
Inter-quartile range \(= 1\)  →  Answer: A
Hint: Option B (\(2\)) would be the range of the middle two quartile positions if the data were spread differently; here both quartile values happen to be adjacent integers, giving \(1\).

Summary of Answers

  • Total number of data values: \(n = 28\)
  • Lower quartile: \(Q_1 = \dfrac{5+5}{2} = 5\)
  • Upper quartile: \(Q_3 = \dfrac{6+6}{2} = 6\)
  • Inter-quartile range: \(Q_3 - Q_1 = 6 - 5 = 1\)
  • Correct option: A. \(1\)
