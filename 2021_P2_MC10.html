HKDSE Math 2021 Paper 2 Q10 Multiple Choice

Inequalities and Linear Programming

Compound inequality "or" Solution set Number line

Question: The solution of \(9x + 8 \leq 4(x - 3)\)   or   \(6 - 7x > 20\)   is

A. \(x \geq -4\)
B. \(x < -2\)
C. \(x \leq -4\)
D. \(x > -2\)

✅ Correct answer: C. \(x < -2\)

📘 Step-by-Step Solution

Step 1: Understand the compound inequality +

We have a compound inequality joined by "or":

\(9x + 8 \leq 4(x - 3)\)   or   \(6 - 7x > 20\)

We need to solve each inequality separately, then combine their solution sets using union (since it is "or").

💡 Hint

For "or", the final solution is the set of all \(x\) that satisfy at least one of the inequalities.

Step 2: Solve the first inequality \(9x + 8 \leq 4(x - 3)\) +

Expand the right-hand side:

\(9x + 8 \leq 4x - 12\)

Bring \(x\) terms to the left, constants to the right:

\(9x - 4x \leq -12 - 8\)

\(5x \leq -20\)

Divide both sides by \(5\) (positive, so inequality sign stays):

\(x \leq -4\)

💡 Hint

Remember: when you multiply or divide by a negative number, reverse the inequality sign. Here \(5\) is positive, so no change.

Step 3: Solve the second inequality \(6 - 7x > 20\) +

Subtract \(6\) from both sides:

\(-7x > 20 - 6\)

\(-7x > 14\)

Divide both sides by \(-7\). Since \(-7 < 0\), reverse the inequality sign:

\(x < -2\)

💡 Hint

Dividing by a negative number flips the sign: \(> \) becomes \( < \).

Step 4: Combine using "or" (union) +

We have:

\(x \leq -4\)   or   \(x < -2\)

The union is the set of all \(x\) that satisfy \(x \leq -4\) or \(x < -2\).

Notice that \(x \leq -4\) is completely contained in \(x < -2\) (since every number \(\leq -4\) is also \(< -2\)).

Therefore, the combined solution is simply \(x < -2\).

💡 Hint

Draw a number line to see the overlap: \(x \leq -4\) is a subset of \(x < -2\). The union is the larger set: \(x < -2\).

Step 5: Final answer +

\(x < -2\)

This matches option B.
