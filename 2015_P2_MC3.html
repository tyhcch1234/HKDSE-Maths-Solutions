Solve for \(p\) given two equations

Question: If

\(5p + 9q = 2\)   and   \(p + 3q = 4\),

then \(p =\)

A. \(-5\)
B. \(-3\)
C. \(3\)
D. \(5\)

To keep things clear, let's give each equation a name:

(1)   \(5p + 9q = 2\)

(2)   \(p + 3q = 4\)

Hint: Labelling helps us refer back without rewriting the full equation.

From equation (2):

\(p + 3q = 4\)

Subtract \(3q\) from both sides:

\(p = 4 - 3q\)   … (3)

Hint: We isolate \(p\) so we can substitute it into equation (1). This is the substitution method.

Substitute \(p = 4 - 3q\) into \(5p + 9q = 2\):

\(5(4 - 3q) + 9q = 2\)

Expand:

\(20 - 15q + 9q = 2\)

Combine like terms:

\(20 - 6q = 2\)

Hint: Be careful with the signs when expanding. \(-15q + 9q = -6q\).

From \(20 - 6q = 2\):

Subtract 20 from both sides:

\(-6q = 2 - 20\)

\(-6q = -18\)

Divide both sides by \(-6\):

\(q = 3\)

Hint: Remember: negative divided by negative gives a positive.

Substitute \(q = 3\) into \(p = 4 - 3q\):

\(p = 4 - 3(3)\)

\(p = 4 - 9\)

\(p = -5\)

Hint: Always double-check by substituting both values into the original equations if time permits.

Final Answer
\(p = -5\)   (Option A)
