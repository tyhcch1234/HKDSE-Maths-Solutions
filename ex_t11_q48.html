T11 Q48

How many vertices does a triangular prism have?

Solution

A triangular prism has two triangular bases.
Each triangular base has $3$ vertices.
The bases are separate, so the total number of vertices is $3 + 3 = 6$.
A triangular prism has $6$ vertices.
