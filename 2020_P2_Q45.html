Statistics — How shifting every data value changes (or doesn't change) the variance
Variance Mean Translation of Data Squared Deviations MC Technique

QThe Question

The variance of the six numbers \[ 20a+3,\quad 20a+5,\quad 20a+9,\quad 20a+11,\quad 20a+15,\quad 20a+17 \] is

A \(5\)
B \(10\)
C \(25\)
D \(20a+25\)

1Key Idea: Subtracting a Constant Does Not Change Variance

Each of the six numbers can be written as \(20a+10\) plus a small "shift". If we subtract the same constant \(20a+10\) from every number, all values move left by the same amount — the shape (spread) of the data is unchanged, so the variance is unchanged.

Step 1

List the six numbers and identify a common constant to subtract:

\[ 20a+3,\;20a+5,\;20a+9,\;20a+11,\;20a+15,\;20a+17 \]

The average of the first and last is \(20a+10\), so subtract \(20a+10\) from each.

Hint: Adding or subtracting the same constant to all data values only translates the set — the mean moves, but the spread (variance) does not.
Step 2

After subtracting \(20a+10\):

\[ -7,\;-5,\;-1,\;1,\;5,\;7 \]

These are much simpler numbers to work with — and they contain no \(a\), so the answer cannot depend on \(a\).

Hint: This immediately eliminates option D (which still contains \(a\)).
The variance is the same as that of \(\{-7,-5,-1,1,5,7\}\).

2Computing the Variance of \(\{-7,-5,-1,1,5,7\}\)

Variance \(= \dfrac{\sum (x-\bar{x})^2}{n}\). First find the mean \(\bar{x}\), then average the squared deviations.

Step 1

Find the mean:

\[ \bar{x}=\frac{(-7)+(-5)+(-1)+1+5+7}{6}=\frac{0}{6}=0 \]
Hint: The numbers are symmetric about \(0\), so the mean is \(0\) — the deviations are just the numbers themselves.
Step 2

Square each deviation from the mean:

\[ (-7)^2=49,\;(-5)^2=25,\;(-1)^2=1,\;1^2=1,\;5^2=25,\;7^2=49 \]
Hint: Squaring removes signs, so \(-7\) and \(7\) contribute the same amount. The total is \(49+25+1+1+25+49=150\).
Step 3

Divide by \(n=6\):

\[ \text{Variance}=\frac{49+25+1+1+25+49}{6}=\frac{150}{6}=25 \]
Hint: Do not divide by \(n-1=5\) unless the question uses the sample variance formula. In HKDSE Paper 2, the population variance (divide by \(n\)) is used.
The required variance is \(\mathbf{25}\) → Option C.

Step 1Tip

Shift rule: Adding (or subtracting) a constant \(c\) to every value leaves the variance unchanged.

\[ \operatorname{Var}(X+c)=\operatorname{Var}(X) \]
Hint: Here we effectively subtracted \(20a+10\), so the \(a\)-term vanishes.
Step 2Tip

Scale rule: Multiplying every value by a constant \(k\) multiplies the variance by \(k^2\).

\[ \operatorname{Var}(kX)=k^2\operatorname{Var}(X) \]

Move the “Scale” slider to verify this numerically in the readout above.

Hint: A negative scale changes signs but the square \(k^2\) keeps the variance positive.
Step 3

Applying the shift rule with \(c=-(20a+10)\) to the original six numbers:

\[ \operatorname{Var}(20a+\{3,5,9,11,15,17\}) = \operatorname{Var}(\{-7,-5,-1,1,5,7\}) = 25 \]
Hint: This is exactly the reasoning in the official solution — no expansion of \((20a+\dots)^2\) needed.
Answer: 25 → Option C.

Final Answer at a Glance

  • The six numbers are \(20a+3,\;20a+5,\;20a+9,\;20a+11,\;20a+15,\;20a+17\).
  • Subtract the constant \(20a+10\) from every number — the variance does not change.
  • New data set: \(\{-7,-5,-1,1,5,7\}\), whose mean is \(0\).
  • Sum of squared deviations: \(49+25+1+1+25+49 = 150\).
  • \(\displaystyle \text{Variance}=\frac{150}{6}=25\).
  • Correct option: C
