❓Question

Which of the following is correct? $\sqrt{333} \approx 18.24828759\ldots$
  • A.$18$  (correct to the nearest integer)
  • B.$18.2$  (correct to 2 decimal places)
  • C.$18.25$  (correct to 3 significant figures)
  • D.$18.2482$  (correct to 4 decimal places)

🧭Step-by-Step Guided Solution

1 Understand what the question is asking ▶

Each option takes the same value $\sqrt{333}\approx 18.24828759\ldots$ and rounds it to a different accuracy. Only one statement is true.

The four accuracies tested are:

  • Correct to the nearest integer
  • Correct to $n$ decimal places (d.p.)
  • Correct to $n$ significant figures (s.f.)
Hint: We never re-use a previously rounded value — always round the original full decimal $18.24828759\ldots$
2 Recall the rounding rule ▶

To round to a given accuracy:

  1. Locate the last digit to keep.
  2. Look at the next digit (the decider).
  3. If the decider is $\mathbf{5,6,7,8,9}$ → round up (add $1$ to the kept digit).
    If the decider is $\mathbf{0,1,2,3,4}$ → round down (keep as is).
  4. Drop all digits after the kept digit.
$\text{kept digit} \;+\underbrace{1}_{\text{if next digit}\ge 5}$
Remember: When rounding up a digit $9$, it becomes $0$ and carries $1$ to the left (e.g. $18.24999\ldots \to 18.25$).
3 Option A — correct to the nearest integer ▶

The integer part is $18$, and the first decimal digit is $2$ (the decider).

$18.\,\underline{2}\,4828759\ldots \quad \text{decider}=2 < 5 \;\Rightarrow\; \text{round down}$

So $\sqrt{333}\approx \mathbf{18}$ correct to the nearest integer.

✔ Option A is a true statement.

4 Option B — correct to 2 decimal places ▶

2 d.p. means keep 2 digits after the decimal point: keep $18.24\ldots$

The next digit (3rd decimal place) is $8$. Since $8\ge 5$, we round up.

$18.24\,\underline{8}\,28759\ldots \quad 8\ge 5 \;\Rightarrow\; 18.24 + 0.01 = 18.25$

But option B claims $18.2$ — that is only 1 decimal place, and even then it is wrong.

✘ Option B is false.

5 Option C — correct to 3 significant figures ▶

Significant figures start from the first non-zero digit. Here the digits $1,8$ are the 1st and 2nd s.f., so the 3rd s.f. is the first decimal digit $2$.

$18.\,\underline{2}\,4828759\ldots \quad \text{decider}=4 < 5 \;\Rightarrow\; \text{round down} \;\Rightarrow\; 18.2$

So the correct value to 3 s.f. is $18.2$. Option C claims $18.25$, which is actually the value to 2 d.p. (or 4 s.f.) — so it is wrong.

✘ Option C is false.

6 Option D — correct to 4 decimal places ▶

4 d.p. means keep $4$ digits after the decimal point: $18.2482\ldots$

The next digit (5th decimal place) is $8$. Since $8\ge 5$, we round up.

$18.2482\,\underline{8}\,759\ldots \quad 8\ge 5 \;\Rightarrow\; 18.2482 + 0.0001 = 18.2483$

The correct value to 4 d.p. is $18.2483$, not $18.2482$.

✘ Option D is false.

📐Quick Rules Reference

Nearest integer

Look at the first decimal digit. If it is $5$ or more, round up; otherwise round down.

18.248… → 18

$n$ decimal places

Keep exactly $n$ digits after the decimal point. The very next digit decides rounding.

2 d.p.: 18.24|8 → 18.25

$n$ significant figures

Count from the first non-zero digit. Leading zeros are not significant.

3 s.f.: 1 8 . 2|4 → 18.2

Common trap

Do not round twice! Round the original full value once, or errors accumulate.

✘ 18.248… → 18.2 → 18.25
