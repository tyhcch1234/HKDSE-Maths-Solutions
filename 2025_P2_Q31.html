Expected Value (Tokens Game)

Question

A box contains six cards numbered 2, 2, 2, 3, 4 and 5 respectively. In a game, a number is randomly drawn from the box and a certain number of tokens will be got according to the following table:

Number drawn2345
Number of tokens got10152550

Find the expected number of tokens got in the game.

  1. 3
  2. 4
  3. 20
  4. 25

Solution

STEP 1 · Probability of each number
Probability of an Event \(P(E)=\dfrac{n(E)}{n(S)}\) Three of the six cards show \(2\), so \(P(2)=\tfrac{3}{6}\).
There are 6 cards in total: \[ P(2)=\frac{3}{6},\quad P(3)=\frac{1}{6},\quad P(4)=\frac{1}{6},\quad P(5)=\frac{1}{6}. \]
STEP 2 · Expected value
Expected Value \(E=\sum p_{i}x_{i}\) Multiply each token value by its probability and add the four results.
\[ E = 10\times\frac{3}{6} + 15\times\frac{1}{6} + 25\times\frac{1}{6} + 50\times\frac{1}{6} = \frac{30+15+25+50}{6} = \frac{120}{6} = 20. \]
Final Answer: D. 20
