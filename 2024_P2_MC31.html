The H.C.F. of $u^{2}v^{3}w$, $u^{3}vw^{2}$ and $u^{2}v^{3}w^{4}$ is

💡

Key Concept

The H.C.F. (Highest Common Factor) of algebraic terms is found by taking the lowest power of each common variable.

🧩 Step-by-step solution

1 Write down each polynomial
+

We have three monomials:

$P_1 = u^{2}v^{3}w$,    $P_2 = u^{3}vw^{2}$,    $P_3 = u^{2}v^{3}w^{4}$

2 Identify the common variables
+

All three terms contain the variables $u$, $v$, and $w$.

So the H.C.F. will include $u$, $v$, and $w$.

3 Find the lowest power of each variable
+

Compare the exponents for each variable across the three terms:

  • $u$: exponents are $2, 3, 2$ → lowest = 2
  • $v$: exponents are $3, 1, 3$ → lowest = 1
  • $w$: exponents are $1, 2, 4$ → lowest = 1

Therefore the H.C.F. is $u^{2} v^{1} w^{1} = u^{2} v w$.

4 Match with the options
+

Option B is $u^{2}vw$, which matches our result.

✅ The answer is B.
