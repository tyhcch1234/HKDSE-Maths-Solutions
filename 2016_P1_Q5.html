HKDSE Math 2016 Paper 1 Q5

Number of Male & Female Members

🥇 Equations 📐 Simultaneous Equations 🔢 Percentage

Question

In a recreation club, there are 180 members and the number of male members is 40% more than the number of female members. Find the difference of the number of male members and the number of female members.

[4 marks]
💡
Key concept: Let the unknown be $x$ and $y$. Translate the percentage condition “40% more than” into an algebraic equation: $x = (1 + 40\%)y = 1.4y$. Then solve the system of two equations.

Step-by-step Solution

Let

$x$ = number of male members,

$y$ = number of female members.

⭐ Hint: Choose variables that are easy to remember (e.g. $x$ for male, $y$ for female).

Total number of members is 180:

$x + y = 180$ … (1)

⭐ Hint: The sum of male and female members equals the total number of members.

The number of male members is 40% more than the number of female members.

“40% more than $y$” means $y + 40\% \cdot y = 1.4y$.

$x = (1 + 40\%)y = 1.4y$ … (2)

⭐ Hint: $1 + 40\% = 1.4$ represents the multiplier for a 40% increase.

Substitute (2) into (1):

$1.4y + y = 180$

$2.4y = 180$

$y = 180 \div 2.4 = 75$

⭐ Hint: Combine like terms — $1.4y + y = 2.4y$. Then divide both sides by $2.4$.

Substitute $y = 75$ into (1) or (2):

$x = 1.4 \times 75 = 105$

Difference = number of male $-$ number of female:

$105 - 75 = 30$

⭐ Hint: The question asks for the difference, so subtract the smaller from the larger.
