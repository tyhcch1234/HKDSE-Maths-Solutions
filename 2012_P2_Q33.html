Place Value in Base 16

Question

\(AD0000002012_{16} =\)

  1. \((10)\,16^{11} + (13)\,16^{10} + 8210\)
  2. \((10)\,16^{12} + (13)\,16^{11} + 131360\)
  3. \((11)\,16^{11} + (14)\,16^{10} + 8210\)
  4. \((11)\,16^{12} + (14)\,16^{11} + 131360\)

Solution

Step 1 · Values of the hex digits

In base 16, \(A = 10\) and \(D = 13\). The number \(AD0000002012_{16}\) has 12 digits.

Hexadecimal Digits \(A=10,\ B=11,\ C=12,\ D=13,\ E=14,\ F=15\) In base \(16\) the letters stand for values from \(10\) to \(15\); here \(A=10\) and \(D=13\).
Step 2 · Identify the place values

Counting places from the right (rightmost digit = \(16^{0}\)):

  • \(A\) is in the \(16^{11}\) place,
  • \(D\) is in the \(16^{10}\) place,
  • \(2\) is in the \(16^{3}\) place, \(1\) is in the \(16^{1}\) place, \(2\) is in the \(16^{0}\) place.
Place Value in Base 16 \(\text{value}=\sum_{i=0}^{n-1}d_{i}\,16^{i}\) Counting places from the right, the digits sit in the \(16^{0},16^{1},16^{2},\dots\) places.
Step 3 · Expand \[ AD0000002012_{16} = 10\times16^{11} + 13\times16^{10} + 2\times16^{3} + 1\times16 + 2\times1. \]
Expanded Form of a Base-16 Numeral \((d_{k}d_{k-1}\cdots d_{0})_{16}=d_{k}16^{k}+d_{k-1}16^{k-1}+\cdots+d_{0}\) Each digit is multiplied by its place value, keeping the digits that are zero as place holders.
Step 4 · Combine the small terms \[ 2\times16^{3} + 16 + 2 = 2\times4096 + 18 = 8192 + 18 = 8210. \]

Therefore \(AD0000002012_{16} = (10)\,16^{11} + (13)\,16^{10} + 8210\).

Final Answer: A. \((10)\,16^{11} + (13)\,16^{10} + 8210\)

Question. In base \(16\), \(B=11\) and \(C=12\). The number \(4B0000C3_{16}\) has \(8\) digits. (a) Write the number in expanded form. (b) Find the value of the part formed by its last four digits.

Show the worked solution
Step 1. The digits are \(4,\ B=11,\ 0,\ 0,\ 0,\ 0,\ C=12,\ 3\), so \(4B0000C3_{16}\) has \(8\) digits and the leftmost digit \(4\) is in the \(16^{7}\) place.
Step 2. (a) \(4B0000C3_{16}=4\times16^{7}+11\times16^{6}+12\times16^{1}+3\times16^{0}\).
Step 3. (b) The last four digits are \(00C3\), i.e. \(0\times16^{3}+0\times16^{2}+12\times16+3\).
Step 4. \(12\times16+3=192+3=195\).
Step 5. So the number is \(4\times16^{7}+11\times16^{6}+195\).
Answer: (a) \(4\times16^{7}+11\times16^{6}+12\times16+3\) (b) \(195\)
