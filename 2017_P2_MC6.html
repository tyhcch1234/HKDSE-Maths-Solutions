Functions and Graphs — Evaluating a Difference of Function Values

Function Evaluation Constant Term Cancellation Quadratic f(x)

Q Question

Let \(k\) be a constant. If \(f(x) = 2x^2 - 5x + k\), then \(f(2) - f(-2) = \)

A. \(-20\).
B. \(0\).
C. \(16\).
D. \(24\).

2 marks

a Evaluating \(f(2)\) and \(f(-2)\)

3

Substitute \(x = 2\) and \(x = -2\) into \(f(x) = 2x^2 - 5x + k\).

0 / 3
1 1M Substitute \(x = 2\)
\[ f(2) = 2(2)^2 - 5(2) + k \] \[ = 8 - 10 + k \] \[ = -2 + k \]
Hint: Always compute the square first, then multiply, then add/subtract.
2 1M Substitute \(x = -2\)
\[ f(-2) = 2(-2)^2 - 5(-2) + k \] \[ = 8 + 10 + k \] \[ = 18 + k \]
Hint: \((-2)^2 = 4\), and \(-5(-2) = +10\). Watch the signs!
3 1A Subtract to find \(f(2) - f(-2)\)
\[ f(2) - f(-2) = (-2 + k) - (18 + k) \] \[ = -2 + k - 18 - k \] \[ = -20 \]
Answer \[ f(2) - f(-2) = -20 \]
Correct option: A
Key insight: The constant \(k\) cancels out completely — it does not affect the difference!

b Visualising Why \(k\) Cancels Out

0
Drag the slider — the difference \(f(2)-f(-2)\) stays constant at \(-20\).

The value of \(k\) shifts the whole parabola up or down. Since both \(f(2)\) and \(f(-2)\) shift by the same amount \(k\), their difference never changes.

0 / 2
1 1M Separate the \(k\)-independent part
Let \(g(x) = 2x^2 - 5x\), so that \(f(x) = g(x) + k\). Then: \[ f(2) - f(-2) = \bigl(g(2) + k\bigr) - \bigl(g(-2) + k\bigr) = g(2) - g(-2) \]
Hint: The \(k\) terms cancel because they appear identically in both function values.
2 1A Compute \(g(2) - g(-2)\)
\[ g(2) = 2(4) - 5(2) = 8 - 10 = -2 \] \[ g(-2) = 2(4) - 5(-2) = 8 + 10 = 18 \] \[ g(2) - g(-2) = -2 - 18 = -20 \]
Conclusion \[ f(2) - f(-2) = -20 \quad\text{independent of } k \]
Correct option: A

📋 Summary of Answers

  • \(f(2) = -2 + k\)
  • \(f(-2) = 18 + k\)
  • \(f(2) - f(-2) = (-2 + k) - (18 + k) = -20\)
  • The constant \(k\) cancels out — the answer does not depend on \(k\).
  • Correct option: A. \(-20\)
