In the figure, \(ABCD\) is a rhombus. \(ABE\) and \(BCF\) are straight lines such that \(BE = EF\). If \(\angle BEF = 56^\circ\), then \(\angle BDC =\)

  1. \(56^\circ\)
  2. \(62^\circ\)
  3. \(59^\circ\)
  4. \(48^\circ\)

Part (a) The isosceles triangle \(BEF\)

\(BE = EF\) means \(\triangle BEF\) is isosceles with apex \(E\). Drag the slider to change \(\angle BEF\) and watch the base angles adapt.

56°
∠BEF = 56° ∠EBF = 62° ∠EFB = 62° sum = 180°
isosceles sides BE = EF base angles (equal) rhombus \(ABCD\)
11M

In \(\triangle BEF\), \(BE = EF\) is given, so it is an isosceles triangle with apex \(E\). Therefore the base angles are equal:

\[ \angle EBF = \angle EFB \qquad \text{(base } \angle\text{s, isos. } \triangle) \]
Hint: The two equal sides \(BE\) and \(EF\) meet at \(E\), so \(E\) is the apex and \(BF\) is the base — the equal angles sit at \(B\) and \(F\).
21M

Angle sum of a triangle:

\[ \angle EBF + \angle EFB = 180^\circ - \angle BEF = 180^\circ - 56^\circ = 124^\circ \]
Hint: The three angles of any triangle add to \(180^\circ\), so the two base angles share the remainder \(180^\circ - 56^\circ\).
31A

Since the two base angles are equal, each one is half of \(124^\circ\):

\[ \angle EBF = \angle EFB = 124^\circ \div 2 = 62^\circ \]
Answer: \(\angle EBF = \angle EFB = 62^\circ\)
0 / 3

Part (b) The exterior angle at \(B\)

\(A\), \(B\), \(E\) are collinear, so \(\angle ABF\) is an exterior angle of \(\triangle BEF\) at vertex \(B\).

56°
∠EBF = 62° ∠BEF = 56° ∠ABF = 62° + 56° = 118°
exterior angle at B base angle ∠EBF apex angle ∠BEF
11M

Because \(A\), \(B\), \(E\) lie on the straight line \(ABE\), the side \(EB\) is produced to \(A\). Hence \(\angle ABF\) is an exterior angle of \(\triangle BEF\) at \(B\):

\[ \angle ABF = \angle EFB + \angle BEF \qquad (\text{ext. } \angle \text{ of } \triangle) \]
Hint: An exterior angle of a triangle equals the sum of the two interior opposite angles — here \(\angle EFB\) and \(\angle BEF\), not the adjacent \(\angle EBF\).
21A

Substitute the values found in part (a):

\[ \angle ABF = 62^\circ + 56^\circ = 118^\circ \]
Answer: \(\angle ABF = 118^\circ\)
0 / 2

Part (c) Use the rhombus to split the angle

In a rhombus the diagonal \(BD\) bisects \(\angle ABC\), so \(\angle BDC=\angle ABC \div 2\).

56°
∠ABC = ∠ABF = 118° ∠BDC = ∠ABC ÷ 2 = 59° check: ∠BCD = 62°
diagonal BD (angle bisector) shaded ∠BDC rhombus \(ABCD\)
11M

Since \(ABE\) is a straight line, the angle \(\angle ABC\) of the rhombus (at \(B\)) is the same as \(\angle ABF\):

\[ \angle ABC = \angle ABF = 118^\circ \]
Hint: \(BC\) lies on the straight line \(BCF\), and \(BA\) lies along \(BE\). So the interior angle at \(B\) of the rhombus equals the exterior angle of \(\triangle BEF\).
21M

Property of a rhombus: the diagonal \(BD\) bisects the angle at \(B\), i.e. \(\angle ABD = \angle DBC\). Hence

\[ \angle BDC = \angle ABC \div 2 \]
Hint: In a rhombus, all sides are equal, so \(\triangle ABD\) and \(\triangle CBD\) are isosceles. This forces the diagonal from \(B\) to bisect the angle at \(B\).
31A

Substitute \(\angle ABC = 118^\circ\):

\[ \angle BDC = 118^\circ \div 2 = 59^\circ \]
Answer: \(\angle BDC = 59^\circ\) — the correct choice is C.
0 / 3

📌 Summary at a glance

  • Part (a): \(\triangle BEF\) is isosceles (\(BE=EF\)) \(\Rightarrow \angle EBF = \angle EFB = \dfrac{180^\circ - 56^\circ}{2} = 62^\circ\)
  • Part (b): Exterior angle of \(\triangle BEF\): \(\angle ABF = 62^\circ + 56^\circ = 118^\circ\)
  • Part (c): Rhombus diagonal bisects the angle: \(\angle BDC = \angle ABC \div 2 = 118^\circ \div 2 = 59^\circ\)
  • Correct option: C 59°
