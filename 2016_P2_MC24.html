Q24 The Question

If the sum of the interior angles of a regular \(n\)-sided polygon is \(3240^\circ\), which of the following is true?
A.The value of \(n\) is \(16\).
B.Each exterior angle of the polygon is \(18^\circ\).
C.The number of diagonals of the polygon is \(20\).
D.Each interior angle of the polygon is \(160^\circ\).

A Finding \(n\) from the Interior-Angle Sum

Explore how the interior-angle sum \((n-2)\times 180^\circ\) varies with \(n\). Find the \(n\) that makes it equal to \(3240^\circ\).

n = 20
Angle sum = 3240°
Each interior = 162°
Each exterior = 18°
0 / 3
Step 11M

Use the angle-sum formula for an \(n\)-sided polygon:

\[ \text{Sum of interior angles} = (n-2)\times 180^\circ \]
Hint: This formula comes from splitting the polygon into \((n-2)\) triangles by drawing diagonals from one vertex.
Step 21A

Set the given sum equal to \(3240^\circ\) and solve:

\[ (n-2)\times 180^\circ = 3240^\circ \] \[ n-2 = \frac{3240}{180} = 18 \] \[ n = 20 \]
Hint: Divide both sides by \(180^\circ\) first — that makes the arithmetic much easier.
Result: \(n = 20\). So option A (\(n=16\)) is false.
Step 31A

With \(n=20\), compute each interior angle:

\[ \text{Each interior angle} = \frac{3240^\circ}{20} = 162^\circ \]
Hint: In a regular polygon all interior angles are equal, so just divide the total by \(n\).
Result: Each interior angle \(=162^\circ\), so option D (\(160^\circ\)) is false.

B Each Exterior Angle of a Regular \(n\)-gon

The exterior angles of any convex polygon always add up to \(360^\circ\). For a regular polygon each one is \(360^\circ \div n\). Drag the slider to see how the exterior angle changes.

n = 20
Sum of exterior = 360°
Each exterior = 18°
Each interior = 162°
0 / 3
Step 11M

Recall: the sum of the exterior angles of a convex polygon (one at each vertex) is always

\[ 360^\circ \]
Hint: This is true regardless of the number of sides, as long as you take exactly one exterior angle at each vertex.
Step 21A

Since the polygon is regular, the \(20\) exterior angles are equal, so each one is

\[ \frac{360^\circ}{20} = 18^\circ \]
Hint: Check visually in the diagram — as \(n\) increases, each exterior angle shrinks (\(360^\circ/n\)).
Result: Each exterior angle \(=18^\circ\). Option B is true.
Step 31A

Check consistency with the interior angle:

\[ \text{interior} + \text{exterior} = 180^\circ \Rightarrow 162^\circ + 18^\circ = 180^\circ \;\checkmark \]
Hint: Interior and exterior angles at the same vertex lie on a straight line, so they are supplementary.
Conclusion: Option B is the correct choice.

C Number of Diagonals of the Polygon

A diagonal joins two non-adjacent vertices. Count from one vertex, then divide by 2 to avoid double-counting.

n = 20
Diagonals from one vertex = 17
Total diagonals = 170
0 / 3
Step 11M

Pick one vertex \(P\) of the \(20\)-gon. How many vertices are not adjacent to \(P\)?

\(P\) itself and its \(2\) neighbours cannot be joined to \(P\) by a diagonal, so from \(P\) there are

\[ 20 - 3 = 17 \]
Hint: A diagonal must join two vertices that are not next to each other — so neither \(P\) nor its two neighbouring vertices count.
Step 21M

There are \(20\) vertices, so counting diagonals this way gives

\[ 17 \times 20 = 340 \]

But each diagonal is counted twice (once from each end-point).

Hint: Diagonal \(AB\) is the same as diagonal \(BA\).
Step 31A

Divide by \(2\) to remove the double counting:

\[ \frac{340}{2} = 170 \]
Hint: General formula: \(\displaystyle C^{n}_{2}-n = \frac{n(n-3)}{2}\). Here \(\frac{20\times 17}{2} = 170\).
Result: Number of diagonals \(=170\). Option C (\(20\)) is false.

D Each Interior Angle — Verify Option D

Confirm the interior angle of the regular \(20\)-gon equals \(162^\circ\), not \(160^\circ\).

n = 20
Each interior = 162°
Option D claims = 160°
Mismatch
0 / 3
Step 11M

From Part A, the total interior-angle sum is \(3240^\circ\) for \(n=20\). Since the polygon is regular, all interior angles are equal:

\[ \text{Each interior angle} = \frac{3240^\circ}{20} \]
Hint: "Regular" guarantees equal angles — so we may simply divide the total.
Step 21A

Evaluate:

\[ \frac{3240}{20} = 162^\circ \]
Hint: Cross-check with exterior angle: \(180^\circ - 162^\circ = 18^\circ\), which matches Part B.
Result: Each interior angle \(=162^\circ\). Option D states \(160^\circ\), which is false.
Step 31A

Verification using the exterior angle:

\[ (n-2)\times 180^\circ = (20-2)\times 180^\circ = 18\times 180^\circ = 3240^\circ \;\checkmark \] \[ \text{Interior} = 180^\circ - \frac{360^\circ}{20} = 180^\circ - 18^\circ = 162^\circ \]
Hint: Both formulas agree, so the answer is consistent.
Conclusion: Only option B is true.

  • B — each exterior angle\(18^\circ\) → B TRUE
  • C — number of diagonals\(\dfrac{20(20-3)}{2}=170\) → C false
  • D — each interior angle\(162^\circ\) → D false

✅ Correct choice: B
