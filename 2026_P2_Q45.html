Variance & Transformations

Question

If the standard deviation of the five numbers \(p,\ q,\ r,\ s\) and \(t\) is \(5\), then the variance of the five numbers \(\dfrac{p+2}{5},\ \dfrac{q+2}{5},\ \dfrac{r+2}{5},\ \dfrac{s+2}{5}\) and \(\dfrac{t+2}{5}\) is

  • A. \(1\)
  • B. \(5\)
  • C. \(9\)
  • D. \(25\)

Solution

Original
Variance and Standard Deviation \(\sigma^{2}=\text{variance},\qquad \sigma=\text{standard deviation}\) A standard deviation of \(5\) means the variance is \(5^{2}=25\); the transformation must be applied to the variance, not to the standard deviation.
Variance \(=5^2=25\).
Transform Each new value is \(\dfrac{x+2}{5}=\dfrac{x}{5}+\dfrac25\): a linear transform with scale factor \(\tfrac15\) plus a constant.
Effect
Effect of a Linear Transformation on Variance \(\operatorname{Var}(aX+b)=a^{2}\operatorname{Var}(X)\) Adding a constant shifts every value without changing the spread, while multiplying by \(a\) multiplies the variance by \(a^{2}\) — here \(a=\tfrac15\).
Adding a constant leaves variance unchanged; scaling by \(k\) multiplies the variance by \(k^2\).
Result
Squared Scale Factor \(25\times\left(\dfrac{1}{5}\right)^{2}=25\times\dfrac{1}{25}=1\) The new variance is \(1\), so the new standard deviation is \(1\) as well.
\(25\times\left(\tfrac15\right)^2=\dfrac{25}{25}=1\).
Answer: A — 1

Question. The standard deviation of a set of numbers is \(6\). Each number \(x\) is changed to \(\dfrac{x-4}{3}\). Find the variance of the new set of numbers. (3 marks)

Show the worked solution
Step 1. Original variance \(=6^{2}=36\).
Step 2. Write the change as \(\dfrac{x-4}{3}=\dfrac{1}{3}x-\dfrac{4}{3}\), a linear transformation with \(a=\tfrac13\) and \(b=-\tfrac43\).
Step 3. Subtracting a constant does not change the variance; multiplying by \(a\) multiplies it by \(a^{2}=\tfrac19\).
Step 4. New variance \(=36\times\dfrac{1}{9}=4\), so the new standard deviation is \(2\).
Answer: \(4\)
