Trigonometry — analysing the curve \(y = h + k\tan 2x^\circ\)
Tangent Function Graph Transformations Increasing / Decreasing Sign of Constants

Q39 The Question

Let \(h\) and \(k\) be constants. The figure shows the graph of \[ y = h + k\tan 2x^\circ,\qquad 0 \le x \le \alpha. \] The curve passes through \((0,\,2)\), decreases for \(x \ge 0\), and meets the \(x\)-axis at \(x=\alpha\). Which of the following are true?

  1. \(h > 0\)
  2. \(k < 0\)
  3. \(\tan\alpha^\circ = \dfrac{1}{k}\)

A. I and II only    B. I and III only    C. II and III only    D. I, II and III

I Testing Statement I : \(h > 0\)

At \(x=0\): \(y = h + k\tan 0^\circ =\) 2.00
Graph starts on \(y\)-axis at \((0,\,2)\)
Step 11M

From the figure, the curve cuts the \(y\)-axis at \(y = 2\). Put \(x = 0\):

\[ y = h + k\tan(0^\circ) = h + k\cdot 0 = h \]
Hint: \(\tan 0^\circ = 0\), so the constant term \(h\) is exactly the \(y\)-intercept.
Step 21A

The curve passes through \((0,\,2)\), hence \(h = 2\), so \(h > 0\) is true.

Statement I is TRUE. \(\;h = 2 > 0\)

II Testing Statement II : \(k < 0\)

Slope \(\dfrac{dy}{dx} \propto k\) : sign of \(k\) = negative
Curve is decreasing \(\Rightarrow k<0\)
Step 11M

For \(0 \le x < 45^\circ\), the angle \(2x^\circ\) lies in the first quadrant, so \(\tan 2x^\circ \ge 0\) and is increasing from \(0\).

Hint: Move the \(k\)-slider. When \(k>0\) the curve rises; when \(k<0\) it falls — the figure shows it falling.
Step 21A

The figure shows the curve is decreasing for \(x \ge 0\). But \(h + k\tan 2x^\circ\) decreasing while \(\tan 2x^\circ\) is increasing forces the multiplier \(k\) to be negative.

Statement II is TRUE. \(\;k < 0\)

III Testing Statement III : \(\tan\alpha^\circ = \dfrac{1}{k}\)

\(\alpha = \tan^{-1}(-h/k)/2 =\) —
\(1/k =\) —
Compare \(\tan\alpha^\circ\) with \(1/k\)
Step 11M

At \(x = \alpha\) the curve meets the \(x\)-axis, so \(y = 0\):

\[ h + k\tan\alpha^\circ = 0 \]
Hint: Here the angle is \(2x^\circ = 2\alpha^\circ\)? No — check the graph: at \(x=\alpha\), the argument is \(2\alpha^\circ\). But the figure labels the crossing at \(x=\alpha\) where the curve meets the axis, giving \(h + k\tan 2\alpha^\circ = 0\).
Step 21M

Watch the mark scheme: the statement uses \(\tan\alpha^\circ\), not \(\tan 2\alpha^\circ\). From \(h + k\tan 2\alpha^\circ = 0\), \[ \tan 2\alpha^\circ = -\frac{h}{k}. \] Since \(h>0\) and \(k<0\), this is positive.

Hint: The proposed claim \(\tan\alpha^\circ = 1/k\) would require \(\tan\alpha^\circ < 0\), but \(\alpha\) is in the first quadrant where \(\tan\alpha^\circ > 0\). Contradiction.
Step 31A

We have \(\alpha \in (0^\circ, 45^\circ)\) (since the crossing is before the asymptote at \(45^\circ\)), so \(\tan\alpha^\circ > 0\). But \(k<0\) gives \(1/k < 0\). Hence \(\tan\alpha^\circ \ne 1/k\) — Statement III is false.

Statement III is FALSE. \(\;\tan\alpha^\circ = \dfrac{1}{k}\) cannot hold since the two sides have opposite signs.
0 / 3

Final Answer at a Glance

  • Statement I — TRUE: the \(y\)-intercept is \(2\), so \(h = 2 > 0\).
  • Statement II — TRUE: the curve decreases while \(\tan 2x^\circ\) increases, forcing \(k<0\).
  • Statement III — FALSE: \(\tan\alpha^\circ > 0\) but \(1/k < 0\); the signs disagree.
  • Correct choice: A (I and II only)
