Given data Unknowns m, n Median (5th datum) Mean / Mode
HKDSE 2020 · Paper 2 · Q30 · Statistics

Question

Consider the following integers:

3   3   8   8   8   10   12   m   n

Let $x$, $y$ and $z$ be the median, the mean and the mode of the above integers respectively. If the range of the above integers is 9, which of the following must be true?

  • I. $\; x = 8$
  • II. $\; y = 8$
  • III. $\; z = 8$
  • A. I only
  • B. II only
  • C. I and III only
  • D. II and III only
1
Use the range to bound $m$ and $n$

Range $=$ (largest) $-$ (smallest) $= 9$. The smallest possible value is $3$, so the largest is at most $3+9=12$; since $12$ already appears, the minimum is at least $12-9=3$. Hence both unknowns lie in:

$$3 \le m \le 12, \qquad 3 \le n \le 12.$$

Hint: range fixes the spread, so each unknown is squeezed into a closed interval.
2
Ordering the 9 data (for the median)

There are $9$ data, so the median is the 5th ordered datum. The five known values are $3,3,8,8,8$; the remaining four are $10,12,m,n$.

To find the smallest possible 5th datum we make $m,n$ as small as possible; to find the largest we make $m,n$ as large as possible.

Hint: only the position of the 5th value matters — not the exact values of $m,n$.
3
Bound the median $x$

Smallest case: $m=n=3$, ordered data $3,3,3,3,8,8,8,10,12$ gives 5th datum $=8$, so $x \ge 8$.

Largest case: $m=n=12$, ordered data $3,3,8,8,8,10,12,12,12$ gives 5th datum $=8$, so $x \le 8$.

Combining: $$x = 8.$$

Hint: the 5th datum is trapped between the possibilities; here it is always 8.
4
Test statement II: is $y = 8$ always?

Mean $= \dfrac{3+3+8+8+8+10+12+m+n}{9} = \dfrac{52+m+n}{9}$.

Take $m=3,\; n=8$:

$$y = \frac{3+3+8+8+8+10+12+3+8}{9} = \frac{63}{9} = 7 \ne 8.$$

So II is FALSE — it does not must hold.

Hint: a single counter-example is enough to disprove a "must be true" claim.
5
Test statement III: is $z = 8$ always?

Take $m = 3,\; n = 3$. The data become $3,3,3,3,8,8,8,10,12$.

The value $3$ occurs $4$ times while $8$ occurs only $3$ times, so the mode is $3$:

$$z = 3 \ne 8.$$

So III is FALSE.

Hint: choosing $m=n=3$ creates a new highest frequency for 3.
6
Conclude

Only statement I holds in every allowed case. Therefore the answer is A.

  • I.  $x=8$  ✓ always true
  • II.  $y=8$  ✗ counter-example: $m=3,n=8 \Rightarrow y=7$
  • III.  $z=8$  ✗ counter-example: $m=n=3 \Rightarrow z=3$
Hint: "must be true" means true for every admissible $m,n$.
Answer
A  ·  I only  ($x = 8$ must be true)
