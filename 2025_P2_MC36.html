Question 36 — Linear Programming: Greatest Value in a Region

Find the greatest value of \(8x-6y+11\) for a point \((x,y)\) lying in region \(D\).

Inequalities Linear Programming Feasible Region Vertices of a Polygon Objective Function

Question

Consider the following system of inequalities and let \(D\) be the region which represents the solution of the system. If \((x,y)\) is a point lying in \(D\), then the greatest value of \(8x-6y+11\) is

{
  • \(x \le 11\)
  • \(4x+5y-19 \ge 0\)
  • \(7x-6y+11 \le 0\)

The boundary lines of \(D\) are \(x=11\), \(4x+5y-19=0\) and \(7x-6y+11=0\), with the three vertices \((11,\tfrac{44}{3})\), \((1,3)\) and \((11,-5)\).

Step-by-Step Guided Solution

1
Read the information given by the figure
▾

The figure shows three boundary lines and the region \(D\) is already shaded/labelled:

  • \(x=11\) — a vertical line,
  • \(4x+5y-19=0\) — a line rising from left to right,
  • \(7x-6y+11=0\) — a line falling from left to right.

The three labelled intersection points are

\[(11,\tfrac{44}{3}),\quad (1,3),\quad (11,-5).\]

Hint — how intersections are found: solve two boundary equations simultaneously. For example, put \(x=11\) into \(4x+5y-19=0\): \(4(11)+5y-19=0 \Rightarrow 5y=-25 \Rightarrow y=-5\), giving \((11,-5)\).
2
Identify the true vertices of region \(D\)
▾

Only two of the three labelled intersection points are actually corners of \(D\):

  • \((11,\tfrac{44}{3})\) — corner where \(x=11\) meets \(7x-6y+11=0\), ✔ in \(D\)
  • \((1,3)\) — corner where the two slanted lines meet, ✔ in \(D\)
  • \((11,-5)\) — intersection of \(x=11\) and \(4x+5y-19=0\), ✘ not in \(D\)

Why is \((11,-5)\) excluded? Check it in the other inequality \(7x-6y+11\le 0\):

\[7(11)-6(-5)+11 = 77+30+11 = 118 \not\le 0.\]

So \((11,-5)\) lies on the wrong side of \(7x-6y+11=0\) and is not a vertex of \(D\).

Key idea: a point is a vertex of \(D\) only if it satisfies all the inequalities of the system.
3
Define the objective function
▾

We want to maximise the linear expression in \(x\) and \(y\). Write it as a function:

\[P(x,y)=8x-6y+11.\]

Hint — why vertices? A linear function on a convex polygon takes its maximum and minimum at a vertex. So we only need to test the vertices of \(D\).

(Equivalently, \(8x-6y+11=k\) are parallel lines; we slide the line outwards as far as possible while it still touches \(D\).)

4
Substitute each vertex of \(D\)
▾

At \((11,\tfrac{44}{3})\):

\[P = 8(11)-6\!\left(\tfrac{44}{3}\right)+11 = 88-6(14.\overline{6})+11 = 88-88+11 = 11.\]

At \((1,3)\):

\[P = 8(1)-6(3)+11 = 8-18+11 = 1.\]

Beware of the trap option D (129): it comes from substituting \((11,-5)\), a point which is not inside region \(D\). Always verify the vertex is in the feasible region first.
5
Conclude the greatest value
▾

Comparing the values at the vertices of \(D\): \(11 > 1\).

\[\therefore \text{the greatest value of } 8x-6y+11 \text{ in } D \text{ is } 11.\]

Answer: B. 11

Region \(D\) is unbounded in one direction, but the objective function still attains its maximum at the vertex \((11,\tfrac{44}{3})\) — the draggable graph above confirms this.
