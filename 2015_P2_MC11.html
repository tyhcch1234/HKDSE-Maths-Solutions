Ratio Unification: Combining a : c and b : c

Ratio & Proportion Rate, Ratio and Variations Multiple Choice

QQuestion

Let \(a\), \(b\) and \(c\) be non-zero numbers. If \(a:c = 5:3\) and \(b:c = 3:2\), then \((a+c):(b+c) =\)

  • A \(7:5\)
  • B \(8:5\)
  • C \(16:15\)
  • D \(19:15\)

1Step-by-Step Guided Solution

Tap each step to reveal the reasoning. Try to predict the next move before opening!

We are told:

\(a:c = 5:3 \qquad\text{and}\qquad b:c = 3:2\)

Notice that the letter \(c\) appears in both ratios. That gives us a way to link \(a\) and \(b\) together.

💡 Hint — Meaning of a ratio \(a:c = 5:3\) means \(a\) can be written as \(5k\) and \(c\) as \(3k\) for some non-zero \(k\). Similarly \(b:c = 3:2\) means \(b = 3m\), \(c = 2m\).

In the first ratio, \(c\) has \(3\) parts. In the second, \(c\) has \(2\) parts. To combine them, take the LCM of \(3\) and \(2\), which is \(6\).

\(a:c = 5:3 = 10:6\)  (multiply both parts by \(2\))
\(b:c = 3:2 = 9:6\)  (multiply both parts by \(3\))

Now \(c = 6\) in both statements, so we can write a single three-part ratio.

Align the values of \(c\) and read across:

\(a:b:c = 10:9:6\)
\(a = 10\) units \(b = 9\) units \(c = 6\) units
\(a\)
\(b\)
\(c\)

Using \(a:b:c = 10:9:6\):

\(a+c = 10 + 6 = 16\)
\(b+c = 9 + 6 = 15\)
💡 Hint — Why can we add parts directly? Each part of a ratio represents the same “unit”. Since \(a\), \(b\), \(c\) are all measured in the same unit, \(10\) parts \(+\,6\) parts \(= 16\) parts.
\((a+c):(b+c) = 16:15\)

This matches option C.

✅ Answer: C  —  \(16:15\)
