Statistics — Mean, Median and Mode of a Frequency Distribution

Frequency Table Mean Median Mode Effect of Adding Data

Question [7 marks]

The table below shows the distribution of the numbers of tokens got by a group of children in a game.

Number of tokens got1234567
Number of children15925425
  1. Find the mean of the distribution. [2 marks]
  2. Are the median and the mode of the distribution equal? Explain your answer. [2 marks]
  3. If \(n\) more children play the game and each of them gets 5 tokens, write down
    1. the value of \(n\) such that the mean of the distribution is increased by 1;
    2. the least value of \(n\) such that the median of the distribution is increased by 2;
    3. the greatest value of \(n\) such that the mode of the distribution remains unchanged. [3 marks]

Part (a) — Finding the Mean 2 marks

The mean is a "weighted average": each score is multiplied by its frequency.

Number of children (frequency) Mean μ = 3
Total children = 42  |  Σ(x·f) = 126  |  mean = 126 / 42 = 3
1Form the weighted sum Σ(x·f)1M
\[ \sum x f = 1(15)+2(9)+3(2)+4(5)+5(4)+6(2)+7(5) = 126 \]
Hint: Multiply each "number of tokens" by the corresponding "number of children" (frequency), then add all seven products. Total = 15 + 18 + 6 + 20 + 20 + 12 + 35 = 126.
2Divide by the total frequency1A
\[ \bar{x} = \frac{126}{15+9+2+5+4+2+5} = \frac{126}{42} = 3 \]
Hint: The total number of children (42) is the sum of the middle row. Always check that Σf matches the group size.
Answer (a): The mean is \(3\) tokens.

Part (b) — Comparing the Median and the Mode 2 marks

The median is the value in the middle of the ordered data; the mode is the most frequent value.

Frequency bars Mode (x = 1) Cumulative frequency
Position of median = (42+1)/2 = 21.5 → 21st and 22nd values both fall in x = 2
1Find the mode (most frequent value)1M
\[ \text{Maximum frequency} = 15 \;\Rightarrow\; \text{mode} = 1 \]
Hint: The mode is simply the x-value whose frequency bar is tallest. Here 15 children got 1 token — the highest count.
2Find the median from the cumulative frequency1A
\[ \text{There are } 42 \text{ children, so median} = \frac{21^{\text{st}} + 22^{\text{nd}}}{2} \]
\[ \text{Cumulative: } 15,\;24,\;26,\;31,\;35,\;37,\;42 \]
\[ \text{21st and 22nd values both lie in the interval } x=2 \;\Rightarrow\; \text{median} = 2 \]
Hint: Since 42 is even, average the 21st and 22nd values. The cumulative frequency reaches 15 at x=1 and 24 at x=2, so both middle values equal 2.
Answer (b): Median = \(2\), Mode = \(1\). They are not equal.
0 / 2

Part (c)(i) — n so that the Mean increases by 1 1 mark

Adding n children who each score 5 tokens changes both the total tokens and the total children.

n = 0 → mean = 3.00  |  new sum = 126, new total = 42
1Set up the new mean equation1M
\[ \frac{126 + 5n}{42 + n} = 3 + 1 = 4 \]
Hint: New total tokens = 126 + 5n (each new child brings 5). New total children = 42 + n. The new mean must be 4.
2Solve for n1A
\[ \frac{126 + 5n}{42 + n} = 4 \;\Rightarrow\; 126 + 5n = 168 + 4n \]
\[ n = 42 \]
Hint: Cross-multiply, then collect like terms. Note 5n − 4n = n and 168 − 126 = 42.
Answer (c)(i): \(n = 42\).

Part (c)(ii) — Least n so that the Median increases by 2 1 mark

The median must jump from 2 to 4. Work with cumulative frequency and where the middle position falls.

Original bars Added n at x = 5 Median marker
n = 10 → total = 52, middle positions 26 & 27 → cumulative at x=4 is 31 ≥ 27 → median = 4
1Recall the original cumulative frequencies1M
\[ \text{Original cumulative: } 15,\;24,\;26,\;31,\;35,\;37,\;42 \]
Hint: After adding n children all at 5 tokens, the cumulative frequencies up to x = 4 are unchanged: 15, 24, 26, 31. Only the cumulative at x = 5, 6, 7 increase by n.
2Force the median to be 41A
\[ \text{Total children} = 42 + n \]
\[ \text{Cum. freq. up to } x = 3 \text{ is } 26;\ \text{up to } x = 4 \text{ is } 31 \]
\[ \text{Median} = 4 \iff \text{middle position} > 26 \text{ and } \le 31 \]
\[ \frac{42+n}{2} > 26 \;\Rightarrow\; n > 10 \]
Hint: The median is 4 only when the middle of the new data sits inside the "4 tokens" block. That block runs from the 27th to the 31st value.
Answer (c)(ii): The least value is \(n = 11\).

Part (c)(iii) — Greatest n so that the Mode is unchanged 1 mark

The mode stays 1 only while the frequency at x = 1 remains strictly the largest.

Frequency (original) Added n at x = 5 Mode at x = 1 (f = 15)
n = 0 → f(5) = 4 < 15 (mode = 1). Try n = 11: f(5) = 15 = f(1) → tie, no longer a unique mode.
1Compare the largest frequency with the boosted one1M
\[ \text{Original } f(1) = 15,\quad f(5) = 4 \]
\[ \text{After adding } n \text{ at } x = 5:\quad f(5) = 4 + n \]
Hint: All the new children score 5, so only the bar for x = 5 grows. Every other bar stays the same.
2Require the mode to stay unique1A
\[ \text{Mode remains } 1 \iff f(1) > f(5) \iff 15 > 4 + n \]
\[ n < 11 \]
Hint: "Greatest value of n" with a strict inequality means \(n = 10\). If \(n = 11\), then f(5) = 15 = f(1), giving two modes (1 and 5), so the mode would change.
Answer (c)(iii): The greatest value is \(n = 10\).
0 / 2

Summary of Answers

  • (a) The mean is \(\bar{x} = \dfrac{126}{42} = 3\).
  • (b) Median = 2 and Mode = 1; they are not equal.
  • (c)(i) \(n = 42\).
  • (c)(ii) Least value of \(n = 11\).
  • (c)(iii) Greatest value of \(n = 10\).
