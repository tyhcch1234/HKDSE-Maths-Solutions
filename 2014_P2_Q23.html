Reflection & Polar Coordinates Rectangular coordinates → reflection → polar form

The rectangular coordinates of the point \(P\) are \((-1,\ \sqrt{3})\). If \(P\) is reflected with respect to the \(x\)-axis, then the polar coordinates of its image are
A. \((2,\ 210^\circ)\)
B. \((2,\ 240^\circ)\)
C. \((4,\ 210^\circ)\)
D. \((4,\ 240^\circ)\)
STEP 1 · APPLY THE REFLECTION
Reflection in the x-axis \((x,\ y)\longmapsto(x,\ -y)\) \(P(-1,\ \sqrt{3})\) reflects to \(P'(-1,\ -\sqrt{3})\): the \(x\)-coordinate is unchanged and the \(y\)-sign flips.

Reflection about the \(x\)-axis sends \((x,\ y) \mapsto (x,\ -y)\). Hence

\[ P(-1,\ \sqrt{3}) \ \mapsto\ P'(-1,\ -\sqrt{3}). \]

Hint: the \(x\)-coordinate stays the same;
only the sign of \(y\) flips.
The point drops to the reflection below the \(x\)-axis.

STEP 2 · FIND THE RADIUS \(r\)
Polar-Rectangular Relation \(r=\sqrt{x^{2}+y^{2}}\) For \(P'(-1,\ -\sqrt{3})\) this gives \(r=\sqrt{1+3}=2\).

\[ r = \sqrt{(-1)^2 + (-\sqrt{3})^2} = \sqrt{1+3} = \sqrt{4} = 2. \]

So the image lies on the circle of radius \(2\) centred at the origin.

STEP 3 · FIND THE ANGLE \(\theta\)
Reference Angle in the Third Quadrant \(\theta=180^\circ+\alpha\) \(P'\) has \(x<0\) and \(y<0\) with reference angle \(60^\circ\), so \(\theta=180^\circ+60^\circ=240^\circ\).

\(P'\) has \(x<0\) and \(y<0\), so it is in the third quadrant.
The reference angle satisfies

\[ \tan\alpha = \frac{\sqrt{3}}{1} \ \Rightarrow\ \alpha = 60^\circ. \]

Therefore

\[ \theta = 180^\circ + 60^\circ = 240^\circ. \]

STEP 4 · WRITE THE POLAR COORDINATES

The image in polar form is \((r,\ \theta) = (2,\ 240^\circ)\).

Check: \(P(-1,\sqrt{3})\) is \((2,\ 120^\circ)\). Reflection about the \(x\)-axis changes \(\theta\) to

\[ 360^\circ - 120^\circ = 240^\circ, \]

keeping \(r = 2\). ✓

Final Answer: B. \((2,\ 240^\circ)\)

Question. The rectangular coordinates of the point \(P\) are \((-3,\ 3\sqrt{3})\). If \(P\) is reflected with respect to the \(y\)-axis, then the polar coordinates of its image are
A. \((6,\ 60^\circ)\)   B. \((6,\ 120^\circ)\)   C. \((6,\ 300^\circ)\)   D. \((3,\ 60^\circ)\)

Show the worked solution
Step 1. Reflection in the \(y\)-axis sends \((x,\ y)\mapsto(-x,\ y)\), so \(P(-3,\ 3\sqrt{3})\mapsto P'(3,\ 3\sqrt{3})\).
Step 2. \(r=\sqrt{3^{2}+(3\sqrt{3})^{2}}=\sqrt{9+27}=\sqrt{36}=6\).
Step 3. \(P'\) has \(x>0\) and \(y>0\), so it is in the first quadrant with \(\tan\alpha=\dfrac{3\sqrt{3}}{3}=\sqrt{3}\);
hence \(\theta=\alpha=60^\circ\).
Step 4. Check: \(6\cos60^\circ=3\) and \(6\sin60^\circ=3\sqrt{3}\) ✓, so the polar coordinates are \((6,\ 60^\circ)\).
Answer: A   \((6,\ 60^\circ)\)
