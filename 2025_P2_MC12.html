Variation

Direct Variation Inverse Variation Combined Variation
Q12

It is given that \(z\) varies directly as the cube of \(x\) and inversely as the square of \(y\). When \(x=3\) and \(y=6\), \(z=3\). When \(x=5\) and \(y=2\), \(z=?\)

Step-by-step Solution

1 Set up the variation equation

Since \(z\) varies directly as \(x^3\) and inversely as \(y^2\):

\[ z = \frac{k x^3}{y^2} \]

where \(k\) is the constant of variation.

2 Find the constant \(k\)

Substitute \(x = 3\), \(y = 6\), \(z = 3\):

\[ 3 = \frac{k (3)^3}{6^2} \] \[ 3 = \frac{27k}{36} \] \[ 3 = \frac{3k}{4} \] \[ k = 4 \]
3 Find \(z\) using the new values

Now \(k = 4\). When \(x = 5\) and \(y = 2\):

\[ z = \frac{4(5)^3}{2^2} \] \[ z = \frac{4 \times 125}{4} \] \[ z = 125 \]

Answer: C. 125

Key takeaway

For combined variation, always write the equation with a constant \(k\), substitute the given set of values to find \(k\), then use that \(k\) to find the unknown.
