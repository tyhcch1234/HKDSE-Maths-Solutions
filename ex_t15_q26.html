Statistics (93) · Sub-Topic: Measures of Dispersion

T15 Q26

If all the data values in a set are equal, what is the variance of the set?

Solution

Let every data value in the set be equal to a constant $c$.
Then the mean is $\bar{x}=\frac{c+c+\cdots+c}{n}=c$.
For each data value, the deviation from the mean is $x_i-\bar{x}=c-c=0$.
The variance is the average of the squared deviations: $\sigma^2=\frac{(0)^2+(0)^2+\cdots+(0)^2}{n}=0$.
Therefore, when all data values are equal, the variance is $0$.
The variance of the set is $0$.
