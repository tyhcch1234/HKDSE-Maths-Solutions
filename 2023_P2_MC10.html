Quadratic graph in vertex (completing-the-square) form — intercepts, direction and points on the curve
Quadratic Function Vertex Form x-intercept y-intercept Graph Reading

Question Multiple Choice

Which of the following statements about the graph of \[ y = 5 + (x-3)^2 \] is true?

AThe graph opens downwards.
BThe \(x\)-intercept of the graph is \(3\).
CThe \(y\)-intercept of the graph is \(5\).
DThe graph passes through the point \((3,\,5)\).

Key idea: read the graph's features (direction, intercepts, a named point) straight from its vertex form \(y = (x-h)^2 + k\), without any long computation.

Part (a)  Does the graph open up or down? 1A

Look at the coefficient of \(x^2\). Drag the slider to change the vertex \(k\) and watch how the curve always opens upward.

\(y = 5 + (x-3)^2\) Coefficient of \(x^2\) = \(+1\) Opens upward ↑
0 / 2
1Expand to see the coefficient of \(x^2\)1M
\[ y = 5 + (x-3)^2 = 5 + x^2 - 6x + 9 = x^2 - 6x + 14 \] The coefficient of \(x^2\) is \(+1 > 0\).
Hint: In \(y=(x-h)^2+k\) the coefficient of \(x^2\) is the same \(+1\); a positive coefficient always gives a “smile” (opens upward).
2Conclusion for option A1A
Since \(1>0\), the parabola opens upward, not downward.
∴ Option A is false.

Part (b)  Find the \(x\)- and \(y\)-intercepts 1M 1A

Move the horizontal line to test where the curve meets the axes. Notice the curve never reaches \(y=0\).

x-intercept: none (curve above \(y=0\)) y-intercept: \((0,\;14)\)
0 / 3
1\(y\)-intercept: put \(x=0\)1M
\[ y = 5 + (0-3)^2 = 5 + 9 = 14 \] So the \(y\)-intercept is \(\mathbf{(0,\,14)}\).
Hint: The \(y\)-intercept is found at \(x=0\), never by reading the constant \(5\) in \(5+(x-3)^2\).
\(y\)-intercept \(= (0,\,14)\), so option C \((0,5)\) is false.
2\(x\)-intercept: put \(y=0\)1M
\[ 0 = 5 + (x-3)^2 \quad\Longrightarrow\quad (x-3)^2 = -5 \] A square can never be negative, so there is no real solution.
Hint: The vertex has \(y\)-value \(5>0\) and the graph opens upward, so the whole curve stays above the \(x\)-axis — it never crosses it.
3Conclusion for options B and C1A
There is no \(x\)-intercept, so “the \(x\)-intercept is \(3\)” is wrong; and the \(y\)-intercept is \(14\), not \(5\).
∴ Options B and C are false.

Part (c)  Check the point \((3,\,5)\) 1A

Slide the test point along the curve and watch the coordinates — the lowest point of the curve is exactly \((3,\,5)\).

Point on curve: \((3.0,\;5.0)\) Vertex = minimum = \((3,\,5)\)
0 / 2
1Substitute \(x=3\) into the equation1M
\[ y = 5 + (3-3)^2 = 5 + 0 = 5 \] So the point \((3,\,5)\) lies on the graph — it is precisely the vertex (the minimum point).
Hint: In the form \(y = k + (x-h)^2\), the vertex is \((h,\,k)\). Comparing: \(h=3\), \(k=5\) — the point \((3,5)\) is read off directly.
∴ Option D is true.
2Eliminate every other option1A
A: opens upward ✗  ·  B: no \(x\)-intercept ✗  ·  C: \(y\)-intercept is \((0,14)\neq(0,5)\) ✗
Answer: D — the graph passes through \((3,\,5)\).

📘 Summary — answers at a glance

  • Rewrite: \(y = x^{2}-6x+14\), so the coefficient of \(x^{2}\) is \(+1>0\) ⇒ the graph opens upward.
  • \(y\)-intercept (\(x=0\)): \(y = 5+(0-3)^2 = \mathbf{(0,\,14)}\) — not \(5\).
  • \(x\)-intercept (\(y=0\)): \((x-3)^2 = -5\) has no real root ⇒ no \(x\)-intercept.
  • Vertex form \(y = 5+(x-3)^2\) ⇒ vertex \(= \mathbf{(3,\,5)}\), the minimum point ⇒ the graph passes through \((3,5)\).
✅ Correct option: D — “The graph passes through the point \((3,\,5)\).”
