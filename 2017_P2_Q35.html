Simultaneous Equations — find the target expression

Question 35. It is given that the real numbers \(p\), \(q\), \(r\) and \(s\) satisfy

\[ p+q = k,\qquad q+r = -1,\qquad r+s = 3,\qquad p+s = 2. \]

If \(k\) and \(p\), \(q\), \(r\), \(s\) are real numbers, then the value of \(k\) is

  • A. \(-2\)
  • B. \(-1\)
  • C. \(1\)
  • D. \(2\)
1
List the given relations
Write the four equations with their labels so nothing is lost:
\[ \begin{aligned} (1)\;&\quad p+q = k\\ (2)\;&\quad q+r = -1\\ (3)\;&\quad r+s = 3\\ (4)\;&\quad p+s = 2 \end{aligned} \]
Hint: the unknowns are p, q, r, s; the equations are linear, so a smart combination will work.
2
Add equations (1) and (3) — and (2) and (4)
Adding (1) and (3) groups \(p+q+r+s\) on the left:
\[(1)+(3):\quad p+q+r+s = k+3\]
Adding (2) and (4) gives the same combined left side:
\[(2)+(4):\quad q+r+p+s = -1+2 = 1\]
Hint: adding all four equations gives \(2(p+q+r+s)=k+4\).
3
Equate the two expressions for \(p+q+r+s\)
Both combined left sides are \(p+q+r+s\), so:
\[k+3 = 1\]
Hint: the unknowns cancel — only \(k\) survives. That is the shortcut this question is testing.
4
Solve for \(k\)
\[k = 1-3 = -1\]
So \(k=-1\). (The system is consistent for any real \(p,q,r,s\) satisfying the relations.)
Hint: subtract \(3\) from both sides of \(k+3=1\).
5
Check with numbers
Pick \(p=2\), \(q=0\): then \(r=-1\), \(s=3-(-1)=4\), and \(p+s=2+4=6\ne 2\) — so that choice fails the consistency check. Instead use any valid set; e.g. from (4) \(s=2-p\), then \(r=3-s=1+p\), \(q=-1-r=-2-p\), and
\[k=p+q=p+(-2-p)=-2p+p-2 \dots\]
Using \(p+q=[(2)+(4)]-[(2)+(3)]\) directly: \(k = 1-3=-1\) always.
Hint: the value of \(k\) is fixed no matter which consistent \((p,q,r,s)\) you choose.
6
Select the correct option
\(k=-1\), which is option B.
\[k = -1 \;\Longrightarrow\; \boxed{\text{B}}\]
Hint: keep an eye out for the “add two pairs of equations to cancel unknowns” trick.
Answer: B. \(k=-1\)
