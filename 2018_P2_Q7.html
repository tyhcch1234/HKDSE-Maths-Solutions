2018 MC Q7

If $f(x)=3x^{2}-2x+1$, then $f(2m-1)=$

A. $6m^{2}-4m+2$
B. $6m^{2}-4m+6$
C. $12m^{2}-16m+2$
D. $12m^{2}-16m+6$
1

Read the function rule

Function Notation\(f(x)=3x^{2}-2x+1\ \Rightarrow\ f(a)=3a^{2}-2a+1\)Every \(x\) in the rule is replaced by the whole bracket \(2m-1\), including inside \(x^{2}\).

The function is given as $f(x)=3x^{2}-2x+1$. This rule tells us: whatever is placed inside the brackets is the input $x$.

So we must replace every $x$ in the rule by the new input $(2m-1)$:

$$f(2m-1)=3(2m-1)^{2}-2(2m-1)+1$$

Hint: substitute the whole bracket in — do not leave any $x$ behind.
2

Expand the square $(2m-1)^2$

Perfect Square Identity\((a-b)^{2}=a^{2}-2ab+b^{2}\)With \(a=2m\) and \(b=1\), \((2m-1)^{2}=4m^{2}-4m+1\) — the middle term \(-4m\) must not be dropped.

Use the identity $(a-b)^2=a^2-2ab+b^2$ with $a=2m,\ b=1$:

$$(2m-1)^{2}=(2m)^{2}-2(2m)(1)+1^{2}=4m^{2}-4m+1$$

Substitute back:

$$f(2m-1)=3(4m^{2}-4m+1)-2(2m-1)+1$$

Hint: a common slip is to write $(2m-1)^2=4m^2-1$ — remember the middle term $-4m$.
3

Distribute through each bracket

Distributive Law\(k(a+b)=ka+kb\)\(3(4m^{2}-4m+1)=12m^{2}-12m+3\) and \(-2(2m-1)=-4m+2\).

$$3(4m^{2}-4m+1)=12m^{2}-12m+3$$

$$-2(2m-1)=-4m+2$$

So the expression becomes

$$f(2m-1)=12m^{2}-12m+3-4m+2+1$$

Hint: watch the sign — $-2(2m-1)$ gives $-4m+2$, not $-4m-2$.
4

Collect like terms

Group the $m^2$, the $m$ and the constant terms:

$$m^{2}:\ 12m^{2}$$

$$m:\ -12m-4m=-16m$$

constant: $3+2+1=6$

$$\therefore\ f(2m-1)=12m^{2}-16m+6$$

Hint: add the constant terms last — it is easy to drop the $+1$ at the end.
5

Check with a numerical test

Let $m=1$, so $2m-1=1$. Then $f(1)=3(1)^2-2(1)+1=2$.

Now test each option with $m=1$:

A: $6-4+2=4$  
B: $6-4+6=8$  
C: $12-16+2=-2$  
D: $12-16+6=2$ ✓

Hint: one quick substitution quickly eliminates the distractors (many students mistakenly get $12m^2-16m+2$ by forgetting the final $+1$).
Answer: D  —  $f(2m-1)=12m^{2}-16m+6$

Question. If \(f(x)=2x^{2}+3x-4\), find \(f(3k-2)\).

Show the worked solution
Step 1. Substitute the whole bracket: \(f(3k-2)=2(3k-2)^{2}+3(3k-2)-4\).
Step 2. \((3k-2)^{2}=9k^{2}-12k+4\).
Step 3. Expand: \(2(9k^{2}-12k+4)=18k^{2}-24k+8\) and \(3(3k-2)=9k-6\).
Step 4. Collect terms: \(18k^{2}+(-24k+9k)+(8-6-4)=18k^{2}-15k-2\). Check with \(k=2\): \(f(4)=32+12-4=40\) and \(18(4)-30-2=40\) ✓.
Answer: \(18k^{2}-15k-2\)
