Statistics — Mean, Range and Variance when a new datum is added
Mean Range Variance Added Datum MCQ

Q The Question

Let \(m_1\), \(r_1\) and \(v_1\) be the mean, the range and the variance of a group of numbers \(\{x_1, x_2, x_3, \ldots, x_{100}\}\) respectively. If \(m_2\), \(r_2\) and \(v_2\) are the mean, the range and the variance of the group of numbers \(\{x_1, x_2, x_3, \ldots, x_{100}, m_1\}\) respectively, which of the following must be true?
I. \(m_1 = m_2\)
II. \(r_1 = r_2\)
III. \(v_1 = v_2\)
A. I and II only
B. I and III only
C. II and III only
D. I, II and III

I Statement I — Is \(m_1 = m_2\) ?

Adding the old mean \(m_1\) as a new datum. A helpful way to see the mean is to picture the data as points on a number line, balanced on a fulcrum. Adding a point exactly at the fulcrum must not move the balance point.

Step 1

Write the old mean from the definition:

\[ m_1 = \frac{x_1 + x_2 + \cdots + x_{100}}{100} \quad \cdots (1) \]
Hint: This is just the definition of the mean of the first 100 numbers. We will reuse the sum \(x_1 + x_2 + \cdots + x_{100}\) several times.
Step 2

Now there are 101 numbers, so the new mean divides by 101:

\[ m_2 = \frac{x_1 + x_2 + \cdots + x_{100} + m_1}{101} \]
Hint: Don’t forget the denominator changes from 100 to 101 because one extra number was added.
Step 3

Split the fraction and substitute the sum using (1):

\[ m_2 = \frac{x_1 + x_2 + \cdots + x_{100}}{101} + \frac{m_1}{101} = \frac{100}{101}\,m_1 + \frac{1}{101}\,m_1 \]
Hint: From (1), \(x_1 + x_2 + \cdots + x_{100} = 100\,m_1\), so the first fraction becomes \(\dfrac{100}{101}m_1\).
Step 4

Combine the two like terms:

\[ m_2 = \frac{100}{101}m_1 + \frac{1}{101}m_1 = \frac{101}{101}m_1 = m_1 \]
✓ Statement I is TRUE: \(m_1 = m_2\). Adding a number equal to the mean does not change the mean.

II Statement II — Is \(r_1 = r_2\) ?

The range is the gap between the largest and smallest values. If the new value \(m_1\) lies between the old extremes, then those extremes are unchanged — the range cannot change!

Step 1

Let \(x_{\min}\) and \(x_{\max}\) be the minimum and maximum of the original group \(\{x_1, x_2, \ldots, x_{100}\}\). Then by definition of range:

\[ r_1 = x_{\max} - x_{\min} \]
Hint: Range is always maximum − minimum, nothing more.
Step 2

Every datum satisfies \(x_{\min} \le x_i \le x_{\max}\) for \(i = 1, 2, \ldots, 100\).

Because \(m_1\) is a mean of these numbers, it must lie inside the same interval:

\[ x_{\min} \le m_1 \le x_{\max} \]
Hint: A mean can never fall outside the smallest and largest data values — it is always squeezed between them.
Step 3

Hence \(x_{\min}\) and \(x_{\max}\) are still the minimum and maximum of the enlarged group \(\{x_1, \ldots, x_{100}, m_1\}\). Therefore:

\[ r_2 = x_{\max} - x_{\min} = r_1 \]
✓ Statement II is TRUE: \(r_1 = r_2\). The new datum sits inside the old range.
0 / 3

III Statement III — Is \(v_1 = v_2\) ?

The variance measures spread about the mean. Look closely at the numerator: even though the mean stays the same, the added term contributes zero to the sum of squared deviations, so the sum is unchanged — but the denominator grows from 100 to 101. The variance must shrink (unless it was already 0).

Step 1

Write the variance of the original group (dividing by the number of data = 100):

\[ v_1 = \frac{(x_1-m_1)^2 + (x_2-m_1)^2 + \cdots + (x_{100}-m_1)^2}{100} \quad \cdots(2) \]
Hint: Each squared deviation is measured from the mean \(m_1\).
Step 2

For the new group there are 101 numbers, and the new mean equals \(m_1\) by Statement I:

\[ v_2 = \frac{(x_1-m_2)^2 + \cdots + (x_{100}-m_2)^2 + (m_1-m_2)^2}{101} = \frac{(x_1-m_1)^2 + \cdots + (x_{100}-m_1)^2 + (m_1-m_1)^2}{101} \]
Hint: The last term is \((m_1 - m_1)^2 = 0\) — the new datum sits exactly on the mean, contributing no spread.
Step 3

Drop the zero term and compare with (2):

\[ v_2 = \frac{(x_1-m_1)^2 + (x_2-m_1)^2 + \cdots + (x_{100}-m_1)^2}{101} = \frac{100}{101}\,v_1 \]
Hint: The numerator is exactly the same sum as in \(v_1\), but the denominator has grown from 100 to 101.
Step 4

Since \(\frac{100}{101} \neq 1\):

\[ v_2 = \frac{100}{101}v_1 \neq v_1 \quad \text{unless } v_1 = 0 \]
✗ Statement III is FALSE (in general): \(v_2 = \frac{100}{101} v_1\). The variance decreases because the denominator increases while the numerator is unchanged.
0 / 4

Summary of Results

  • I. TRUE — \(m_2 = \dfrac{100}{101}m_1 + \dfrac{1}{101}m_1 = m_1\)
  • II. TRUE — \(x_{\min} \le m_1 \le x_{\max}\), so \(r_2 = x_{\max} - x_{\min} = r_1\)
  • III. FALSE — \(v_2 = \dfrac{100}{101}v_1 \neq v_1\) (unless \(v_1 = 0\))
Answer: A  (I and II only)
