Estimation, Approximation & Error

Q Question

There is a bag of white sugar. The weight of white sugar in the bag is measured as correct to the nearest kg. If the bag of white sugar is packed into \(n\) packets such that the weight of white sugar in each packet is measured as correct to the nearest g, find the greatest possible value of \(n\).

S Step-by-step solution

Let \(W\) kg be the measured weight of the bag (to the nearest kg).

"Correct to the nearest kg" means the true weight is within \(0.5\) kg of the measured value. So:

\[ 4.5 \;\le\; W \;<\; 5.5 \]

Similarly, let \(w_i\) g be the measured weight of the \(i\)-th packet (to the nearest g). Then:

\[ 9.5 \;\le\; w_i \;<\; 10.5 \quad \text{for } i = 1, 2, \ldots, n \]
Hint: Rounding to the nearest unit
When a value is rounded to the nearest \(u\), the true value \(x\) satisfies \(a - \frac{u}{2} \le x < a + \frac{u}{2}\), where \(a\) is the rounded value. Here \(u = 1\) kg for the bag and \(u = 1\) g for each packet.

Since \(1\) kg \(= 1000\) g, we multiply the bag inequality by \(1000\):

\[ 4500 \;\le\; 1000W \;<\; 5500 \]

The total weight of all \(n\) packets must equal the total weight of the bag (assuming no loss):

\[ 1000W = w_1 + w_2 + \cdots + w_n \]

Each packet has \(9.5 \le w_i < 10.5\). Adding these \(n\) inequalities:

\[ 9.5n \;\le\; w_1 + w_2 + \cdots + w_n \;<\; 10.5n \]

Substitute \(w_1 + w_2 + \cdots + w_n = 1000W\):

\[ 9.5n \;\le\; 1000W \;<\; 10.5n \]

This means the minimum total weight is \(9.5n\) and the maximum (though not attained) approaches \(10.5n\).

For \(n\) packets to be possible, the minimum total weight \(9.5n\) must be less than \(5500\) (because \(1000W < 5500\)):

\[ 9.5n \;<\; 5500 \]

Solve for \(n\):

\[ n \;<\; \frac{5500}{9.5} = 578.9473684\ldots \]
Hint: Why not also use the lower bound?
The lower bound \(1000W \ge 4500\) gives \(9.5n \le 1000W\) and \(10.5n > 1000W \ge 4500\), which leads to \(n > 4500/10.5 \approx 428.57\) — a very loose condition. The critical restriction for the greatest \(n\) is the upper bound \(1000W < 5500\).

We have \(n < 578.9473684\ldots\). Since \(n\) must be a positive integer, the greatest possible value is:

\[ n = 578 \]

Check: \(9.5 \times 578 = 5491 < 5500\) ✓. If \(n = 579\), \(9.5 \times 579 = 5500.5 \ge 5500\), which violates the condition.

Correct answer: C. 578

Key Takeaways

  • "Correct to the nearest kg" → true weight in \([measured - 0.5, measured + 0.5)\) kg.
  • Convert all weights to the same unit (grams) before combining inequalities.
  • When summing \(n\) packet inequalities, \(9.5n \le \text{total} < 10.5n\).
  • For the greatest \(n\), use the upper bound on the total weight: \(9.5n < 5500\).
  • Divide and take the floor of the result: \(n < 578.947\ldots\) → \(n_{\max} = 578\).
