HKDSE Math 2020 Paper 2 Q14 Estimation, Approximation & Error

Pentagon Area — Range of Actual Values

Q

In the figure, \(PQRST\) is a pentagon, where all the measurements are correct to the nearest cm. Let \(A\ \text{cm}^2\) be the actual area of the pentagon. Find the range of values of \(A\).

#MaximumError #LowerBound #UpperBound #AreaDecomposition

Step-by-Step Solution

1

Understand the Error Bounds

Each measurement is correct to the nearest cm. This means the maximum absolute error is \(\frac{1}{2} = 0.5\) cm.

For a measurement \(x\) cm, the actual value lies in the interval:

\(x - 0.5 \le \text{actual} < x + 0.5\)

So we get the following bounds:

\(PQ\)

\(5.5 \le PQ < 6.5\)

\(QR\)

\(9.5 \le QR < 10.5\)

\(RS\)

\(2.5 \le RS < 3.5\)

\(PT\)

\(4.5 \le PT < 5.5\)

2

Decompose the Area

The pentagon can be split into a trapezium and a triangle. There are two ways to do this — both give the same area but help us see which measurements are critical:

Method 1: Trapezium \(PQRS\) + Triangle \(PST\)

\[ \text{Area} = \frac{1}{2}(PQ+RS)\cdot QR + \frac{1}{2}\cdot PT\cdot (PQ-RS) \]

Area increases when \(PQ, QR, PT\) increase.

Method 2: Trapezium \(PRT\) + Triangle \(RST\)

\[ \text{Area} = \frac{1}{2}(QR+PT)\cdot PQ + \frac{1}{2}\cdot RS\cdot (QR-PT) \]

Area increases when \(RS\) increases.

💡 Hint: We must find the combination of lower bounds and upper bounds that gives the minimum and maximum possible total area.

3

Find the Lower Bound for \(A\)

To minimise the area, we use the lower bound for each measurement that increases the area. Using Method 1:

\[ A_{\min} = \frac{1}{2}(5.5+2.5)(9.5) + \frac{1}{2}(4.5)(5.5-2.5) \]

But we must also check Method 2 with lower bounds to ensure we truly have the smallest possible area. Substituting lower bounds into Method 2:

\[ \frac{1}{2}(9.5+4.5)(5.5) + \frac{1}{2}(2.5)(9.5-4.5) = 38.5 + 6.25 = 44.75 \]

Both methods give \(44.75\) when using all lower bounds, so the minimum possible area is \(44.75\ \text{cm}^2\).

Note: For the lower bound, we use \(A \ge 44.75\) (included).

4

Find the Upper Bound for \(A\)

To maximise the area, we use the upper bound for each measurement. Using Method 1:

\[ A_{\max} = \frac{1}{2}(6.5+3.5)(10.5) + \frac{1}{2}(5.5)(6.5-3.5) \]

Check Method 2 with upper bounds:

\[ \frac{1}{2}(10.5+5.5)(6.5) + \frac{1}{2}(3.5)(10.5-5.5) = 52 + 8.75 = 60.75 \]

Both methods give \(60.75\) when using all upper bounds, so the maximum possible area is \(60.75\ \text{cm}^2\).

Note: For the upper bound, since all values are strictly less than the upper limits, the area is strictly less than \(60.75\). So \(A < 60.75\).

5

Final Answer

Combining the lower and upper bounds, the range of possible values for the actual area \(A\) is:

\[ 44.75 \le A < 60.75 \]

Therefore, the answer is B.

📘 Key takeaway: When calculating error bounds for combined measurements, always consider which combination of lower/upper bounds produces the extreme values. For sums keep the same signs, for differences use the bounds that increase the magnitude of the difference.
