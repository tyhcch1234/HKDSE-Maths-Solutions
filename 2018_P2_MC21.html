Trigonometry in a Right-Trapezium Configuration
Right Angles Trisection of a Side Sine / Cosine / Tangent Ratios Must-Be-True Reasoning

Question

In the figure, \(ABCD\) is a trapezium with \(\angle ABC = \angle BAD = 90^\circ\). \(E\) and \(F\) are points lying on \(AB\) such that \(E\) and \(F\) divide \(AB\) into three equal parts. Which of the following must be true?

\(\text{I. } AF\sin\alpha = BE\sin\beta\)
\(\text{II. } CE\cos\alpha = DF\cos\beta\)
\(\text{III. } AD\tan\alpha = BC\tan\beta\)

A. I and II only
B. I and III only
C. II and III only
D. I, II and III

Original Figure

Part 1 — Understanding the Figure

Since \(\angle BAD = \angle ABC = 90^\circ\), the trapezium has two right angles on the base \(AB\). The points \(E,F\) trisect \(AB\), so \[ AE = EF = FB .\] Let \(AE = EF = FB = x\). Then \(AB = 3x\), \(AF = 2x\), and \(BE = 2x\).

1 Label the unknown length 1M

Let \(AE = EF = FB = x\). Then \[ AB = 3x,\quad AF = 2x,\quad BE = 2x .\]

Hint: The trisection gives all of these immediately — no extra work needed.
2 Note key equalities 1M

\[ AF = BE = 2x \qquad\text{and}\qquad AE = EF = FB .\] Also \(AD\perp AB\) and \(BC\perp AB\).

Hint: The equality \(AF=BE\) is the single most useful fact in this problem.
Key fact: \(AF = BE\).

Part 2 — Statement I: \(AF\sin\alpha = BE\sin\beta\)

Consider the two right-angled triangles \(\triangle BCE\) and \(\triangle ADF\).

1 Set up the sine ratios 1M

In the right-angled triangle \(\triangle BCE\) (right angle at \(B\)): \[ \sin\alpha = \frac{BC}{CE} .\] In the right-angled triangle \(\triangle ADF\) (right angle at \(A\)): \[ \sin\beta = \frac{AD}{DF} .\]

Hint: \(\alpha\) is at \(E\) (between \(EC\) and \(EB\)), \(\beta\) is at \(F\) (between \(FD\) and \(FA\)).
2 Substitute into Statement I 1M

Statement I claims: \[ AF\sin\alpha = BE\sin\beta \] Substitute: \[ AF\cdot\frac{BC}{CE} = BE\cdot\frac{AD}{DF} .\] Since \(AF = BE\), the inequality \(BC \neq AD\) makes the two sides different.

Hint: Because \(AF=BE\), Statement I reduces to \(\frac{BC}{CE} = \frac{AD}{DF}\).
3 Test with a numerical example 1A

Take \(x=1\), \(AD=1\), \(BC=2\): \[ CE = \sqrt{BC^2+BE^2} = \sqrt{4+4} = 2\sqrt{2}, \] \[ DF = \sqrt{AD^2+AF^2} = \sqrt{1+4} = \sqrt{5}. \] \[ AF\sin\alpha = 2\cdot\frac{2}{2\sqrt2} = \sqrt2 \approx 1.414, \] \[ BE\sin\beta = 2\cdot\frac{1}{\sqrt5} \approx 0.894. \] They are not equal — Statement I is false.

Hint: A single counterexample is enough to disprove a “must be true” statement.
Statement I is NOT true.

Part 3 — Statement II: \(CE\cos\alpha = DF\cos\beta\)

Apply the cosine ratio in the same two right-angled triangles. This is the statement about the horizontal projections.

1 Use the cosine ratio 1M

In \(\triangle BCE\): \[ \cos\alpha = \frac{BE}{CE} \;\Longrightarrow\; CE\cos\alpha = BE.\] In \(\triangle ADF\): \[ \cos\beta = \frac{AF}{DF} \;\Longrightarrow\; DF\cos\beta = AF.\]

Hint: \(\cos\alpha\) is the adjacent over hypotenuse — the adjacent side is \(BE\).
2 Compare with the equality \(BE=AF\) 1A

From the trisection, \(AF = BE\). Therefore \[ CE\cos\alpha = BE = AF = DF\cos\beta .\]

Hint: Both sides collapse to the same length — no dependence on the heights \(AD\), \(BC\).
Statement II is TRUE.

Part 4 — Statement III: \(AD\tan\alpha = BC\tan\beta\)

Use the tangent ratio, which links the two vertical heights to the two base segments.

1 Tangent ratios 1M

In \(\triangle BCE\): \[ \tan\alpha = \frac{BC}{BE} \;\Longrightarrow\; BC = BE\tan\alpha .\] In \(\triangle ADF\): \[ \tan\beta = \frac{AD}{AF} \;\Longrightarrow\; AD = AF\tan\beta .\]

Hint: Tangent is opposite over adjacent — the adjacent sides are \(BE\) and \(AF\).
2 Rearrange to match the statement 1M

From the first relation: \[ \tan\alpha = \frac{BC}{BE} .\] Multiply both sides by \(AD\): \[ AD\tan\alpha = AD\cdot\frac{BC}{BE} .\] From the second relation: \[ \tan\beta = \frac{AD}{AF} .\] Multiply both sides by \(BC\): \[ BC\tan\beta = BC\cdot\frac{AD}{AF} .\]

Hint: We are just writing each side of Statement III in terms of \(AD\), \(BC\), \(BE\), \(AF\).
3 Use \(AD\neq 0\) and \(AF=BE\) 1A

Since \(AF = BE\), \[ AD\cdot\frac{BC}{BE} = AD\cdot\frac{BC}{AF} ,\] and \[ BC\cdot\frac{AD}{AF} = BC\cdot\frac{AD}{BE} .\] These are equal because multiplication is commutative: \[ AD\cdot\frac{BC}{BE} = BC\cdot\frac{AD}{BE} .\] Hence \(AD\tan\alpha = BC\tan\beta\).

Hint: Be careful about which length pairs with which — but the two expressions are symmetric under swapping \(AD\leftrightarrow BC\).
Statement III is TRUE.

Summary & Answer

  • Set-up: \(AE = EF = FB = x\), hence \(AF = BE = 2x\).
  • I. \(AF\sin\alpha = BE\sin\beta\) — reduces to \(BC/CE = AD/DF\), not generally true. False.
  • II. \(CE\cos\alpha = BE\) and \(DF\cos\beta = AF\), and \(BE = AF\). True.
  • III. \(AD\tan\alpha = AD\cdot\frac{BC}{BE}\) and \(BC\tan\beta = BC\cdot\frac{AD}{AF}\), equal since \(BE = AF\). True.
  • Conclusion: Statements II and III only.
  • Correct option: C
