HKDSE 2021 · Paper 2 · Q5

Estimation, Approximation and Error

If $x = 6.24$ (correct to $2$ decimal places), find the range of values of $x$.

  • A. $6.235 < x \le 6.245$
  • B. $6.235 \le x < 6.245$
  • C. $6.23 < x \le 6.25$
  • D. $6.23 \le x < 6.25$

Step-by-step Solution

1 Interpret the given information

The value is rounded to $2$ decimal places, i.e. to the nearest $0.01$.

Hint: “correct to $n$ d.p.” means the error is at most half of the last place value.

2 Find half of the last place value

Last place value $= 0.01$, so the maximum error is $\dfrac{0.01}{2} = 0.005$.

Hint: The interval is centred at the stated value with total width $0.01$.

Maximum Absolute Error \(\text{maximum absolute error}=\dfrac{1}{2}\times\text{last place value}\) “Correct to \(2\) decimal places” means rounding to the nearest \(0.01\), so the error is at most \(0.005\).
3 Build the range around $6.24$

$$6.24 - \frac{0.01}{2} \le x < 6.24 + \frac{0.01}{2}$$

Hint: The lower bound is included, the upper bound is excluded.

Measurement Interval \(M-\dfrac{u}{2}\le x With \(M=6.24\) and \(u=0.01\): \(6.235\le x<6.245\).
4 Simplify both bounds

$$6.235 \le x < 6.245$$

Hint: $6.235$ rounds up to $6.24$ (included); $6.245$ rounds up to $6.25$, so it is not included.

Answer: B  —  $6.235 \le x < 6.245$
