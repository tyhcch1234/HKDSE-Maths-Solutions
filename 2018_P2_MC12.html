HKDSE Math 2018 Paper 2 Q12

Sequences
# Recurrence Relation # Sequence Terms # Substitution # Algebraic Manipulation

Let \(a_n\) be the \(n\)-th term of a sequence. If \(a_3 = 21\), \(a_6 = 89\) and

\[ a_{n+2} = a_n + a_{n+1} \quad \text{for any positive integer } n, \]

then \(a_1 = \)

Step-by-step Solution

1 Understand the recurrence relation ▼

The given relation is:

\[ a_{n+2} = a_n + a_{n+1} \]

This means every term is the sum of the two preceding terms.

💡 Hint: You can also rearrange it as \(a_n = a_{n+2} - a_{n+1}\), which allows you to work backwards from later terms.
2 Use \(a_3\) and \(a_6\) to find \(a_4\) ▼

We need a bridge between \(a_3\) and \(a_6\). Use the relation with \(n = 4\):

\[ a_{6} = a_{4} + a_{5} \]

But \(a_5 = a_3 + a_4\) (from \(n = 3\)). So:

\[ a_6 = a_4 + (a_3 + a_4) = 2a_4 + a_3 \]

Now substitute the known values \(a_3 = 21\) and \(a_6 = 89\):

\[ 89 = 2a_4 + 21 \implies 2a_4 = 68 \implies a_4 = 34 \]
💡 Hint: This is the key insight — combine two equations to eliminate \(a_5\).
3 Work backwards to find \(a_2\) ▼

Now use the relation with \(n = 2\):

\[ a_4 = a_2 + a_3 \]

Rearrange to isolate \(a_2\):

\[ a_2 = a_4 - a_3 = 34 - 21 = 13 \]
💡 Hint: Working backwards uses \(a_n = a_{n+2} - a_{n+1}\).
4 Finally, find \(a_1\) ▼

Use the relation with \(n = 1\):

\[ a_3 = a_1 + a_2 \]

Rearrange:

\[ a_1 = a_3 - a_2 = 21 - 13 = 8 \]

Therefore, \(a_1 = 8\).

💡 Alternative: You can also use \(a_1 = 2a_3 - a_4 = 2(21) - 34 = 8\) directly.
✅ Correct answer: A. 8
