HKDSE Math 2014 Paper 2 Q12 Rate, Ratio & Variations

Which is true? a, b, c ordering

It is given that $\displaystyle \frac{4}{5a} = \frac{5}{7b} = \frac{7}{9c}$ where $a$, $b$ and $c$ are positive numbers. Which of the following is true?

A. $a < b < c$
B. $a < c < b$
C. $b < a < c$
D. $b < c < a$
Proportion Common ratio k Inequality

1 Step‑by‑Step Solution

Let the common value be $k$:

$\displaystyle \frac{4}{5a} = \frac{5}{7b} = \frac{7}{9c} = k$

Since $a, b, c$ are positive, $k$ is also positive.

💡 Hint: Introducing $k$ turns a chain of ratios into separate equations.

From $\displaystyle \frac{4}{5a} = k$:

$4 = 5ak \;\Rightarrow\; a = \dfrac{4}{5k}$

From $\displaystyle \frac{5}{7b} = k$:

$5 = 7bk \;\Rightarrow\; b = \dfrac{5}{7k}$

From $\displaystyle \frac{7}{9c} = k$:

$7 = 9ck \;\Rightarrow\; c = \dfrac{7}{9k}$

💡 Hint: Cross‑multiply each equation to isolate $a$, $b$, $c$.

Since $k$ is positive, the order of $a$, $b$, $c$ depends solely on the fractions:

$a = \dfrac{4}{5k}, \quad b = \dfrac{5}{7k}, \quad c = \dfrac{7}{9k}$

Compare the numerators and denominators:

  • $\dfrac{4}{5} \approx 0.8$
  • $\dfrac{5}{7} \approx 0.714$
  • $\dfrac{7}{9} \approx 0.778$

Since $0.714 < 0.778 < 0.8$, we get:

$b < c < a$

💡 Hint: Dividing by the same positive $k$ preserves inequalities.

✅ Conclusion

The correct option is D. $b < c < a$.
