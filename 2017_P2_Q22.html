In the figure, \(ABC\) is an equilateral triangle of side \(16\text{ cm}\). \(D\) and \(E\) are points lying on \(AB\) and \(BC\) respectively such that \(AD = 4\text{ cm}\) and \(\angle CDE = 60^\circ\). Find \(CE\).

Options:

Summary of Key Results

  • Height of △ABC: \(h = \text{BC}\cdot\sin 60^\circ = 2\tan 40^\circ\) type reasoning.
  • Using △BCE: \(CE = BC\tan\angle CBE\)
  • Using △ADE: \(\tan\angle AED = \dfrac{AD}{DE}\)
  • Key relation: \(DE = 3 - 2\tan 40^\circ\) cm
  • Answer: \(\angle AED = 57^\circ\) (corr. to nearest degree)
