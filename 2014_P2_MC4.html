Quadratic Equation with Equal Roots

Interactive step‑by‑step solution & visualisation

Question

Let $a$ be a constant. If the quadratic equation $$x^2 + ax + (a-1) = 0$$ has equal roots, then $a =$

Step‑by‑Step Solution

Bring all terms to one side so the equation is in the form $ax^2+bx+c=0$:

$$x^2 + ax + (a-1) = 0$$

Here the coefficients are:

  • $a_{\text{quad}} = 1$ (coefficient of $x^2$)
  • $b = a$ (coefficient of $x$)
  • $c = a - 1$ (constant term)
Hint: Always identify $a$, $b$, $c$ correctly before computing the discriminant.

A quadratic equation has equal roots if and only if its discriminant $\Delta = 0$.

Recall the discriminant formula:

$$\Delta = b^2 - 4ac$$
Hint: $\Delta > 0$ gives two distinct real roots; $\Delta = 0$ gives one repeated real root; $\Delta < 0$ gives no real roots.

Using $a_{\text{quad}}=1$, $b=a$, $c=a-1$:

$$\Delta = a^2 - 4(1)(a-1) = 0$$

This gives:

$$a^2 - 4a + 4 = 0$$
Hint: Be careful: the coefficient $b$ is $a$ (the same letter as the unknown constant), so $b^2 = a^2$.

Factorise the left‑hand side:

$$(a-2)^2 = 0$$

Taking square roots:

$$a - 2 = 0 \quad \Rightarrow \quad a = 2$$

Since the quadratic in $a$ is a perfect square, the solution $a = 2$ is a repeated root.

Hint: $a^2 - 4a + 4$ is a perfect square trinomial; no need to use the quadratic formula.

The only value of $a$ that makes the discriminant zero is $a = 2$.

Comparing with the given choices:

  • A. $-1$ — incorrect
  • B. $2$ — correct ✓
  • C. $0$ or $-4$ — incorrect
  • D. $0$ or $4$ — incorrect
Answer: B. $2$

Key Takeaway

  • For a quadratic equation to have equal roots, set the discriminant $\Delta = b^2 - 4ac = 0$.
  • Always write the equation in standard form $ax^2+bx+c=0$ first.
  • Recognise perfect square trinomials like $a^2-4a+4=(a-2)^2$ to solve quickly.
  • Double‑check the options — in this question only $a=2$ satisfies the condition.
