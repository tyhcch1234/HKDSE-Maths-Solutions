Question [2025MC#39]

For $90^\circ < \theta < 270^\circ$, how many roots does the equation

$\tan^3\theta = 2\tan\theta$

have?

A. 2
B. 3
C. 4
D. 5
STEP 1 · REARRANGE TO ZERO

Bring everything to one side so the equation can be factorised:

$$\tan^3\theta - 2\tan\theta = 0$$

Do not divide by $\tan\theta$ — that would lose the root $\tan\theta = 0$.

STEP 2 · FACTORISE
Factorising a Trigonometric Equation \(\tan\theta\left(\tan^{2}\theta-2\right)=0\) Never divide by \(\tan\theta\): factorising keeps the root \(\tan\theta=0\).

Take out the common factor $\tan\theta$:

$$\tan\theta\,(\tan^2\theta - 2) = 0$$

A product is zero iff at least one factor is zero — this gives us the two separate families of roots.

STEP 3 · SOLVE tan θ = 0

$$\tan\theta = 0 \;\Rightarrow\; \theta = 0^\circ,\ 180^\circ,\ 360^\circ,\dots$$

Inside $90^\circ < \theta < 270^\circ$ the only solution is

$$\boxed{\theta = 180^\circ}$$

1 root so far.

STEP 4 · SOLVE tan²θ = 2
Period of the Tangent Function \(\tan(\theta+180^\circ)=\tan\theta\) \(\tan\theta=\pm\sqrt2\) gives one solution per branch inside \(90^\circ<\theta<270^\circ\).

$$\tan^2\theta = 2 \;\Rightarrow\; \tan\theta = \sqrt{2} \ \text{ or } \ \tan\theta = -\sqrt{2}$$

Using the calculator (reference angle $\approx 54.7^\circ$):

$$\tan\theta = \sqrt{2} \;\Rightarrow\; \theta \approx 125.3^\circ \quad (\text{Quadrant II})$$

$$\tan\theta = -\sqrt{2} \;\Rightarrow\; \theta \approx 234.7^\circ \quad (\text{Quadrant III})$$

tan repeats every $180^\circ$,
so each of these two branches gives exactly ONE solution inside the given interval.

STEP 5 · COUNT THE ROOTS

Collect all solutions with $90^\circ < \theta < 270^\circ$:

$$\theta = 125.3^\circ,\quad 180^\circ,\quad 234.7^\circ$$

That is exactly 3 distinct roots.

Number of roots = 3  →  Answer: B

Question. For \(0^\circ<\theta<360^\circ\), how many roots does \(\tan^{3}\theta=3\tan\theta\) have?

Show the worked solution
Step 1. \(\tan^{3}\theta-3\tan\theta=0\Rightarrow\tan\theta\left(\tan^{2}\theta-3\right)=0\).
Step 2. \(\tan\theta=0\Rightarrow\theta=180^\circ\) only (\(0^\circ\) and \(360^\circ\) are excluded) — \(1\) root.
Step 3. \(\tan\theta=\sqrt3\Rightarrow\theta=60^\circ,\,240^\circ\); \(\tan\theta=-\sqrt3\Rightarrow\theta=120^\circ,\,300^\circ\) — \(4\) roots.
Step 4. Total \(=1+4=5\) roots.
Answer: \(5\) roots
