QQuestion

Evaluate and simplify the following expression:

\[ \frac{\cos 60^\circ}{1-\cos(90^\circ-\theta)} \;+\; \frac{\cos 240^\circ}{1-\cos(270^\circ-\theta)} \;=\; \]
A. \(\dfrac{1}{\cos^2\theta}\) B. \(\dfrac{\cos\theta}{\tan\theta}\) C. \(\dfrac{\cos\theta}{\cos\theta}\) D. \(\dfrac{1}{\cos\theta\,\tan\theta}\)

(Multiple-choice, 1 mark per correct option)

1Simplify the special angles

First evaluate the numerical trigonometric values \(\cos 60^\circ\) and \(\cos 240^\circ\) appearing in the numerators.

cos60° = 0.5 cos240° = −0.5 1 − sinθ = 0.234
Step 11M

Use exact values of special angles:

\[ \cos 60^\circ = \tfrac{1}{2}, \qquad \cos 240^\circ = \cos(180^\circ+60^\circ) = -\cos 60^\circ = -\tfrac{1}{2} \]
Hint: \(\cos\) is negative in the third quadrant, so \(\cos 240^\circ = -\tfrac12\).
Answer: Numerators become \(\tfrac12\) and \(-\tfrac12\).
0 / 1

2Use complementary & supplementary identities

Rewrite the denominators using \(\cos(90^\circ-\theta)=\sin\theta\) and \(\cos(270^\circ-\theta)=-\sin\theta\).

cos(90°−θ) = sinθ cos(270°−θ) = −sinθ 1 − sin²θ = cos²θ
Step 11M

Apply complementary angle identity to the first denominator:

\[ \cos(90^\circ-\theta) = \sin\theta \]
Hint: \(\cos(90^\circ-\theta)=\sin\theta\) — a standard complementary relation.
Step 21M

Apply supplementary reduction to the second denominator:

\[ \cos(270^\circ-\theta) = \cos\big(180^\circ+(90^\circ-\theta)\big) = -\cos(90^\circ-\theta) = -\sin\theta \]
Hint: \(\cos(180^\circ+\alpha) = -\cos\alpha\).
Step 31A

Substitute into the original expression:

\[ \frac{\tfrac12}{1-\sin\theta} + \frac{-\tfrac12}{1-(-\sin\theta)} = \frac{1}{2(1-\sin\theta)} - \frac{1}{2(1+\sin\theta)} \]
Answer: \(\dfrac{1}{2(1-\sin\theta)} - \dfrac{1}{2(1+\sin\theta)}\)
0 / 3

3Combine and simplify

Put over a common denominator and apply the Pythagorean identity \(1-\sin^2\theta=\cos^2\theta\).

Expression = sinθ / cos²θ = 0.000 tanθ / cosθ = 0.000
Step 11M

Combine the two fractions over a common denominator:

\[ \frac{1}{2}\left[\frac{1}{1-\sin\theta} - \frac{1}{1+\sin\theta}\right] = \frac{1}{2}\cdot\frac{(1+\sin\theta)-(1-\sin\theta)}{(1-\sin\theta)(1+\sin\theta)} \]
Hint: Use \((1-\sin\theta)(1+\sin\theta)=1-\sin^2\theta\).
Step 21M

Simplify the numerator and denominator:

\[ = \frac{1}{2}\cdot\frac{2\sin\theta}{1-\sin^2\theta} \]
Hint: \(2\sin\theta / 2 = \sin\theta\).
Step 31A

Apply the Pythagorean identity \(1-\sin^2\theta=\cos^2\theta\):

\[ = \frac{\sin\theta}{\cos^2\theta} = \frac{\sin\theta}{\cos\theta}\cdot\frac{1}{\cos\theta} = \frac{\tan\theta}{\cos\theta} \]
Hint: \(\tan\theta = \dfrac{\sin\theta}{\cos\theta}\).
Answer: \(\dfrac{\tan\theta}{\cos\theta}\) — matches Option D.
0 / 3

Summary of Answers

  • Numerators: \(\cos 60^\circ = \tfrac12\), \(\cos 240^\circ = -\tfrac12\)
  • Denominators: \(1-\cos(90^\circ-\theta)=1-\sin\theta\), \(1-\cos(270^\circ-\theta)=1+\sin\theta\)
  • Combined: \(\displaystyle \frac{1}{2}\cdot\frac{2\sin\theta}{1-\sin^2\theta} = \frac{\sin\theta}{\cos^2\theta}\)
  • Final simplified form: \(\displaystyle \frac{\tan\theta}{\cos\theta}\)
  • Correct option: D
