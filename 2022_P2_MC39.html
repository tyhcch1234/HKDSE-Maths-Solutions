Trigonometric equations — counting roots in a full rotation
Trigonometric Identities General Solution Counting Roots Quadrants

Q Question Multiple Choice

For \(0^\circ \le x < 360^\circ\), how many roots does the equation \[ \sin^2 x = 6\cos^2 x \] have?

  • A.  2
  • B.  3
  • C.  4
  • D.  5

A Reduce to a single trigonometric ratio

Convert the equation so that only \(\sin x\) appears, using the Pythagorean identity \(\sin^2 x + \cos^2 x = 1\).

Step 1

Replace \(\cos^2 x\) with \(1 - \sin^2 x\) so everything is in terms of \(\sin x\):

\[ \sin^2 x = 6(1 - \sin^2 x) \]
Hint: This is the only substitution that turns the equation into a quadratic — always convert to the same ratio.
Step 2

Expand and collect the \(\sin^2 x\) terms:

\[ \sin^2 x = 6 - 6\sin^2 x \] \[ 7\sin^2 x = 6 \]
Hint: Move all \(\sin^2 x\) to the left; the constant \(6\) stays on the right.
Result: \(\sin^2 x = \dfrac{6}{7}\)
0 / 2

B Solve for \(x\) in \(0^\circ \le x < 360^\circ\)

Take square roots and use the quadrants to find every solution in the required range.

Step 1

Take the square root of both sides. Remember both signs are possible:

\[ \sin x = \pm\sqrt{\frac{6}{7}} \]
Hint: \(\sin^2 x = k\) gives two equations: \(\sin x = +\sqrt{k}\) and \(\sin x = -\sqrt{k}\).
Step 2

Numerically, \(\sqrt{6/7} \approx 0.925820\).

Base angle:

\[ x_0 = \sin^{-1}(0.925820) \approx 67.79^\circ \]
Hint: The calculator gives the principal value, which is always in the first quadrant (for positive sine).
Step 3

Case 1: \(\sin x > 0\) — sine is positive in Quadrants I and II:

\[ x = 67.79^\circ \quad \text{or} \quad x = 180^\circ - 67.79^\circ = 112.21^\circ \]

Case 2: \(\sin x < 0\) — sine is negative in Quadrants III and IV:

\[ x = 180^\circ + 67.79^\circ = 247.79^\circ \quad \text{or} \quad x = 360^\circ - 67.79^\circ = 292.21^\circ \]
Hint: Each sign of sine gives exactly two solutions in one full revolution — one per quadrant. Total = 4.
Answer: \(x \approx 67.79^\circ,\ 112.21^\circ,\ 247.79^\circ,\ 292.21^\circ\) → 4 roots → C
0 / 3

✓ Summary

  • Use \(\sin^2 x + \cos^2 x = 1\) to get a quadratic in \(\sin x\).
  • \(\sin^2 x = \dfrac{6}{7} \;\Rightarrow\; \sin x = \pm\sqrt{\dfrac{6}{7}} \approx \pm 0.925820\).
  • Base angle: \(x_0 = \sin^{-1}(0.925820) \approx 67.79^\circ\).
  • Positive sine: \(x \approx 67.79^\circ,\ 112.21^\circ\).
  • Negative sine: \(x \approx 247.79^\circ,\ 292.21^\circ\).
  • Total number of roots in \(0^\circ \le x < 360^\circ\): 4.
  • Correct option: C.
