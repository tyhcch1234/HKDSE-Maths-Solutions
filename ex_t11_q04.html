Geometry (106) · Sub-Topic: Angles in Triangles/Polygons

T11 Q04

A regular octagon has 8 sides. Find the size of each exterior angle.

Solution

The sum of the exterior angles of any convex polygon is $360^\circ$.
A regular octagon has $8$ equal exterior angles.
Each exterior angle is $\frac{360^\circ}{8}=45^\circ$.
The size of each exterior angle is $45^\circ$.
