Functions & Graphs — Substitution & Functional Identities
Quadratic Function f(k) Notation Substitution Symmetry of Parabola Must Be True

QQuestion Multiple Choice

Let \( f(x)=x^{2}-x+1 \). If \(k\) is a constant, which of the following must be true?

  • A. \( f(k)=f(-k) \)
  • B. \( f(k)=f(1-k) \)
  • C. \( f(k+1)=f(k)+f(1) \)
  • D. \( f(k-1)=f(k)-f(1) \)

ATesting Option A: is \( f(k)=f(-k) \)?

1.0
f(k) = … f(−k) = … f(k) − f(−k) = …
Step 11M
\[ f(k)=k^{2}-k+1 \]
Hint: Replace every \(x\) in \(f(x)=x^2-x+1\) by \(k\).
Step 21M
\[ f(-k)=(-k)^{2}-(-k)+1=k^{2}+k+1 \]
Hint: \((-k)^2=k^2\) but \(-(-k)=+k\). The middle sign flips!
Step 31A
\[ f(k)=f(-k)\iff k^{2}-k+1=k^{2}+k+1 \] \[ \iff -k=k \iff 2k=0 \iff k=0 \]
Hint: This only works for \(k=0\). Choose \(k=1\): \(f(1)=1\), \(f(-1)=3\) — not equal.
Option A is not always true — it fails for \(k\ne 0\). ✗
0 / 3

BTesting Option B: is \( f(k)=f(1-k) \)?

0.4
f(k) = … f(1−k) = … f(k) − f(1−k) = 0 always ✓
Step 11M
\[ f(1-k)=(1-k)^{2}-(1-k)+1 \]
Hint: Substitute \(x=1-k\) carefully — treat \(1-k\) as one block.
Step 21M
\[ (1-k)^{2}=1-2k+k^{2} \] \[ -(1-k)=-1+k \] \[ \therefore f(1-k)=(1-2k+k^{2})+(-1+k)+1 \]
Hint: Expand the square first, then distribute the minus sign. Watch the signs!
Step 31M
\[ f(1-k)=k^{2}-k+1 \] \[ \therefore f(1-k)=f(k) \]
Hint: Combine like terms: \(k^2 - 2k + k + (1-1+1)=k^2-k+1\).
Step 41A
\[ \boxed{f(k)=f(1-k)\ \text{for all }k} \]
Hint: Geometrically, \(1-k\) is the mirror image of \(k\) about \(x=\tfrac12\). The parabola is symmetric about \(x=\tfrac12\).
Option B must be true. ✓ (Correct answer)
0 / 4

CTesting Option C: is \( f(k+1)=f(k)+f(1) \)?

1.0
f(k+1) = … f(k)+f(1) = … Difference = …
Step 11M
\[ f(k+1)=(k+1)^{2}-(k+1)+1 \]
Hint: Substitute \(x=k+1\).
Step 21M
\[ (k+1)^{2}=k^{2}+2k+1 \] \[ -(k+1)=-k-1 \] \[ \therefore f(k+1)=(k^{2}+2k+1)-(k+1)+1=k^{2}+k+1 \]
Hint: Simplify: \(k^2 + 2k - k + (1-1+1)=k^2+k+1\).
Step 31M
\[ f(1)=1^{2}-1+1=1 \] \[ f(k)+f(1)=(k^{2}-k+1)+1=k^{2}-k+2 \]
Hint: \(f(1)=1\), so \(f(k)+f(1)=k^2-k+2\).
Step 41A
\[ f(k+1)=f(k)+f(1)\iff k^{2}+k+1=k^{2}-k+2 \] \[ \iff k+1=-k+2 \iff 2k=1 \iff k=\tfrac12 \]
Hint: Try \(k=1\): \(f(2)=3\) but \(f(1)+f(1)=2\). Not equal → not always true.
Option C is not always true — it holds only when \(k=\tfrac12\). ✗
0 / 4

DTesting Option D: is \( f(k-1)=f(k)-f(1) \)?

1.0
f(k−1) = … f(k)−f(1) = … Difference = …
Step 11M
\[ f(k-1)=(k-1)^{2}-(k-1)+1 \]
Hint: Substitute \(x=k-1\).
Step 21M
\[ (k-1)^{2}=k^{2}-2k+1 \] \[ -(k-1)=-k+1 \] \[ \therefore f(k-1)=(k^{2}-2k+1)-(k-1)+1=k^{2}-3k+3 \]
Hint: Simplify: \(k^2-2k-k+(1+1+1)=k^2-3k+3\).
Step 31M
\[ f(k)-f(1)=(k^{2}-k+1)-1=k^{2}-k \]
Hint: Remember \(f(1)=1\).
Step 41A
\[ f(k-1)=f(k)-f(1)\iff k^{2}-3k+3=k^{2}-k \] \[ \iff -3k+3=-k \iff 3=2k \iff k=\tfrac32 \]
Hint: Try \(k=1\): \(f(0)=1\) but \(f(1)-f(1)=0\). Not equal → not always true.
Option D is not always true — it holds only when \(k=\tfrac32\). ✗
0 / 4

📘 Summary — Answers at a Glance

  • Option A: \(f(k)=f(-k)\iff k=0\) — not always true ✗
  • Option B: \(f(k)=f(1-k)\) — true for all \(k\) ✓  ← Correct Answer
  • Option C: \(f(k+1)=f(k)+f(1)\iff k=\tfrac12\) — not always true ✗
  • Option D: \(f(k-1)=f(k)-f(1)\iff k=\tfrac32\) — not always true ✗
  • Key idea: \(f(x)=x^{2}-x+1\) is symmetric about \(x=\tfrac12\) since \(f(x)=f(1-x)\). Options A, C, D only hold for one specific value of \(k\), so they cannot “must be true”.
