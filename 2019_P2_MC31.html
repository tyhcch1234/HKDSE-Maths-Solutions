Question 31 — Linear Function of a Logarithm

Laws of Indices, Exponential & Logarithmic Functions

Logarithms Linear Function Intercepts Change of Base Indices Laws

QQuestion

It is given that $\log_9 y$ is a linear function of $\log_3 x$.

The intercepts on the vertical axis and on the horizontal axis of the graph of the linear function are 7 and 8 respectively. Which of the following must be true?

A$x^{4}y^{7}=3^{56}$
B$x^{7}y^{4}=3^{56}$
C$x^{7}y^{8}=3^{56}$
D$x^{8}y^{7}=3^{56}$

1Step-by-Step Guided Solution

Click each step to reveal the reasoning. Try to predict before opening!

1 Name the variables & set up the linear relation ▾

Since $\log_9 y$ is a linear function of $\log_3 x$, we can write

$$\log_9 y = m\,\log_3 x + c$$

Here:

  • $\log_3 x$ is the input (horizontal-axis variable)
  • $\log_9 y$ is the output (vertical-axis variable)
  • $m$ is the slope, $c$ is the vertical intercept
Hint — What is an intercept?
Vertical-axis intercept = value of output when the input is $0$.
Horizontal-axis intercept = value of input when the output is $0$.
2 Read off the two given intercepts ▾

The vertical-axis intercept is $7$, so when $\log_3 x = 0$:

$$\log_9 y = 7$$

The horizontal-axis intercept is $8$, so when $\log_9 y = 0$:

$$\log_3 x = 8$$
Hint: These two statements give us two points on the line:
$(0,\;7)$ and $(8,\;0)$ in the $(\log_3 x,\ \log_9 y)$ plane.
3 Find the slope and the full linear equation ▾

Using the two points $(0,7)$ and $(8,0)$:

$$m=\frac{0-7}{8-0}=-\frac{7}{8}$$

So the line is

$$\log_9 y = -\frac{7}{8}\log_3 x + 7$$
Hint — Slope formula: $m=\dfrac{y_2-y_1}{x_2-x_1}$. A negative slope means the graph falls as we move right.
4 Convert both logs to base 3 ▾

We want one common base. Note $9 = 3^2$, so by the change-of-base / power rule:

$$\log_9 y=\frac{\log_3 y}{\log_3 9}=\frac{\log_3 y}{2}$$

Substitute into the line equation:

$$\frac{\log_3 y}{2}=-\frac{7}{8}\log_3 x+7$$
Hint — Power rule: $\log_{a^n} b=\dfrac{1}{n}\log_a b$.
Here $a=3$, $n=2$, so $\log_9 y=\tfrac12\log_3 y$.
5 Clear denominators to combine the logs ▾

Multiply the whole equation by $8$:

$$4\log_3 y=-7\log_3 x+56$$

Rearrange so both log terms are on the left:

$$7\log_3 x+4\log_3 y=56$$
Hint — Log laws: $n\log_a u=\log_a u^{\,n}$ and $\log_a P+\log_a Q=\log_a(PQ)$.
6 Compress into a single logarithm & convert to indices ▾

Apply the log laws to the left-hand side:

$$\log_3\bigl(x^{7}y^{4}\bigr)=56$$

Now remove the logarithm by writing it in exponential form:

$$x^{7}y^{4}=3^{56}$$
Therefore the correct choice is B: $x^{7}y^{4}=3^{56}$.
Hint — Why must it be true? The line equation was derived purely from the two given intercepts, so the relation $x^{7}y^{4}=3^{56}$ holds for every point on that line.

2Visualise the Line

Drag the slider to move a point along the line $\log_9 y = -\tfrac78\log_3 x + 7$ and watch the relation $x^{7}y^{4}=3^{56}$ stay true.

$\log_3 x = $ 4.00
$\log_9 y = $ 3.50
$x = 3^{\log_3 x} = $ 81.000
$y = 9^{\log_9 y} = $ 2187.000
$7\log_3 x + 4\log_3 y = $ 56.00

Notice: $7\log_3 x + 4\log_3 y$ is always $56$, i.e. $\log_3\!\left(x^{7}y^{4}\right)=56$, so $x^{7}y^{4}=3^{56}$.

3Key Exam Takeaways

  • A linear function means $Y = mX + c$ — identify which quantity is $X$ and which is $Y$.
  • Intercepts are read by setting the other variable to $0$ (careful: "vertical-axis intercept" means $X=0$).
  • Always try to put logs into the same base using $\log_{a^n} b=\frac{1}{n}\log_a b$.
  • Finish with the log laws: $n\log_a u=\log_a u^n$ and $\log_a P+\log_a Q=\log_a PQ$, then convert to index form.
✓ Answer: B — $x^{7}y^{4}=3^{56}$
