Using angle sums and similar triangles to find the correct tangent ratio in a special quadrilateral.

Angle Sum of Δ Similar Triangles (AAA) Tangent Ratio Right Angles

QQuestion

The figure shows the quadrilateral \(ABCD\). If \(\angle ABC + \angle ADC = \angle ACD = \angle BAC = 90^\circ\), which of the following must be true?

  1. \(\tan \angle ACB = \dfrac{AB}{AD}\)
  2. \(\tan \angle ACB = \dfrac{AB}{CD}\)
  3. \(\tan \angle ADC = \dfrac{BC}{AD}\)
  4. \(\tan \angle ADC = \dfrac{BC}{CD}\)

(The four options A–D should not be confused with the vertices \(A,B,C,D\).)

1Part (a) — Understanding the figure & angle labels

Let \(\angle ABC = x\) and \(\angle ADC = y\). The condition \(\angle ABC + \angle ADC = 90^\circ\) gives the key relation \[ x + y = 90^\circ. \] Use the slider below to change \(x\) and watch how the quadrilateral (with \(\angle BAC = \angle ACD = 90^\circ\)) reshapes.

x = 35° y = 55° x + y = 90°
Step 1 1M
Since \(\angle ABC + \angle ADC = 90^\circ\), letting \(\angle ABC = x\) and \(\angle ADC = y\) immediately gives \[ x + y = 90^\circ. \]
Hint: Use one variable \(x\) and write \(y = 90^\circ - x\) to make the algebra simpler.
Step 2 1A
In \(\triangle ACD\), \(\angle ACD = 90^\circ\), so \[ \angle CAD = 180^\circ - 90^\circ - y = 90^\circ - y = x. \] Hence \(\angle CAD = \angle ABC\).
Hint: Angle sum of a triangle is \(180^\circ\).
Step 3 1A
In \(\triangle ABC\), \(\angle BAC = 90^\circ\), so \[ \angle ACB = 180^\circ - 90^\circ - x = 90^\circ - x = y. \] So \(\angle ACB = \angle ADC\).
Hint: This equality of angles will be used to show two triangles are similar.
Key facts: \(x+y=90^\circ\), \(\angle CAD = x\), \(\angle ACB = y\).

2Part (b) — Similar triangles & the ratio

The two right-angled triangles \(\triangle ABC\) and \(\triangle CAD\) share three equal angles, so they are similar (AAA). Use the checkbox to highlight the correspondence and see which sides are in which ratio.

AB = 0 BC = 0 AC = 0 tan ∠ACB = AB/AC
Step 1 1M
Compare the corresponding angles: \[ \angle BAC = \angle ACD = 90^\circ,\quad \angle ABC = \angle CAD = x,\quad \angle ACB = \angle ADC = y. \] Hence \(\triangle ABC \sim \triangle CAD\) (AAA).
Hint: Match the vertices in the correct order: \(A \leftrightarrow C\), \(B \leftrightarrow A\), \(C \leftrightarrow D\).
Step 2 1A
From the similarity, corresponding sides are proportional: \[ \frac{AB}{CA} = \frac{BC}{AD} = \frac{AC}{CD}. \] (Here \(AB\) corresponds to \(CA\), \(BC\) to \(AD\), and \(AC\) to \(CD\).)
Hint: Careful — the naming order of the triangles gives the side correspondence directly.
Step 3 1A
Consider the correct option. In \(\triangle ADC\), \[ \tan \angle ADC = \frac{AC}{CD}. \] From the similarity ratio \(\dfrac{BC}{AD} = \dfrac{AC}{CD}\), we get \[ \tan \angle ADC = \frac{AC}{CD} = \frac{BC}{AD}. \]
Hint: This matches option C. Check the other options to confirm they fail.
Answer: \(\displaystyle \tan \angle ADC = \frac{BC}{AD}\) — option C.
Step 4 1A
Why the others fail: \[ \tan\angle ACB = \frac{AB}{AC} \neq \frac{AB}{AD},\quad \frac{AB}{CD}\ \text{is not a tangent ratio,} \] and \(\dfrac{BC}{CD}\) mixes two different correspondences, so it is not forced to be \(\tan \angle ADC\).
Hint: \(\tan\) in a right triangle = \(\dfrac{\text{opposite}}{\text{adjacent}}\) for that angle.
Final: The only statement that must be true is \(\tan \angle ADC = \dfrac{BC}{AD}\), i.e. C.

Summary of Answers

  • Set \(\angle ABC = x\) and \(\angle ADC = y\); the condition gives \(x + y = 90^\circ\).
  • In \(\triangle ACD\) (right angle at \(C\)): \(\angle CAD = 90^\circ - y = x\).
  • In \(\triangle ABC\) (right angle at \(A\)): \(\angle ACB = 90^\circ - x = y\).
  • Therefore \(\triangle ABC \sim \triangle CAD\) (AAA), giving \(\dfrac{AB}{CA} = \dfrac{BC}{AD} = \dfrac{AC}{CD}\).
  • Since \(\tan \angle ADC = \dfrac{AC}{CD}\), we obtain \(\tan \angle ADC = \dfrac{BC}{AD}\).
  • Correct option: C
