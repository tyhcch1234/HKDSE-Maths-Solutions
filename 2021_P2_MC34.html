QUESTION [2021MC#34]

The graph in the figure shows the linear relation between $\log_5 x$ and $\log_5 y$. Which of the following must be true?

A. $\;xy^2 = 625$
B. $\;x^2y = 625$
C. $\;\dfrac{y^2}{x} = 625$
D. $\;\dfrac{y}{x^2} = 625$
EXPLORE Point-on-line visualiser

Drag the slider to move a point along the line. Observe how log₅ x and log₅ y are related.

−404
Relation: $\log_5 y - 2 = \dfrac{1}{2}(\log_5 x - 0)$

SOLUTION Step-by-Step Breakdown

From the given linear graph, we can identify two important intercepts:

  • x-intercept: $(\log_5 x,\, \log_5 y) = (-4,\, 0)$
  • y-intercept: $(\log_5 x,\, \log_5 y) = (0,\, 2)$

These two points completely determine the straight line.

Let $X = \log_5 x$ and $Y = \log_5 y$. Then the line passes through $(-4, 0)$ and $(0, 2)$.

Gradient formula:

$$m = \frac{Y_2 - Y_1}{X_2 - X_1} = \frac{2 - 0}{0 - (-4)} = \frac{2}{4} = \frac{1}{2}$$

Using the point-slope form with point $(0, 2)$ and slope $\frac{1}{2}$:

$$\log_5 y - 2 = \frac{1}{2}\,(\log_5 x - 0)$$

This is the standard form connecting $X$ and $Y$.

Multiply both sides by 2:

$$2\log_5 y - 4 = \log_5 x$$

Using the power law of logarithms: $2\log_5 y = \log_5 y^2$

$$\log_5 y^2 - \log_5 x = 4$$

Using the quotient law: $\log_5\!\left(\dfrac{y^2}{x}\right) = 4$

Recall: if $\log_b M = n$, then $M = b^n$.

$$\frac{y^2}{x} = 5^4 = 625$$

$\therefore$ The answer is C.

✓

Correct Answer

C.   $\dfrac{y^2}{x} = 625$

💡 Key Takeaways

  • • A linear relation on a $\log$-$\log$ graph means a power relation between the original variables.
  • • Read the two intercepts, find the gradient, then eliminate fractions.
  • • Use log laws backwards: combine $a\log M - b\log N$ into a single log first, then convert to index form.
