Trigonometry — solving a quadratic equation in \(\cos x\) and counting roots in \(0^\circ \le x < 360^\circ\)

Trigonometric Equations Quadratic in cos x Factorisation General Solution Number of Roots

QQuestion Multiple Choice

[2018MC#38]

For \(0^\circ \le x < 360^\circ\), how many roots does the equation \[6\cos^2 x = \cos x + 5\] have?

  • A.  2
  • B.  3
  • C.  4
  • D.  5
    • >

aRearrange into a Quadratic in \(\cos x\)

Step 1

Bring all terms to one side:

\[6\cos^2 x - \cos x - 5 = 0\]
Hint: The equation is quadratic in \(\cos x\). Treat \(u = \cos x\) and factorise \(6u^2 - u - 5 = 0\).
Step 2

Factorise the quadratic:

\[(6\cos x + 5)(\cos x - 1) = 0\]
Hint: Check: \(6u^2 - 6u + 5u - 5 = (6u+5)(u-1)\).
\[6\cos^2 x - \cos x - 5 = (6\cos x + 5)(\cos x - 1)\]
0 / 2

bSolve \(\cos x = 1\) in \(0^\circ \le x < 360^\circ\)

Step 1

From factor (i):

\[\cos x = 1\]

In the range \(0^\circ \le x < 360^\circ\), the only solution is:

\[x = 0^\circ\]
Hint: \(\cos x = 1\) only at the right-most point of the unit circle, i.e. \(x = 0^\circ\) (and \(360^\circ\) is NOT included).
Root: \(x = 0^\circ\) — 1 root from this factor.
0 / 1

cSolve \(\cos x = -\dfrac{5}{6}\) in \(0^\circ \le x < 360^\circ\)

0°
Step 1

From factor (ii):

\[\cos x = -\frac{5}{6}\]

Since \(-1 < -\frac{5}{6} < 0\), the reference angle is acute:

\[\alpha = \cos^{-1}\!\left(\frac{5}{6}\right) \approx 33.5573^\circ\]
Hint: \(\cos x\) is negative in Quadrants II and III, so there will be TWO solutions in the given range.
Step 2

Quadrant II solution:

\[x_1 = 180^\circ - 33.5573^\circ \approx 146.4427^\circ\]

Quadrant III solution:

\[x_2 = 180^\circ + 33.5573^\circ \approx 213.5573^\circ\]
Hint: Drag the slider on the unit-circle canvas to see the ray sweep — it hits the vertical line \(\cos x = -\frac{5}{6}\) twice.
Roots: \(x \approx 146.4427^\circ\) and \(x \approx 213.5573^\circ\) — 2 roots from this factor.
0 / 2

★Final Answer at a Glance

  • Rearrange: \[6\cos^2 x - \cos x - 5 = 0\]
  • Factorise: \[(6\cos x + 5)(\cos x - 1) = 0\]
  • Case 1: \(\cos x = 1 \Rightarrow x = 0^\circ\) — 1 root
  • Case 2: \(\cos x = -\frac{5}{6} \Rightarrow x \approx 146.4427^\circ,\ 213.5573^\circ\) — 2 roots
  • Total number of roots in \(0^\circ \le x < 360^\circ\): 1 + 2 = 3
  • Correct option: B. 3
