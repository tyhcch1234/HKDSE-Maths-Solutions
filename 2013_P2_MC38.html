Sequences Arithmetic Sequence Sum of Terms

HKDSE Math 2013 Paper 2 Q38

Topic 5 · Formulas and Sequences

Question

The nth term of a sequence is \(2n - 19\). Which of the following is/are true?

I.

25 is a term of the sequence.

II.

The sequence has 10 negative terms.

III.

The sum of the first \(n\) terms of the sequence is \(n^2 - 18n\).

A. I only
B. II only
C. I and III only
D. II and III only
Correct Answer: C (I and III only)

📖 Step-by-Step Guided Solution

1

Understand the General Term

The sequence is defined by \(T(n) = 2n - 19\). This is an arithmetic sequence because the coefficient of \(n\) is constant.

Hint · Common difference

For any arithmetic sequence, \(T(n+1) - T(n) = d\) (constant).

Check: \(T(n+1) - T(n) = [2(n+1) - 19] - (2n - 19) = 2\).

So the first term is \(T(1) = 2(1) - 19 = -17\), and the sequence increases by 2 each time.

2

Check Statement I — Is 25 a term?

Set \(T(n) = 25\) and solve for \(n\):

\(2n - 19 = 25\)

Solving gives:

\(2n = 44 \;\Rightarrow\; n = 22\)
✔ \(n = 22\) is a positive integer, so 25 is the 22nd term.

Thus Statement I is true.

3

Check Statement II — Negative terms count

A term is negative when \(T(n) < 0\):

\(2n - 19 < 0 \;\Rightarrow\; 2n < 19 \;\Rightarrow\; n < 9.5\)

Since \(n\) must be a positive integer, the possible values are \(n = 1, 2, 3, \dots, 9\). That is 9 terms.

✘ The sequence has 9 negative terms, not 10.

Thus Statement II is false.

4

Check Statement III — Sum of first \(n\) terms

Use the arithmetic series sum formula:

\(S_n = \dfrac{n}{2}\bigl(T(1) + T(n)\bigr)\)

Here \(T(1) = -17\) and \(T(n) = 2n - 19\).

\(S_n = \dfrac{n}{2}\bigl((-17) + (2n - 19)\bigr) = \dfrac{n}{2}(2n - 36) = n(n - 18)\)
✔ \(S_n = n^2 - 18n\), which matches the given expression.

Thus Statement III is true.

5

Conclusion

Statement I is true, Statement II is false, Statement III is true.

✅ Answer: C (I and III only)
