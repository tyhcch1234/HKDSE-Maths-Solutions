Coordinate Geometry — Translation and Rotation of Points

Translation Rotation about Origin 90° Anticlockwise Coordinates of a Point

Question

The coordinates of the point \(A\) are \((-5,-2)\). \(A\) is translated rightwards by \(9\) units to the point \(B\). \(B\) is then rotated anticlockwise about the origin through \(90^\circ\) to the point \(C\). Find the \(y\)-coordinate of \(C\).

  1. \(-4\)
  2. \(-2\)
  3. \(2\)
  4. \(4\)

Part (a) — Translation: find \(B\) Translation

Point \(A\) / its original position Point \(B\) after translation
0 / 3
Step 1
A translation rightwards by \(9\) units changes the \(x\)-coordinate only; the \(y\)-coordinate is unchanged.
Hint: Move right → add to \(x\). Move up → add to \(y\). Here we move right only, so \(y_A=y_B\).
Step 2
Apply the rule to \(A(-5,-2)\): \[ x_B = x_A + 9 = -5+9 = 4,\qquad y_B = y_A = -2 \]
Hint: Keeping the same \(y\)-value means \(A\) and \(B\) lie on the same horizontal line \(y=-2\).
Step 3
Hence the coordinates of \(B\):
\[ B = (4,\,-2) \]

Part (b) — Rotation: find \(C\) 90° Anticlockwise

Point \(B\) before rotation Point \(C'\\) after rotation Radius \(OB\)
0 / 3
Step 1
Under an anticlockwise rotation of \(90^\circ\) about the origin, the point \((x,y)\) maps to \[ (x,y)\;\longrightarrow\;(-y,\,x). \]
Hint: Remember the rotation matrix for \(90^\circ\) anticlockwise: \(\begin{pmatrix}\cos 90^\circ & -\sin 90^\circ\\ \sin 90^\circ & \cos 90^\circ\end{pmatrix}=\begin{pmatrix}0&-1\\1&0\end{pmatrix}\).
Step 2
Apply the rule to \(B(4,-2)\): \[ x_C = -y_B = -(-2) = 2,\qquad y_C = x_B = 4 \]
Hint: The number of units you moved right becomes the number of units you move up.
Step 3
So \(C=(2,4)\), and the required \(y\)-coordinate is \(4\).
\[ C = (2,\,4) \quad\Rightarrow\quad y\text{-coordinate of }C = 4 \]

Summary of Answers

  • Part (a): \(B=(4,-2)\) — translation rightwards by \(9\): \(x+9,\;y\) unchanged.
  • Part (b): \((x,y)\to(-y,x)\) for a \(90^\circ\) anticlockwise rotation about \(O\).
  • \(C=(-(-2),\,4)=(2,\,4)\).
  • Final answer: the \(y\)-coordinate of \(C\) is \(\mathbf{4}\) → Option D.
