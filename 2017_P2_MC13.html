Number of Dots in the \(7^{\text{th}}\) Pattern

Topic: Formulas and Sequences — using a recurrence relation to build up a sequence.

Q The Question

In the figure, the 1st pattern consists of 1 dot. For any positive integer \(n\), the \((n+1)\)th pattern is formed by adding \((2n+2)\) dots to the \(n\)th pattern. Find the number of dots in the 7th pattern.

2 Step-by-Step Solution

Let \(T(n)\) be the number of dots in the \(n\)th pattern. The question gives us two facts:

\[ (1)\;\; T(1) = 1 \] \[ (2)\;\; T(n+1) = T(n) + (2n+2) \quad \text{for any positive integer } n \]
Hint — what the symbols mean:
\(T(n)\): total dots in the \(n\)th pattern.
\((2n+2)\): the number of new dots added when moving from pattern \(n\) to pattern \(n+1\).
Rule (2) is a recurrence relation: each term is built from the previous one.

We want \(T(7)\). Apply rule (2) repeatedly, each time reducing the index by 1:

\[ T(7) = T(6) + 14 \qquad (\text{put } n=6) \] \[ T(6) = T(5) + 12 \qquad (\text{put } n=5) \] \[ \vdots \] \[ T(2) = T(1) + 4 \qquad (\text{put } n=1) \]
Hint: Why does \(n=6\) give \(14\)? Because \(2n+2 = 2(6)+2 = 14\).
The added amounts for \(n=1,2,\dots,6\) are \(4,6,8,10,12,14\) — an arithmetic sequence with common difference \(2\).

Substitute each equation into the previous one:

\[ T(7) = T(1) + 4 + 6 + 8 + 10 + 12 + 14 \]

Since \(T(1)=1\):

\[ T(7) = 1 + 4 + 6 + 8 + 10 + 12 + 14 \]
Shortcut (optional): The added terms form an arithmetic series with first term \(4\), last term \(14\), \(6\) terms. Its sum is \[ \frac{(4+14)\times 6}{2} = 54. \] Hence \(T(7) = 1 + 54 = 55\).
\[ T(7) = 1 + 4 + 6 + 8 + 10 + 12 + 14 = 55 \]

Therefore the number of dots in the \(7\)th pattern is 55.

Check with the table below: \(T(2)=5,\;T(3)=11,\;T(4)=19,\;T(5)=29,\;T(6)=41,\;T(7)=55\). Each step's increase matches \(4,6,8,10,12,14\).
