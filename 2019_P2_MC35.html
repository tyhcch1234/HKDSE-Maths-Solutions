HKDSE Math 2019 · Paper 2 · Q35

Linear Programming
Greatest Value in Feasible Region

#Inequalities #LinearProgramming #FeasibleRegion #ObjectiveFunction #CornerPointMethod

Question: Consider the following system of inequalities:

\(x + 2y \leq 20\) \(7x - 6y \leq 20\) \(13x + 6y \geq 20\)

Let \(R\) be the region which represents the solution of the above system of inequalities. If \((x, y)\) is a point lying in \(R\), then the greatest value of

\(7x + 8y + 9\)

is

A. 15    B. 77    C. 113    D. 115

Step-by-step solution

tap to expand
1
Identify the three boundary lines & inequalities
›

Write each inequality as an equation to draw the boundary lines:

\(L_1: x + 2y = 20\)
\(L_2: 7x - 6y = 20\)
\(L_3: 13x + 6y = 20\)

The inequalities are:

\(x + 2y \leq 20\) (below \(L_1\))
\(7x - 6y \leq 20\) (below \(L_2\))
\(13x + 6y \geq 20\) (above \(L_3\))

💡 Hint: "\(\leq\)" means the region is on the side of the line containing the origin (0,0) if possible — test (0,0) to confirm.
2
Find intersection points (vertices of feasible region R)
›

Solve pairs of line equations to get corner points:

1. \(L_1\) & \(L_2\): \(x+2y=20\) and \(7x-6y=20\)
Multiply first by 3: \(3x+6y=60\), add to second: \(10x = 80 \Rightarrow x=8\).
Then \(8+2y=20 \Rightarrow y=6\). → Point A(8, 6)
2. \(L_1\) & \(L_3\): \(x+2y=20\) and \(13x+6y=20\)
From first: \(x=20-2y\). Substitute: \(13(20-2y)+6y=20 \Rightarrow 260-26y+6y=20 \Rightarrow -20y=-240 \Rightarrow y=12\)
Then \(x=20-24=-4\). → Point B(-4, 12)
3. \(L_2\) & \(L_3\): \(7x-6y=20\) and \(13x+6y=20\)
Add: \(20x = 40 \Rightarrow x=2\). Then \(14-6y=20 \Rightarrow -6y=6 \Rightarrow y=-1\). → Point C(2, -1)

Feasible region is bounded by these three vertices if they satisfy all inequalities. Check point (0,0): \(0\leq20\) ✓, \(0\leq20\) ✓, \(0\geq20\) ✗ — so (0,0) is not in R; the region is the triangle formed by A, B, C (verified in next step).

💡 Hint: Always check that the corner points actually satisfy all three inequalities. They do: A(8,6) satisfies \(8+12=20\), \(56-36=20\), \(104+36=140 \geq 20\) ✓
3
Evaluate the objective function at each vertex
›

Objective: \(P = 7x + 8y + 9\). Substitute each point:

At \(A(8, 6)\): \(P = 7(8) + 8(6) + 9 = 56 + 48 + 9 = 113\)
At \(B(-4, 12)\): \(P = 7(-4) + 8(12) + 9 = -28 + 96 + 9 = 77\)
At \(C(2, -1)\): \(P = 7(2) + 8(-1) + 9 = 14 - 8 + 9 = 15\)

So the values are 113, 77, 15. The greatest among them is 113.

💡 Hint: The linear objective function attains its maximum/minimum at a vertex of the feasible region (corner point method). Here the vertices gave 113, 77, 15.
4
Confirm the maximum & match with options
›

Greatest value is \(113\) at point \(A(8,6)\).

Compare with choices: A. 15, B. 77, C. 113, D. 115.

So the correct answer is C. 113.
