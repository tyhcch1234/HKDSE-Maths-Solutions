T11 Q41

How many edges does a cube have?

Solution

A cube has 6 square faces.
Each square face has 4 edges, so counting face by face gives $6 \times 4 = 24$ edge counts.
Each edge is shared by exactly 2 faces, so it is counted twice.
Therefore, the number of edges is $\frac{6 \times 4}{2} = \frac{24}{2} = 12$.
A cube has $12$ edges.
