The Problem

In Figure 5, the 1st pattern consists of 3 dots. For any positive integer n, the (n+1)th pattern is formed by adding 2 dots to the nth pattern. Find the least value of m such that the total number of dots in the first m patterns exceeds 6 888.

Step-by-Step Guided Solution

The number of dots in the patterns forms an arithmetic sequence:

3,   5,   7,   9,   …

First term \(a = 3\),   Common difference \(d = 2\).

Hint: The nth term of an arithmetic sequence is \(T_n = a + (n-1)d\). Here, \(T_n = 3 + (n-1)2 = 2n + 1\).

The total number of dots in the first \(m\) patterns is the sum of the first \(m\) terms:

\(S_m = 3 + 5 + 7 + \cdots + (2m+1)\)

Hint: The last term is the mth term, which is \(2m + 1\).

Using the arithmetic sum formula \(S_n = \frac{n}{2}(a + l)\), where \(l\) is the last term:

\(S_m = \frac{m}{2}\big(3 + (2m+1)\big)\)

Simplify:

\(S_m = \frac{m}{2}(2m+4) = m(m+2) = m^2 + 2m\)

Hint: Always check if you can factor out numbers to simplify before expanding.

We want the total number of dots to exceed 6888, so:

\(m^2 + 2m > 6888\)

Bring all terms to one side:

\(m^2 + 2m - 6888 > 0\)

Hint: "Exceeds" means strictly greater than (\(>\)).

We factorise \(m^2 + 2m - 6888\):

\((m - 82)(m + 84) > 0\)

The critical values are \(m = 82\) and \(m = -84\). Since \(m\) is a positive integer (\(m > 0\)), we only consider the positive critical value.

Hint: For a quadratic inequality \(>0\) with roots \(r_1 < r_2\), the solution is \(m < r_1\) or \(m > r_2\).

From \((m - 82)(m + 84) > 0\), we have \(m < -84\) or \(m > 82\).

Since \(m\) is a positive integer, we take \(m > 82\).

The least integer satisfying \(m > 82\) is \(m = 83\).

Answer: \(m = 83\)

Key Takeaways

  • Recognise arithmetic sequences from pattern problems (constant difference).
  • Use \(S_n = \frac{n}{2}(a+l)\) or \(S_n = \frac{n}{2}[2a+(n-1)d]\) to find the sum.
  • Translate word problems into quadratic inequalities.
  • Solve quadratic inequalities by factorising and testing intervals.
  • Always consider the context (positive integer \(m\)) when choosing the final answer.
