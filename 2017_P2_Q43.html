HKDSE Math 2017 Paper 2 Q43

Probability: At Most 3 Hits

Complementary probability & binomial model

Probability Complement Rule Independent Events Binomial

Question: When Teresa throws a dart, the probability that she hits the target is 0.7. If Teresa throws the dart 4 times, find the probability that she hits the target at most 3 times.

A. 0.0081
B. 0.2401
C. 0.7599
D. 0.9919
1 Understand "at most 3 times" ▼

"At most 3 times" means the number of hits can be 0, 1, 2, or 3.

So we are looking for:

\[ P(\text{hits} \le 3) = P(0) + P(1) + P(2) + P(3) \]
💡 Hint: Adding four separate probabilities is possible, but there is a much faster way — use the complement!
2 Use the complement rule ▼

The only case that is not "at most 3 hits" is "hits exactly 4 times".

\[ P(\text{hits} \le 3) = 1 - P(\text{hits} = 4) \]
💡 Concept: For any event \(A\), \(P(A) = 1 - P(\text{not } A)\). This is the complement rule.
3 Find P(hits exactly 4 times) ▼

Each throw is independent. The probability of hitting the target on a single throw is \(0.7\).

To hit 4 times in a row:

\[ P(\text{hits} = 4) = 0.7 \times 0.7 \times 0.7 \times 0.7 = 0.7^4 \]
\[ 0.7^4 = 0.2401 \]
💡 Hint: \(0.7^4\) means multiplying 0.7 by itself 4 times. \(0.7 \times 0.7 = 0.49\), then \(0.49 \times 0.49 = 0.2401\).
4 Compute the final answer ▼

Now substitute back into the complement:

\[ P(\text{hits} \le 3) = 1 - 0.7^4 = 1 - 0.2401 = 0.7599 \]
✅ Final answer: 0.7599 — this matches option C.

ANSWER
0.7599
Option C
