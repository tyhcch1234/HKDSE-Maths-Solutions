HKDSE Math 2018 Paper 2 Q34

Finding the greatest value of a linear expression over a feasible region.

📋 The Inequality System

Consider the following system of inequalities:

\[\begin{cases} x - 21 \leq 0 \\ x - y - 35 \leq 0 \\ x + 5y - 91 \leq 0 \\ 3x + 2y \geq 0 \end{cases}\]

Let \(D\) be the region representing the solution of the above system. If \((x, y)\) is a point lying in \(D\), then the greatest value of \(5x + 6y + 234\) is

A. 45
B. 150
C. 178
D. 423

(The answer is C. 178)

🧭 Step-by-Step Solution

💡 Hint: The Fundamental Theorem of Linear Programming

The maximum (or minimum) of a linear function over a bounded feasible region always occurs at a corner point (vertex) of that region. So we just test all corner points.
