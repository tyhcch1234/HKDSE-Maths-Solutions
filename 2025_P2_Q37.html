Step 1 — given: p, q, r is an arithmetic sequence with common difference d.

Question

Let $p$, $q$ and $r$ be non-zero real numbers. If $p$, $q$, $r$ is an arithmetic sequence, which of the following must be true?
  • I.  $3^{p},\ 3^{q},\ 3^{r}$ is a geometric sequence.
  • II.  $\dfrac{5}{p},\ \dfrac{5}{q},\ \dfrac{5}{r}$ is a geometric sequence.
  • III.  $p-q,\ q-r,\ r-p$ is an arithmetic sequence.
A. I only
B. II only
C. I and III only
D. II and III only

Step-by-step solution

Tip: scroll slowly — each step highlights the matching part of the figure on the left.

Step 1Translate "arithmetic sequence" into a common difference $d$.

Let $d$ be the common difference of the arithmetic sequence $p,\ q,\ r$. Then

$$q=p+d,\qquad r=p+2d,\qquad d\neq 0 \text{ is possible.}$$

Key idea: an arithmetic sequence only says the gap between consecutive terms is constant.
Arithmetic Sequence \(q-p=r-q=d\) Write \(q=p+d\) and \(r=p+2d\); every statement is tested by substituting these.
Step 2Test statement I: is $3^{p},\ 3^{q},\ 3^{r}$ geometric?

Substitute the arithmetic relations into the powers of $3$:

$$3^{q}=3^{p+d}=3^{d}\cdot 3^{p}$$ $$3^{r}=3^{p+2d}=(3^{d})^{2}\cdot 3^{p}$$

So each term is obtained by multiplying the previous one by the same constant $3^{d}\neq 0$:

$$3^{p},\;3^{p}\!\cdot\!3^{d},\;3^{p}\!\cdot\!(3^{d})^{2}\ \Longrightarrow\ \text{common ratio } = 3^{d}.$$

Statement I is TRUE — it is a geometric sequence with common ratio $3^{d}$.

Powers turn an arithmetic (additive) pattern into a geometric (multiplicative) one.
Geometric Sequence \(\dfrac{T_2}{T_1}=\dfrac{T_3}{T_2}=R\) \(3^{q}=3^{p}\cdot3^{d}\) and \(3^{r}=3^{p}\cdot(3^{d})^{2}\), so the common ratio is \(3^{d}\).
Step 3Test statement II: is $\dfrac{5}{p},\ \dfrac{5}{q},\ \dfrac{5}{r}$ geometric?

Compare consecutive ratios:

$$\frac{5}{q}\div\frac{5}{p}=\frac{p}{q}=\frac{p}{p+d}$$ $$\frac{5}{r}\div\frac{5}{q}=\frac{q}{r}=\frac{p+d}{p+2d}$$

For a geometric sequence these two ratios must be equal, i.e.

$$\frac{p}{p+d}=\frac{p+d}{p+2d}\ \Longleftrightarrow\ p(p+2d)=(p+d)^{2}\ \Longleftrightarrow\ p^{2}+2pd=p^{2}+2pd+d^{2}\ \Longleftrightarrow\ d^{2}=0.$$

But $d^{2}=0$ fails whenever $d\neq 0$ (e.g. $p=1,\ q=2,\ r=3$ gives ratios $\tfrac12\neq\tfrac23$). So the pattern is not guaranteed.

Statement II is NOT true in general.

Reciprocals do not preserve a geometric pattern — the counter-example $1,2,3$ kills it.
Step 4Test statement III: is $p-q,\ q-r,\ r-p$ arithmetic?

Write each term using $p$ and $d$:

$$p-q=p-(p+d)=-d,\qquad q-r=(p+d)-(p+2d)=-d,\qquad r-p=(p+2d)-p=2d$$

Check the gap between consecutive terms:

$$(q-r)-(p-q)=(-d)-(-d)=0 \quad\checkmark$$ $$(r-p)-(q-r)=2d-(-d)=3d \quad\neq 0 \text{ when } d\neq 0.$$

Since the second gap $3d$ differs from the first gap $0$, the three terms are not an arithmetic sequence in general.

Statement III is NOT true in general.

Note $p-q=q-r=-d$ gives only two equal terms; the third breaks the pattern.
Step 5Conclude.

Only statement I must be true. Hence the correct choice is

$$\boxed{\text{A. I only}}$$

Read the options: "I only" corresponds to option A.
Answer: A (I only)
Only $3^{p},3^{q},3^{r}$ must be a geometric sequence (common ratio $3^{d}$); statements II and III can fail.

Question. Let \(p\), \(q\) and \(r\) be an arithmetic sequence. Which of the following must be true? I. \(2^{p},2^{q},2^{r}\) is a geometric sequence. II. \(p+1,q+1,r+1\) is an arithmetic sequence. III. \(p^{2},q^{2},r^{2}\) is an arithmetic sequence.

Show the worked solution
Step 1. Let \(q=p+d\), \(r=p+2d\).
Step 2. I: \(2^{q}=2^{p}\cdot2^{d}\) and \(2^{r}=2^{p}\cdot(2^{d})^{2}\), so the common ratio is \(2^{d}\) — true.
Step 3. II: \((q+1)-(p+1)=d=(r+1)-(q+1)\), so the common difference is still \(d\) — true.
Step 4. III: for \(1,2,3\) the squares are \(1,4,9\), whose gaps \(3\) and \(5\) differ — false.
Answer: I and II only
