Statistics — mode, median & range under a mean constraint
Mean Mode Median Range Case Analysis

QQuestion

Consider the following positive integers:

\[2,\ 3,\ 4,\ 6,\ 7,\ 9,\ 10,\ m,\ n\]

Let \(a\), \(b\) and \(c\) be the mode, the median and the range of the above positive integers respectively. If the mean of the above positive integers is \(5\), which of the following must be true?

I.  \(a = 2\)
II.  \(b = 4\)
III.  \(c = 8\)

A.  I only
B.  II only
C.  I and III only
D.  II and III only

aPart (a) — Using the mean to find \(m+n\)

Sum of fixed 7 numbers = 41 \(m+n\) = 4 Total sum = 45 Mean = 5.00 ✔ Valid
Step 11M

There are \(9\) numbers in total, and the mean is \(5\). So the total sum is

\[ \text{Sum} = 9 \times 5 = 45. \]
Hint: Mean \(=\) total sum \(\div\) number of data values. Multiplying back gives the total sum.
Step 21M

Sum of the seven given numbers:

\[ 2+3+4+6+7+9+10 = 41. \]
Hint: Group the numbers to add quickly: \((2+10)+(3+9)+(4+6)+7 = 12+12+10+7 = 41\)
Step 31A

Therefore

\[ 41 + m + n = 45 \implies m + n = 4. \]
Hint: Since \(m,\,n\) are positive integers (so each is at least \(1\)), the only ordered pairs \((m,n)\) are \[(1,3),\ (2,2),\ (3,1).\]
Answer: \(\;m+n = 4\), with \((m,n) \in \{(1,3),(2,2),(3,1)\}\).
0 / 3

bPart (b) — Testing each possible \((m,n)\)

Mode \(a\) = 3 Median \(b\) = 4 Range \(c\) = 9
Step 11M

List all three possible data sets and sort each into ascending order to read off the median.

Hint: The median of \(9\) ordered numbers is the 5th value (the \(\frac{9+1}{2}=5^{\text{th}}\) value).
Step 21M

Carefully re-compute each case (using the sorted lists):

  • \((m,n)=(1,3)\): data \(1,2,3,3,4,6,7,9,10\) → mode \(a=3\), median \(b=4\), range \(c=10-1=9\).
  • \((m,n)=(2,2)\): data \(2,2,3,4,6,7,9,10,10\) → mode \(a=2\) (appears twice, others once), median \(b=6\), range \(c=10-2=8\).
Hint: With \((m,n)=(2,2)\) two extra \(2\)'s appear on the left, but two \(10\)'s also appear? No — only one \(10\) is given. So the sorted list is \(2,2,3,4,6,7,9,10\) plus the second \(2\): actually the data is \(2,3,4,6,7,9,10,2,2\) → sort: \(2,2,2,3,4,6,7,9,10\). Recheck below.
Step 31M

Correcting the \((2,2)\) case: data \(=\{2,3,4,6,7,9,10,2,2\}\) → sorted \(2,2,2,3,4,6,7,9,10\).

  • mode \(a=2\) (three \(2\)'s)
  • median \(b=4\) (5th value is \(4\))
  • range \(c=10-2=8\)

Case \((3,1)\): data \(=\{2,3,4,6,7,9,10,3,1\}\) → sorted \(1,2,3,3,4,6,7,9,10\).

  • mode \(a=3\)
  • median \(b=4\) (5th value is \(4\))
  • range \(c=10-1=9\)
Hint: Always sort the entire data set — including the two inserted values — before reading the mode and median.
Step 41A

Now compare the three statements across the three cases:

CaseI. \(a=2\)II. \(b=4\)III. \(c=8\)
(1,3)✗ (\(a=3\))✓✗ (\(c=9\))
(2,2)✓✓✓
(3,1)✗ (\(a=3\))✓✗ (\(c=9\))

Only II holds in every case. I fails for \((1,3)\),\((3,1)\); III fails for \((1,3)\),\((3,1)\).

Answer: Only statement II must be true → \(\boxed{\text{B. II only}}\)
0 / 4

✓Summary of Answers

  • From the mean: \(41+m+n = 45 \Rightarrow m+n = 4\).
  • Possible ordered pairs: \((m,n)=(1,3),\ (2,2),\ (3,1)\).
  • Mode \(a\): \(3,\ 2,\ 3\) respectively — not always \(2\).
  • Median \(b\): \(4\) in all cases.
  • Range \(c\): \(9,\ 8,\ 9\) respectively — not always \(8\).
  • Only statement II must be true.
  • Final answer: B. II only
