HKDSE Math 2021 Paper 2 Q36

Topic 5: Formulas and Sequences

Geometric Sequence Common Ratio Logical Reasoning
Question

If \(p, q, r, s\) is a geometric sequence, which of the following must be true?

I. \(ps = qr\)

II. \(p + s = q + r\)

III. \(p < q < r < s\)

A. I only
B. II only
C. I and III only
D. II and III only

Step-by-Step Solution

Step 1

Define the terms of the Geometric Sequence

Let the first term be \(p\) and the common ratio be \(u\).

The terms of the sequence can be expressed as:

  • First term: \(p = p\)
  • Second term: \(q = p \cdot u\)
  • Third term: \(r = p \cdot u^2\)
  • Fourth term: \(s = p \cdot u^3\)
Hint: In a geometric sequence, each term is obtained by multiplying the previous term by the common ratio \(u\).
Step 2

Verify Statement I: \(ps = qr\)

Substitute the expressions we found in Step 1 into both sides of the equation.

Left Hand Side (L.H.S.):

\(ps = p \cdot (p u^3) = p^2 u^3\)

Right Hand Side (R.H.S.):

\(qr = (p u) \cdot (p u^2) = p^2 u^3\)

L.H.S. = R.H.S.
Conclusion: Statement I is true for all geometric sequences.
Step 3

Investigate Statement II: \(p + s = q + r\)

To check if this must be true, we test if there is any case where it fails.

Counterexample Test:

Let \(p = 1\) and \(u = -2\).

Then the sequence is:

\(q = 1 \cdot (-2) = -2\)

\(r = 1 \cdot (-2)^2 = 4\)

\(s = 1 \cdot (-2)^3 = -8\)

Check the equation:

L.H.S. = \(p + s = 1 + (-8) = -7\)

R.H.S. = \(q + r = (-2) + 4 = 2\)

\(-7 \neq 2\)

Conclusion: Statement II is not always true (it's a false statement).
Step 4

Investigate Statement III: \(p < q < r < s\)

Using the same counterexample from Step 3 (\(p=1, u=-2\)), let's check the inequality.

The sequence is: \(1, -2, 4, -8\)

Here, \(p = 1\), \(q = -2\), \(r = 4\), \(s = -8\).

Checking the inequality:

Is \(1 < -2\)?

No, \(1\) is not less than \(-2\).

Conclusion: Statement III is not always true (it fails when the common ratio is negative).
Step 5

Determine the Correct Option

From our analysis:

  • Statement I is true.
  • Statement II is false.
  • Statement III is false.

Only Statement I must be true.

The correct answer is

Option A: I only
