Let \(k\) be a constant such that \[ 2x^4 + kx^3 - 4x - 16 \] is divisible by \(2x + k\). Find \(k\).

🧩 Step-by-Step Solution

Step 1 ○

Understand the Given Condition

The polynomial \(P(x) = 2x^4 + kx^3 - 4x - 16\) is divisible by \(2x + k\).

By the Factor Theorem, if \(P(x)\) is divisible by a linear factor \((ax + b)\), then \(P\left(-\frac{b}{a}\right) = 0\).

💡 Hint: Divisible means the remainder is \(0\). Don't just plug in \(0!\) Find the root of the divisor first.
Step 2 ○

Find the Root of the Divisor

The divisor is \(2x + k\). Set it to zero to find the root:

\[ 2x + k = 0 \quad\Rightarrow\quad x = -\frac{k}{2} \]

So we substitute \(x = -\frac{k}{2}\) into \(P(x)\) and set the result to \(0\).

Step 3 ○

Substitute & Simplify

Set \(P\left(-\frac{k}{2}\right) = 0\):

\[ 2\left(-\frac{k}{2}\right)^4 + k\left(-\frac{k}{2}\right)^3 - 4\left(-\frac{k}{2}\right) - 16 = 0 \]

Simplify term by term:

  • \(2 \cdot \frac{k^4}{16} = \frac{k^4}{8}\)
  • \(k \cdot \left(-\frac{k^3}{8}\right) = -\frac{k^4}{8}\)
  • \(-4 \cdot \left(-\frac{k}{2}\right) = +2k\)
  • \(-16\) stays

Result:

\[ \frac{k^4}{8} - \frac{k^4}{8} + 2k - 16 = 0 \]

✨ The \(k^4\) terms cancel out! This is a key observation.
Step 4 ○

Solve for \(k\)

Since the \(k^4\) terms cancel, we are left with a linear equation:

\[ 2k - 16 = 0 \]

\[ 2k = 16 \quad\Rightarrow\quad k = 8 \]

Answer: \(k = 8\) → Option D

Step 5 ○

Let's Verify!

Substitute \(k = 8\) into \(P(x)\):

\[ P(x) = 2x^4 + 8x^3 - 4x - 16 \]

Divisor: \(2x + 8 = 0 \Rightarrow x = -4\).

Check \(P(-4)\):

\[ 2(-4)^4 + 8(-4)^3 - 4(-4) - 16 = 512 - 512 + 16 - 16 = 0 \checkmark \]

✓ Remainder is zero. \(k = 8\) is correct!

📝 Key Takeaway

Factor Theorem

If \(P(x)\) is divisible by \((ax + b)\), then \(P\left(-\frac{b}{a}\right) = 0\).

Remainder Theorem

The remainder when \(P(x)\) is divided by \((ax + b)\) is \(P\left(-\frac{b}{a}\right)\).

For this particular polynomial, the \(k^4\) terms cancel, leaving a simple linear equation. Always simplify carefully before solving!
