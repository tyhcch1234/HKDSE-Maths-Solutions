Effect of a linear transformation on mean, range and variance
Statistics Mean Range Variance Linear Transformation

Q The Question 2 marks

The mean, the range and the variance of a set of numbers are \(m\), \(r\) and \(v\) respectively. Each number of the set is multiplied by \(6\) and then \(5\) is added to each resulting number to form a new set of numbers. Which of the following is/are true?

I. The mean of the new set of numbers is \(6m+5\).
II. The range of the new set of numbers is \(6r+5\).
III. The variance of the new set of numbers is \(6v+5\).

  • A. I only
  • B. II only
  • C. I and III only  ✗ (not correct — see below)
  • D. II and III only

(Use the interactive diagrams and the step-by-step solution below to decide which statements really hold.)

I Statement I — the Mean

5
Original mean \(m = 10\)
New mean \(= a\cdot m + b = 65\)
Step 11M

Recall the definition of the mean of \(n\) numbers \(x_1,x_2,\dots,x_n\):

\[ m=\frac{x_1+x_2+\cdots+x_n}{n}. \]
Hint: A mean is a linear operation — it "distributes" over sums and scalar multiples.
Step 21M

Form the new numbers \(y_i = 6x_i + 5\) and average them:

\[ \bar{y}=\frac{\sum (6x_i+5)}{n}=\frac{6\sum x_i + 5n}{n}=6\cdot\frac{\sum x_i}{n}+5. \]
Hint: The constant \(5\) is added \(n\) times, so it contributes \(\frac{5n}{n}=5\) to the mean — exactly one \(5\), not \(5n\).
Step 31A

Substituting \(\frac{\sum x_i}{n}=m\):

\[ \bar{y}=6m+5. \]
✅ Statement I is TRUE: new mean \(=6m+5\).

II Statement II — the Range

6
5
Original range \(r = 12\)
\(a\cdot r = 72\),   \(a\cdot r + b = 77\)
Actual new range \(= 72\)
Step 11M

Let \(x_{\min}\) and \(x_{\max}\) be the smallest and largest of the original numbers, so

\[ r = x_{\max}-x_{\min}. \]
Hint: Multiplying every number by a positive constant \(6\) does not change which number is the smallest or the largest.
Step 21M

For the new set \(y_i=6x_i+5\), the smallest value is \(6x_{\min}+5\) and the largest is \(6x_{\max}+5\). Thus

\[ \text{new range}=(6x_{\max}+5)-(6x_{\min}+5)=6(x_{\max}-x_{\min})=6r. \]
Hint: The \(+5\) cancels in the subtraction — adding a constant can never change how far apart two numbers are. Watch the diagram: the whole point-cloud slides but its width only stretches by factor \(a\).
Step 31A

Comparing with statement II, which claims the range is \(6r+5\):

\[ 6r \neq 6r+5 \quad(\text{since }5\neq 0). \]
❌ Statement II is FALSE. The correct new range is \(6r\).

III Statement III — the Variance

6
5
Original variance \(v = 4\)
\(a^2 v = 144\),   \(a v + b = 29\)
Actual new variance \(= 144\)
Step 11M

Variance measures the average squared deviation from the mean:

\[ v=\frac{\sum (x_i-m)^2}{n}. \]
Hint: For the new set we must measure deviation from the new mean, \(\bar y = 6m+5\) — not from the old mean \(m\).
Step 21M

Compute deviations in the new set using \(\bar{y}=6m+5\):

\[ y_i-\bar{y}=(6x_i+5)-(6m+5)=6(x_i-m). \]
Hint: The \(+5\) cancels completely here too — shifting a distribution does not change its spread. Only the factor \(6\) survives.
Step 31M

Square and average:

\[ \text{new variance}=\frac{\sum \big(6(x_i-m)\big)^2}{n} =36\cdot\frac{\sum (x_i-m)^2}{n}=36v. \]
Hint: Squaring the factor \(6\) gives \(6^2=36\). This is why a scale change squares in the variance, but a shift does nothing.
Step 41A

Statement III claims the variance is \(6v+5\), but we found \(36v\):

\[ 36v \neq 6v+5 \quad \text{in general.} \]
❌ Statement III is FALSE. The correct new variance is \(6^2v=36v\).

✓ Summary & Final Answer

For the transformation \(y = ax + b\) applied to every value of a data set:

StatisticFormula for new setHere \(a=6,\ b=5\)True?
Mean\(a\,m + b\)\(6m+5\)I ✓
Range\(a\,r\)  (if \(a>0\))\(6r\)II ✗
Variance\(a^2 v\)\(36v\)III ✗
  • Only Statement I is true.
  • Therefore the correct option is A. I only.
  • Golden rule: shift affects location (mean, median), scale affects spread — range is multiplied by \(a\), variance by \(a^2\), but a constant shift changes neither.
