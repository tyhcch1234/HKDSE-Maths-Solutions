If \(k\) is a constant such that \[ x^3 + 4x^2 + kx - 12 \] is divisible by \( x + 3 \), then \( k = \)

A. \(-25\)
B. \(-1\)
C. \(1\)
D. \(17\)

Guided Solution

The problem states that the polynomial \( P(x) = x^3 + 4x^2 + kx - 12 \) is divisible by \(x + 3\).

This means that when we divide \(P(x)\) by \(x + 3\), the remainder is \(0\).

Hint: The Factor Theorem tells us that if a polynomial \(P(x)\) is divisible by \(x - a\), then \(P(a) = 0\).

We need to find the value of \(x\) that makes the divisor \(x + 3\) equal to zero.

\(x + 3 = 0 \implies x = -3\)

So, we substitute \(x = -3\) into the polynomial and set it equal to zero.

Hint: According to the Remainder Theorem, the remainder when \(P(x)\) is divided by \(x - a\) is \(P(a)\). If it's divisible, the remainder is zero, so \(P(-3) = 0\).

Substitute \(x = -3\) into \(P(x) = x^3 + 4x^2 + kx - 12\):

\(P(-3) = (-3)^3 + 4(-3)^2 + k(-3) - 12 = 0\)

\(\downarrow\)

\(-27 + 4(9) - 3k - 12 = 0\)

\(\downarrow\)

\(-27 + 36 - 3k - 12 = 0\)

\(\downarrow\)

\(-3 - 3k = 0\)

\(\downarrow\)

\(-3k = 3\)

\(\downarrow\)

\(k = -1\)

Therefore, the correct answer is B. \(-1\).
