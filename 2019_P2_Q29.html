Box-and-Whisker

Step 1 — a box-and-whisker diagram shows the five-number summary.

Min / Max Lower / Upper quartile Median Inter-quartile range

[2019 MC #29]  15. Statistics

Which of the following can be obtained from any box-and-whisker diagram?

I.  Range II.  Standard deviation III.  Inter-quartile range A. I and II only B. I and III only C. II and III only D. I, II and III
1 What a box-and-whisker diagram shows
Five-Number Summary \(\text{min},\ Q_{1},\ \text{median},\ Q_{3},\ \text{max}\) A box-and-whisker diagram shows only these five values, and anything computed from them.

Every box-and-whisker diagram is drawn from the five-number summary: the minimum value, the lower quartile $Q_1$, the median $Q_2$, the upper quartile $Q_3$ and the maximum value.

Left whisker end $=$ min  |  left box edge $=Q_1$  |  line $=$ median  |  right box edge $=Q_3$  |  right whisker end $=$ max

Hint: only these five values (and anything computed from them) can be read off.

2 Check I — Range
Range \(\text{range}=\text{maximum}-\text{minimum}\) The two whisker ends give the maximum and the minimum, so the range is always readable.

The ends of the whiskers give the minimum and the maximum, so

$$\text{Range}=\text{max}-\text{min}$$

is always obtainable.  $\checkmark$

Hint: the total span of the diagram is exactly the range.

3 Check III — Inter-quartile range
Inter-Quartile Range \(\text{IQR}=Q_{3}-Q_{1}\) The width of the box is exactly \(Q_{3}-Q_{1}\), so the IQR can always be read off.

The two ends of the box give $Q_1$ and $Q_3$, so

$$\text{IQR}=Q_3-Q_1$$

is always obtainable — it is the width of the box.  $\checkmark$

Hint: the box length is the inter-quartile range, read directly from the diagram.

4 Check II — Standard deviation

Consider the data set

$$\{-3,\,-3,\,-3,\,-3a,\,0,\,3a,\,3,\,3,\,3\},\qquad 0\le a\le 1.$$

Its five-number summary is $0,\,3,\,-3,\,3,\,-3$ — i.e. the same for every $a$ — so the box-and-whisker diagram never changes. But the standard deviation

$$\sigma=\sqrt{2(a^{2}+3)}$$

increases as $a$ goes from $0$ to $1$. Two different data sets share one diagram yet have different standard deviations.

Hence the standard deviation cannot be obtained.  $\times$

Hint: the diagram loses the individual data values, so spread measures such as s.d. are not recoverable.

Answer: B  (I and III only)

Question. Which of the following can always be obtained from a box-and-whisker diagram? I. the range II. the inter-quartile range III. the mean

Show the worked solution
Step 1. A box-and-whisker diagram records only the minimum, \(Q_{1}\), the median, \(Q_{3}\) and the maximum.
Step 2. I: range \(=\text{max}-\text{min}\), and both whisker ends are shown,
so I can be obtained.
Step 3. II: IQR \(=Q_{3}-Q_{1}\), the width of the box, so II can be obtained.
Step 4. III: the mean uses every data value;
two data sets with the same five-number summary can have different means,
so the mean cannot be obtained.
Step 5. Hence only I and II can be obtained.
Answer: I and II only
