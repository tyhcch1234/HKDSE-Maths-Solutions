Linear Programming

Question

Consider the following system of inequalities:
\[ y\le 7,\qquad 3x-4y\le 2,\qquad 6x+13y\ge 25 \]
Let \(R\) be the region which represents the solution of the above system of inequalities. If \((x,y)\) is a point lying in \(R\), then the least value of \(5x+4y+28\) is

  • A. \(1\)
  • B. \(19\)
  • C. \(42\)
  • D. \(106\)

Solution

Vertices \(R\) is the triangle with vertices \((10,7),\ (-11,7),\ (2,1)\) (intersections of the boundary lines).
Evaluate \(f=5x+4y+28\): at \((10,7)\to106\); at \((-11,7)\to1\); at \((2,1)\to42\).
Minimum Least value \(=1\) (at \((-11,7)\)).
Answer: A — 1
