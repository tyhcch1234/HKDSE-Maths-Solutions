Inequalities & Counting Integers

Solve two linear inequalities simultaneously, then count the positive integers that satisfy both.

Linear Inequalities Solving Simultaneous Inequalities Number Line Integer Counting

QQuestion

(a) Find the range of values of \(x\) which satisfy both

\[ \frac{4x+6}{7} > 2(x-3) \quad \text{and} \quad 2x - 10 \le 0. \]

(b) How many positive integers satisfy both the inequalities in (a)?

[4 marks]

💡 Tip: Solve each inequality separately first, then intersect the two solution sets on a number line.

1Step-by-Step Guided Solution

Click each step to reveal the working. Try to solve it yourself before opening the next step!

1 Solve the first inequality: clear the fraction ▶

Start with the first inequality:

\[ \frac{4x+6}{7} > 2(x-3) \]

Multiply both sides by 7 (7 is positive, so the inequality sign does not change):

\[ 4x + 6 > 14(x-3) \]
Hint: Multiply every term inside the bracket by 14 — do not forget the \(x\) term!
2 Expand, collect terms and solve for \(x\) ▶

Expand the right-hand side, then bring all \(x\) terms to one side:

\[ 4x + 6 > 14x - 42 \]
\[ 6 + 42 > 14x - 4x \]
\[ 48 > 10x \]
\[ x < \frac{24}{5} \]
Hint: Dividing (or multiplying) an inequality by a positive number keeps the sign. Here we divide by 10: \(48/10 = 24/5 = 4.8\).
✅ From inequality 1:   \(x < \dfrac{24}{5}\)   (i.e. \(x < 4.8\))
3 Solve the second inequality: \(2x - 10 \le 0\) ▶
\[ 2x - 10 \le 0 \]

Add 10 to both sides:

\[ 2x \le 10 \]

Divide both sides by 2:

\[ x \le 5 \]
Hint: This is a single-step linear inequality. Dividing by the positive number 2 keeps the \(\le\) sign.
✅ From inequality 2:   \(x \le 5\)
4 Intersect the two solution sets (Part a answer) ▶

We need values of \(x\) that satisfy both conditions at the same time:

\[ x < \frac{24}{5} \quad \text{AND} \quad x \le 5 \]

Since \(\dfrac{24}{5} = 4.8 < 5\), the condition \(x < 4.8\) is stricter. So the combined (intersection) solution is:

🎯 (a) The required solution is   \(x < \dfrac{24}{5}\)
Hint: On a number line, draw both arrows. The answer is where they overlap. Because 5 is to the right of 4.8, everything satisfying \(x < 4.8\) automatically satisfies \(x \le 5\).
5 Count the positive integers (Part b answer) ▶

Positive integers are \(1, 2, 3, 4, 5, \dots\). We need \(x < 4.8\), so \(x\) can only be:

\[ x = 1,\ 2,\ 3,\ 4 \]

Note \(x = 5\) is not included, because \(5\) is not less than \(4.8\).

Hint: Do not confuse "positive integers" with "non-negative integers". \(0\) is not positive, so it is excluded.
🎯 (b) There are 4 positive integers satisfying both inequalities.
