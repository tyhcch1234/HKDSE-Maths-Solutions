Variation & Coordinate Geometry

Direct Variation, Constants, and Area of a Triangle

Q Question

It is given that \(f(x)\) is the sum of two parts, one part varies as \(x^2\) and the other part is a constant. Suppose that \(f(2) = 59\) and \(f(7) = -121\).

(a) Find \(f(6)\). [4 marks]

(b) \(A (6, a)\) and \(B (-6, b)\) are points lying on the graph of \(y = f(x)\). Find the area of \(\Delta ABC\), where \(C\) is a point lying on the \(x\)-axis. [4 marks]

📐 Visual Exploration: Graph of \(y = f(x)\)

Drag the slider to move point \(C\) along the \(x\)-axis and observe how the area of \(\Delta ABC\) changes. The area is maximised when \(C\) is at the vertex of the parabola.

0
Area = 0 sq. units

💡 Step-by-Step Guided Solution

1

Set up the function with variation

The function \(f(x)\) is the sum of two parts:

  • One part varies as \(x^2\) → can be written as \(p x^2\)
  • The other part is a constant → can be written as \(q\)

So we can write:

\(f(x) = p x^2 + q\)

where \(p\) and \(q\) are non-zero constants.

Formula Concept: "Varries as \(x^2\)" means direct variation with \(x^2\), so the term is of the form \(k x^2\). "Constant" means it does not change with \(x\), so it is a fixed number \(q\).
2

Use given values to form equations

We are given \(f(2) = 59\) and \(f(7) = -121\).

Substitute \(x = 2\):

\(p(2)^2 + q = 59 \quad\Rightarrow\quad 4p + q = 59\)   ... (1)

Substitute \(x = 7\):

\(p(7)^2 + q = -121 \quad\Rightarrow\quad 49p + q = -121\)   ... (2)

3

Solve for \(p\) and \(q\)

Subtract equation (1) from equation (2):

\((49p + q) - (4p + q) = -121 - 59\)

\(45p = -180\)

\(p = -4\)

Substitute \(p = -4\) into (1):

\(4(-4) + q = 59\)

\(-16 + q = 59\)

\(q = 75\)

So we have:

\(f(x) = 75 - 4x^2\)

Method: This is a system of two linear equations in \(p\) and \(q\). We can solve it by elimination (subtracting equations) or substitution.
4

Find \(f(6)\)

Now substitute \(x = 6\) into \(f(x) = 75 - 4x^2\):

\(f(6) = 75 - 4(6)^2\)

\(= 75 - 4(36)\)

\(= 75 - 144\)

\(f(6) = -69\)

Therefore, the answer to part (a) is \(-69\).

5

Part (b): Identify points \(A\) and \(B\)

Points \(A(6, a)\) and \(B(-6, b)\) lie on \(y = f(x)\).

From part (a), \(a = f(6) = -69\).

Since \(f(-6) = 75 - 4(-6)^2 = 75 - 144 = -69\), we have \(b = -69\).

So the coordinates are:

\(A(6, -69)\) and \(B(-6, -69)\)

Notice that both points have the same \(y\)-coordinate, so \(AB\) is a horizontal line segment.

Key Observation: Since \(f(x) = 75 - 4x^2\) is an even function (\(f(-x) = f(x)\)), the graph is symmetric about the \(y\)-axis. So \(f(-6) = f(6)\).
6

Find the base \(AB\)

The length of \(AB\) is the difference in \(x\)-coordinates (since \(y\)-coordinates are the same):

\(AB = 6 - (-6) = 12\)

7

Find the height of the triangle

Point \(C\) lies on the \(x\)-axis. The height of \(\Delta ABC\) is the vertical distance from the line \(AB\) (which is at \(y = -69\)) to the \(x\)-axis (\(y = 0\)).

Height \(= |-69 - 0| = 69\) units

This height is constant regardless of where \(C\) is on the \(x\)-axis, because \(AB\) is horizontal.

8

Calculate the area of \(\Delta ABC\)

Area of triangle \(= \frac{1}{2} \times \text{base} \times \text{height}\)

Area \(= \frac{1}{2} \times 12 \times 69\)

\(= 6 \times 69\)

\(= 414\) square units

Therefore, the area of \(\Delta ABC\) is \(414\) square units.
