Question

The solution of $\;x-\dfrac{x-1}{2}>5\;$ or $\;1

  • A. $x>9$.
  • B. $x>12$.
  • C. $9
  • D. $x>9$.

SolutionStep by step

Step 1 · Solve branch A \[ x-\frac{x-1}{2}>5 \] Multiply both sides by $2$ (positive, so the inequality sign is unchanged): \[ 2x-(x-1)>10 \]
Hint: Put every term over a common denominator $2$, i.e. write $x=\dfrac{2x}{2}$ first.
Properties of Inequalities\(a0\Rightarrow acMultiplying \(x-\dfrac{x-1}{2}>5\) by \(2\) is safe because \(2>0\), so the sign stays \(>\).
Step 2 · Simplify branch A \[ 2x-x+1>10 \qquad\Rightarrow\qquad x+1>10 \] \[ x>9 \]
Hint: Distribute the minus sign carefully: $-(x-1)=-x+1$.
Distributive Law\(-(a-b)=-a+b\)The minus sign in front of \((x-1)\) changes both terms, giving \(2x-x+1>10\).
Step 3 · Solve branch B \[ 112 \]
Hint: Adding the same number to both sides never flips the inequality sign.
Step 4 · Combine with “or” The solution set is \[ \{x>9\}\ \cup\ \{x>12\} \] On the number line, $\{x>9\}$ already contains every point with $x>12$, so the smaller/larger interval absorbs the other: \[ (9,\infty)\ \cup\ (12,\infty)=(9,\infty) \]
Hint: With “or” take the union; with “and” take the intersection.
Union of Intervals\((a,\infty)\cup(b,\infty)=\left(\min\{a,b\},\infty\right)\)Every \(x>12\) already satisfies \(x>9\), so the smaller bound \(9\) absorbs the other.
Step 5 · Conclusion \[ \therefore\ \text{the solution is } x>9. \]
Hint: Check $x=10$: branch A gives $10-\tfrac{9}{2}=5.5>5$ ✓ — so $10$ must be in the answer, which rules out $x>12$.
Answer: \(x>9\)  →  Option A.
