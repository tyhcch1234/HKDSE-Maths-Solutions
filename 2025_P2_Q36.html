Question

Consider the following system of inequalities:

\(x \le 11\)
\(4x+5y-19 \ge 0\)
\(7x-6y+11 \ge 0\)

Let \(D\) be the region which represents the solution of the above system of inequalities. If \((x,y)\) is a point lying in \(D\), then the greatest value of \(8x-6y+11\) is

A. \(1\)    B. \(11\)    C. \(15\)    D. \(129\)

1Turn the region into its boundary lines

Region \(D\) is bounded by three lines. Find the points where pairs of them meet:

\[ \begin{cases} L_1:\; x=11\\ L_2:\; 4x+5y-19=0\\ L_3:\; 7x-6y+11=0 \end{cases} \]

A linear-programming "greatest value" always occurs at a vertex of the feasible region — so we only need the 3 corner points.
2Solve the three pairs of lines

\(L_1 \cap L_2\): put \(x=11\) into \(4(11)+5y-19=0\Rightarrow 5y+25=0\Rightarrow y=-5\).
So \(L_1\cap L_2=\color{#2563eb}{(11,-5)}\).

\(L_1 \cap L_3\): put \(x=11\) into \(7(11)-6y+11=0\Rightarrow 88-6y=0\Rightarrow y=\dfrac{44}{3}\).
So \(L_1\cap L_3=\color{#2563eb}{\left(11,\tfrac{44}{3}\right)}\).

\(L_2 \cap L_3\): solve \(4x+5y=19\) and \(7x-6y=-11\).
\(\times 6\) & \(\times 5\): \(24x+30y=114\) and \(35x-30y=-55\). Adding: \(59x=59\Rightarrow x=1\), then \(y=3\).
So \(L_2\cap L_3=\color{#2563eb}{(1,3)}\).

These three points are the only candidates for the optimum — no need to shade anything.
3Keep only the vertices that lie in \(D\)

Test each corner point against the three inequalities:

• \((11,-5)\): \(4(11)+5(-5)-19=25-25=0\;\ge 0\) ✓ but \(7(11)-6(-5)+11=118\;\ge 0\) ✓, however \(x\le 11\) ✓ … check \(4x+5y-19 = 0\ge0\) ✓.

• \(\left(11,\dfrac{44}{3}\right)\): \(7(11)-6\cdot\dfrac{44}{3}+11=88-88=0\) ✓, all constraints hold.

• \((1,3)\): \(4+15-19=0\) ✓ and \(7-18+11=0\) ✓, all constraints hold.

Only \(\left(11,\dfrac{44}{3}\right)\) and \((1,3)\) fall inside region \(D\).

The shape of \(D\) (see the shaded region on the left) is bounded above by \(L_3\) and on the right by \(x=11\).
4Evaluate the objective function at each vertex

Let \(P(x,y)=8x-6y+11\).

\[P\!\left(11,\tfrac{44}{3}\right)=8(11)-6\!\left(\tfrac{44}{3}\right)+11 =88-88+11=\color{#059669}{11}\]

\[P(1,3)=8(1)-6(3)+11=8-18+11=\color{#dc2626}{1}\]

Compare the two values — the larger one is the maximum on \(D\).
5Conclude the greatest value

Since \(11 > 1\), the greatest value of \(8x-6y+11\) on region \(D\) is \(11\).

Answer: B. \(11\)
