Trigonometry (59) · Sub-Topic: Trigonometric Identities

T13 Q37

Simplify the expression $1 + \tan^2\theta$ using a trigonometric identity.

Solution

Recall that $\tan\theta = \frac{\sin\theta}{\cos\theta}$, so $\tan^2\theta = \frac{\sin^2\theta}{\cos^2\theta}$.
Then $1+\tan^2\theta = 1+\frac{\sin^2\theta}{\cos^2\theta}$.
Write with a common denominator: $1+\frac{\sin^2\theta}{\cos^2\theta} = \frac{\cos^2\theta+\sin^2\theta}{\cos^2\theta}$.
Use $\sin^2\theta+\cos^2\theta=1$: $\frac{\cos^2\theta+\sin^2\theta}{\cos^2\theta} = \frac{1}{\cos^2\theta}$.
Since $\sec\theta = \frac{1}{\cos\theta}$, we get $\frac{1}{\cos^2\theta} = \sec^2\theta$ (where $\cos\theta \ne 0$).
Therefore, $1+\tan^2\theta = \sec^2\theta$ (for $\cos\theta \ne 0$).
