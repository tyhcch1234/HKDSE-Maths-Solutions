HKDSE 2020 Paper 1 Q4 3 marks Rate, Ratio & Variations

Ratio Problem – Step-by-Step Solution

Let \(a\), \(b\) and \(c\) be non-zero numbers such that \(\displaystyle \frac{a}{b} = \frac{6}{7}\) and \(3a = 4c\). Find \(\displaystyle \frac{b + 2c}{a + 2b}\).

[3 marks]

🧭 Guided Solution

Step 1 — Express \(a : b\) from the first condition ▼

Given \(\displaystyle \frac{a}{b} = \frac{6}{7}\), we can write the ratio as:

\[ a : b = 6 : 7 \]

💡 Hint: The ratio \(\frac{a}{b} = \frac{6}{7}\) directly gives \(a:b = 6:7\). Remember to keep the order: \(a\) first, then \(b\).
Step 2 — Express \(a : c\) from the second condition ▼

Given \(3a = 4c\), we can rearrange to find the ratio \(a : c\):

\[ \frac{a}{c} = \frac{4}{3} \quad\Rightarrow\quad a : c = 4 : 3 \]

💡 Hint: Dividing both sides by \(3c\) gives \(\frac{a}{c} = \frac{4}{3}\). Write the ratio as \(a : c = 4 : 3\).
Step 3 — Combine to get \(a : b : c\) ▼

We have \(a : b = 6 : 7\) and \(a : c = 4 : 3\).

To combine, make the term for \(a\) the same in both ratios. The LCM of 6 and 4 is 12.

RatioMultiply byNew ratio
\(a : b = 6 : 7\)×2\(12 : 14\)
\(a : c = 4 : 3\)×3\(12 : 9\)

\[ a : b : c = 12 : 14 : 9 \]

💡 Hint: The common term is \(a\). Scale both ratios so \(a\) becomes 12. Then the combined ratio is \(a : b : c = 12 : 14 : 9\).
Step 4 — Introduce a parameter \(k\) ▼

Since \(a : b : c = 12 : 14 : 9\), we can write:

\[ a = 12k,\quad b = 14k,\quad c = 9k \]

where \(k\) is a non-zero constant.

💡 Hint: Using a parameter \(k\) allows us to substitute into the expression \(\frac{b+2c}{a+2b}\) without knowing the actual values.
Step 5 — Substitute and simplify ▼

\[ \frac{b + 2c}{a + 2b} = \frac{14k + 2(9k)}{12k + 2(14k)} \]

Simplify numerator and denominator:

\[ = \frac{14k + 18k}{12k + 28k} = \frac{32k}{40k} \]

Cancel the common factor \(k\) (since \(k \neq 0\)):

\[ = \frac{32}{40} = \frac{4}{5} \]

\[ \boxed{\frac{4}{5}} \]
💡 Hint: \(k\) cancels out completely, leaving a numerical answer. Always simplify the fraction to its lowest terms.
