Place Value in Base 16

Question

\(A00000E00011_{16} =\)

  1. \(10\times16^{11} + 14\times16^{5} + 17\)
  2. \(11\times16^{11} + 15\times16^{5} + 17\)
  3. \(10\times16^{12} + 14\times16^{6} + 272\)
  4. \(11\times16^{12} + 15\times16^{6} + 272\)

Solution

Step 1 · Values of the hex digits

In base 16, \(A = 10\) and \(E = 14\). The number \(A00000E00011_{16}\) has 12 digits.

Hexadecimal Digits \(\text{A}=10,\ \text{B}=11,\ \ldots,\ \text{F}=15\) In \\(A00000E00011_{16}\\) the letters stand for \\(A=10\\) and \\(E=14\\), each counted as one digit.
Step 2 · Identify the place values

Counting places from the right (rightmost digit = \(16^{0}\)):

  • the final \(1\) is in the \(16^{0}\) place,
  • the \(1\) before it is in the \(16^{1}\) place,
  • \(E\) is in the \(16^{5}\) place,
  • \(A\) is in the \(16^{11}\) place.
Place Value in Base b \(d_{n}\ldots d_{1}d_{0}{}_{b}=d_{n}b^{n}+\cdots+d_{1}b+d_{0}\) The \\(E\\) sits five places to the left of the units digit, so its place value is \\(16^{5}\\), while \\(A\\) is in the \\(16^{11}\\) place.
Step 3 · Expand \[ A00000E00011_{16} = 10\times16^{11} + 14\times16^{5} + 1\times16 + 1\times1. \]
Step 4 · Combine the small terms \[ 1\times16 + 1 = 17, \]

so \(A00000E00011_{16} = 10\times16^{11} + 14\times16^{5} + 17\).

Final Answer: A. \(10\times16^{11} + 14\times16^{5} + 17\)

Question. Express \\(B00000D00031_{16}\\) in expanded form, where the digits are hexadecimal.

Show the worked solution
Step 1. In base \\(16\\), \\(B=11\\) and \\(D=13\\), and the numeral has \\(12\\) digits.
Step 2. Counting from the right: the last \\(1\\) is in the \\(16^{0}\\) place, the \\(3\\) in the \\(16^{1}\\) place, \\(D\\) in the \\(16^{5}\\) place and \\(B\\) in the \\(16^{11}\\) place.
Step 3. Hence \\(B00000D00031_{16}=11\times16^{11}+13\times16^{5}+3\times16+1\\).
Step 4. Combining the last two terms, \\(3\times16+1=49\\), so the value is \\(11\times16^{11}+13\times16^{5}+49\\).
Answer: \(11\times16^{11}+13\times16^{5}+49\)
