Question 5 — Ratio & Proportion in Three Variables

Find the value of a two-variable expression given two relations among $a$, $b$ and $c$.

The Question

Let $a$, $b$ and $c$ be non-zero numbers such that

$$5a = 6c \qquad\text{and}\qquad \frac{2b+7c}{b+c} = 4.$$

Find $\dfrac{5a+8b}{2b+3c}$.

(4 marks)

Ratio Proportion Simultaneous Relations Substitution with a constant $k$

Core Idea

Two separate conditions link three unknowns. Instead of solving for each unknown (which is impossible — the system is under-determined), we extract the ratio $a:b:c$ from the two conditions, then replace $a$, $b$, $c$ by $12k$, $15k$, $10k$. The constant $k$ cancels out, leaving a pure number.

Step-by-Step Solution

Start with the first given relation:

$$5a = 6c$$

Divide both sides by $5c$ so that each side becomes a ratio of one variable:

$$\frac{a}{c} = \frac{6}{5}$$

Hence

$$a:c = 6:5.$$

1M
Hint — Rearranging a proportion If $ma = nc$ with $m,n\neq 0$, then $\dfrac{a}{c}=\dfrac{n}{m}$, i.e. $a:c = n:m$. The coefficients cross over when you form the ratio.

The second condition is a fractional equation:

$$\frac{2b+7c}{b+c} = 4$$

Since $b, c$ are non-zero, $b+c \neq 0$ (otherwise the expression would be undefined — actually we must check $b+c\neq0$; the given equality guarantees it). Multiply both sides by $b+c$:

$$2b + 7c = 4(b + c)$$

Expand the bracket:

$$2b + 7c = 4b + 4c$$

Collect like terms:

$$7c - 4c = 4b - 2b \quad\Longrightarrow\quad 3c = 2b$$

So $\dfrac{b}{c} = \dfrac{3}{2}$, i.e.

$$b:c = 3:2.$$

Hint — Clearing a fraction Whenever you see $\dfrac{\text{linear}}{\text{linear}} = \text{number}$, cross-multiply first. It always collapses to a simple linear relation between the two variables.

We have two separate ratios that share the variable $c$:

$$a:c = 6:5 \qquad\text{and}\qquad b:c = 3:2.$$

Rewrite both so that the part for $c$ is the same number. The LCM of $5$ and $2$ is $10$:

$$a:c = 6:5 = 12:10$$

$$b:c = 3:2 = 15:10$$

Now both ratios share $c = 10$ (in the common scale), so we can glue them together:

$$a:b:c = 12:15:10.$$

Hint — Matching the shared term To merge $a:c$ and $b:c$, scale each ratio (multiply both parts by the same number) until the $c$-parts are equal. Then the two "$a$" and "$b$" parts can sit in one triple ratio.

Because only the ratio is fixed, the actual values of $a,b,c$ are free up to a common factor. Let

$$a = 12k,\qquad b = 15k,\qquad c = 10k,$$

where $k$ is a non-zero constant.

1M

Substitute these into the required expression:

$$\frac{5a+8b}{2b+3c} = \frac{5(12k) + 8(15k)}{2(15k) + 3(10k)}$$

1M
Hint — Why $k$ works Any three numbers with ratio $12:15:10$ can be written as $12k, 15k, 10k$ for some non-zero $k$. Choosing a letter for the common factor lets us keep full generality while doing algebra on just one symbol.

Compute numerator and denominator separately.

Numerator: $5(12k) + 8(15k) = 60k + 120k = 180k$.

Denominator: $2(15k) + 3(10k) = 30k + 30k = 60k$.

Therefore

$$\frac{5a+8b}{2b+3c} = \frac{180k}{60k} = 3.$$
