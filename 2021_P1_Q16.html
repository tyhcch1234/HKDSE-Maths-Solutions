Straight Lines & Region R

The straight lines \(L_1\) and \(L_2\) are perpendicular to each other. The \(y\)-intercept of \(L_1\) is \(3\). It is given that \(L_1\) and \(L_2\) intersect at the point \((2, 6)\). Let \(R\) be the region (including the boundary) bounded by \(L_1\), \(L_2\) and the \(x\)-axis. It is given that \(R\) represents the solution of a system of inequalities. (a) Find the system of inequalities. [3 marks] (b) Find the least value of \(8x-5y\), where \((x, y)\) is a point lying in \(R\). [2 marks]

Part (a) – Find the system of inequalities

1

Find the equation of \(L_1\)

Use the y‑intercept \((0,3)\) and the intersection point \((2,6)\).

Slope of \(L_1\):

\[ m_1 = \frac{6-3}{2-0} = \frac{3}{2} \]

Equation of \(L_1\):

\[ y - 3 = \frac{3}{2}(x - 0) \]

\[ 3x - 2y + 6 = 0 \]

Hint: Slope = \( \frac{y_2 - y_1}{x_2 - x_1} \). Point‑slope form: \( y - y_1 = m(x - x_1) \).
2

Find the equation of \(L_2\)

Since \(L_1 \perp L_2\), the slope of \(L_2\) is \(m_2 = -\frac{1}{m_1} = -\frac{2}{3}\).

Using point \((2,6)\):

\[ y - 6 = -\frac{2}{3}(x - 2) \]

\[ 2x + 3y - 22 = 0 \]

Hint: Perpendicular lines: \(m_1 \cdot m_2 = -1\).
3

Determine the inequalities

Region \(R\) is bounded by \(L_1\), \(L_2\) and the x‑axis. Test a point inside \(R\), e.g. \((2,0)\) or \((0,0)\) (not in R). We use \((2,1)\) which is inside.

For \(L_1\): \(3x - 2y + 6 \ge 0\) (region below \(L_1\) includes boundary)

For \(L_2\): \(2x + 3y - 22 \le 0\) (region below \(L_2\) includes boundary)

Above x‑axis: \(y \ge 0\)

System of inequalities:

\[ \begin{cases} 3x - 2y + 6 \ge 0 \\ 2x + 3y - 22 \le 0 \\ y \ge 0 \end{cases} \]
Hint: Pick a test point (e.g. \((2,1)\)) and substitute into each line to see the correct inequality sign.

Part (b) – Find the least value of \(8x - 5y\)

4

Identify the vertices of \(R\)

The vertices are the intersection points of the boundaries.

  • \(L_1 \cap x\text{-axis}\): set \(y=0\) in \(3x - 2(0) + 6 = 0 \Rightarrow x = -2\) → \((-2,0)\)
  • \(L_1 \cap L_2\): given as \((2,6)\)
  • \(L_2 \cap x\text{-axis}\): set \(y=0\) in \(2x + 0 - 22 = 0 \Rightarrow x = 11\) → \((11,0)\)
Hint: The minimum of a linear function over a polygon occurs at a vertex.
5

Evaluate \(8x - 5y\) at each vertex

At \((-2,0)\): \(8(-2) - 5(0) = -16\) ← smallest

At \((2,6)\): \(8(2) - 5(6) = 16 - 30 = -14\)

At \((11,0)\): \(8(11) - 5(0) = 88\)

Least value of \(8x - 5y\) is \(-16\).

Hint: Always check all vertices. The minimum is the smallest of these values.
