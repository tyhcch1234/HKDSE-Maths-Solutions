QUESTION

The H.C.F. and the L.C.M. of three expressions are $x^{2}y^{2}z$ and $x^{3}y^{4}z^{5}$ respectively. If the first expression and the second expression are $x^{3}y^{2}z^{2}$ and $x^{3}y^{3}z^{5}$ respectively, then the third expression is

  • A. $x^{2}y^{4}z$
  • B. $x^{2}y^{4}z^{2}$
  • C. $x^{3}y^{3}z$
  • D. $x^{3}y^{3}z^{2}$

Step‑by‑Step Solution

1Set up the unknown third expression.

Let the third expression be $x^{p}y^{q}z^{r}$, where $p,q,r$ are non‑negative integers.

The three expressions are then:

$\quad E_1=x^{3}y^{2}z^{2},\qquad E_2=x^{3}y^{3}z^{5},\qquad E_3=x^{p}y^{q}z^{r}.$

Hint: every term is built from the same three factors $x,y,z$ — only the powers differ, so we only need to find $p,q,r$.
2Key rule: HCF takes the minimum power, LCM takes the maximum power.

For each factor separately,

$\quad\text{power in HCF}=\min(\text{powers}),\qquad \text{power in LCM}=\max(\text{powers}).$

FactorAbout the H.C.F.About the L.C.M.Value of the power
$x$$\min(3,3,p)=2$$\max(3,3,p)=3$$p=2$
$y$$\min(2,3,q)=2$$\max(2,3,q)=4$$q=4$
$z$$\min(2,5,r)=1$$\max(2,5,r)=5$$r=1$
Hint: the HCF gives a lower bound and the LCM gives an upper bound on each power — squeeze $p,q,r$ from both sides.
3Fix $p$ using the $x$-powers.

$\min(3,3,p)=2\;\Rightarrow\;p=2$ (since $3,3>2$).

Check with the LCM: $\max(3,3,p)=\max(3,3,2)=3$ ✓

Hint: if $p\ge 3$ the minimum would stay $3$; if $p<2$ the minimum would be $p<2$. So $p$ must equal $2$.
4Fix $q$ using the $y$-powers.

$\min(2,3,q)=2\;\Rightarrow\;q\ge 2$.

$\max(2,3,q)=4\;\Rightarrow\;q\le 4$ and $q=4$ (the maximum must actually be attained).

Combining: $q=4$.

Hint: both bounds are needed — the min forces $q\ge2$, but the max forces $q=4$.
5Fix $r$ using the $z$-powers.

$\min(2,5,r)=1\;\Rightarrow\;r\le 1$ and $r=1$.

Check with the LCM: $\max(2,5,r)=\max(2,5,1)=5$ ✓

Hint: since $2>1$, the minimum is $1$ only if the third power $r$ is exactly $1$.
6State the third expression.

$\therefore$ the third expression is $x^{2}y^{4}z.$

Verify: HCF $=\min$ of each column $=x^{2}y^{2}z$ ✓   LCM $=\max$ of each column $=x^{3}y^{4}z^{5}$ ✓

Hint: always check the answer against both the given HCF and the given LCM.
Answer:  A.   $x^{2}y^{4}z$
