HKDSE Math 2020 Paper 2 Q35 Arithmetic Sequences Logarithms Trigonometric Identities

Which sequences are arithmetic?

If \(a > 0\), which of the following are arithmetic sequences?

I. \(\log a^{-3},\; \log a,\; \log a^{5}\)

II. \(8 - 4a,\; 9 - 5a,\; 10 - 6a\)

III. \(\cos(90 - a)^\circ,\; \cos 90^\circ,\; \cos(90 + a)^\circ\)

A. I and II only
B. I and III only
C. II and III only
D. I, II and III

Key Definition

A sequence is arithmetic if the difference between consecutive terms is a constant. That is, \(T_2 - T_1 = T_3 - T_2\) (the common difference).

Step-by-Step Solution

Tap each step to reveal the reasoning — try to predict the next move before you open it!

First, simplify each term using log laws: \(\log a^n = n \log a\) and \(\log a^{-3} = -3\log a\).

Sequence I becomes: \(-3\log a,\; 1\log a,\; 5\log a\)

Find the differences:

  • \(T_2 - T_1 = \log a - (-3\log a) = 4\log a\)
  • \(T_3 - T_2 = 5\log a - \log a = 4\log a\)

Since the differences are equal (\(4\log a\)), Sequence I is arithmetic.

Sequence II: \(8 - 4a,\; 9 - 5a,\; 10 - 6a\).

Find the differences:

  • \(T_2 - T_1 = (9 - 5a) - (8 - 4a) = 9 - 5a - 8 + 4a = 1 - a\)
  • \(T_3 - T_2 = (10 - 6a) - (9 - 5a) = 10 - 6a - 9 + 5a = 1 - a\)

The differences are equal (\(1 - a\)), so Sequence II is arithmetic.

Recall the trigonometric identities for complementary angles:

  • \(\cos(90^\circ - a) = \sin a\)
  • \(\cos(90^\circ + a) = -\sin a\)
  • \(\cos 90^\circ = 0\)

So the sequence is: \(\sin a,\; 0,\; -\sin a\)

Find the differences:

  • \(T_2 - T_1 = 0 - \sin a = -\sin a\)
  • \(T_3 - T_2 = -\sin a - 0 = -\sin a\)

The differences are equal (\(-\sin a\)), so Sequence III is arithmetic.

All three sequences I, II, and III have a constant common difference.

Therefore, the correct answer is D. I, II and III.

Quick Formula Sheet

  • Arithmetic Sequence: \(T_n = a + (n-1)d\), where \(d\) is the common difference.
  • Log Laws: \(\log a^n = n \log a\) and \(\log a - \log b = \log(a/b)\).
  • Trigonometric Complementary Angles: \(\cos(90^\circ - \theta) = \sin\theta\) and \(\cos(90^\circ + \theta) = -\sin\theta\).
