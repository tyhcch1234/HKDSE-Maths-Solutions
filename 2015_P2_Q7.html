HKDSE 2015 · Paper 2 · Q7
If $\beta$ is a root of the equation $$4\beta^{2}-5\beta-1=0,$$ then $7+10\beta-8\beta^{2}=$
A. 5 B. 7 C. 9 D. 11
1Write down what “root” means
Since $\beta$ is a root of $4\beta^{2}-5\beta-1=0$, $$4\beta^{2}-5\beta-1=0 .$$
A root is a value that makes the equation true — so we may substitute it into the equation itself.
Root of an Equation \(f(\beta)=0\ \Longrightarrow\ \text{substitute }\beta\text{ into the equation}\) Since \(\beta\) is a root, \(4\beta^{2}-5\beta-1=0\), so the block \(4\beta^{2}-5\beta\) equals \(1\).
2Rearrange to identify the reusable block
Add $1$ to both sides: $$4\beta^{2}-5\beta=1 .$$
We only need to know the value of the combination $4\beta^{2}-5\beta$, not $\beta$ itself.
Matching Coefficients \(7+10\beta-8\beta^{2}=7-2\left(4\beta^{2}-5\beta\right)\) The target contains \(-8\beta^{2}+10\beta\), which is exactly \(-2\) times the block \(4\beta^{2}-5\beta\).
3Match the target expression to that block
Factor the target: $$7+10\beta-8\beta^{2}=7-2\left(4\beta^{2}-5\beta\right).$$ Check: expanding gives $-8\beta^{2}+10\beta+7$. ✓
Look for the same coefficients: $-8\beta^{2}+10\beta=-2\left(4\beta^{2}-5\beta\right)$.
4Substitute the value
Put $4\beta^{2}-5\beta=0+1=1$… rather, use the root relation directly: $$4\beta^{2}-5\beta-1=0 \;\Longrightarrow\; 4\beta^{2}-5\beta=1 .$$ Hence $$7+10\beta-8\beta^{2}=7-2(1)=7-2=5 .$$
The answer is numeric — no need to solve for $\beta$ (its value is irrational).
Substitution Using the Given Equation \(7+10\beta-8\beta^{2}=-2\left(4\beta^{2}-5\beta-1\right)+5\) Because \(4\beta^{2}-5\beta-1=0\), the bracket vanishes and the value is \(5\), without solving for \(\beta\).
5Alternative one-line check
Note that $$7+10\beta-8\beta^{2}=-2\left(4\beta^{2}-5\beta-1\right)+5 =-2(0)+5=5 .$$
This is the official method: rewrite the target as $-2\times(\text{the given equation})+5$.
Answer: A. 5

Question. If \(\beta\) is a root of \(2\beta^{2}+3\beta-4=0\), then \(5-6\beta-4\beta^{2}=\)

Show the worked solution
Step 1. Since \(\beta\) is a root, \(2\beta^{2}+3\beta-4=0\), i.e. \(2\beta^{2}+3\beta=4\).
Step 2. Match the target to this block: \(5-6\beta-4\beta^{2}=5-2\left(2\beta^{2}+3\beta\right)\).
Step 3. Substitute \(2\beta^{2}+3\beta=4\): the expression equals \(5-2(4)=5-8=-3\).
Step 4. Check the official method: \(5-6\beta-4\beta^{2}=-2\left(2\beta^{2}+3\beta-4\right)+5-8=-2(0)-3=-3\) ✓.
Answer: \(-3\)
