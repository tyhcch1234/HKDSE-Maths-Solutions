Linear Programming — Find \(k\)

Linear Programming Feasible Region Corner Point Method Objective Function

Question:

Consider the following system of inequalities:

\(0 \le x \le 2\)

\(2x + y + 3 \ge 0\)

\(x + y + 1 \le 0\)

Let \(D\) be the region which represents the solution of the above system. Find the constant \(k\) such that the least value of \(4x + 3y + k\) is \(24\), where \((x, y)\) is a point lying in \(D\).

A. 25 B. 27 C. 37 D. 53

Step-by-Step Solution

The system defines a bounded polygon \(D\) on the Cartesian plane:

  • \(0 \le x \le 2\) (vertical strip)
  • \(2x + y + 3 \ge 0 \;\Rightarrow\; y \ge -2x - 3\)
  • \(x + y + 1 \le 0 \;\Rightarrow\; y \le -x - 1\)

💡 The feasible region \(D\) is the intersection of these half-planes.

Solve the boundary lines in pairs:

  • \(x = 0\) & \(x + y + 1 = 0\):
    \((0, -1)\)
  • \(x + y + 1 = 0\) & \(x = 2\):
    \((2, -3)\)
  • \(2x + y + 3 = 0\) & \(x = 2\):
    \((2, -7)\)
  • \(2x + y + 3 = 0\) & \(x = 0\):
    \((0, -3)\)

💡 These four points are the vertices of the shaded region \(D\).

Substitute each \((x, y)\) into the objective function \(4x + 3y + k\):

At \((0, -1)\): \(4(0) + 3(-1) + k = -3 + k\)

At \((2, -3)\): \(4(2) + 3(-3) + k = -1 + k\)

At \((2, -7)\): \(4(2) + 3(-7) + k = -13 + k\)

At \((0, -3)\): \(4(0) + 3(-3) + k = -9 + k\)

💡 The smallest value among these is \(-13 + k\) (at \((2, -7)\)).

We are told the least value is \(24\):

\(-13 + k = 24\)

Solving gives:

\(k = 37\)

✅ The answer is C. 37

📌 Key Takeaway

For a linear objective function on a convex feasible region, the minimum or maximum always occurs at a corner point (vertex) of the region. Evaluate the function at every vertex, compare the values, and use the given condition to solve for the unknown constant.
