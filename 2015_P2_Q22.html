Question & Solution

2015 MC #22

If an interior angle of a regular polygon is 5 times an exterior angle of the polygon, which of the following is/are true?

  1. Each interior angle of the polygon is $150^\circ$.
  2. The number of diagonals of the polygon is 6.
  3. The number of folds of rotational symmetry of the polygon is 6.
A. I only
B. II only
C. I and III only
D. II and III only
STEP 1 · Set up the angle relation
Interior and Exterior Angles of a Polygon \(\text{int.}\ \angle+\text{ext.}\ \angle=180^{\circ}\) The interior angle is 5 times the exterior angle, and the two are supplementary at each vertex.

Let $n$ be the number of sides of the regular polygon.

At each vertex,
the interior angle and the exterior angle are supplementary:

$$\text{int. } \angle + \text{ext. } \angle = 180^\circ$$

The question says the interior angle is 5 times the exterior angle,
so let the exterior angle be $x$:

$$5x + x = 180^\circ \;\Rightarrow\; 6x = 180^\circ \;\Rightarrow\; x = 30^\circ$$

So each exterior angle is $30^\circ$ and each interior angle is $150^\circ$.

STEP 2 · Find the number of sides $n$
Sum of Exterior Angles of a Polygon \(n\times\text{ext.}\ \angle=360^{\circ}\) With each exterior angle \(30^{\circ}\), \(n=360^{\circ}\div30^{\circ}=12\).

The exterior angles of any convex polygon add up to $360^\circ$:

$$n \times 30^\circ = 360^\circ \;\Rightarrow\; n = 12$$

So the polygon is a regular 12-gon (a dodecagon).

Equivalent check: sum of interior angles $=(n-2)\times180^\circ$ is 5 times $360^\circ$. Then $(n-2)\times180 = 1800 \Rightarrow n=12$. ✓
STEP 3 · Test statement I

Each interior angle of a regular 12-gon is

$$\frac{(12-2)\times 180^\circ}{12} = \frac{1800^\circ}{12} = 150^\circ$$

TRUE Statement I is correct.

STEP 4 · Test statement II — count diagonals
Number of Diagonals of a Polygon \(\dfrac{n(n-3)}{2}\) For the 12-gon this gives \(\dfrac{12\times9}{2}=54\), not 6.

Fix a vertex $P$. It cannot be joined to itself or to its 2 neighbours,
so the number of diagonals from $P$ is

$$12 - 3 = 9$$

Counting over all 12 vertices gives $12\times 9 = 108$ endpoints,
and each diagonal is counted twice:

$$\text{number of diagonals} = \frac{12\times 9}{2} = 54$$

FALSE Statement II says 6,
so it is incorrect.

General formula: number of diagonals $=\dfrac{n(n-3)}{2}$. Here $\dfrac{12\times9}{2}=54$.
STEP 5 · Test statement III — rotational symmetry

A regular $n$-gon has rotational symmetry about its centre through angles

$$\frac{360^\circ}{n},\; 2\cdot\frac{360^\circ}{n},\; \dots,\; n\cdot\frac{360^\circ}{n}$$

So it has exactly $n$ folds (orders) of rotational symmetry.
For $n=12$, that is $12$, not $6$.

FALSE Statement III is incorrect.

STEP 6 · Conclusion

Only statement I is true.

Answer: A  ·  I only
Quick recap: ext. $\angle = 30^\circ$ → $n=12$ → int. $\angle = 150^\circ$ ;
diagonals $=54$ ✗;
rotational folds $=12$ ✗.

Question. If an interior angle of a regular polygon is 4 times an exterior angle of the polygon, which of the following are true? I. Each interior angle is \(144^{\circ}\). II. The number of diagonals of the polygon is 35. III. The number of folds of rotational symmetry of the polygon is 5.

Show the worked solution
Step 1. Let the exterior angle be \(x\): \(4x+x=180^{\circ}\), so \(x=36^{\circ}\) and the interior angle is \(144^{\circ}\).
Step 2. The exterior angles add up to \(360^{\circ}\), so \(n=360^{\circ}\div36^{\circ}=10\): a regular 10-gon.
Step 3. Statement I: \(\dfrac{(10-2)\times180^{\circ}}{10}=144^{\circ}\) — true.
Step 4. Statement II: number of diagonals \(=\dfrac{10(10-3)}{2}=35\) — true.
Step 5. Statement III: a regular 10-gon has 10 folds of rotational symmetry,
not 5 — false.
So only I and II are true.
Answer: I and II only
