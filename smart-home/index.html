01方案總覽：誰在控制誰

整個系統只有 4 個角色。ESP32 是「腦」，繼電器是「手」，你手上的瀏覽器就是「遙控器」。

架構：瀏覽器 → 路由器 → ESP32 → 繼電器 → 電器。全程在你自己的內網，資料不出家門。

① 為什麼揀 ESP32

WiFi + 藍牙內建、3.3V GPIO、雙核 240MHz，價錢同一杯奶茶差不多。比 ESP8266 多腳位、多 RAM，開網頁伺服器更穩。

② 為什麼要繼電器

ESP32 的腳位只出 3.3V / 十幾 mA，直接接電燈會即刻燒。繼電器做「隔離開關」：低壓訊號控制高壓通斷。

③ 為什麼自己寫網頁

唔靠米家 / Tuya 雲端，無延遲、無斷網風險、無私隱問題；想加咩功能就加咩，仲可以接入 Home Assistant。

03接線：6 條線就搞定

先做「低壓側」（ESP32 ↔ 繼電器），確認網頁按得到「咯」一聲，最後才接 220V 側。

ESP32 腳位接到繼電器作用
5V（VIN）VCC繼電器線圈供電（5V）
GNDGND共地，一定要接，否則訊號亂跳
GPIO 26IN1第 1 路：廳燈
GPIO 27IN2第 2 路：風扇
GPIO 4DHT11 DATA溫濕度（另接 3V3 / GND）
GPIO 14HC-SR501 OUT人體感應（另接 5V / GND）

低壓側 4 條線（紅＝5V、灰＝GND、綠＝訊號）；高壓側只借繼電器的 COM / NO 做開關，ESP32 本身完全不接觸 220V。

落手做：5 個步驟

  1. 斷電。拔掉所有電源，包括牆身插頭。做強電部分時，總掣都要關。
  2. 接低壓 4 條線。5V→VCC、GND→GND、GPIO26→IN1、GPIO27→IN2。用母對母杜邦線，插實聽到「咔」一聲。
  3. 先試繼電器。插 USB 供電，跑下面第 04 節的測試程式，聽聽有無「咯、咯」的切換聲，模塊上紅燈有無跟住亮。
  4. 接強電。把要控制的電器火線（L）剪開，兩端分別接 COM 同 NO；中性線（N）直通不動。NO = 平時斷開，斷電時電器係關的，最安全。
  5. 通電測試。先插電器，再插 ESP32。用手機開網頁按開關，聽到繼電器響、燈著就成功。
安全紅線（一定要睇）：
  • 220V 會致命。唔肯定 L／N／E 邊條係邊條，就唔好自己剪線，找註冊電工。
  • 繼電器模塊的電路板背面有機會帶電，一定要放入絕緣膠盒，唔好裸露放在木枱上。
  • 金屬外殼電器（雪櫃、洗衣機、熱水壺）要接接地線（E），不要用這種模塊搞，改用有認證的智能插座。
  • 第一次試，建議先用 5V LED 燈條 / 小風扇代替 220V 電器，成功後才升級。

04燒錄程式：Arduino IDE 15 分鐘

ESP32 用 Arduino IDE 寫最簡單，香港／台灣的電腦都裝得到。全程免費。

事前準備

  1. 裝 Arduino IDE 2.x：去 arduino.cc 下載。裝好後開 File → Preferences，在「Additional boards manager URLs」貼上
    https://espressif.github.io/arduino-esp32/package_esp32_index.json
  2. 裝 ESP32 開發板包：左邊 Boards Manager 搜 esp32，安裝 esp32 by Espressif。
  3. 裝 DHT 庫：Library Manager 搜 DHT sensor library，裝 Adafruit 版本（會問要唔要一併裝 Adafruit Unified Sensor，按「Install all」）。
  4. 揀板：Tools → Board → ESP32 Arduino → ESP32 Dev Module；Port 揀你插住的那個（Windows 係 COMx，Mac 係 /dev/cu.usbserial-xxxx）。
  5. 插線、上傳：把下面整段程式貼入新 Sketch，改 WiFi 名同密碼，按 → 上傳。如果卡在 Connecting...，按住板上 BOOT 鍵再按一下 EN 鍵就得。

/* ============================================================
   智能家居 Web 控制器 v1.0
   硬件：ESP32 NodeMCU-32S + 2 路 5V 光耦繼電器 + DHT11 + HC-SR501
   功能：網頁開關 2 路電器、顯示溫濕度、人體感應自動開燈
   ============================================================ */

#include <WiFi.h>
#include <WebServer.h>
#include <ESPmDNS.h>
#include <DHT.h>

// 內嵌控制頁（完整內容放喺檔案最尾，避免阻住主程式閱讀）
extern const char PAGE[];

// ---------- 1. 改成你自己的 WiFi ----------
const char* SSID = "YOUR_WIFI_NAME";
const char* PASS = "YOUR_WIFI_PASSWORD";

// ---------- 2. 腳位設定 ----------
#define CH 2                                   // 繼電器路數
const uint8_t RELAY_PIN[CH] = {26, 27};        // GPIO26, GPIO27
const char*  CH_NAME[CH]    = {"廳燈", "風扇"};
const bool   ACTIVE_LOW     = true;            // 低電平觸發模塊 = true

#define DHT_PIN 4
#define DHT_TYPE DHT11
#define PIR_PIN 14

// ---------- 3. 自動化參數 ----------
bool  AUTO_PIR   = true;                       // 人體感應自動開燈
const uint32_t PIR_HOLD_MS = 180000;           // 無人 3 分鐘後關燈

DHT dht(DHT_PIN, DHT_TYPE);
WebServer server(80);
bool relayState[CH] = {false, false};
uint32_t lastMotion = 0;

// ============ 工具函式 ============
void setRelay(uint8_t i, bool on) {
  relayState[i] = on;
  digitalWrite(RELAY_PIN[i], (on != ACTIVE_LOW) ? HIGH : LOW);
}

String stateJson() {
  float t = dht.readTemperature();
  float h = dht.readHumidity();
  bool  pir = digitalRead(PIR_PIN) == HIGH;
  String s = "{\"relay\":[";
  for (uint8_t i = 0; i < CH; i++) {
    if (i) s += ",";
    s += relayState[i] ? "1" : "0";
  }
  s += "],\"t\":";
  s += isnan(t) ? String("\"-\"") : String(t, 1);
  s += ",\"h\":";
  s += isnan(h) ? String("\"-\"") : String(h, 0);
  s += ",\"pir\":";
  s += pir ? "1" : "0";
  s += ",\"up\":";
  s += String(millis() / 1000);
  s += "}";
  return s;
}

// ============ HTTP 處理 ============
void handleRoot() {
  server.send_P(200, "text/html; charset=utf-8", PAGE);
}

void handleState() {
  server.send(200, "application/json", stateJson());
}

void handleSet() {
  if (!server.hasArg("ch") || !server.hasArg("v")) {
    server.send(400, "text/plain; charset=utf-8", "缺少參數：ch / v");
    return;
  }
  int  c = server.arg("ch").toInt();
  bool v = server.arg("v") == "1";
  if (c < 0 || c >= CH) {
    server.send(400, "text/plain; charset=utf-8", "ch 超出範圍");
    return;
  }
  setRelay(c, v);
  Serial.printf("[WEB] ch%d -> %s\n", c, v ? "ON" : "OFF");
  server.send(200, "application/json", stateJson());
}

// ============ setup ============
void setup() {
  Serial.begin(115200);
  delay(200);

  for (uint8_t i = 0; i < CH; i++) {
    pinMode(RELAY_PIN[i], OUTPUT);
    setRelay(i, false);                  // 上電預設全部關
  }
  pinMode(PIR_PIN, INPUT);
  dht.begin();

  WiFi.mode(WIFI_STA);
  WiFi.begin(SSID, PASS);
  Serial.print("連線 WiFi");
  uint32_t start = millis();
  while (WiFi.status() != WL_CONNECTED && millis() - start < 15000) {
    delay(500);
    Serial.print(".");
  }

  if (WiFi.status() == WL_CONNECTED) {
    Serial.println("\n已連線！網址： http://" + WiFi.localIP().toString());
  } else {
    // 連不上就自己開熱點，方便現場改設定
    Serial.println("\n連線失敗，開啟 AP：SmartHome-Setup");
    WiFi.mode(WIFI_AP);
    WiFi.softAP("SmartHome-Setup", "12345678");
    Serial.println("AP 網址： http://192.168.4.1");
  }

  if (MDNS.begin("smarthome")) {
    Serial.println("亦可以用 http://smarthome.local");
    MDNS.addService("http", "tcp", 80);
  }

  server.on("/", handleRoot);
  server.on("/api/state", handleState);
  server.on("/api/set", handleSet);
  server.onNotFound([]() {
    server.send(404, "text/plain; charset=utf-8", "404 Not Found");
  });
  server.begin();
  Serial.println("Web 伺服器已啟動");
  lastMotion = millis();
}

// ============ loop ============
void loop() {
  server.handleClient();

  // 人體感應自動化
  if (AUTO_PIR) {
    if (digitalRead(PIR_PIN) == HIGH) {
      lastMotion = millis();
      if (!relayState[0]) setRelay(0, true);
    } else if (relayState[0] && millis() - lastMotion > PIR_HOLD_MS) {
      setRelay(0, false);
    }
  }
  delay(20);
}

06加感應器：由「手動」變「自動」

開關只是第一步。加兩個十幾蚊的感應器，就可以做到「回家自動開燈、太濕自動抽濕」。

DHT11 溫濕度

接 VCC→3V3、GND→GND、DATA→GPIO4（模塊通常已內建上拉電阻，唔使自己加）。精度 ±2°C / ±5%RH，睇趨勢夠用；要準就換 DHT22 / SHT30。

自動化例子：濕度 > 75% 且有人在 → 開抽濕機；濕度 < 55% → 關。

HC-SR501 人體感應

接 VCC→5V、GND→GND、OUT→GPIO14。板上兩個旋鈕：左邊調靈敏度／距離（3–7 米），右邊調延時（0.3–200 秒）。

通電後有 30–60 秒熱機期，期間會亂觸發，屬正常。

加一段「太濕自動開抽濕機」的邏輯（放入 loop）
// 每 5 秒讀一次，避免 DHT11 讀得太密而出錯
static uint32_t lastRead = 0;
if (millis() - lastRead > 5000) {
  lastRead = millis();
  float h = dht.readHumidity();
  if (!isnan(h)) {
    if (h > 75 && digitalRead(PIR_PIN) == HIGH) setRelay(2, true);   // 太濕 + 有人 → 開
    if (h < 55)                                    setRelay(2, false);  // 乾返 → 關
  }
}
小技巧：把 setRelay() 當成唯一的「動作出口」，所有自動化都經它，就永遠不會出現「網頁顯示開、實際關」的狀態不同步。

07通電前安全檢查表

逐項打勾，全部 ✓ 才好插電。這部分比程式重要一百倍。

  • ☐ 繼電器 VCC / GND 無接反（接反會即刻燒）
  • ☐ ESP32 與繼電器 共地（GND 相連）
  • ☐ 強電接 COM / NO，不是 NC
  • ☐ 火線（L）有經過保險絲或原有斷路器
  • ☐ 繼電器額定電流 ≥ 電器電流（10A ≈ 2200W）
  • ☐ 220V 接點有用絕緣膠盒包好，摸不到金屬
  • ☐ 電線用足夠線徑（≥1.5mm²），接頭鎖實不鬆
  • ☐ 模塊遠離水源、窗邊、金屬枱面
  • ☐ 第一次測試有人在場，唔好通宵無人看管
  • ☐ 唔肯定 → 停手，找註冊電工（香港：註冊電業承辦商）
最後提醒：本頁示範的是低壓電子控制原理。任何涉及固定電力裝置（入牆線路）的改動，在香港受《電力條例》規管，須由註冊電業承辦商施工。想零風險入門，可以先用「智能插座 + 繼電器控制 5V 燈條」練手，完全唔碰 220V。

08常見問題

新手最容易撞到的 7 個坑。

按了網頁，繼電器有「嗒」聲但電器唔動？

多數係接錯 COM／NO，或者你接的是 NC（常閉）。用萬用電錶蜂鳴檔量一下：未通電時 COM–NO 應該不通、COM–NC 應該通；通電切換後反過來。

繼電器完全無反應，指示燈都唔亮？

兩個原因：① 5V 供電不足 — ESP32 的 5V 腳經 USB 出來只有幾百 mA，繼電器一吸就跌電，改用獨立 5V 2A 火牛，GND 同 ESP32 共地；② 買了 12V 線圈版本，5V 推唔郁。看模塊上印的字，要 5V。

ESP32 成日自己重啟／WiFi 斷？

供電問題佔九成。繼電器切換瞬間電流突波會拉低電壓，加一個 1000µF 電解電容在 5V–GND 之間通常就搞定。另外 ESP32 只支援 2.4GHz WiFi，5GHz 連不上。

可唔可以控制冷氣機／電視？

可以，但唔用繼電器 — 冷氣機停電再通電不會自動開機，要用 紅外發射模塊（IR LED + 38kHz）模擬遙控器訊號，淘寶約 ¥3。呢個係另一個項目，之後可以加。

停電再來電，電器會不會自己開？

不會。程式上電時 setRelay(i, false) 全部歸零，加上用 NO 接點，斷電即斷路，符合安全要求。

會唔會被人由外面 hack 入來開關？

只要不把 80 port 直接映射出公網，外部就完全連不到。要異地控制就用 Tailscale（免費、零設定、點對點加密）或 Cloudflare Tunnel，唔好開 DMZ。

想接入 Home Assistant / Apple 家庭？

最簡單：HA 用 rest 或 command_line 直接 call /api/set；想雙向同步就裝 ESPHome 重寫（YAML 幾行，仲有自動發現）。Apple 家庭就要經 HA 的 HomeKit Bridge 轉接。

自己做 vs 買現成智能插座，邊個抵？

買現成：$50–80、即插即用、有認證，適合控制單一電器。自己做：¥40 可控多路、可加感應器、可自訂邏輯、資料不出街，適合想學嘢同做整合。兩者可以並存。
