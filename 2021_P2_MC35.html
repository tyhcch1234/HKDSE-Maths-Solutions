Complex Numbers & Real / Imaginary Parts

Let \(\alpha\) be a real number. Define

\[ w = \frac{\alpha + i}{\alpha - i}, \quad u = w + \frac{1}{w}, \quad v = w - \frac{1}{w}. \]

Which of the following must be true?

I. \(u\) is a real number.
II. The real part of \(v\) is equal to \(0\).
III. The imaginary part of \(w\) is equal to the imaginary part of \(2w\).

A. I and II only    B. I and III only    C. II and III only    D. I, II and III

Complex Numbers Real & Imaginary Parts Algebraic Manipulation Rationalisation
1
Simplify \(w\)

Rationalise the denominator by multiplying numerator and denominator by the conjugate \(\alpha + i\).

\[ w = \frac{\alpha + i}{\alpha - i} \cdot \frac{\alpha + i}{\alpha + i} = \frac{(\alpha + i)^2}{\alpha^2 + 1} = \frac{\alpha^2 - 1 + 2\alpha i}{\alpha^2 + 1} \]

So \(w = \dfrac{\alpha^2 - 1}{\alpha^2 + 1} + \dfrac{2\alpha}{\alpha^2 + 1}i\).

Hint: For a complex number \(z = a + bi\), the real part is \(a\) and the imaginary part is \(b\). Here, \(\operatorname{Re}(w) = \frac{\alpha^2 - 1}{\alpha^2 + 1}\) and \(\operatorname{Im}(w) = \frac{2\alpha}{\alpha^2 + 1}\).
2
Check statement I: \(u\) is real
I

Recall \(u = w + \frac{1}{w}\). Compute using \(w = \frac{\alpha + i}{\alpha - i}\) and \(\frac{1}{w} = \frac{\alpha - i}{\alpha + i}\).

\[ u = \frac{\alpha + i}{\alpha - i} + \frac{\alpha - i}{\alpha + i} = \frac{(\alpha + i)^2 + (\alpha - i)^2}{(\alpha - i)(\alpha + i)} \]

Expand the numerator: \((\alpha + i)^2 + (\alpha - i)^2 = (\alpha^2 + 2\alpha i + i^2) + (\alpha^2 - 2\alpha i + i^2) = 2\alpha^2 - 2\).

Denominator: \(\alpha^2 + 1\). Thus

\[ u = \frac{2\alpha^2 - 2}{\alpha^2 + 1} = \frac{2(\alpha^2 - 1)}{\alpha^2 + 1} \]

This is a real number because it has no imaginary part.

Statement I is true.
3
Check statement II: \(\operatorname{Re}(v) = 0\)
II

Recall \(v = w - \frac{1}{w}\). Compute:

\[ v = \frac{\alpha + i}{\alpha - i} - \frac{\alpha - i}{\alpha + i} = \frac{(\alpha + i)^2 - (\alpha - i)^2}{(\alpha - i)(\alpha + i)} \]

Numerator: \((\alpha^2 + 2\alpha i + i^2) - (\alpha^2 - 2\alpha i + i^2) = 4\alpha i\).

Denominator: \(\alpha^2 + 1\). So

\[ v = \frac{4\alpha}{\alpha^2 + 1}i \]

Thus \(\operatorname{Re}(v) = 0\).

Statement II is true.
4
Check statement III: \(\operatorname{Im}(w) = \operatorname{Im}(2w)\)?
III

From Step 1, we have \(\operatorname{Im}(w) = \dfrac{2\alpha}{\alpha^2 + 1}\).

Also, \(2w = 2\left(\dfrac{\alpha^2 - 1}{\alpha^2 + 1} + \dfrac{2\alpha}{\alpha^2 + 1}i\right)\), so \(\operatorname{Im}(2w) = 2 \cdot \dfrac{2\alpha}{\alpha^2 + 1} = \dfrac{4\alpha}{\alpha^2 + 1}\).

Equality \(\operatorname{Im}(w) = \operatorname{Im}(2w)\) would require

\[ \frac{2\alpha}{\alpha^2 + 1} = \frac{4\alpha}{\alpha^2 + 1} \quad \Longrightarrow \quad 2\alpha = 4\alpha \quad\Longrightarrow\quad \alpha = 0. \]

The statement says “must be true” for all real \(\alpha\), but this equality fails when \(\alpha \neq 0\).

Statement III is false.
