Q Question Multiple Choice

Which of the following statements about the graph of \[ y = 16 - (x-6)^2 \] is true?

  • A. The graph cuts the \(x\)-axis.
  • B. The graph opens upwards.
  • C. The \(y\)-intercept of the graph is \(16\).
  • D. The graph passes through the origin.

A Part (a) — Does the graph open upwards or downwards? 1M

Move the slider to see how the vertex \((6,16)\) sits above the \(x\)-axis. Toggle the axis-crossing points on/off.

Equation: y = 16 − (x − 6)²
Vertex: (6, 16)  |  Coefficient of (x−6)²: −1 < 0
Direction: opens downwards
x-intercepts: x = 2 and x = 10 → graph cuts the x-axis ✔
0 / 3 steps revealed
1Read off the vertex1M

In vertex form \(y = a(x-h)^2 + k\), the vertex is \((h,k)\).

\[ y = 16 - (x-6)^2 = -1\,(x-6)^2 + 16 \]

So \(a=-1\), \(h=6\), \(k=16\).

The minus in front of \((x-6)^2\) is the key — it is the value of \(a\).
Vertex = \((6,\,16)\).
2Determine opening direction1A

The coefficient of \((x-6)^2\) is \(-1 < 0\).

\[\therefore \text{ the graph opens downwards.}\]
Positive \(a\) → opens up (U-shape). Negative \(a\) → opens down (∩-shape).
The graph opens downwards ⇒ option B is false.
3Does it cut the x-axis?1A

Vertex \((6,16)\) lies above the \(x\)-axis (\(k=16>0\)) and the graph opens downwards — like a hill whose peak is above ground.

Solve \(16-(x-6)^2=0 \Rightarrow (x-6)^2=16 \Rightarrow x-6=\pm 4\).

\[ x = 2 \quad\text{or}\quad x = 10 \]
A downward-opening parabola with a peak above the axis must cross the axis on both sides.
The graph cuts the x-axis at \(x=2\) and \(x=10\) ⇒ option A is TRUE.

B Part (b) — Check the \(y\)-intercept 1M

The \(y\)-intercept is found by setting \(x=0\). Adjust the slider for \(x\) to watch the point \((0,y)\) move along the curve.

Current point: (0.0, -20.00)
When x = 0: y = 16 − (0 − 6)² = 16 − 36 = −20
y-intercept = −20 ≠ 16 and ≠ 0 → the graph does not pass through the origin
0 / 2 steps revealed
1Substitute \(x=0\)1M

Put \(x=0\):

\[ y = 16 - (0-6)^2 = 16 - 36 = -20 \]
Careful! \((0-6)^2=(-6)^2=36\), not \(-36\). Then \(16-36=-20\).
The \(y\)-intercept is \(-20\), NOT \(16\).
2Test options C and D1A

Option C claims the \(y\)-intercept is \(16\). We found \(-20\) ⇒ false.

Option D claims the graph passes through the origin \((0,0)\). This requires \(y=0\) when \(x=0\), i.e. the \(y\)-intercept must be \(0\). Since it is \(-20\), the graph does not pass through the origin ⇒ false.

A graph passes through the origin iff its \(y\)-intercept equals 0.
C and D are both false. The only true statement is A.

★ Summary of Answers

  • Vertex: \((6,\,16)\) — lies above the \(x\)-axis.
  • Opening: coefficient of \((x-6)^2\) is \(-1<0\) → opens downwards.
  • x-intercepts: \(x=2\) and \(x=10\) → the graph cuts the \(x\)-axis.
  • y-intercept: \(y=-20\) (not \(16\), not \(0\)).
  • Correct choice: A — “The graph cuts the \(x\)-axis.”
