Coordinate Geometry — Locus of a point equidistant from two parallel lines

Coordinate Geometry Parallel Lines Perpendicular Distance Locus Mid-parallel Line

Question Multiple Choice

The equations of the straight lines \(L_1\) and \(L_2\) are \[3x - y + 7 = 0 \quad \text{and} \quad 12x - 4y - 11 = 0\] respectively. Let \(P\) be a moving point in the rectangular coordinate plane such that the perpendicular distance from \(P\) to \(L_1\) is equal to the perpendicular distance from \(P\) to \(L_2\). Find the equation of the locus of \(P\).

A.\(8x - 24y - 17 = 0\)
B.\(8x - 24y + 17 = 0\)
C.\(24x - 8y - 17 = 0\)
D.\(24x - 8y + 17 = 0\) ✓

Part 1 · Explore the geometry Concept

Drag the slider to move the point \(P\). Watch the two perpendicular distances \(d_1\) and \(d_2\). The locus is the set of all \(P\) for which \(d_1=d_2\).

Slide \(P\) around: the distances to \(L_1\) and \(L_2\) change, but on the dashed locus they are equal.

Step A · Are \(L_1\) and \(L_2\) parallel? 1M

Both lines have the same slope, so they are parallel and the equidistant locus must be parallel to them too.
Step 11M

Find the slope of each line by rewriting in slope-intercept form \(y = mx + c\).

\[ L_1: 3x - y + 7 = 0 \;\Rightarrow\; y = 3x + 7 \quad \Rightarrow \quad m_1 = 3 \] \[ L_2: 12x - 4y - 11 = 0 \;\Rightarrow\; 4y = 12x - 11 \;\Rightarrow\; y = 3x - \tfrac{11}{4} \quad \Rightarrow \quad m_2 = 3 \]
Hint: If two lines have the same slope \(m_1 = m_2\), they are parallel. Then every locus point equidistant from them lies on the line exactly halfway between them.
Result: \(m_1 = m_2 = 3\), so \(L_1 \parallel L_2\).
Step 21A

Find the \(y\)-intercepts of both lines.

\[ L_1: y = 3x + 7 \;\Rightarrow\; c_1 = 7 \] \[ L_2: y = 3x - \tfrac{11}{4} \;\Rightarrow\; c_2 = -\tfrac{11}{4} \]
Hint: For parallel lines \(y = 3x + c_1\) and \(y = 3x + c_2\), the equidistant locus is the parallel line whose intercept is the average: \[ c = \frac{c_1 + c_2}{2}. \]
Result: \(c_1 = 7\), \(c_2 = -\dfrac{11}{4}\).

Step B · Find the locus equation 1M 1A

The locus (red) must sit exactly halfway between the two parallel lines, so its intercept is the average of \(7\) and \(-\tfrac{11}{4}\).
Step 31M

The locus is the parallel line halfway between \(L_1\) and \(L_2\), so its \(y\)-intercept is

\[ c = \frac{c_1 + c_2}{2} = \frac{7 + \left(-\frac{11}{4}\right)}{2} = \frac{\frac{28}{4}-\frac{11}{4}}{2} = \frac{\frac{17}{4}}{2} = \frac{17}{8}. \]
Hint: Average the two intercepts. Equivalently, average the two whole equations, since both lines share the same \(x\)- and \(y\)-coefficients.
Result: \(y = 3x + \dfrac{17}{8}\).
Step 41A

Convert to general form (clear fractions):

\[ y = 3x + \frac{17}{8} \;\Rightarrow\; 8y = 24x + 17 \;\Rightarrow\; 24x - 8y + 17 = 0. \]
Hint: Match with the choices. \(24x - 8y + 17 = 0\) matches option D exactly.
Answer: \(24x - 8y + 17 = 0\) — Option D.
0 / 2

Check · Perpendicular-distance method Verification

Directly set the perpendicular distances equal: for a line \(ax+by+c=0\), \[ d = \frac{|ax + by + c|}{\sqrt{a^2+b^2}}. \] Since \(L_1\) and \(L_2\) have the same \(x,y\)-coefficients ratio, the denominators match and the absolute values collapse to a linear (midway) equation.

Write \(L_2\) with the same coefficient pattern \(3x - y\):

\[ 12x - 4y - 11 = 0 \;\Rightarrow\; 3x - y - \frac{11}{4} = 0. \] \[ \left| \frac{3x - y + 7}{\sqrt{3^2+(-1)^2}} \right| = \left| \frac{3x - y - \frac{11}{4}}{\sqrt{3^2+(-1)^2}} \right| \Rightarrow \left| 3x - y + 7 \right| = \left| 3x - y - \frac{11}{4} \right|. \] The two parallel lines \(3x-y+7=0\) and \(3x-y-\tfrac{11}{4}=0\) straddle the locus, so we take opposite signs: \[ 3x - y + 7 = -\left(3x - y - \frac{11}{4}\right) \] \[ 3x - y + 7 = -3x + y + \frac{11}{4} \] \[ 6x - 2y + 7 - \frac{11}{4} = 0 \] \[ 6x - 2y + \frac{17}{4} = 0 \;\Rightarrow\; 24x - 8y + 17 = 0. \]
Confirms: \(24x - 8y + 17 = 0\), Option D.

Summary of Answers

  • Slopes: \(m_1 = m_2 = 3\) ⟹ \(L_1 \parallel L_2\).
  • \(y\)-intercepts: \(c_1 = 7\), \(c_2 = -\dfrac{11}{4}\).
  • Locus intercept: \(c = \dfrac{c_1+c_2}{2} = \dfrac{17}{8}\).
  • Locus equation: \(y = 3x + \dfrac{17}{8}\) ⟹ \(24x - 8y + 17 = 0\).
  • Correct option: D.
  • Key idea: the locus of points equidistant from two parallel lines is the line exactly midway between them.
