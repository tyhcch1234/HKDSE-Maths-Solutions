Let \(k\) be a constant. Find the range of values of \(k\) such that \[ x^2 + kx + 2k + 5 \ge 0 \] for any real number \(x\).

Key takeaway

For \(ax^2+bx+c \ge 0\) for all real \(x\), we need \(a > 0\) and the discriminant \(\Delta = b^2 - 4ac \le 0\).
Here \(a=1 > 0\), so only \(\Delta \le 0\) matters. This gives \(k \le -8\) or \(k \ge -4\). (Option D)
