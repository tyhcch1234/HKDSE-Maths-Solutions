Question [4 marks]

5.
(a) Find the range of values of $x$ which satisfy both $$7(x-2) \le \frac{11x+8}{3}$$ and $$6-x < 5.$$

(b) How many integers satisfy both inequalities in (a)?

STEP 1
Multiplication Property of Inequalities \(a\le b \;\Longrightarrow\; ac\le bc\quad(c>0)\) Multiplying \(7(x-2)\le\dfrac{11x+8}{3}\) by the positive number \(3\) keeps the inequality sign unchanged.

Solve the first inequality:

$$7(x-2) \le \frac{11x+8}{3}$$

Multiply both sides by $3$ (positive, so the inequality sign is unchanged):

$$21(x-2) \le 11x+8$$

$$21x-42 \le 11x+8$$

$$10x \le 50$$

$$\boxed{x \le 5}$$

Hint: clear the fraction first, then collect $x$-terms on one side.
STEP 2
Reversing the Inequality Sign \(a-b\) Dividing \(-x<-1\) by \(-1\) turns the result into \(x>1\), with the sign reversed.

Solve the second inequality:

$$6-x < 5$$

$$-x < -1$$

Divide by $-1$, so reverse the sign:

$$\boxed{x > 1}$$

Hint: multiplying/dividing by a negative number flips the inequality.
STEP 3
Intersection of Two Solution Sets \(x>a \text{ and } x\le b \;\Longrightarrow\; a Combining \(x\le5\) with \(x>1\) leaves the overlap \(1

Combine both results (intersection):

$$x > 1 \quad \text{and} \quad x \le 5$$

$$\therefore\ 1 < x \le 5$$

Hint: the answer is the overlap of the two solution sets.
STEP 4

(b) Count the integers in $1 < x \le 5$:

$$x = 2,\ 3,\ 4,\ 5$$

There are $\mathbf{4}$ such integers.

Hint: $x=1$ is excluded (strict inequality), $x=5$ is included.
Answer: (a) $1 < x \le 5$   •   (b) $4$ integers
