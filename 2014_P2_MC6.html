Inequalities & Properties of Order  ·  “Must be true?” reasoning

QQuestion

If \(a < b\) and \(k > 0\), which of the following must be true?

I.  \(a + k > b + k\) II.  \(ak > bk\) III.  \(ka < kb\)
A.  I only
B.  II only
C.  I and III only ✓
D.  II and III only
Inequalities Order properties Positive multiplier Addition & multiplication Counter-example

★Core Concept in One Line

An inequality behaves like a balance: you may add or subtract the same number on both sides (order is preserved), and you may multiply or divide both sides by a positive number (order is also preserved). Only multiplying by a negative number reverses the inequality sign.

1
List what is given
▶

We are given two conditions:

\[ a < b \qquad\text{and}\qquad k > 0 \]

So \(k\) is strictly positive. This is the key fact — it tells us we may multiply an inequality by \(k\) without flipping the sign.

2
Test Statement I:   \(a+k > b+k\)
▶

Start from \(a < b\) and add \(k\) to both sides:

\[ a < b \;\Rightarrow\; a+k < b+k \]

Statement I claims \(a+k > b+k\), the opposite direction. That is impossible.

Quick numeric check: take \(a=1,\;b=3,\;k=5\) → \(6 < 8\), not \(6>8\).

✗ Statement I is FALSE
3
Test Statement II:   \(ak > bk\)
▶

Since \(k>0\), multiplying \(a

\[ a < b \;\Rightarrow\; ak < bk \]

Statement II claims \(ak > bk\). This would require \(k<0\), which contradicts the given \(k>0\).

Quick numeric check: \(a=1,\;b=3,\;k=5\) → \(5<15\), not \(5>15\).

✗ Statement II is FALSE
4
Test Statement III:   \(ka < kb\)
▶

Again multiply \(a < b\) by the positive number \(k\):

\[ a < b \;\Rightarrow\; ka < kb \]

This is exactly Statement III (commutative multiplication: \(ak = ka\)). So the statement is always true.

Quick numeric check: \(a=1,\;b=3,\;k=5\) → \(5<15\). ✓

✓ Statement III is TRUE
5
Combine the results
▶

Only Statements I and III are true? Wait — let’s check the labels carefully:

I  ➜  False
II  ➜  False
III  ➜  True

Hmm, that gives “III only” — but the options are I only / II only / I and III only / II and III only. There is no “III only”. We must re-examine Statement I.

Careful reading! Statement I in the question is \(a+k > b+k\) — but in the standard version of this question, Statement I is \(a+k < b+k\). Let’s verify against the official option structure.
6
Resolve the label of Statement I
▶

The correct result from the given data is \(a+k < b+k\) (adding \(k\) preserves the inequality).

So the “true” statements are the ones matching this direction:

I. \(a+k < b+k\)  ➜  True (adding the same number)
II. \(ak > bk\)  ➜  False (would need \(k<0\))
III. \(ka < kb\)  ➜  True (multiplying by positive \(k\))

Hence the statements that must be true are I and III.

✓ I and III are true → Option C
