[2020MC#35]

If $a>0$, which of the following are arithmetic sequences?

I.   $\log a^{-3},\ \log a,\ \log a^{5}$
II.   $8-4a,\ 9-5a,\ 10-6a$
III.   $\cos(90-a)^\circ,\ \cos 90^\circ,\ \cos(90+a)^\circ$

  • A. I and II only
  • B. I and III only
  • C. II and III only
  • D. I, II and III
1

Key idea & given information

Test for an Arithmetic Sequence \(T_{2}-T_{1}=T_{3}-T_{2}\ (=d)\) Each of I, II, III is checked by subtracting consecutive terms and comparing.

Three numbers $T_1,T_2,T_3$ form an arithmetic sequence iff $T_2-T_1=T_3-T_2$,
i.e. the common difference between consecutive terms is constant.

Here $a>0$,
so $\log a$ is a real number and all angles are in degrees.

Test each of I,
II, III separately using the same "subtract consecutive terms" method.

2

Sequence I: $\log a^{-3},\ \log a,\ \log a^{5}$

Power Law of Logarithms \(\log a^{k}=k\log a\quad(a>0)\) This turns \(\log a^{-3},\ \log a,\ \log a^{5}\) into \(-3\log a,\ \log a,\ 5\log a\).

Write each term using the power law $\log a^{k}=k\log a$:

  • $T_1=\log a^{-3}=-3\log a$
  • $T_2=\log a=1\cdot\log a$
  • $T_3=\log a^{5}=5\log a$

Differences:

  • $T_2-T_1=\log a-(-3\log a)=\log a+3\log a=4\log a$
  • $T_3-T_2=5\log a-\log a=4\log a$

Both differences equal $4\log a$  
⇒ 
I is an arithmetic sequence. ✓

Find the difference of consecutive terms — "power law of logarithms" is the key trick.

3

Sequence II: $8-4a,\ 9-5a,\ 10-6a$

Differences:

  • $T_2-T_1=(9-5a)-(8-4a)=9-5a-8+4a=1-a$
  • $T_3-T_2=(10-6a)-(9-5a)=10-6a-9+5a=1-a$

Both differences equal $1-a$  
⇒ 
II is an arithmetic sequence. ✓

Here each term is linear in $a$ — the $a$-coefficient decreases by 1 each time.

4

Sequence III: $\cos(90-a)^\circ,\ \cos 90^\circ,\ \cos(90+a)^\circ$

Complementary Angle Identities \(\cos(90^{\circ}-\theta)=\sin\theta,\qquad \cos(90^{\circ}+\theta)=-\sin\theta\) So the three terms become \(\sin a^{\circ},\ 0,\ -\sin a^{\circ}\), an A.P. with difference \(-\sin a^{\circ}\).

Use the compound-angle (supplementary) identities:

  • $\cos(90-a)^\circ=\sin a^\circ$  
    (i.e. $\cos(90^\circ-\theta)=\sin\theta$)
  • $\cos 90^\circ=0$
  • $\cos(90+a)^\circ=-\sin a^\circ$  
    (i.e. $\cos(90^\circ+\theta)=-\sin\theta$)

Differences:

  • $T_2-T_1=0-\sin a^\circ=-\sin a^\circ$
  • $T_3-T_2=-\sin a^\circ-0=-\sin a^\circ$

Both differences equal $-\sin a^\circ$  
⇒ 
III is an arithmetic sequence. ✓

$\cos(90^\circ-\theta)=\sin\theta$ and $\cos(90^\circ+\theta)=-\sin\theta$ — so the three terms are $+\sin a^\circ,\ 0,\ -\sin a^\circ$,
forming an A.P. with common difference $-\sin a^\circ$.

5

Conclusion

I, II and III all have a constant common difference and are arithmetic sequences.

Answer: D — I, II and III
PRACTICESimilar question — try it yourself

Question. If \(a>0\), which of the following are arithmetic sequences? I. \(\log a^{-2},\ \log a^{2},\ \log a^{6}\) II. \(5-3a,\ 7-5a,\ 9-7a\) III. \(\sin(90-a)^{\circ},\ \sin 90^{\circ},\ \sin(90+a)^{\circ}\) A. I and II only B. I and III only C. II and III only D. I, II and III [1 mark]

Show the worked solution
Step 1. Three terms form an A.P. exactly when \(T_{2}-T_{1}=T_{3}-T_{2}\).
Step 2. I: the terms are \(-2\log a,\ 2\log a,\ 6\log a\), and both differences equal \(4\log a\) \u2713.
Step 3. II: \(T_{2}-T_{1}=(7-5a)-(5-3a)=2-2a\) and \(T_{3}-T_{2}=(9-7a)-(7-5a)=2-2a\) \u2713.
Step 4. III: the terms are \(\cos a^{\circ},\ 1,\ \cos a^{\circ}\);
the differences \(1-\cos a^{\circ}\) and \(\cos a^{\circ}-1\) are opposite, so they are equal only when \(\cos a^{\circ}=1\). Not an A.P. in general \u2717.
Step 5. Only I and II are always arithmetic sequences.
Answer: A. I and II only
