HKDSE Math 2020 Paper 2 Q6 Topic 4: Polynomials

Remainder Theorem & Factor Theorem

Find the value of \(a\), then evaluate \(g(2)\).

📝

Question

Let \(g(x) = ax^3 + 4ax^2 - 24\), where \(a\) is a constant. If \(x+2\) is a factor of \(g(x)\), then \(g(2) =\)

A. −96
B. 0
C. 3
D. 48 ✓
Factor Theorem Remainder Theorem Polynomials Substitution
💡

Key Concept

Factor Theorem

If \((x - k)\) is a factor of polynomial \(P(x)\), then \(P(k) = 0\).

Equivalent form for \((x + 2)\)

Since \(x+2 = x-(-2)\), the factor theorem gives \(g(-2) = 0\).

🧭

Step-by-Step Solution

Step 1 Apply the Factor Theorem

Since \(x+2\) is a factor of \(g(x)\), we substitute \(x = -2\):

$$g(-2) = 0$$
Hint: \(x+2 = 0 \Rightarrow x = -2\). This is the root we substitute.
Step 2 Substitute into \(g(x)\)

Substitute \(x = -2\) into \(g(x) = ax^3 + 4ax^2 - 24\):

$$a(-2)^3 + 4a(-2)^2 - 24 = 0$$
Step 3 Simplify the powers

Evaluate the integer powers:

\((-2)^3 = -8\),   \((-2)^2 = 4\)
\(a(-8) + 4a(4) - 24 = 0\)
Step 4 Collect like terms and solve for \(a\)
\(-8a + 16a - 24 = 0\)
\(8a - 24 = 0\)
\(8a = 24\)
\(\therefore a = 3\)
Step 5 Rewrite \(g(x)\) with \(a = 3\)
$$g(x) = 3x^3 + 12x^2 - 24$$
Step 6 Evaluate \(g(2)\)

Substitute \(x = 2\):

\(g(2) = 3(2)^3 + 12(2)^2 - 24\)
\(= 3(8) + 12(4) - 24\)
\(= 24 + 48 - 24\)
\(\therefore g(2) = 48\)

✓ Correct Answer: D. 48

Common Mistakes

  • 1. Substituting \(x = 2\) instead of \(x = -2\). Since \(x+2 = 0 \Rightarrow x=-2\).
  • 2. Sign errors with \((-2)^3 = -8\) and \((-2)^2 = +4\).
  • 3. Stopping after finding \(a = 3\) without computing the required \(g(2)\).
