HKDSE Math 2012 Paper 2 Q14 Estimation & Error Approximation Inequalities

Maximum Number of Pieces

Question

The length of a piece of thin string is measured as 25 m correct to the nearest m. If the string is cut into n pieces such that the length of each piece is measured as 5 cm correct to the nearest cm, find the greatest possible value of n.

A. 445
B. 566
C. 567
D. 650

Step-by-Step Solution

The length of the whole string is measured as 25 m correct to the nearest m.

This means the true length \( L \) satisfies:

\[ 24.5 \text{ m} \le L < 25.5 \text{ m} \]

In centimetres:

\[ 2450 \text{ cm} \le L < 2550 \text{ cm} \]

Hint: "Correct to the nearest m" means the maximum error is \( 0.5 \text{ m} \).

Each piece has length measured as 5 cm correct to the nearest cm.

So the true length of each piece \( \ell_i \) satisfies:

\[ 4.5 \text{ cm} \le \ell_i < 5.5 \text{ cm} \]

This must be true for every piece \( i = 1, 2, \ldots, n \).

Hint: The smallest possible piece is \( 4.5 \text{ cm} \).

The total length of all pieces equals the whole string:

\[ L = \ell_1 + \ell_2 + \cdots + \ell_n \]

Since each \( \ell_i \ge 4.5 \text{ cm} \):

\[ L \ge 4.5n \]

But also \( L < 2550 \text{ cm} \), so:

\[ 4.5n < 2550 \]

Divide both sides by 4.5:

\[ n < \frac{2550}{4.5} \]
\[ n < 566.666\ldots \]

Since \( n \) must be a positive integer, the greatest possible value is:

\[ n = 566 \]

Answer: B. 566

Key Takeaway

  • Always convert units to a consistent scale (here: cm).
  • The maximum length of the whole string is strictly less than 2550 cm.
  • The minimum length of each piece is at least 4.5 cm.
  • To maximize \( n \), use the smallest possible piece length and the largest possible total length.
  • Solve the inequality \( 4.5n < 2550 \) and take the largest integer \( n \).
