HKDSE Math 2018 Paper 1 Q4 [3 marks]

Probability with Balls in a Box

#Probability #Algebra #LinearEquation

Question

A box contains \(n\) white balls, \(5\) black balls and \(8\) red balls. If a ball is randomly drawn from the box, then the probability of drawing a red ball is \(\frac{2}{5}\). Find the value of \(n\).

Visual representation (counts are illustrative):

White (n): … (n balls) | Black (5): | Red (8):

Step-by-Step Solution

1

Find the total number of balls.

The box contains:

  • \(n\) white balls
  • \(5\) black balls
  • \(8\) red balls

Total number of balls \(= n + 5 + 8 = n + 13\).

Hint

Total count = sum of all individual color counts.

2

Write the probability of drawing a red ball.

Probability \(= \frac{\text{number of red balls}}{\text{total number of balls}} = \frac{8}{n + 13}\).

Hint

P(event) = (favorable outcomes) / (total outcomes). Here, favorable = red balls = 8.

3

Set up the equation.

Given that the probability is \(\frac{2}{5}\), we have:

\[ \frac{8}{n + 13} = \frac{2}{5} \]

Hint

Equate the expression from Step 2 to the given probability.

4

Solve for \(n\).

Cross-multiply:

\[ 8 \times 5 = 2 \times (n + 13) \]

\[ 40 = 2n + 26 \]

\[ 2n = 14 \]

\[ n = 7 \]

Hint

Cross-multiplication: if \(\frac{a}{b} = \frac{c}{d}\), then \(ad = bc\).
