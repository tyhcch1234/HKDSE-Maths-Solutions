Step 1
\[\angle ABC = \angle ABE + \angle CBE = 90^\circ\]
Hint: \(BE\) lies inside \(\angle ABC\), so \(\angle CBE = \angle ABC - \angle ABE\).

\[\angle CBE = 90^\circ - 28^\circ = 62^\circ\]
\(\boxed{\angle CBE = 62^\circ}\) — the answer is B.

Summary of Answers

  • \(AC\) is a diameter \(\Rightarrow\) \(\angle ABC = 90^\circ\) (angle in semi-circle).
  • \(\angle ABE = \angle ADE = \mathbf{28^\circ}\) (angles in the same segment).
  • \(\angle CBE = \angle ABC - \angle ABE = 90^\circ - 28^\circ = \mathbf{62^\circ}\).
  • Correct option: B. \(62^\circ\).
