2014 Paper 2 · Question 21

Geometry — Angles and Equal Chords in a Circle

Circle Geometry Equal Chords Angle Sum of Polygon Congruent Triangles RHS

Q The Question

In the figure, \(O\) is the centre of the circle \(ABCDEF\). \(\triangle PQR\) intersects the circle at \(A, B, C, D, E\) and \(F\). If \(\angle QPR = 38^\circ\) and \(AB = CD = EF\), then \(\angle QOR =\)

A. \(71^\circ\)    B. \(90^\circ\)    C. \(109^\circ\)    D. \(142^\circ\)

(Multiple-choice · 1 mark) Note: the letter \(P\) labels the top vertex of \(\triangle PQR\).

a Part (a) — Set up the perpendicular feet & find \(\angle YOZ\)

\(\angle QPR\) = 38° \(\angle OZQ\) = 90° \(\angle OYR\) = 90° \(\angle YOZ\) = 142°
38°
Step 11M

Let \(X\), \(Y\) and \(Z\) be the feet of the perpendiculars from \(O\) to \(QR\), \(RP\) and \(PQ\) respectively.

So \(\angle OZQ = 90^\circ\), \(\angle OYR = 90^\circ\), \(\angle OXQ = 90^\circ\).

Hint: Drop perpendiculars from the centre \(O\) onto the three sides of \(\triangle PQR\). These are the shortest distances from \(O\) to each side — exactly the distances used for the "equal chords, equidistant from centre" property.
Step 21M

In quadrilateral \(PYOZ\), the angle sum is \(360^\circ\):

\[ \angle YOZ = 360^\circ - \angle YPZ - \angle PYO - \angle PZO \] \[ = 360^\circ - 38^\circ - 90^\circ - 90^\circ = 142^\circ \]
Hint: \(\angle YPZ = \angle QPR = 38^\circ\) because \(PZ\) lies along \(PQ\) and \(PY\) lies along \(PR\). Also \(\angle PYO = \angle PZO = 90^\circ\) by construction.
Step 31A

So \(\angle YOZ = 142^\circ\), and at a point \(O\):

\[ \angle XOY + \angle ZOX = 360^\circ - 142^\circ = 218^\circ \]
Answer: \(\angle YOZ = 142^\circ\) and \(\angle XOY + \angle ZOX = 218^\circ\).

b Part (b) — Prove \(\triangle QOX \cong \triangle QOZ\) and split the angles

\(OX\) = radius \(OZ\) = radius \(\angle QOX\) = — \(\angle QOZ\) = — \(\angle ROX\) = —
100°
Step 11M

Consider \(\triangle QOX\) and \(\triangle QOZ\):

\[ \angle OXQ = \angle OZQ = 90^\circ \quad \text{(construction)} \] \[ OQ = OQ \quad \text{(common side)} \] \[ OX = OZ \quad \text{(equal chords } CD = EF \text{, equidistant from centre)} \]
Hint: Chords \(CD\) and \(EF\) are equal, so they are equidistant from the centre \(O\). Since \(OX \perp CD\) and \(OZ \perp EF\), this means \(OX = OZ\).
Step 21A

Hence:

\[ \triangle QOX \cong \triangle QOZ \quad \text{(RHS)} \] \[ \therefore \angle QOX = \angle QOZ \quad \text{(corr. } \angle \text{s, } \cong \triangle \text{s)} \] \[ \angle QOX = \tfrac{1}{2}\angle ZOX \]
Hint: Two right-angled triangles with equal hypotenuse \(OQ\) and equal leg \(OX = OZ\) must be congruent (RHS). Congruent triangles have all corresponding angles equal.
Step 31A

By the same argument (equal chords \(AB = CD\), so \(OY = OX\); common side \(OR\)):

\[ \triangle ROX \cong \triangle ROY \quad \Rightarrow \quad \angle ROX = \tfrac{1}{2}\angle XOY \]
Answer: \(\angle QOX = \tfrac{1}{2}\angle ZOX\) and \(\angle ROX = \tfrac{1}{2}\angle XOY\).
0 / 3

c Part (c) — Compute \(\angle QOR\)

\(\angle ZOX + \angle XOY\) = 218° \(\angle QOX\) = — \(\angle ROX\) = — \(\angle QOR\) = —
38°
Step 11M

From part (a), \(\angle YOZ = 142^\circ\), so at \(O\):

\[ \angle ZOX + \angle XOY = 360^\circ - 142^\circ = 218^\circ \]
Hint: \(\angle ZOX\), \(\angle XOY\) and \(\angle YOZ\) together make one full turn about \(O\).
Step 21M

Now \(OQ\) lies inside \(\angle ZOX\) and \(OR\) lies inside \(\angle XOY\) (both rays pass through the interior of \(\triangle PQR\)), so:

\[ \angle QOR = \angle QOX + \angle ROX = \tfrac{1}{2}\angle ZOX + \tfrac{1}{2}\angle XOY \]
Hint: Use the half-angle results from part (b). Each of the two big angles at \(O\) is bisected by a ray from \(O\) to a vertex of the triangle.
Step 31A

Factor out \(\tfrac12\) and substitute the total:

\[ \angle QOR = \tfrac{1}{2}(\angle ZOX + \angle XOY) = \tfrac{1}{2}\cdot 218^\circ = 109^\circ \]
Answer: \(\angle QOR = 109^\circ\) — option C.
0 / 3

✓ Summary of Results

  • Feet of perpendiculars from \(O\): \(X\) on \(QR\), \(Y\) on \(RP\), \(Z\) on \(PQ\).
  • Quadrilateral \(PYOZ\): \(\angle YOZ = 360^\circ - 38^\circ - 90^\circ - 90^\circ = \mathbf{142^\circ}\).
  • At point \(O\): \(\angle XOY + \angle ZOX = 360^\circ - 142^\circ = \mathbf{218^\circ}\).
  • Equal chords \(\Rightarrow\) equidistant from centre: \(OX = OY = OZ\).
  • \(\triangle QOX \cong \triangle QOZ\) (RHS) \(\Rightarrow \angle QOX = \tfrac12\angle ZOX\).
  • \(\triangle ROX \cong \triangle ROY\) (RHS) \(\Rightarrow \angle ROX = \tfrac12\angle XOY\).
  • \(\angle QOR = \tfrac12(\angle ZOX + \angle XOY) = \tfrac12(218^\circ) = \mathbf{109^\circ}\).
  • Correct option: C — \(109^\circ\).
