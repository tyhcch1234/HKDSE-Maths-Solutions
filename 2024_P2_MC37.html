HKDSE Math 2024 Paper 2 Q37

Inequalities & Linear Programming

Question

Consider the following system of inequalities:

\[ \begin{cases} x - 2y \ge 1 \\ x + 4y \le 13 \\ 2x - y \ge -1 \end{cases} \]

Let \(R\) be the region which represents the solution of the above system of inequalities. Find the constant \(c\) such that the least value of \(P(x,y) = 5x - 2y + c\) is \(22\), where \((x,y)\) is a point lying in \(R\).

Step-by-Step Solution

1

Identify the Feasible Region & Corner Points

The feasible region \(R\) is a polygon bounded by the three lines. The corners are the intersections of these lines.

• Intersection of \(x - 2y = 1\) and \(x + 4y = 13\) → \((5, 2)\)

• Intersection of \(x - 2y = 1\) and \(2x - y = -1\) → \((-1, -1)\)

• Intersection of \(x + 4y = 13\) and \(2x - y = -1\) → \((1, 3)\)

How to find intersections

Solve pairs of linear equations simultaneously. For example, from \(x - 2y = 1\) and \(x + 4y = 13\), subtract to get \(6y = 12\) → \(y = 2\), then \(x = 5\).

2

Express the Objective Function

The objective function is given as \(P(x,y) = 5x - 2y + c\). The least value of \(P\) on \(R\) is 22.

\[ P(x,y) = 5x - 2y + c \]

Why check corner points?

For a linear objective function over a convex polygonal region, the maximum and minimum occur at the vertices (corner points).

3

Evaluate \(P\) at Each Corner Point

Since the minimum of \(P\) is 22, \(P\) must be \(\ge 22\) at every corner point.

At \((5,2)\):   \(P = 5(5) - 2(2) + c = 25 - 4 + c = 21 + c\) \(21 + c \ge 22 \;\Rightarrow\; c \ge 1\)
At \((-1,-1)\):   \(P = 5(-1) - 2(-1) + c = -5 + 2 + c = -3 + c\) \(-3 + c \ge 22 \;\Rightarrow\; c \ge 25\)
At \((1,3)\):   \(P = 5(1) - 2(3) + c = 5 - 6 + c = -1 + c\) \(-1 + c \ge 22 \;\Rightarrow\; c \ge 23\)

Important condition

The least value is exactly 22, so \(P \ge 22\) for all points in \(R\). Checking corners gives the strongest constraints.

4

Combine the Conditions to Find \(c\)

We need \(c\) to satisfy all three inequalities simultaneously. The most restrictive condition is:

\(c \ge 25\) Since \(c \ge 1\), \(c \ge 23\), and \(c \ge 25\), the minimum valid \(c\) is \(25\).

Therefore, the constant \(c\) is 25.

✅ Answer: C. 25

Key takeaway: For linear programming, evaluate the objective function at each corner point of the feasible region to find the minimum or maximum.
