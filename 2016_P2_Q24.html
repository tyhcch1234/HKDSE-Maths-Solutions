[2016 MC #24] If the sum of the interior angles of a regular $n$-sided polygon is $3240^\circ$, which of the following is true?

A. The value of $n$ is 16.    B. Each exterior angle of the polygon is $18^\circ$.
C. The number of diagonals of the polygon is 20.    D. Each interior angle of the polygon is $160^\circ$.
STEP 1 · Angle-sum formula
The sum of the interior angles of an $n$-sided polygon is $$(n-2)\times 180^\circ .$$
This is the most basic polygon fact — a triangle ($n=3$) gives $(3-2)\times180^\circ=180^\circ$. ✓
Angle Sum of a Polygon \(\text{sum of interior angles}=(n-2)\times180^{\circ}\) A triangle \((n=3)\) gives \(180^{\circ}\), so the formula fits the given total \(3240^{\circ}\).
STEP 2 · Find n
$$(n-2)\times180^\circ = 3240^\circ$$ $$n-2 = 3240^\circ \div 180^\circ = 18$$ $$\boxed{n = 20}$$ So option A is false (it wrongly says $n=16$).
Divide by $180^\circ$ first — it is much faster than expanding the bracket.
STEP 3 · Interior & exterior angle
Each interior angle $$=\frac{3240^\circ}{20}=162^\circ .$$ Each exterior angle $$=180^\circ-162^\circ = 18^\circ .$$ So option B is TRUE, and option D is false ($162^\circ\neq160^\circ$).
Interior and Exterior Angles of a Regular Polygon \(\text{exterior angle}=\dfrac{360^{\circ}}{n},\qquad \text{interior angle}=180^{\circ}-\dfrac{360^{\circ}}{n}\) With \(n=20\) the interior angle is \(162^{\circ}\) and the exterior angle \(18^{\circ}\).
STEP 4 · Count the diagonals (check C)
An exterior angle can also be found by the exterior-angle sum: $$\text{each exterior angle}=\frac{360^\circ}{20}=18^\circ .$$ From a vertex $P$, the diagonals join $P$ to the other $20-1-2=17$ non-adjacent vertices: $$\text{number of diagonals}=\frac{17\times20}{2}=170 .$$ So option C is false (it wrongly says 20).
Number of Diagonals of a Polygon \(\dfrac{n(n-3)}{2}\) Each of the \(20\) vertices joins \(17\) non-adjacent vertices, and each diagonal is counted twice.
STEP 5 · Conclusion
OptionClaimVerdict
A$n=16$✗ ($n=20$)
Bexterior angle $=18^\circ$✓
C20 diagonals✗ (170)
Dinterior angle $=160^\circ$✗ ($162^\circ$)
Answer:  B — each exterior angle of the polygon is $18^\circ$.

Question. If the sum of the interior angles of a regular \(n\)-sided polygon is \(2520^{\circ}\), which of the following is true? A. The value of \(n\) is \(18\). B. Each exterior angle of the polygon is \(22.5^{\circ}\). C. The number of diagonals of the polygon is \(120\). D. Each interior angle of the polygon is \(157^{\circ}\). [1 mark]

Show the worked solution
Step 1. \((n-2)\times180^{\circ}=2520^{\circ}\), so \(n-2=2520^{\circ}\div180^{\circ}=14\) and \(n=16\) (A is false).
Step 2. Each exterior angle \(=\dfrac{360^{\circ}}{16}=22.5^{\circ}\), so B is true.
Step 3. Each interior angle \(=\dfrac{2520^{\circ}}{16}=157.5^{\circ}\), so D is false.
Step 4. Number of diagonals \(=\dfrac{16(16-3)}{2}=\dfrac{16\times13}{2}=104\), so C is false.
Step 5. Only B is true.
Answer: B \u2014 each exterior angle is \(22.5^{\circ}\)
