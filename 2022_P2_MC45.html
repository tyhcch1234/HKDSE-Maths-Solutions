Statistics — Effect of adding a constant & multiplying by a negative number on mean, standard deviation and inter-quartile range

Mean Standard Deviation Inter-quartile Range Linear Transformation

Question MC · 4 marks

It is given that \(d\) is a real number. Let \(S_1\) be a group of numbers \[ \{d-6,\; d-2,\; d-1,\; d+3,\; d+5,\; d+7\} \] and \(S_2\) be another group of numbers \[ \{d-7,\; d-5,\; d-3,\; d+1,\; d+2,\; d+6\}. \] Which of the following is/are true?

  1. I.  The means of \(S_1\) and \(S_2\) are equal.
  2. II.  The standard deviations of \(S_1\) and \(S_2\) are equal.
  3. III. The inter-quartile ranges of \(S_1\) and \(S_2\) are equal.
A. I only
B. II only
C. I and III only
D. II and III only

Key Idea — Reduce to a base set \(S_3\) Setup

Both groups are translations of the same base set. Set \[ S_3 = \{-6,\;-2,\;-1,\;3,\;5,\;7\}. \] Then \(S_1\) is obtained from \(S_3\) by adding \(d\), while \(S_2\) is obtained from \(S_3\) by multiplying by \(-1\) and then adding \(d\): \[ S_1 = S_3 + d, \qquad S_2 = -S_3 + d. \] Use the slider below to see how the two data sets move as \(d\) changes. The two dot plots are drawn on a common number line.

0
Hint — shifting and flipping. Adding the same constant \(d\) to every value slides the whole dot plot. Multiplying every value by \(-1\) reflects the dot plot about 0. A reflection does not change how far apart the values are, so the spread stays the same.

Statement I — Are the means equal? Part I

Compare the means \(\bar{x}_1\) and \(\bar{x}_2\) directly, using the fact that both are shifts of \(S_3\).

0
Step 1M1

First compute the mean of the base set \(S_3\):

\[ \bar{x}_3 = \frac{-6+(-2)+(-1)+3+5+7}{6} = \frac{6}{6} = 1. \]
Hint. The sum of \(S_3\) is \(6\), so \(\bar{x}_3 = 1\). Everything else is built from this.
Step 2M1

Since \(S_1 = S_3 + d\), adding \(d\) to every number adds \(d\) to the mean:

\[ \bar{x}_1 = \bar{x}_3 + d = 1 + d. \]

Since \(S_2 = -S_3 + d\), multiply every number of \(S_3\) by \(-1\) then add \(d\):

\[ \bar{x}_2 = (-1)\bar{x}_3 + d = -1 + d. \]
Hint. \(\bar{x}_2 = -1+d = d-1\), while \(\bar{x}_1 = 1+d = d+1\). They differ by \(2\).
Step 3A1

Comparing them:

\[ \bar{x}_1 = d+1 \neq d-1 = \bar{x}_2 \quad\text{for all } d. \]
Statement I is FALSE. The means are never equal (they differ by \(2\)).

Statement II — Are the standard deviations equal? Part II

A horizontal shift by \(d\) and a reflection by \(-1\) do not change how far apart the data values are. Here you compare the actual spreads numerically.

0
Step 1M1

Let the standard deviation of \(S_3\) be \(\sigma\). A translation does not change the standard deviation:

\[ \sigma_1 = \sigma. \]
Hint. Adding \(d\) to each data value moves the mean by \(d\) too, so \((x-\bar{x})\) is unchanged. Hence the standard deviation is unchanged.
Step 2M1

Multiplying every value by \(-1\) makes each deviation become \(-(x-\bar{x})\). Squaring removes the minus sign:

\[ (x-\bar{x})^2 = \big(-(x-\bar{x})\big)^2. \]

Then adding \(d\) changes nothing. Therefore

\[ \sigma_2 = (1)\,\sigma = \sigma. \]
Hint. Only the absolute value of the multiplier matters for the standard deviation. \(\lvert -1 \rvert = 1\), so the s.d. is multiplied by \(1\).
Step 3A1

Hence \(\sigma_1 = \sigma_2 = \sigma\).

Statement II is TRUE. The standard deviations are equal.
0 / 3

Statement III — Are the inter-quartile ranges equal? Part III

The inter-quartile range (IQR) is \(Q_3 - Q_1\). Shifting the data shifts the quartiles by the same amount, and reflecting the data reflects the quartiles about \(0\).

0
Step 1M1

Let \(q\) be the inter-quartile range of \(S_3\). Since \(S_1 = S_3 + d\) shifts every value by \(d\), both \(Q_1\) and \(Q_3\) shift by \(d\), so their difference is unchanged:

\[ \text{IQR}(S_1) = q. \]
Hint. The sorted order of the data is unchanged by adding \(d\), so the same data values remain the quartiles — just moved.
Step 2M1

For \(S_2 = -S_3 + d\), multiplying by \(-1\) reverses the order of the data. The lowest value becomes the highest and vice versa, so the first quartile becomes the negative of the third quartile:

\[ Q_1(S_2) = -Q_3(S_3) + d, \qquad Q_3(S_2) = -Q_1(S_3) + d. \]

Adding \(d\) then shifts both, which again cancels in the difference:

\[ \text{IQR}(S_2) = \big(-Q_1(S_3)+d\big) - \big(-Q_3(S_3)+d\big) = Q_3(S_3) - Q_1(S_3) = q. \]
Hint. The IQR measures the width of the middle 50%. Reflecting a box plot about 0 keeps the width of the box the same.
Step 3A1

The two inter-quartile ranges are both equal to \(q\).

Statement III is TRUE. The inter-quartile ranges are equal.
0 / 3

Summary — Final Answer

  • Statement IFalse — \(\bar{x}_1 = d+1 \ne d-1 = \bar{x}_2\).
  • Statement IITrue — adding \(d\) and multiplying by \(-1\) keep the standard deviation unchanged.
  • Statement IIITrue — translations and reflections preserve the inter-quartile range.
Correct option: D (II and III only)
