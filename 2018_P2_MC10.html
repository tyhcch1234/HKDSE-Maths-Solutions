HKDSE Math 2018 Paper 2 Q10 2. Rate, Ratio and Variations

Ratio Problem Solver

Simplify the ratio \(a : b : c\) and evaluate \(\dfrac{a+3b}{b+3c}\).

Let \(a\), \(b\) and \(c\) be non-zero numbers. If \(3a = 4b\) and \(a : c = 2 : 5\), then

\(\displaystyle \frac{a+3b}{b+3c} =\)

A \(\displaystyle \frac{5}{3}\)
B \(\displaystyle \frac{13}{33}\)
C \(\displaystyle \frac{30}{53}\)
D \(\displaystyle \frac{75}{38}\)

Step-by-Step Solution

Given \(3a = 4b\).

Divide both sides by \(b\) (non-zero): \(\displaystyle \frac{a}{b} = \frac{4}{3}\).

Thus \(a : b = 4 : 3\).

Hint

When you have \(ka = lb\), you can cross-multiply: \(a : b = l : k\). Here \(3a = 4b\) gives \(a : b = 4 : 3\).

We have \(a : b = 4 : 3\) and \(a : c = 2 : 5\).

Make the part for \(a\) the same. The LCM of 4 and 2 is 4.

  • \(a : b = 4 : 3\)   (already has \(a=4\))
  • \(a : c = 2 : 5 = 4 : 10\)   (multiply both parts by 2)

Therefore \(a : b : c = 4 : 3 : 10\).

Hint

To combine two ratios sharing \(a\), scale each ratio so the number of parts for \(a\) matches.

Since \(a : b : c = 4 : 3 : 10\), we can take \(a = 4k\), \(b = 3k\), \(c = 10k\) for some non-zero constant \(k\).

Substitute:

\[ \frac{a+3b}{b+3c} = \frac{4k + 3(3k)}{3k + 3(10k)} \]

\[ = \frac{4k + 9k}{3k + 30k} = \frac{13k}{33k} \]

The \(k\) cancels out: \(\displaystyle \frac{13}{33}\).

Hint

Using a common factor \(k\) makes the algebra clean. Any non-zero \(k\) gives the same final ratio.

Therefore \(\displaystyle \frac{a+3b}{b+3c} = \frac{13}{33}\), which matches option B.

Correct answer

B. \(\displaystyle \frac{13}{33}\)
