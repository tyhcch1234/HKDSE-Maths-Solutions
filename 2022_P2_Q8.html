Question

Let $f(x)=x^{2}-x+1$. If $k$ is a constant, which of the following must be true?

  • A. $\;f(k)=f(-k)$
  • B. $\;f(k)=f(1-k)$
  • C. $\;f(k+1)=f(k)+f(1)$
  • D. $\;f(k-1)=f(k)-f(1)$
Step 1 · Recognise the shape

Write the function and find the axis of symmetry

Axis of Symmetry of a Parabola \(y=a(x-h)^{2}+k\ \Rightarrow\ \text{axis }x=h\) \(f(x)=\left(x-\tfrac12\right)^{2}+\tfrac34\) has axis \(x=\tfrac12\), so \(f(a)=f(1-a)\).

$f(x)=x^{2}-x+1$ is a parabola opening upward.

$f(x)=\left(x-\tfrac12\right)^{2}+\tfrac34$, so the axis of symmetry is $x=\tfrac12$.

This means $f$ gives equal values at points mirrored about $x=\tfrac12$: $\;f(a)=f(1-a)$.

Check: $a$ and $1-a$ are equidistant from $\tfrac12$. That is exactly what option B claims — verify it algebraically.
Step 2 · Test A

Is $f(k)=f(-k)$?

$f(k)=k^{2}-k+1$  and  $f(-k)=(-k)^{2}-(-k)+1=k^{2}+k+1$.

Setting them equal: $k^{2}-k+1=k^{2}+k+1 \Rightarrow -k=k \Rightarrow k=0$.

False in general. It holds only when $k=0$ (a single, special case — not "must be true").

In the figure: $f(k)$ (orange) and $f(-k)$ (purple) generally sit at different heights.
Step 3 · Test B

Is $f(k)=f(1-k)$?

Expanding a Perfect Square \((1-k)^{2}=1-2k+k^{2}\) Expanding \(f(1-k)\) gives \(k^{2}-k+1\), exactly \(f(k)\), so B holds for every \(k\).

$f(1-k)=(1-k)^{2}-(1-k)+1$

$\phantom{f(1-k)}=(1-2k+k^{2})-(1-k)+1$

$\phantom{f(1-k)}=k^{2}-2k+1-1+k+1$

$\phantom{f(1-k)}=k^{2}-k+1=f(k)$.

True for all $k$ ✓ — no restriction on $k$ needed.

Geometrically the two points are mirror images about the axis $x=\tfrac12$, so equal $y$-values are guaranteed.
Step 4 · Test C

Is $f(k+1)=f(k)+f(1)$?

$f(k+1)=(k+1)^{2}-(k+1)+1=k^{2}+k+1$.

$f(k)+f(1)=(k^{2}-k+1)+(1-1+1)=k^{2}-k+2$.

Equal $\Rightarrow k^{2}+k+1=k^{2}-k+2 \Rightarrow 2k=1 \Rightarrow k=\tfrac12$.

False in general. Only true for the special value $k=\tfrac12$.

The function is not "additive": $f(k+1)\ne f(k)+f(1)$ in general.
Step 5 · Test D

Is $f(k-1)=f(k)-f(1)$?

$f(k-1)=(k-1)^{2}-(k-1)+1=k^{2}-3k+3$.

$f(k)-f(1)=(k^{2}-k+1)-(1)=k^{2}-k$.

Equal $\Rightarrow k^{2}-3k+3=k^{2}-k \Rightarrow -3k+3=-k \Rightarrow 3=2k \Rightarrow k=\tfrac32$.

False in general. Only true for the special value $k=\tfrac32$.

Again, only one particular $k$ works, so the statement is not "must be true".
Step 6 · Conclusion

Compare all four options

OptionStatementRequiresVerdict

B$f(k)=f(1-k)$nothingAlways ✓
C$f(k+1)=f(k)+f(1)$$k=\tfrac12$Not always

Answer: B

Question. It is given that \(f(x)=x^{2}-5x+3\) and \(k\) is a real number. Which of the following must be true? A. \(f(k)=f(-k)\) B. \(f(k)=f(5-k)\) C. \(f(k+1)=f(k)+f(1)\) D. \(f(k-1)=f(k)-f(1)\)

Show the worked solution
Step 1. Complete the square: \(f(x)=\left(x-\tfrac52\right)^{2}-\tfrac{13}{4}\), so the axis of symmetry is \(x=\tfrac52\).
Step 2. \(k\) and \(5-k\) are mirror images about \(x=\tfrac52\), so \(f(k)=f(5-k)\): \(f(5-k)=(5-k)^{2}-5(5-k)+3=k^{2}-5k+3=f(k)\).
Step 3. Test A with \(k=1\): \(f(1)=-1\) but \(f(-1)=9\), so A fails.
Step 4. Test C with \(k=1\): \(f(2)=-3\) while \(f(1)+f(1)=-2\); D also fails at \(k=1\) since \(f(0)=3\neq0\).
Answer: B \(\big(f(k)=f(5-k)\big)\)
