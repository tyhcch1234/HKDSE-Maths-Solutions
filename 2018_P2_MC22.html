Circle Geometry — Angles in the Same Segment & Isosceles Triangle

Cyclic Quadrilateral Angles in Same Segment Isosceles Triangle Angle Sum of Triangle

Q22 The Question

In the figure, \(ABCD\) is a circle. \(AD\) produced and \(BC\) produced meet at the point \(E\). It is given that \(BD = DE\), \(\angle BAC = 66^\circ\) and \(\angle ABD = 30^\circ\). Find \(\angle CED\).
A. \(42^\circ\)    B. \(28^\circ\)    C. \(38^\circ\)    D. \(32^\circ\)

Original Figure

Part A Setting up the unknown \(x = \angle CED\) and using \(BD = DE\)

We begin by labelling the required angle \(\angle CED\) as \(x\). Since \(B, C, E\) are collinear and \(A, D, E\) are collinear, \(D\) and \(C\) lie on the sides of triangle \(ABE\). Because \(BD = DE\), triangle \(BDE\) is isosceles with vertex \(D\).

arc BD = 0° arc DE = 0° ∠BED = 0°
0 / 2
Step 1

Let \(\angle CED = x\). Since \(E, C, B\) are collinear and \(E, D, A\) are collinear,

\[ \angle BED = \angle CED = x .\]
Hint: Use the given \(BD = DE\). Triangle \(BDE\) is isosceles with equal sides \(BD\) and \(DE\), so the angles opposite them are equal: the angle opposite \(BD\) is \(\angle BED\), and opposite \(DE\) is \(\angle EBD\).
Step 2

In \(\triangle BDE\), since \(BD = DE\) (given),

\[ \angle EBD = \angle BED = x \qquad (\text{base }\angle\text{s, isos. }\triangle) \]
Hint: Both base angles of the isosceles triangle equal the same unknown \(x\). This gives us a way to express \(\angle ABE\) in terms of \(x\) later.
Result: \(\angle EBD = \angle BED = x\)

Part B Using angles in the same segment: \(\angle CAD = \angle CBD\)

\(\angle BAC = 66^\circ\) and \(\angle ABD = 30^\circ\) are given. We need one more relation: the angles in the same segment subtended by chord \(CD\). Both \(\angle CAD\) and \(\angle CBD\) subtend chord \(CD\), so they are equal.

∠CAD = 0° ∠CBD = 0° Equal? ✓
0 / 1
Step 1

In the circle, \(\angle CAD\) and \(\angle CBD\) stand on the same chord \(CD\) (same arc \(CD\)):

\[ \angle CAD = \angle CBD \qquad (\angle\text{s in the same segment}) \]

But \(\angle CBD = \angle EBD = x\), so \(\angle CAD = x\).

Hint: Look at the chord \(CD\). The apex \(A\) is on one side and \(B\) on the other. Both angles open onto the same chord \(CD\), so they are equal — no need to know the centre or the radius.
Result: \(\angle CAD = x\)

Part C Angle sum of \(\triangle ABE\) to solve for \(x\)

The three angles of triangle \(ABE\) are now all expressed in terms of \(x\). Summing them to \(180^\circ\) gives a single linear equation.

∠ABE = 0° ∠BAE = 0° ∠AEB = 0° Sum = 0°
0 / 3
Step 1

Find \(\angle ABE\), which is split by line \(BD\):

\[ \angle ABE = \angle ABD + \angle DBE = 30^\circ + x .\]

Also, in triangle \(ABE\), angle \(\angle BAE\) is split by \(AC\):

\[ \angle BAE = \angle BAC + \angle CAE = 66^\circ + x .\]
Hint: \(\angle DBE = \angle EBD = x\) from Part A, and \(\angle CAE = \angle CAD = x\) from Part B. Add the sub-angles at \(B\) and at \(A\).
Step 2

Apply the angle sum of triangle \(ABE\):

\[ \angle ABE + \angle BAE + \angle AEB = 180^\circ \] \[ (30^\circ + x) + (66^\circ + x) + x = 180^\circ \]
Hint: \(\angle AEB = \angle BED = x\). Collect the terms: \(3x + 96^\circ = 180^\circ\).
Step 3

Solve the equation:

\[ 3x + 96^\circ = 180^\circ \] \[ 3x = 84^\circ \] \[ x = 28^\circ \]
Hint: Back-substitute to check: \((30+28) + (66+28) + 28 = 58 + 94 + 28 = 180^\circ\) ✓
Answer: \(\angle CED = x = 28^\circ\) → choice B

Summary of Answers

  • Let \(x = \angle CED\).
  • \(BD = DE \Rightarrow \triangle BDE\) is isosceles \(\Rightarrow \angle EBD = \angle BED = x\) (base \(\angle\)s, isos. \(\triangle\)).
  • \(\angle CAD = \angle CBD = x\) (\(\angle\)s in the same segment, chord \(CD\)).
  • In \(\triangle ABE\): \((x + 30^\circ) + (x + 66^\circ) + x = 180^\circ\).
  • \(3x + 96^\circ = 180^\circ \Rightarrow 3x = 84^\circ \Rightarrow x = 28^\circ\).
  • Answer: \(\angle CED = 28^\circ\) → Option B.
