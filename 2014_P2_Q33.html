HKDSE 2014 Paper 2 · Q33 Laws of Indices / Logarithms

Step 1 — Given: compare $124^{241}$, $241^{214}$, $412^{142}$, $421^{124}$.

[2014 MC #33]

Which of the following is the greatest?

A. $124^{241}$
B. $241^{214}$
C. $412^{142}$
D. $421^{124}$
1Take logarithms — the key idea

A power $a^{b}$ is huge, so direct comparison is impossible. But $\log$ is an increasing function, so comparing $a^{b}$ is the same as comparing $\log\left(a^{b}\right)$.

$\log\left(a^{b}\right)=b\log a$

Hint: $\log x$ increasing means $P>Q \iff \log P>\log Q$. So compare the four values $b\log a$.
2Evaluate each logarithm
A:$\log 124^{241}=241\log 124=504.5146261$ B:$\log 241^{214}=214\log 241=509.7516471$ C:$\log 412^{142}=142\log 412=371.3154047$ D:$\log 421^{124}=124\log 421=325.4109799$
Hint: use a calculator's $\log$ (base 10) key — the base does not matter, only that it is the same for all four.
3Compare the bar heights

Arrange from smallest to largest:

$325.41\ (\text{D}) \;<\; 371.32\ (\text{C}) \;<\; 504.51\ (\text{A}) \;<\; \mathbf{509.75}\ (\text{B})$

Hint: note A and B are very close — B only wins by about 5.24, so careful computation matters.
4Reverse the logarithm

Since $\log x$ is an increasing function of $x$, the largest logarithm corresponds to the largest number. Hence $\log 241^{214}$ is the greatest value, so $241^{214}$ is the greatest.

Hint: increasing function means the ordering is preserved — no need to undo the log to strip it away.
Answer: B  ·  $241^{214}$ is the greatest.
