QQuestion

Let \(\alpha\) and \(\beta\) be real numbers such that

\(\beta = 5\alpha - 18 \qquad \text{and} \qquad \beta = \alpha^{2} - 13\alpha + 63.\)

(a) Find \(\alpha\) and \(\beta\). [2 marks]
(b) The 1st term and the 2nd term of an arithmetic sequence are \(\log \alpha\) and \(\log \beta\) respectively. Find the least value of \(n\) such that the sum of the first \(n\) terms of the sequence is greater than \(888\). [4 marks]

▶Step-by-Step Guided Solution

1
Part (a): Set the two expressions for β equal
▾

Since both expressions equal \(\beta\), we can equate them:

\(5\alpha - 18 = \alpha^{2} - 13\alpha + 63\)

Hint: Both are different expressions for the same value \(\beta\). Substituting one into the other is the standard method for solving simultaneous equations.
2
Rearrange into a standard quadratic equation
▾

Bring all terms to one side:

\(5\alpha - 18 = \alpha^{2} - 13\alpha + 63\)

\(0 = \alpha^{2} - 18\alpha + 81\)

\(\alpha^{2} - 18\alpha + 81 = 0\)

Hint: Move every term to one side so the equation equals \(0\). Combine like terms: \(-13\alpha - 5\alpha = -18\alpha\), and \(63 + 18 = 81\).
3
Solve the quadratic equation for α
▾

Note that \(\alpha^{2} - 18\alpha + 81\) is a perfect square:

\(\alpha^{2} - 18\alpha + 81 = (\alpha - 9)^{2} = 0\)

So:

\(\alpha = 9\)

Hint: Check: \(18^{2} - 4(1)(81) = 324 - 324 = 0\) — a repeated root. Recognising a perfect square \((a-b)^2 = a^2 - 2ab + b^2\) saves time.

Substitute \(\alpha = 9\) into \(\beta = 5\alpha - 18\):

\(\beta = 5(9) - 18 = 45 - 18 = 27\)

✓ Answer to (a): \(\alpha = 9,\quad \beta = 27\)
4
Part (b): Identify the arithmetic sequence
▾

Let \(T(n)\) be the \(n\)th term of the arithmetic sequence. First term:

\(T(1) = \log \alpha = \log 9 = \log 3^{2} = 2\log 3\)

Second term:

\(T(2) = \log \beta = \log 27 = \log 3^{3} = 3\log 3\)

Common difference \(d\):

\(d = T(2) - T(1) = 3\log 3 - 2\log 3 = \log 3\)

Hint: Use \(\log a^{m} = m\log a\) to simplify. Since the two logarithms have the same base \(3\), the difference is simply \(\log 3\).
5
General term and sum formula
▾

The \(n\)th term is:

\(T(n) = 2\log 3 + (n-1)\log 3 = (n+1)\log 3\)

Sum of the first \(n\) terms (use \(S_{n} = \frac{n}{2}[2a + (n-1)d]\)):

\(S_{n} = \frac{n}{2}\left[2(2\log 3) + (n-1)\log 3\right]\)

\(S_{n} = \frac{n}{2}(3\log 3 + n\log 3) = \frac{n\log 3}{2}(n+3)\)

Hint: Arithmetic sum formula: \(S_{n} = \dfrac{n}{2}\big[2a + (n-1)d\big]\) where \(a = 2\log 3\) and \(d = \log 3\).
6
Set up and solve the inequality
▾

We need \(S_{n} > 888\):

\(\frac{n\log 3}{2}(n+3) > 888\)

\((\log 3)n^{2} + (3\log 3)n - 1776 > 0\)

Using \(\log 3 \approx 0.47712\):

\(0.47712\,n^{2} + 1.43136\,n - 1776 > 0\)

Solving the corresponding quadratic equation gives two roots:

\(n \approx -62.53 \quad \text{or} \quad n \approx 59.53\)

Hint: Since the parabola opens upwards (coefficient of \(n^2\) is positive), the inequality \(> 0\) holds when \(n < -62.53\) or \(n > 59.53\). Because \(n\) is a positive integer (number of terms), we take the positive root.
7
Find the least integer value of n
▾

Since \(n\) must be a positive integer and \(n > 59.53\), the smallest possible value is:

\(n = 60\)

✓ Answer to (b): The least value of \(n\) is \(60\).
