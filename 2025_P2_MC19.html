Square & Rhombus · Angle Properties & Similar Triangles
Square Rhombus Congruent Triangles Similar Triangles Angles

Question

In the figure, \(ABCD\) is a square. Let \(E\) be a point such that \(CDEF\) is a rhombus, where \(F\) is a point lying on \(BC\) produced. \(AB\) is produced to the point \(G\) such that \(BG = BC\). Which of the following are true?

I.   \(DF = FG\)
II.   \(\triangle BFG \sim \triangle DEF\)
III.   \(\angle ABG + \angle BFD = 180^\circ\)

A. I and II only
B. I and III only
C. II and III only
D. I, II and III ✓

Original Figure

Part (a) — Establish the Key Angles

Let us first find the angles in the figure using the properties of the square and the rhombus.

∠ACB = 45° · ∠FCD = 135° · ∠CFB = 22.5°
0 / 4
1

Since \(ABCD\) is a square, all sides are equal and each interior angle is \(90^\circ\). The diagonal \(AC\) bisects \(\angle BCD\):

\[ \angle ACB = \angle ACD = 45^\circ \]
Split the square along the diagonal to get two \(45^\circ\!-\!45^\circ\!-\!90^\circ\) triangles.
2

Since \(BCD\) is a straight line,

\[ \angle FCD = 180^\circ - \angle ACB - \angle ACD = 180^\circ - 45^\circ - 45^\circ = 90^\circ \]

Wait — here \(F\) lies on \(BC\) produced, so \(B,\,C,\,F\) are collinear. Thus

\[ \angle FCD = 180^\circ - \angle ACD = 180^\circ - 45^\circ = 135^\circ \]
Adjacent angles on a straight line sum to \(180^\circ\).
3

Because \(CDEF\) is a rhombus, \(CD = DE = EF = FC\), so \(\triangle DCF\) is isosceles with \(CD = CF\), giving

\[ \angle CFD = \angle CDF = \frac{180^\circ - 135^\circ}{2} = 22.5^\circ \]
Base angles of an isosceles triangle are equal.
4

Similarly, \(\triangle BCF\) is isosceles with \(BC = CF\), so

\[ \angle CFB = \angle CBF = \frac{180^\circ - 135^\circ}{2} = 22.5^\circ \]
∠ACB = 45°, ∠FCD = 135°, ∠CFB = ∠CBF = 22.5°

Part (b) — Prove I. \(DF = FG\)

Use congruence and the alternate angle property with the parallel lines.

DF = FG (equal) · BF = GF · ΔDEF ≅ ΔDCF ≅ ΔBCF
0 / 4
1

Since \(ABCD\) is a square, \(AD /\!/ BC\), and because \(F\) lies on \(BC\) produced, we have \(AF /\!/ BG\). By the alternate angle property,

\[ \angle FBG = \angle CFB = 22.5^\circ \]
Alternate angles are equal when a transversal cuts parallel lines.
2

By the corresponding angle property,

\[ \angle FGB = \angle CFD = 22.5^\circ \]
Corresponding angles are equal for parallel lines.
3

In \(\triangle BFG\), \(\angle FBG = \angle FGB = 22.5^\circ\), so the sides opposite these equal angles are equal:

\[ BF = GF \]
Sides opposite equal angles in a triangle are equal (isosceles triangle).
4

Note that \(\triangle DEF \cong \triangle DCF \cong \triangle BCF\) (SSS). Hence \(DF = BF\). Since \(BF = GF\), we get

\[ DF = FG \]
∴ Statement I is true.

Part (c) — Prove II. \(\triangle BFG \sim \triangle DEF\)

Show the two triangles are similar by the AA (Angle–Angle) criterion.

∠FBG = ∠FGB = 22.5° · ∠EFD = ∠EDF = 22.5° · ΔBFG ~ ΔDEF (AA)
0 / 3
1

From the rhombus \(CDEF\), the diagonals bisect the angles. Since \(\angle FCD = 135^\circ\) and \(\angle CFD = 22.5^\circ\), we also have

\[ \angle EFD = \angle EDF = 22.5^\circ \]
Opposite angles of a rhombus are equal, and each diagonal bisects a pair of opposite angles.
2

From Part (b), we already know

\[ \angle FBG = \angle FGB = 22.5^\circ \]

So two angles of \(\triangle BFG\) equal two angles of \(\triangle DEF\):

\[ \angle FBG = \angle EFD = 22.5^\circ, \quad \angle FGB = \angle EDF = 22.5^\circ \]
Match corresponding vertices: \(B \leftrightarrow E\), \(G \leftrightarrow D\).
3

Therefore, by the AA similarity criterion,

\[ \triangle BFG \sim \triangle DEF \]
∴ Statement II is true.

Part (d) — Prove III. \(\angle ABG + \angle BFD = 180^\circ\)

Compute the two angles and check their sum.

∠ABG = 135° · ∠BFD = 45° · Sum = 180°
0 / 3
1

At vertex \(B\), the angle \(\angle ABG\) is split into three parts by the rays \(BC\) and \(BF\):

\[ \angle ABG = \angle ABC + \angle CBF + \angle FBG = 90^\circ + 22.5^\circ + 22.5^\circ = 135^\circ \]
\(\angle ABC = 90^\circ\) because \(ABCD\) is a square.
2

At \(F\), the angle \(\angle BFD\) is split by the ray \(FC\):

\[ \angle BFD = \angle CFB + \angle CFD = 22.5^\circ + 22.5^\circ = 45^\circ \]
Use the angle values found in Part (a).
3

Now sum the two angles:

\[ \angle ABG + \angle BFD = 135^\circ + 45^\circ = 180^\circ \]
∴ Statement III is true.

Summary of Answers

  • Part (a): \(\angle ACB = 45^\circ\), \(\angle FCD = 135^\circ\), \(\angle CFB = \angle CBF = 22.5^\circ\)
  • I. \(DF = FG\) — True (via \(BF = GF\) and \(DF = BF\))
  • II. \(\triangle BFG \sim \triangle DEF\) — True (AA similarity)
  • III. \(\angle ABG + \angle BFD = 180^\circ\) — True (\(135^\circ + 45^\circ\))

Therefore, the correct choice is D. I, II and III.
