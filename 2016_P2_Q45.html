Statistics — Effect of Linear Transformation on Variance

Variance Linear Transformation Scaling & Shifting Standard Deviation

QQuestion

The variance of a set of numbers is \(49\). Each number of the set is multiplied by \(4\) and then \(9\) is added to each resulting number to form a new set of numbers. Find the variance of the new set of numbers.

  1. \(196\)
  2. \(205\)
  3. \(784\)
  4. \(793\)
    5. >

APart A — What a linear change does to the spread

Before computing, build intuition: adding a constant shifts every value but never changes the spread; multiplying by \(k\) stretches the spread by a factor \(k\) (and the variance by \(k^2\)).

Multiplier \(k\) = 4 Shift \(c\) = 9 Original SD \(=\sigma\) = 7.00 New SD \(=|k|\sigma\) = 28.00 New variance \(=k^2\sigma^2\) = 784.00
4
9
Step 1

Interpret the transformation. Let the original numbers be \(x_1, x_2, \dots, x_n\) and the new numbers be

\[ y_i = 4x_i + 9 \qquad (i = 1, 2, \dots, n). \]
Hint: Before writing any formula, decide what type of transformation this is. “Multiply by a constant then add a constant” is exactly \(y = kx + c\) with \(k = 4\), \(c = 9\).
Step 2

Recall the two key rules (with \(k, c\) constants):

\[ \bar{y} = k\bar{x} + c, \qquad \sigma_y = |k|\,\sigma_x. \]

The mean moves by the same transformation, but the standard deviation is affected only by the stretching factor \(|k|\) — the shift \(c\) has no effect.

Hint: Why does \(c\) vanish? Every deviation \(y_i - \bar{y} = (kx_i + c) - (k\bar{x} + c) = k(x_i - \bar{x})\) — the \(+c\) cancels out.
Step 3

Convert standard deviation to variance. Since \(\sigma_x^2 = 49\),

\[ \sigma_x = 7. \]

Hence

\[ \sigma_y = |4| \times 7 = 28. \]
Hint: Do not forget to square the multiplier when you return to variance — \(\text{Var}(kX+c) = k^2\,\text{Var}(X)\), not \(k\,\text{Var}(X)\).
Step 4

Square to get the new variance:

\[ \text{new variance} = \sigma_y^2 = 28^2 = 784. \]
Answer: \(\text{Variance of new set} = 784\) → option C

9
Step 1

Write the standard deviation of the original set from its variance:

\[ \sigma_x^2 = 49 \;\Rightarrow\; \sigma_x = 7. \]
Hint: Variance is the square of standard deviation — take the positive square root to get back to the SD scale.
Step 2

Apply the transformation \(y = 4x + 9\) to the standard deviation:

\[ \sigma_y = 4\sigma_x = 4 \times 7 = 28. \]
Hint: Shifting by \(+9\) does not change the spread, so it drops out of this step completely. Only the multiplier matters here.
Step 3

Square to return to variance:

\[ \sigma_y^2 = 28^2 = 784. \]
Answer: \(784\)
Step 4

Equivalently, using the general rule

\[ \text{Var}(kX + c) = k^2\,\text{Var}(X) = 4^2 \times 49 = 16 \times 49 = 784. \]
Hint: Spot the trap options: \(196 = 4 \times 49\) uses \(k\) instead of \(k^2\); \(793 = 784 + 9\) adds the shift to the variance. Both are wrong because they misuse the roles of \(k\) and \(c\).
Answer: \(784\) → option C

📌 Summary of Answers

  • Original variance: \(\sigma_x^2 = 49\), so original SD \(\sigma_x = 7\).
  • Transformation: \(y = 4x + 9\) (\(k = 4\), \(c = 9\)).
  • Key rule: \(\text{Var}(kX + c) = k^2\,\text{Var}(X)\) — the shift \(c\) never affects the variance.
  • New variance: \(4^2 \times 49 = 784\).
  • Final answer: 784 — option C.
  • Distractors: A (196) ignores the square; D (793) adds the shift.
