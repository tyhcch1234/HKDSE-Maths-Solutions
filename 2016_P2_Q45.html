[2016MC#45]

The variance of a set of numbers is $49$. Each number of the set is multiplied by $4$ and then $9$ is added to each resulting number to form a new set of numbers. Find the variance of the new set of numbers.

  • A. $196$
  • B. $205$
  • C. $784$  
  • D. $793$

Step-by-step solution

1

What is given

Original set $x_1, x_2, \dots, x_n$ with $$\operatorname{Var}(x) = 49.$$ Every value is transformed by $$y_i = 4x_i + 9.$$

Hint: write down the transformation clearly — which operations, and in what order?
Variance of a Data Set \(\operatorname{Var}(x)=\dfrac{\sum \left(x-\mu\right)^{2}}{n}=\sigma^{2}\) The original set has \(\operatorname{Var}(x)=49\), i.e. a standard deviation of \(7\).
2

Rule 1 — multiplying by a constant

For any constant $k$, $$\operatorname{Var}(kx) = k^{2}\operatorname{Var}(x).$$ Variance is measured in squared units, so the factor $k$ must be squared.

Think of the standard deviation: multiplying by $k$ multiplies $\sigma_x$ by $k$ when $k>0$ and by $-k$ when $k<0$, so the variance gets $k^2$.
Variance under Multiplication \(\operatorname{Var}(kx)=k^{2}\operatorname{Var}(x)\) Multiplying every number by \(4\) multiplies the variance by \(4^{2}=16\), not by \(4\).
3

Rule 2 — adding a constant

For any constant $c$, $$\operatorname{Var}(x+c)=\operatorname{Var}(x).$$ Adding $9$ shifts every value by the same amount, so the spread is unchanged.

The diagram shows the whole cluster sliding to the right without changing its width.
Variance under Translation \(\operatorname{Var}(x+c)=\operatorname{Var}(x)\) Adding \(9\) to every number shifts the whole set but leaves the spread, so the variance is unchanged.
4

Combine the two rules

$$\operatorname{Var}(4x+9)=\operatorname{Var}(4x)=4^{2}\operatorname{Var}(x)=16\times 49.$$

Compute: $$16 \times 49 = 784.$$

Multiply first, then square the multiplier — do not add 9 before squaring.
5

Check the distractors

$49\times 4 = 196$ (A) forgets to square $4$.
$196+9 = 205$ (B) wrongly adds the shift to the variance.
$784+9 = 793$ (D) adds $9$ to a variance, but a shift never changes variance.

Only the multiplicative part is squared; the additive part is ignored.
Answer C  ·  The variance of the new set of numbers is $784$.

Question. The variance of a set of numbers is \(25\). Each number of the set is multiplied by \(3\) and then \(7\) is added to each resulting number to form a new set of numbers. Find the variance of the new set of numbers.
A. \(75\)    B. \(225\)    C. \(232\)    D. \(756\)   (1 mark)

Show the worked solution
Step 1. Write the transformation as \(y=3x+7\).
Step 2. Adding \(7\) does not change the variance: \(\operatorname{Var}(3x+7)=\operatorname{Var}(3x)\).
Step 3. Multiplying by \(3\) multiplies the variance by \(3^{2}=9\): \(\operatorname{Var}(3x)=9\times25=225\).
Step 4. Hence the new variance is \(225\), which is option B.
Answer: B. \(225\)
