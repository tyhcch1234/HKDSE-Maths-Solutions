Q

The figure shows the graph of \(y = ab^{x}\), where \(a\) and \(b\) are constants. Which of the following graphs may represent the relation between \(x\) and \(\log_{7} y\)?

✦ Step-by-Step Guided Solution

Click each step to reveal the reasoning. Use the hint buttons when you're stuck.

The curve passes through \((0, 3)\). Substitute \(x = 0\), \(y = 3\):

\(3 = ab^{0}\)

Since \(b^{0} = 1\) (for any \(b \neq 0\)):

\(a = 3\)
💡 Hint: Any non-zero number raised to the power 0 equals 1. So \(b^0 = 1\).

The graph decreases and approaches zero as \(x\) increases — it is an exponential decay curve.

\(0 < b < 1\)
💡 Hint: For \(y = ab^x\) with \(a > 0\): if \(b > 1\), the curve grows; if \(0 < b < 1\), the curve decays.

Start with \(y = 3b^{x}\) and take \(\log_7\) of both sides:

\(\log_{7} y = \log_{7}(3b^{x})\)

Apply the product and power laws of logarithms:

\(\log_{7} y = \log_{7} 3 + x\log_{7} b\)
💡 Hint (Laws of Logs):
• Product law: \(\log(MN) = \log M + \log N\)
• Power law: \(\log(M^k) = k\log M\)

Compare with the linear form \(Y = mX + c\) where \(Y = \log_7 y\) and \(X = x\):

Gradient

\(m = \log_7 b\)

Intercept

\(c = \log_7 3\)

So the graph of \(\log_7 y\) against \(x\) is a straight line.

y-intercept: \(c = \log_7 3\). Since \(3 > 1\), this is positive.

Gradient: \(m = \log_7 b\). Since \(0 < b < 1\), we have \(\log_7 b < 0\), so the gradient is negative.

💡 Hint:
• \(\log_7 3 > 0\) because \(3 > 7^0 = 1\).
• \(\log_7 b < 0\) because \(0 < b < 1 = 7^0\).

We need a straight line with:

  • Positive vertical intercept (cuts the \(\log_7 y\)-axis above \(O\))
  • Negative gradient (slopes downwards from left to right)

Only Option B shows a line leaning downwards with a positive intercept.

🔑 Key Takeaways

  • ▸ The y-intercept gives \(a\): substitute \((0, y_0)\) into \(y = ab^x\).
  • ▸ The shape (growth vs decay) tells you whether \(b > 1\) or \(0 < b < 1\).
  • ▸ Taking logs converts an exponential relation into a linear one: \(\log y = \log a + x\log b\).
  • ▸ The intercept \(\log_7 a\) and gradient \(\log_7 b\) determine the line's appearance.
