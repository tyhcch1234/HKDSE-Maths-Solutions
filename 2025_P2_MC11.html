Given a three-term ratio in α, β, γ — find the ratio α : β.

1 Step-by-Step Guided Solution

Tap any step to reveal the reasoning. Use Next Step to move forward one at a time.

0 / 5 steps revealed
1 Turn the three-term ratio into two equations ›

A ratio \(a:b:c = 4:9:5\) means there is a common multiplier \(k\) such that

\[ \alpha+2\beta = 4k, \quad \beta+2\gamma = 9k, \quad \gamma+2\alpha = 5k \]

But a faster, more standard DSE approach is to pair up the parts of the ratio directly:

\[ \frac{\alpha+2\beta}{\beta+2\gamma} = \frac{4}{9} \qquad \text{and} \qquad \frac{\alpha+2\beta}{\gamma+2\alpha} = \frac{4}{5} \]
💡 Hint — Ratio to Fraction
If \(x:y = m:n\), then \(\dfrac{x}{y} = \dfrac{m}{n}\). Each part of the ratio can be compared with any other part in the same way.
2 Equation (1): cross-multiply the first pair ›

Start from

\[ \frac{\alpha+2\beta}{\beta+2\gamma} = \frac{4}{9} \]

Cross-multiplying:

\[ 9(\alpha+2\beta) = 4(\beta+2\gamma) \]
\[ 9\alpha + 18\beta = 4\beta + 8\gamma \]

Move all terms involving \(\gamma\) to one side:

\[ 8\gamma = 9\alpha + 14\beta \quad \cdots (1) \]
💡 Hint — Rearranging
We isolate \(\gamma\) because the target is \(\alpha:\beta\). Keeping \(\gamma\) on the left makes it easy to substitute later.
3 Equation (2): cross-multiply the second pair ›

Now use

\[ \frac{\alpha+2\beta}{\gamma+2\alpha} = \frac{4}{5} \]

Cross-multiplying:

\[ 5(\alpha+2\beta) = 4(\gamma+2\alpha) \]
\[ 5\alpha + 10\beta = 4\gamma + 8\alpha \]

Move the \(\alpha\) terms together:

\[ 20\beta - 6\alpha = 4\gamma \quad \cdots (2) \]
💡 Hint — Careful with signs
\(10\beta - 5\alpha - 8\alpha\) is a common slip. Rearrange step by step: \(10\beta - 5\alpha = 4\gamma + 8\alpha\), then \(10\beta - 5\alpha - 8\alpha = 4\gamma\), giving \(10\beta - 13\alpha = 4\gamma\). Multiply by 2 to match the \(8\gamma\) in (1).
4 Eliminate \(\gamma\) by combining (1) and (2) ›

From (1): \(8\gamma = 9\alpha + 14\beta\).   Multiplying (2) by 2 gives \(8\gamma = 20\beta - 6\alpha\).

Since both equal \(8\gamma\):

\[ 9\alpha + 14\beta = 20\beta - 6\alpha \]

Collect like terms:

\[ 9\alpha + 6\alpha = 20\beta - 14\beta \]
\[ 15\alpha = 6\beta \]
💡 Hint — Elimination Method
Match the coefficient of \(\gamma\) in both equations (here \(8\gamma\)), then subtract the equations to cancel \(\gamma\) completely.
5 Convert to the ratio \(\alpha:\beta\) ›

From \(15\alpha = 6\beta\):

\[ \frac{\alpha}{\beta} = \frac{6}{15} = \frac{2}{5} \]

Therefore

\[ \alpha : \beta = 2 : 5 \]
✅ Answer: A  (\(2:5\))
Quick check: Take \(\alpha = 2\), \(\beta = 5\). Then from (1): \(8\gamma = 9(2) + 14(5) = 18 + 70 = 88\), so \(\gamma = 11\). Now \(\alpha+2\beta = 2+10 = 12\), \(\beta+2\gamma = 5+22 = 27\), \(\gamma+2\alpha = 11+4 = 15\). Ratio \(= 12:27:15 = 4:9:5\).

3 Key Takeaways

  • Ratio → Fraction: \(a:b = m:n \iff \dfrac{a}{b} = \dfrac{m}{n}\).
  • Pair up the parts: A 3-term ratio gives you 2 independent equations — enough to eliminate the unwanted variable.
  • Eliminate one variable (here \(\gamma\)) to leave only the two variables you want.
  • Simplify the ratio at the end: divide both numbers by their HCF (\(15:6 \to 5:2\), so \(\alpha:\beta = 2:5\)).
  • Always verify by substituting a convenient set of values back into the original ratio.
