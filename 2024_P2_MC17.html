Plane Geometry — Similar Triangles & Areas of Trapeziums
Square & Parallel Lines Similar Triangles Area Ratio Trapezium Multiple Choice

Question Multiple Choice

In the figure, \(ABCD\) is a square. Let \(M\) be the mid-point of \(BC\). \(E\) is a point lying on \(AD\) such that \(AE = 3ED\), \(F\) is a point lying on \(BC\) produced such that \(CF = ED\), \(AF\) and \(ME\) intersect at the point \(H\), while \(ME\) and \(DF\) intersect at the point \(G\). If the area of \(\triangle BHM\) is \(4\text{ cm}^2\), then the area of the trapezium \(AEGH\) is

A. \(30\text{ cm}^2\)
B. \(33\text{ cm}^2\)
C. \(39\text{ cm}^2\)
D. \(45\text{ cm}^2\)

Original Figure

Part (a) — Set up lengths & similarity ratios

AE = 3k BM = MC = 2k CF = k HM / GF = 2/5

Notice the parallel structure: \(BMFC\) lie on one straight line, and the whole square gives us a very clean set of similar triangles.

1Assign \(ED = k\) and read off every length

Let \(ED = k\). Then because \(AE = 3ED\),

\[ AE = 3k,\qquad AD = 4k .\]

As \(ABCD\) is a square, \(BC = 4k\). Since \(M\) is the mid-point of \(BC\) and \(CF = ED = k\):

\[ BM = MC = 2k,\qquad CF = k,\qquad BF = BC + CF = 5k .\]
Hint: Always reduce the picture to one unknown \(k\). Here every single segment becomes a multiple of \(k\), which is exactly what the markscheme does.
2Spot \(\triangle BHM \sim \triangle BGF\)

In \(\triangle BHM\) and \(\triangle BGF\):

  • \(\angle BHM = \angle BGF\) (vertically opposite angles, since \(H\), \(M\), \(G\), \(F\) are collinear),
  • \(\angle HBM = \angle GBF\) (common angle).

So the two triangles are similar (AA), giving

\[ \frac{HM}{GF} = \frac{BM}{BF} = \frac{2k}{2k+2k+k} = \frac{2k}{5k} = \frac{2}{5}. \]
Hint: \(M\) lies between \(B\) and \(F\), so \(BF\) is the sum \(BM + MC + CF\), not merely \(BM + CF\).
Similarity ratio \(\triangle BHM : \triangle BGF = 2 : 5\)
0 / 2

Part (b) — Areas of the triangles

[BHM] = 4 cm² [BGF] = 25 cm² [FGHM] = 21 cm² EG : GF = 1 : 1
1Area ratio from the length ratio

For similar figures, areas are in the square of the linear ratio:

\[ \frac{[\triangle BGF]}{[\triangle BHM]} = \left(\frac{GF}{HM}\right)^{2} = \left(\frac{5}{2}\right)^{2} = \frac{25}{4}. \]

Given \([\triangle BHM] = 4\text{ cm}^2\):

\[ [\triangle BGF] = 4 \times \frac{25}{4} = 25\text{ cm}^2 . \]
Hint: Be careful — the ratio \(5/2\) is length. Squaring it is the step that most candidates lose a mark for.
2Subtract to get the trapezium \(FGHM\)

Since \(\triangle BHM\) lies inside \(\triangle BGF\) (sharing vertex \(B\) and cut off by line \(ME\)):

\[ [FGHM] = [\triangle BGF] - [\triangle BHM] = 25 - 4 = 21\text{ cm}^2 . \]
Area of trapezium \(FGHM = 21\text{ cm}^2\)
Hint: This is the “remainder” trapezium. We will use it as the reference area for Part (c).
3Show \(EG = GF\) and get \(HM, AH\)

Since \(AE /\!/ DF\) (both on the square's parallel sides), and \(AD /\!/ BC\), the quadrilateral \(AMFE\) is a parallelogram — so \(AF\) and \(ME\) bisect each other. Hence

\[ EG = GF = 5x \quad \text{say, and}\quad HM = 2x . \]

Then on the straight line \(ME\):

\[ AH = AF - HF \quad\Longrightarrow\quad AH = 8x, \qquad \text{so } HM = 2x,\; AH = 8x .\]
Hint: The mid-point property comes from the parallelogram: diagonals bisect each other. The ratio \(AH : HM = 4 : 1\) mirrors \(AE : BM\).
\(EG = GF = 5x\), \(HM = 2x\), \(AH = 8x\)
0 / 3

Part (c) — Area of trapezium \(AEGH\)

parallel sides 8x & 5x [AEGH] / [FGHM] = 13/7 [AEGH] = 39 cm²
1Common height → ratio of parallel sides

Both trapeziums \(AEGH\) and \(FGHM\) have the same height \(h\) measured between the parallel lines \(AD\) and \(BF\):

\[ [AEGH] = \frac{(AH + EG)\,h}{2}, \qquad [FGHM] = \frac{(HM + GF)\,h}{2}. \]

Using \(AH = 8x,\; EG = GF = 5x,\; HM = 2x\):

\[ \frac{[AEGH]}{[FGHM]} = \frac{(8x + 5x)h/2}{(2x + 5x)h/2} = \frac{13x}{7x} = \frac{13}{7}. \]
Hint: In trapeziums with the same height, the area ratio is simply the ratio of the sums of parallel sides — the \(h/2\) cancels completely.
2Substitute the known area

From Part (b), \([FGHM] = 21\text{ cm}^2\). Therefore

\[ [AEGH] = 21 \times \frac{13}{7} = 3 \times 13 = 39\text{ cm}^2 . \]
Area of trapezium \(AEGH = \boxed{39\text{ cm}^2}\) → Answer C
Check: \(39\) is larger than the trapezium \(FGHM = 21\), consistent with \(AEGH\) having longer parallel sides (\(13x\) vs \(7x\)).
0 / 2

Summary of Results

  • Set \(ED = k\) ⇒ \(AE = 3k\), \(BM = MC = 2k\), \(CF = k\), \(BF = 5k\).
  • \(\triangle BHM \sim \triangle BGF\) with \(\dfrac{HM}{GF} = \dfrac{2}{5}\).
  • \(\dfrac{[\triangle BGF]}{[\triangle BHM]} = \left(\dfrac{5}{2}\right)^2 = \dfrac{25}{4}\) ⇒ \([\triangle BGF] = \mathbf{25\text{ cm}^2}\).
  • Trapezium \([FGHM] = 25 - 4 = \mathbf{21\text{ cm}^2}\).
  • \(EG = GF = 5x\), \(HM = 2x\), \(AH = 8x\) ⇒ \(\dfrac{[AEGH]}{[FGHM]} = \dfrac{13}{7}\).
  • Therefore \([AEGH] = 21 \times \dfrac{13}{7} = \mathbf{39\text{ cm}^2}\) — Answer C.
