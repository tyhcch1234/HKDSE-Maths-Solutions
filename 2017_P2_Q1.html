[2017MC#1]  ·  4. Polynomials
\[ 3m^{2}-5mn+2n^{2}+m-n = \text{?} \]
A. \((m-n)(3m-2n+1)\)
B. \((m-n)(3m+2n+1)\)
C. \((m+n)(3m-2n-1)\)
D. \((m+n)(3m+2n-1)\)

Step-by-step solution

1Read the given expression
\[ 3m^{2}-5mn+2n^{2}+m-n \]
It has 5 terms: a quadratic part in \(m,\,n\) plus the linear part \(+\,m-n\). Four terms suggest grouping in pairs.
2Factorise the quadratic core \(3m^{2}-5mn+2n^{2}\)
\[3m^{2}-5mn+2n^{2}=3m^{2}-3mn-2mn+2n^{2}\] \[=3m(m-n)-2n(m-n)\] \[=(m-n)(3m-2n)\]
Split the middle term: need two numbers with product \(3\cdot 2=6\) and sum \(-5\) → the pair \(-3,\,-2\).
Splitting the Middle Term \(acx^{2}+(ad+bc)x+bd=(ax+b)(cx+d)\) For \(3m^{2}-5mn+2n^{2}\) the pair \(-3mn\) and \(-2mn\) splits \(-5mn\) so that each group shares a bracket.
3Re-attach the linear part and group
\[3m^{2}-5mn+2n^{2}+m-n\] \[=\underbrace{(m-n)(3m-2n)}_{\text{orange}}+\underbrace{(m-n)\cdot 1}_{\text{green}}\]
Note \(m-n=1\cdot(m-n)\), so both groups share the factor \((m-n)\).
4Take out the common factor \((m-n)\)
\[=(m-n)\bigl(3m-2n\bigr)+(m-n)\cdot 1\] \[=(m-n)\bigl[(3m-2n)+1\bigr]\] \[=(m-n)(3m-2n+1)\]
Factor out the bracket \((m-n)\) just like factoring a common monomial.
Common Factor Law \(AB+AC=A(B+C)\) Both groups contain the bracket \((m-n)\), so it can be taken out, leaving \((3m-2n)+1\).
5Check by expansion
\[(m-n)(3m-2n+1)=3m^{2}-2mn+m-3mn+2n^{2}-n\] \[=3m^{2}-5mn+2n^{2}+m-n\quad \checkmark\]
Expanding returns the original expression, so the factorisation is correct.
6Match the option & conclude
\[3m^{2}-5mn+2n^{2}+m-n=(m-n)(3m-2n+1)\]
This is exactly Option A.
Answer: A   \((m-n)(3m-2n+1)\)

Question. \(2p^{2}+pq-3q^{2}+2p+3q=\)
A. \((2p+3q)(p-q+1)\)   B. \((2p-3q)(p+q+1)\)   C. \((2p+3q)(p+q-1)\)   D. \((p-3q)(2p+q+1)\)

Show the worked solution
Step 1. Factorise the quadratic core: split \(pq\) as \(3pq-2pq\), so \(2p^{2}+3pq-2pq-3q^{2}=p(2p+3q)-q(2p+3q)=(2p+3q)(p-q)\).
Step 2. Re-attach the linear part: \(2p^{2}+pq-3q^{2}+2p+3q=(2p+3q)(p-q)+(2p+3q)\cdot1\).
Step 3. Take out the common factor \((2p+3q)\): \((2p+3q)\left[(p-q)+1\right]=(2p+3q)(p-q+1)\).
Step 4. Check by expanding: \(2p^{2}-2pq+2p+3pq-3q^{2}+3q=2p^{2}+pq-3q^{2}+2p+3q\), so the answer is A.
Answer: A   \((2p+3q)(p-q+1)\)
