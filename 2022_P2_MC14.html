Step-by-Step Solution

We are given:

  • First pattern: \(T(1) = 8\)
  • Recurrence relation: \(T(n+1) = T(n) + (2n + 6)\) for any positive integer \(n\).

💡 Hint

This means the (n+1)th pattern is formed by adding \((2n+6)\) dots to the nth pattern. To reach the 7th pattern, we must start from the 1st and apply the recurrence step by step.

Apply the recurrence relation for different values of \(n\) from 1 to 6:

\(T(2) = T(1) + (2 \times 1 + 6) = T(1) + 8\)

\(T(3) = T(2) + (2 \times 2 + 6) = T(2) + 10\)

\(T(4) = T(3) + (2 \times 3 + 6) = T(3) + 12\)

\(T(5) = T(4) + (2 \times 4 + 6) = T(4) + 14\)

\(T(6) = T(5) + (2 \times 5 + 6) = T(5) + 16\)

\(T(7) = T(6) + (2 \times 6 + 6) = T(6) + 18\)

💡 Hint

The increments form an arithmetic progression: \(8, 10, 12, 14, 16, 18\) with common difference 2. Starting from \(T(1)=8\), we can add all increments up to \(T(7)\).

Starting from \(T(1) = 8\), we sum all added dots from pattern 1 to pattern 7:

\(T(7) = T(1) + 8 + 10 + 12 + 14 + 16 + 18\)

\(T(7) = 8 + 8 + 10 + 12 + 14 + 16 + 18\)

\(T(7) = 86\)

✅ Answer

The number of dots in the 7th pattern is 86. (Option C)

Sum of arithmetic series: \(S = \frac{k}{2}(a + l)\) where \(k\) is the number of terms, \(a\) is the first term, \(l\) is the last term.

For the increments \(8, 10, 12, 14, 16, 18\): there are 6 terms, first term 8, last term 18.

Sum of increments = \(\frac{6}{2}(8 + 18) = 3 \times 26 = 78\)

Total dots = \(T(1) + \text{Sum of increments} = 8 + 78 = 86\)

Alternatively, the general formula for the \(n\)th term is \(T(n) = n^2 + 5n + 2\). Verify: \(T(7) = 7^2 + 5(7) + 2 = 49 + 35 + 2 = 86\).
