HKDSE Math 2019 Paper 1 Q7 6. Equations [4 marks]

Ratio Problem

In a playground, the ratio of the number of adults to the number of children is \(13 : 6\). If \(9\) adults and \(24\) children enter the playground, then the ratio of the number of adults to the number of children becomes \(8 : 7\). Find the original number of adults in the playground.

Step-by-Step Solution

1

Let the original numbers be \(13k\) and \(6k\)

Since the ratio of adults to children is \(13 : 6\), we can represent the original number of adults as \(13k\) and the original number of children as \(6k\), where \(k\) is a positive constant.

💡 Hint: Using \(13k\) and \(6k\) automatically preserves the ratio \(13 : 6\) for any positive value of \(k\).
2

Set up the equation after new people enter

After \(9\) adults and \(24\) children enter:

  • New adults: \(13k + 9\)
  • New children: \(6k + 24\)

The new ratio is \(8 : 7\), so we can write:

\[ \frac{13k + 9}{6k + 24} = \frac{8}{7} \]
💡 Hint: A ratio \(a : b\) can be written as the fraction \(\frac{a}{b}\). Here, the "new adults" is the numerator, and "new children" is the denominator.
3

Solve the equation by cross-multiplication

Cross-multiplying:

\(7(13k + 9) = 8(6k + 24)\)

\(91k + 63 = 48k + 192\)

\(91k - 48k = 192 - 63\)

\(43k = 129\)

💡 Hint (Cross-multiplication): If \(\frac{a}{b} = \frac{c}{d}\), then \(ad = bc\). Multiply the numerator of the left side by the denominator of the right side, and vice versa.
4

Find \(k\) and the original number of adults

From \(43k = 129\):

\[ k = \frac{129}{43} = 3 \]

The original number of adults is \(13k\):

\[ 13 \times 3 = 39 \]

∴ The original number of adults is 39.

💡 Hint: Remember the question asks for the number of adults, which is \(13k\), not \(k\) itself.
Step 1 of 4

Final Answer

The original number of adults is 39
