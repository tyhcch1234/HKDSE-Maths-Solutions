Laws of Indices, Exponential and Logarithmic Functions
Laws of Indices Logarithms Increasing Function Ordering Numbers

The Question

Which of the following is the least?

  • A\((-345)^{768}\)
  • B\(453^{-786}\)
  • C\(\left(\dfrac{1}{435}\right)^{867}\)
  • D\(\left(\dfrac{2}{543}\right)^{876}\)

Guided Solution — Step by Step

Each option is a power with a very large index, so we cannot compute them directly. But \(\log_{10} x\) is an increasing function:

\[ a > b > 0 \;\Longleftrightarrow\; \log a > \log b \]

Therefore, instead of comparing the powers themselves, we compare their common logarithms. The smallest logarithm belongs to the smallest number.

Hint — power law of logarithms: \[ \log M^{\,n} = n\log M \] This law turns an enormous index into an ordinary multiplying factor.

The index \(768\) is even, so the negative base becomes positive:

\[ (-345)^{768} = 345^{768} \]

Now take logarithms:

\[ \log\left[(-345)^{768}\right] = \log 345^{768} = 768\log 345 \approx 1949.045065 \]
Hint: \(\log(-345)^{768}\) really means \(\log\big(345^{768}\big)\) — the logarithm is applied to the power, which is already positive. This is a very common trap.

Here the index is negative, so the value is a very small positive number:

\[ \log\left(453^{-786}\right) = -786\log 453 \approx -2087.693187 \]
Hint: \(786\log 453 \approx 786\times 2.6561 \approx 2087.7\), and the minus sign makes the logarithm negative — a first sign that this value is extremely small.
\[ \log\left(\frac{1}{435}\right)^{867} = 867\log\frac{1}{435} \approx -2287.570186 \]
Hint: \(\log\dfrac{1}{435} = -\log 435 \approx -2.6385\). Multiplying by \(867\) makes it strongly negative.
\[ \log\left(\frac{2}{543}\right)^{876} = 876\log\frac{2}{543} \approx -2131.982375 \]
Hint: \(\dfrac{2}{543}\) is smaller than \(\dfrac{1}{435}\), so its logarithm is more negative; however the index \(876\) is only slightly larger than \(867\).
OptionExpressionLogarithm (approx.)
A\((-345)^{768}\)\(1949.045065\)
B\(453^{-786}\)\(-2087.693187\)
C\(\left(\frac{1}{435}\right)^{867}\)\(-2287.570186\)
D\(\left(\frac{2}{543}\right)^{876}\)\(-2131.982375\)

The smallest logarithm is \(-2287.570186\), which belongs to option C.

Hint: since \(\log x\) is an increasing function, \[ \log a < \log b \;\Longrightarrow\; a < b \] so the least logarithm corresponds to the least number.

Answer

C

The least is \(\left(\dfrac{1}{435}\right)^{867}\).
Comparing the common logarithms \(1949.045065,\;-2087.693187,\;-2287.570186,\;-2131.982375\), the smallest is \(-2287.570186\). Since \(\log x\) is increasing, option C is the least.
