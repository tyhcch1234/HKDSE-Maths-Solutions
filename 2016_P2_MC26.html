Coordinate Geometry — Point on a line equidistant from two given points

Coordinate Geometry Distance Formula Straight Line \(x-2y=0\) Equidistant Points Perpendicular Bisector

The Question

The coordinates of the points \(A\) and \(B\) are \((9,-2)\) and \((-1,8)\) respectively. If \(C\) is a point lying on the straight line \(x-2y=0\) such that \(AC=BC\), then the \(x\)-coordinate of \(C\) is

A. \(1\)
B. \(2\)
C. \(3\)
D. \(4\)

Part (a) — Parametrising the Point \(C\) Setup

Any point on the line \(x-2y=0\) can be written using a single parameter. Rearranging gives \(x=2y\), so if \(y=c\) then \(x=2c\).

C = (9.00, 4.50) AC = 6.52 BC = 10.61 |AC−BC| = 4.09
Step 11M

Let \(C=(2c,\,c)\), where \(c\) is a real number, since \(C\) lies on \(x-2y=0\).

Hint: A point on a straight line has only one degree of freedom. Using one parameter \(c\) turns the two unknown coordinates into a single unknown — much easier to solve.
\(C=(2c,\,c)\)
Step 21M

Write the given points: \(A=(9,-2)\) and \(B=(-1,8)\).

Hint: Always label \(x_1,y_1\) and \(x_2,y_2\) clearly before substituting into any formula.
As given in the question.
0 / 2

Part (b) — Using \(AC=BC\) to Find \(c\) Solve

The condition \(AC=BC\) means \(C\) lies on the perpendicular bisector of \(AB\). We square the distances to avoid square roots.

C = (0.00, 0.00) AC = 13.45 BC = 8.06 AC² − BC² = 116.00
Step 11M

Distance formula: \(AC^2 = (2c-9)^2 + (c-(-2))^2 = (2c-9)^2 + (c+2)^2\).

Hint: Square the distance before expanding — you never need to take a square root.
Step 21M

Similarly, \(BC^2 = (2c-(-1))^2 + (c-8)^2 = (2c+1)^2 + (c-8)^2\).

Hint: Watch the signs: subtracting a negative makes a positive. \(2c-(-1)=2c+1\).
Step 31M

Since \(AC=BC\), we have \(AC^2=BC^2\). Equate and expand:

\[ (4c^2-36c+81)+(c^2+4c+4) = (4c^2+4c+1)+(c^2-16c+64) \] \[ 5c^2-32c+85 = 5c^2-12c+65 \]
Hint: The \(c^2\) terms cancel — the equation becomes linear, so there is exactly one solution (which is why the answer is unique).
Step 41A

Rearranging:

\[ -32c+85 = -12c+65 \;\Longrightarrow\; -20c = -20 \;\Longrightarrow\; c = 1 \]

Therefore the \(x\)-coordinate of \(C\) is \(2c = 2(1) = 2\).

Hint: The question asks for the \(x\)-coordinate, not \(c\). Remember \(x_C = 2c\).
\(x\)-coordinate of \(C = 2\)  ⟹  Answer: B
0 / 4

Summary of Answers

  • Parametrisation of \(C\) on \(x-2y=0\):   \(C=(2c,\,c)\)
  • Condition:   \(AC^2=BC^2\)
  • Equation after expanding:   \(5c^2-32c+85 = 5c^2-12c+65\)
  • Solution:   \(c=1\)
  • Required \(x\)-coordinate:   \(x_C = 2c = 2\)
  • Correct option:   B
