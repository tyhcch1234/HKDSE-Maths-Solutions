Question 37

The real part of

\[ \frac{2i^{12} + 3i^{13} + 4i^{14} + 5i^{15} + 6i^{16}}{1 - i} \]
A.  \(-3\)
B.  \(-1\)
C.  \(1\)
D.  \(3\)

🌀 Key Idea: The Powers of \(i\) Cycle

Drag the slider to see how \(i^n\) repeats every 4 powers.

\(i^{12} =\) 1
remainder of \(n \div 4\) determines the value
\(n \div 4\) remainder: 0
\(i^0\)\(1\)
\(i^1\)\(i\)
\(i^2\)\(-1\)
\(i^3\)\(-i\)

✏️ Step-by-Step Solution

Since \(i^4 = 1\), we reduce each exponent modulo 4:

\(i^{12} = (i^4)^3 = 1\)
\(i^{13} = i^{12}\cdot i = i\)
\(i^{14} = i^{12}\cdot i^2 = -1\)
\(i^{15} = i^{12}\cdot i^3 = -i\)
\(i^{16} = (i^4)^4 = 1\)
💡 Hint: \(i^1 = i,\; i^2 = -1,\; i^3 = -i,\; i^4 = 1\). The cycle repeats every 4.

Replace each power with its value:

\[ \begin{aligned} &2(1) + 3(i) + 4(-1) + 5(-i) + 6(1) \\[2pt] &= 2 + 3i - 4 - 5i + 6 \\[2pt] &= (2 - 4 + 6) + (3i - 5i) \\[2pt] &= 4 - 2i \end{aligned} \]
💡 Hint: Group real parts together and imaginary parts together.

Multiply numerator and denominator by the conjugate of \(1-i\), which is \(1+i\).

\[ \frac{4 - 2i}{1 - i} \times \frac{1 + i}{1 + i} \]
💡 Hint: For \(a+bi\), the conjugate is \(a-bi\). Use \((a+bi)(a-bi) = a^2 + b^2\) to remove \(i\) from the denominator.
\[ \begin{aligned} \frac{(4 - 2i)(1 + i)}{(1 - i)(1 + i)} &= \frac{4 + 4i - 2i - 2i^2}{1^2 + 1^2} \\[2pt] &= \frac{4 + 2i - 2(-1)}{2} \\[2pt] &= \frac{4 + 2i + 2}{2} \\[2pt] &= \frac{6 + 2i}{2} \\[2pt] &= 3 + i \end{aligned} \]
💡 Hint: Remember \(i^2 = -1\). Denominator: \((1)^2 + (1)^2 = 2\).

In the form \(a + bi\), the real part is \(a\).

\[ 3 + i \]

So the real part is 3.

Answer: D. 3

Answer: D. 3

📌 Quick Recap

Powers of \(i\)

\(i^4 = 1\), so reduce exponents modulo 4.

\(i^0=1\) \(i^1=i\) \(i^2=-1\) \(i^3=-i\)

Rationalising denominator

Multiply numerator & denominator by the conjugate.

\(\frac{a+bi}{c+di} = \frac{(a+bi)(c-di)}{c^2+d^2}\)
