I Statement I — Is \(m<0\)? 1 mark

0 / 2
Step 1 1M

From the graph, line \(L: mx+ny=3\) cuts the \(x\)-axis at a negative value (to the left of \(O\)).

\[ \text{x-intercept} = \frac{3}{m} \quad\text{and it is negative.} \]
Hint: Set \(y=0\): \(mx=3 \Rightarrow x=\dfrac{3}{m}\). If this is negative, the numerator \(3\) and denominator \(m\) must have opposite signs.
\[ \frac{3}{m} < 0 \;\Longrightarrow\; m < 0 \]
Step 2 1A

Since \(3>0\), the inequality \(\dfrac{3}{m}<0\) forces \(m\) to be negative.

Statement I is TRUE: \(m < 0\). ✓

II Statement II — Is \(n>3\)? 1 mark

4.0
0 / 3
Step 1 1M

The graph shows the line crossing the positive \(y\)-axis at a value smaller than \(1\).

\[ \text{y-intercept} = \frac{3}{n} \quad\text{with } 0 < \frac{3}{n} < 1. \]
Hint: Setting \(x=0\) gives \(ny=3\), so \(y=\dfrac{3}{n}\). The graph shows this value is positive but less than 1.
Step 2 1M

Because \(\dfrac{3}{n}>0\), we get \(n>0\). Multiply the upper bound by \(n\) (positive, so the inequality direction is preserved):

\[ \frac{3}{n} < 1 \;\Longrightarrow\; 3 < n \quad (n>0) \]
Step 3 1A

Combining both facts: \(n>0\) and \(n>3\), so \(n>3\).

Statement II is TRUE: \(n > 3\). ✓

III Statement III — Is \(m+n>0\)? 1 mark

0 / 3
Step 1 1M

Rewrite \(mx+ny=3\) as \(y=-\dfrac{m}{n}x+\dfrac{3}{n}\), so the slope of \(L\) is \(-\dfrac{m}{n}\).

\[ \text{slope of } L = -\frac{m}{n} \]
Hint: From the graph, the slope of \(L\) is smaller than the slope of the line through \((-1,0)\) and \((0,1)\), which is \(\dfrac{1-0}{0-(-1)}=1\).
Step 2 1M

Since \(L\) is less steep than the reference line of slope \(1\):

\[ -\frac{m}{n} < \frac{1-0}{0-(-1)} = 1 \]

Multiply both sides by \(n>0\) (already established in Part II):

\[ -m < n \;\Longrightarrow\; m+n > 0 \]
Step 3 1A

Rearranging gives \(m+n>0\).

Statement III is TRUE: \(m+n > 0\). ✓

✓ Final Answer & Summary

  • I. \(m<0\) — TRUE (negative x-intercept \(\Rightarrow \tfrac{3}{m}<0\))
  • II. \(n>3\) — TRUE (y-intercept \(0<\tfrac{3}{n}<1 \Rightarrow n>3\))
  • III. \(m+n>0\) — TRUE (slope \(-\tfrac{m}{n}<1 \Rightarrow m+n>0\))
  • Conclusion: All three statements are true. Answer is D — I, II and III.
