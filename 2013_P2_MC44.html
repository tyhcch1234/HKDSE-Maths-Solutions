The Question

If the first three digits and the last five digits of an eight-digit phone number are formed by a permutation of 5, 6, 9 and a permutation of 2, 3, 4, 7, 8 respectively, how many different eight-digit phone numbers can be formed?

Step-by-Step Guided Solution

An eight-digit phone number is split into two independent blocks:

  • Positions 1–3 are some permutation of the digits \(\{5, 6, 9\}\).
  • Positions 4–8 are some permutation of the digits \(\{2, 3, 4, 7, 8\}\).

No digit is repeated inside a block, and no digit crosses from one block to the other — so we can count each block separately and multiply.

💡 Hint: When a task splits into stages, the Multiplication Principle says: \[ \text{Total} = (\text{ways for stage 1}) \times (\text{ways for stage 2}). \]

We have 3 distinct digits: \(5, 6, 9\). We want to fill 3 positions.

Using the factorial for permutations of \(n\) distinct objects:

\[ P(n,n) = n! = n \times (n-1) \times \dots \times 1. \]

So the number of ways to arrange the first block is:

\[ 3! = 3 \times 2 \times 1 = 6. \]
💡 Hint: \(3!\) counts every possible ordering of three distinct items. For example: \(569,\ 596,\ 659,\ 695,\ 956,\ 965\).

We have 5 distinct digits: \(2, 3, 4, 7, 8\). We want to fill 5 positions.

Again using the factorial:

\[ 5! = 5 \times 4 \times 3 \times 2 \times 1 = 120. \]
💡 Hint: \(5! = 120\) counts every possible ordering of five distinct items.

Because the first block and the second block do not share any digits, choosing an arrangement for the first block does not restrict the second block.

Therefore, by the Multiplication Principle:

\[ \text{Total} = 3! \times 5! = 6 \times 120 = 720. \]

Answer

C. 720

🔑 Key Takeaways

  • 1 If \(n\) distinct objects must fill \(n\) positions, the number of permutations is \(n!\).
  • 2 When stages are independent, multiply the number of choices: \(3! \times 5! = 720\).
  • 3 Watch out for false distractors: \(3! + 5! = 126\) and \(5! \times 336 = 40320\) — check what each answer represents!
