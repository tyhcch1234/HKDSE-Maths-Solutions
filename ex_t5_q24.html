T5 Q24

In an arithmetic sequence, the 4th term is 9 and the common difference is 2. Find the first term.

Solution

Use the arithmetic sequence formula $a_n=a+(n-1)d$.
For the 4th term, set $n=4$: $a_4=a+3d$.
Substitute $a_4=9$ and $d=2$: $9=a+3(2)$.
Simplify: $9=a+6$.
Solve for $a$: $a=9-6=3$.
Check: $a_4=3+3(2)=9$, which matches the given information.
The first term is $3$.
