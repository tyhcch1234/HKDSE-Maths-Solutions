Step 1

Let \(\angle ACD = x\). In \(\triangle ACD\), the exterior angle at \(D\) of the triangle (formed by the straight line \(ADE\)) is \(\angle CDE = 66^\circ\).

\[ \angle CAD = \angle CDE - \angle ACD = 66^\circ - x \qquad (\text{ext. } \angle \text{ of } \triangle) \]
Hint: In \(\triangle ACD\), the exterior angle \(\angle CDE\) equals the sum of the two interior opposite angles, \(\angle CAD + \angle ACD\).
Step 2

In \(\triangle ABD\): \(AB = BD\) is given, so \(\triangle ABD\) is isosceles. Therefore the base angles are equal:

\[ \angle BDA = \angle BAD = 66^\circ - x \qquad (\text{base } \angle\text{s, isos. } \triangle) \]

Since \(ABD\) is on the straight line \(ABC\), the exterior angle of \(\triangle ABD\) at \(B\) is:

\[ \angle CBD = \angle BAD + \angle BDA = (66^\circ - x) + (66^\circ - x) = 132^\circ - 2x \]
Hint: \(\angle BAD\) is the same angle as \(\angle CAD\) because \(A,B,C\) are collinear.
Step 3

In \(\triangle BCD\): \(BC = CD\) is given, so \(\triangle BCD\) is isosceles, giving equal base angles:

\[ \angle CDB = \angle CBD = 132^\circ - 2x \qquad (\text{base } \angle\text{s, isos. } \triangle) \]
Hint: Notice \(x\) appears twice — the relation \(\angle CDB = 132^\circ - 2x\) now locks the picture together.
Step 4

At \(D\), the three angles \(\angle BDA\), \(\angle CDB\) and \(\angle CDE\) lie on the straight line \(ADE\), so their sum is \(180^\circ\):

\[ (66^\circ - x) + (132^\circ - 2x) + 66^\circ = 180^\circ \] \[ 264^\circ - 3x = 180^\circ \] \[ 3x = 84^\circ \] \[ x = 28^\circ \]
\(\angle ACD = 28^\circ\) — the answer is A.

✓Summary of Answers

  • Given: \(ABC\), \(ADE\) straight lines; \(AB=BD\); \(BC=CD\); \(\angle CDE=66^\circ\).
  • Let \(x=\angle ACD\).
  • Step 1 (ext. ∠ of ΔACD): \(\angle CAD = 66^\circ - x\).
  • Step 2 (isos. ΔABD + ext. ∠): \(\angle BDA = 66^\circ - x\), \(\angle CBD = 132^\circ - 2x\).
  • Step 3 (isos. ΔBCD): \(\angle CDB = 132^\circ - 2x\).
  • Step 4 (adj. ∠s on st. line at D): \((66^\circ - x)+(132^\circ - 2x)+66^\circ = 180^\circ\).
  • Solve: \(3x = 84^\circ \Rightarrow x = 28^\circ\).
  • Answer: \(\boxed{\angle ACD = 28^\circ}\) → Option A.
