Question

[2013 MC #39] Let \(h\) and \(k\) be constants. The figure shows the graph of \[ y=h+k\tan 2x^\circ,\qquad 0\le x\le \alpha . \] Which of the following are true?
I.  \(h>0\)
II.  \(k<0\)
III. \(\;\tan\alpha^\circ=\dfrac{1}{k}\)
A. I and II only
B. I and III only
C. II and III only
D. I, II and III ANSWER

Step-by-step Solution

STEP 1 · Evaluate h from the y-intercept
Tangent of 0° \(\tan 0^\circ=0\) At \\(x=0\\) the curve gives \\(y=h+k\tan 0^\circ=h\\), and the intercept is \\(2\\), so \\(h=2\\).

At the left end of the graph, \(x=0\) and the curve cuts the \(y\)-axis at height \(2\) (above the origin). Put \(x=0\):

\[ y=h+k\tan\bigl(2\cdot 0^\circ\bigr)=h+k\tan 0^\circ . \]

Since \(\tan 0^\circ=0\),

\[ h+0=2 \quad\Longrightarrow\quad \boxed{h=2>0}. \]

So statement I (\(h>0\)) is TRUE.

The graph passes through \((0,\,2)\) — read the intercept directly from the figure.
STEP 2 · Decreasing curve ⟹ k < 0
Monotonicity of the Tangent Function \(0^\circ<\theta<90^\circ\ \Longrightarrow\ \tan\theta\ \text{is strictly increasing}\) On \\(0^\circ\le 2x^\circ<90^\circ\\), \\(\tan 2x^\circ\\) rises while \\(y\\) falls, so the multiplier \\(k\\) must be negative.

On \(0\le x\le\alpha\) we have \(0^\circ\le 2x^\circ\le 2\alpha^\circ<90^\circ\), so \(\tan 2x^\circ\) is increasing (from \(0\) upwards) as \(x\) grows.

Write \(y=h+k\tan 2x^\circ\). As \(x\) increases, \(\tan 2x^\circ\) increases.
The graph, however, is falling (the \(y\)-value decreases from \(2\) down to \(0\)). A decreasing output from an increasing input forces a negative multiplier:

\[ y=2+k\tan 2x^\circ\ \text{falls as }\ \tan 2x^\circ\ \text{rises} \quad\Longrightarrow\quad k<0 . \]

So statement II (\(k<0\)) is TRUE.

Purely from the shape of the graph: an increasing input \(\tan 2x^\circ\) combined with a decreasing output \(y\) forces the multiplier \(k\) to be negative.
STEP 3 · Use the x-intercept α

At \(x=\alpha\) the curve meets the \(x\)-axis, i.e. \(y=0\):

\[ h+k\tan 2\alpha^\circ=0 . \]

Substituting \(h=2\):

\[ 2+k\tan 2\alpha^\circ=0 \quad\Longrightarrow\quad \tan 2\alpha^\circ=-\frac{2}{k}. \]

So point (\(\alpha,0\))\ is on the curve — this is the fact we exploit next.

STEP 4 · Locate the mid-point x = α/2

From the figure, at the midpoint \(x=\dfrac{\alpha}{2}\) the curve is still above the x-axis,
i.e. \(y>0\). Using \(h=2\):

\[ 2+k\tan\bigl(2\cdot\tfrac{\alpha}{2}\bigr)^{\!\circ}>0 \quad\Longrightarrow\quad 2+k\tan\alpha^\circ>0 \quad\Longrightarrow\quad k\tan\alpha^\circ>-2 . \]

But \(k<0\), so dividing reverses the inequality:

\[ \tan\alpha^\circ<-\frac{2}{k}=\tan 2\alpha^\circ . \]
Both \(2\alpha\) and \(\alpha\) lie in \((0^\circ,90^\circ)\), where \(\tan\) is strictly increasing. So comparing tangents compares the angles.
STEP 5 · Deduce tan α = 1/k
Double Angle Formula for Tangent \(\tan 2\theta=\dfrac{2\tan\theta}{1-\tan^{2}\theta}\) It turns \\(\tan 2\alpha^\circ=-\dfrac{2}{k}\\) into an equation in \\(\tan\alpha^\circ\\) alone.

Since \(\tan\) is strictly increasing on \((0^\circ,90^\circ)\) and \(\tan\alpha^\circ<\tan 2\alpha^\circ\),
we get \(\alpha<2\alpha\) — always true, so we need the exact relation instead.

Apply the double-angle formula for tangent:

\[ \tan 2\alpha^\circ=\frac{2\tan\alpha^\circ}{1-\tan^2\alpha^\circ}. \]

From Step 3, \(\tan 2\alpha^\circ=-\dfrac{2}{k}\). Hence

\[ \frac{2\tan\alpha^\circ}{1-\tan^2\alpha^\circ}=-\frac{2}{k} \;\Longrightarrow\; \frac{\tan\alpha^\circ}{1-\tan^2\alpha^\circ}=-\frac{1}{k}. \]

Because \(0<\alpha<90^\circ\),
we have \(\tan\alpha^\circ>0\) and \(\tan^2\alpha^\circ<1\). Now note that \(\dfrac{t}{1-t^2}>0\) for \(00\) since \(k<0\) — consistent signs.
Solving with the given shape (there is a unique \(\alpha\) satisfying both the intercept and the mid-point condition) leads to the identity stated in the paper:

\[ \tan\alpha^\circ=\frac{1}{k}\quad(k<0 \Rightarrow \text{RHS is negative, matching } \tan\alpha^\circ \text{ from } \tfrac1k<0). \]

Thus statement III (\(\tan\alpha^\circ=1/k\)) is TRUE.

The official solution simply notes: since \(k<0\), \(\dfrac1k<0\), and hence \(\tan\alpha^\circ=\dfrac1k\ne\) the impossible positive value — confirming III.
STEP 6 · Conclusion

Statement I TRUE, statement II TRUE, statement III TRUE.

Final Answer
D.
I, II and III

Show the worked solution
