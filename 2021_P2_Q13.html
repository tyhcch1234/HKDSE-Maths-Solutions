2021 P2 Q13Formulas and Sequences

In the figure, the 1st pattern consists of 3 dots. For any positive integer $n$, the $(n+1)$th pattern is formed by adding $(2n+3)$ dots to the $n$th pattern. Find the number of dots in the 8th pattern.

  • A. 63
  • B. 75
  • C. 80
  • D. 99
1Define $T(m)$ and read the given conditions

Let $T(m)$ be the number of dots in the $m$th pattern.
We are given:

(1) $T(1) = 3$  
 
and 
 
(2) $T(n+1) = T(n) + (2n+3)$ for every positive integer $n$.

Patterns 1,
2, 3 indeed have $3,\ 3+5=8,\ 8+7=15$ dots.

Hint: The rule (2) is a recurrence relation — each pattern is the previous one plus a growing number of dots.
2Unroll the recurrence one step at a time
Recurrence Relation \(T(n+1)=T(n)+f(n)\) Each pattern adds \(2n+3\) dots, so we unroll from \(T(1)=3\) up to \(T(8)\).

Apply (2) with $n = 7, 6, 5, \dots, 1$:

$T(8) = T(7) + 17$  
 
(by (2) with $n=7$)
$T(7) = T(6) + 15$  
 
(by (2) with $n=6$)

Substituting downwards until we reach the known value $T(1)$:

$T(8) = T(1) + 5 + 7 + 9 + 11 + 13 + 15 + 17$  
 
(by (2) with $n=1,2,\dots,7$)

Hint: Each step adds the odd number $2n+3$: for $n=1,2,\dots,7$ these are $5,7,9,11,13,15,17$.
3Substitute $T(1)=3$ and sum
Sum of an Arithmetic Sequence \(S_{n}=\dfrac{n}{2}\,(a+\ell)\) The added terms \(5,7,\ldots,17\) form an arithmetic sequence with 7 terms.

$T(8) = 3 + 5 + 7 + 9 + 11 + 13 + 15 + 17$  
 
(by (1))

The 7 added terms form an arithmetic sequence with first term $5$,
last term $17$, so their sum is

$\dfrac{7(5+17)}{2} = 7 \times 11 = 77.$

Hence $T(8) = 3 + 77 = 80$.

Hint: Sum of an arithmetic sequence $= \dfrac{\text{no. of terms} \times (\text{first} + \text{last})}{2}$.
4Check with a closed form

Since $\displaystyle\sum_{k=1}^{n-1}(2k+3) = (n-1)n + 3(n-1) = n^2 + 2n - 3$,

$T(n) = 3 + (n^2 + 2n - 3) = n^2 + 2n$.

Verify: $T(1)=3$, $T(2)=8$, $T(3)=15$ ✓ — and $T(8) = 8^2 + 2(8) = 64 + 16 = 80$.

Hint: The verification matches every pattern drawn in the figure.
Answer: C  ·  the 8th pattern has $\boxed{80}$ dots.

Question. The number of dots in the \(m\)th pattern of a sequence is \(T(m)\), where \(T(1)=2\) and \(T(n+1)=T(n)+(3n+1)\) for every positive integer \(n\). Find the number of dots in the 10th pattern.

Show the worked solution
Step 1. Unroll the recurrence: \(T(10)=T(1)+\displaystyle\sum_{n=1}^{9}(3n+1)\).
Step 2. \(\displaystyle\sum_{n=1}^{9}(3n+1)=3(1+2+\cdots+9)+9=3(45)+9=144\).
Step 3. Hence \(T(10)=2+144=146\).
Step 4. Check the first few terms: \(T(2)=6\), \(T(3)=13\), \(T(4)=23\) — each step adds \(4,7,10\) as required.
Answer: \(146\) dots
