The Question

Let \(a_n\) be the \(n\)th term of a sequence. If \(a_2 = 3\), \(a_5 = 41\) and

\(a_{n+2} = 2a_{n+1} + a_n\)  for any positive integer \(n\),

then \(a_6 = \ ?\)

A. 99
B. 101
C. 239
D. 243
💡 Hint — the "give me an example" trick

You are given two known terms \(a_2=3\) and \(a_5=41\). The rule links three consecutive terms. Set \(n=3\) to jump from \(a_3,a_4\) to \(a_5\) — that gives an equation for the single unknown \(a_3\).

Step-by-Step Solution

The recurrence is

\(a_{n+2} = 2a_{n+1} + a_n \quad (n \ge 1)\)

Reading it in words:

The term two places ahead equals 2 × (the next term) plus the current term.

So e.g. with \(n=1\): \(a_3 = 2a_2 + a_1\). With \(n=3\): \(a_5 = 2a_4 + a_3\).

⚠️ Common mistake: writing \(a_5 = 2a_3 + a_2\). The indices must increase by exactly 1 each time.

The jump \(a_3 \to a_5\) is 2 steps, so take \(n=3\):

n = 3 : a₅ = 2a₄ + a₃

(also: a₄ = 2a₃ + a₂ with n = 2)

Known: \(a_2 = 3\), \(a_5 = 41\). Unknowns: \(a_3, a_4, a_6\). We have two equations and two unknowns \(a_3,a_4\) — solvable!

From \(n=2\):

\(a_4 = 2a_3 + a_2 = 2a_3 + 3\)

Substitute into \(a_5 = 2a_4 + a_3\):

41 = 2(2a₃ + 3) + a₃

41 = 4a₃ + 6 + a₃

41 = 5a₃ + 6

35 = 5a₃

a₃ = 7

Now plug \(a_3 = 7\) back into \(a_4 = 2a_3 + 3\):

a₄ = 2(7) + 3

a₄ = 17

Quick check: \(a_5 = 2a_4 + a_3 = 2(17) + 7 = 41\). ✓ Matches the given value.

We need \(n=4\): \(a_6 = 2a_5 + a_4\). Both \(a_5\) and \(a_4\) are now known.

a₆ = 2a₅ + a₄

= 2(41) + 17

= 82 + 17

a₆ = 99

The answer is

A. 99

🎯 Key Takeaway

  1. In a recurrence relation, substitute the correct \(n\) — check that the indices differ by 1.
  2. Use the known far-apart terms (here \(a_2, a_5\)) to build an equation for the term in between.
  3. Once two consecutive terms are known, generate all following terms forward.
  4. In MC, always verify: \(2(17)+7=41\) ✓ and \(2(41)+17=99\).
