Multiple Choice — Recognising the graph of a quadratic function from its coefficients

Functions & Graphs Quadratic Graphs Sign of Coefficients y-intercept

QQuestion

Read the given condition, then decide which graph is possible.

2016MC#9. If \(-1<a<0\), which of the following may represent the graph of

\[ y=(ax+1)^2+a \quad ? \]

A. opens downwards, \(y\)-intercept negative  ·  B. opens downwards, \(y\)-intercept positive  ·  C. opens upwards, \(y\)-intercept negative  ·  D. opens upwards, \(y\)-intercept positive

Key idea: Expand \(y=(ax+1)^2+a\) into standard form \(y=Ax^2+Bx+C\). The sign of \(A\) tells us whether the parabola opens upwards or downwards, and \(C\) is the \(y\)-intercept.

AExpand into standard form

Rewrite \(y=(ax+1)^2+a\) as \(y=Ax^2+Bx+C\) and inspect the leading coefficient and constant term.

a = −0.50 A = a² = 0.25 > 0 C = 1 + a = 0.50 > 0 vertex = (…)
Step 1
Expand the square: \[ y=(ax+1)^2+a=a^2x^2+2ax+1+a \]
Hint: Compare with the standard form \(y=Ax^2+Bx+C\). Here \(A=a^2\), \(B=2a\) and \(C=1+a\).
Step 2
Look at the coefficient of \(x^2\): \[ A=a^2 > 0 \quad\text{for all } a\neq 0 \] Since \(-1<a<0\), certainly \(a\neq 0\), so \(A>0\).
Hint: Any non-zero number squared is positive. So no matter what \(a\) is (as long as \(a\neq 0\)), the parabola opens upwards.
Conclusion: The graph opens upwards.
Step 3
The constant term is \(C=1+a\). Since \(-1<a<0\): \[ 0<1+a<1 \;\Longrightarrow\; C>0 \]
Hint: The constant term \(C\) is exactly the \(y\)-intercept (the point where \(x=0\)). Adding 1 to a number \(a\in(-1,0)\) pushes it into \((0,1)\).
Conclusion: The \(y\)-intercept is positive.

BMatch with the four options

Use the two conclusions (opens upwards, \(y\)-intercept positive) to pick the correct graph.

Correct option: D A = a² > 0 → opens up ↑ C = 1+a > 0 → intercept above O
Step 1
From Part A we have two facts about the graph of \(y=(ax+1)^2+a\):
Fact 1: The coefficient of \(x^2\) is \(a^2>0\) → the parabola opens upwards.
Fact 2: The constant term is \(1+a>0\) → the \(y\)-intercept lies above the origin.
Step 2
Eliminate the options that contradict a fact: \[ \begin{aligned} &\text{A: opens downwards} &&\Rightarrow \text{reject}\\ &\text{B: opens downwards} &&\Rightarrow \text{reject}\\ &\text{C: opens upwards, } y\text{-intercept }<0 &&\Rightarrow \text{reject}\\ &\text{D: opens upwards, } y\text{-intercept }>0 &&\Rightarrow \text{keep} \end{aligned} \]
Hint: Only option D matches both facts at the same time.
Answer: The required graph is D.
Step 3
To be sure, try a sample value such as \(a=-\tfrac12\): \[ y=\left(-\tfrac12 x+1\right)^2-\tfrac12 =\tfrac14 x^2-x+\tfrac12 \] Here \(A=\tfrac14>0\) (opens upwards) and \(C=\tfrac12>0\) (\(y\)-intercept at \(\left(0,\tfrac12\right)\), above the origin). The graph matches option D exactly.
Hint: Substitute more values of \(a\) into the slider above — the shape and the positive \(y\)-intercept never change.
Final answer: \(\boxed{\text{D}}\)
