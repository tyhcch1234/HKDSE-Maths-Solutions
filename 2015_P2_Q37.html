HKDSE 2015 P2 · Q37

Let \(x_n\) be the \(n\)th term of a geometric sequence. If \(x_6 = 216\) and \(x_8 = 96\), which of the following must be true?

I.   \(x_3 = 729\)
II.   \(\dfrac{x_5}{x_7} > 1\)
III.   \(x_2 + x_4 + x_6 + \cdots + x_{2n} < 2015\)
A. I only
B. II only
C. I and III only
D. II and III only

Step-by-step solution

STEP 1Set up the general term.

Let \(r\) be the common ratio. Then \(x_n = x_2\,r^{\,n-2}\), so

\[x_6 = x_2r^4 = 216 \quad \text{……(1)}\] \[x_8 = x_2r^6 = 96 \quad \text{……(2)}\]

Hint: linking every term to the same base term \(x_2\) turns the two given values into two equations in \(x_2\) and \(r\).
STEP 2Find the common ratio \(r\).

\((2) \div (1)\):

\[r^2 = \frac{96}{216} = \frac{4}{9} \quad\Longrightarrow\quad r = \pm\frac{2}{3}\]

Careful: \(r^2=\frac49\) gives two possible values of \(r\), namely \(+\frac23\) and \(-\frac23\). Both must be tested.
STEP 3Find the base term \(x_2\).

From (1): \(x_2\left(\frac{4}{9}\right)^2 = 216\)

\[x_2 = 216 \times \frac{81}{16} = \frac{2187}{2} = 1093.5\]

\(x_2\) is fixed regardless of the sign of \(r\), because (1) only contains \(r^4\).
STEP 4Check statement I: \(x_3 = 729\).

\(x_3 = x_2r = \dfrac{2187}{2}\left(\pm\dfrac23\right)\)

  • If \(r = \frac23\): \(x_3 = 729\) ✓
  • If \(r = -\frac23\): \(x_3 = -729\) ✗

So \(x_3 = 729\) is not always true → I is false.

“Must be true” means it holds for every valid value of \(r\). One counter-example kills the statement.
STEP 5Check statement II: \(\dfrac{x_5}{x_7} > 1\).

\[\frac{x_5}{x_7} = \frac{x_2r^3}{x_2r^5} = \frac{1}{r^2} = \frac{1}{\frac49} = \frac94 > 1\]

✓ II is true for both \(r=\frac23\) and \(r=-\frac23\) (the sign cancels).

The ratio only involves \(r^2\), so it is independent of the sign of \(r\).
STEP 6Check statement III: sum of even-indexed terms \(< 2015\).

The even-indexed terms form a geometric series with first term \(x_2\) and ratio \(r^2\):

\[S_n = x_2 + x_4 + x_6 + \cdots + x_{2n} = \frac{x_2\left[1-(r^2)^n\right]}{1-r^2}\]

\[= \frac{\frac{2187}{2}\left[1-\left(\frac49\right)^n\right]}{1-\frac49} = \frac{19683}{10}\left[1-\left(\frac49\right)^{\!n}\right]\]

Write each even term as \(x_{2k}=x_2(r^2)^{k-1}\) — this is a GP with ratio \(r^2=\frac49\).
STEP 7Bound the sum.

Since \(0 < \left(\frac49\right)^n \le \frac49 < 1\), the bracket is always less than 1, and

\[S_n = \frac{19683}{10}\left[1-\left(\frac49\right)^{\!n}\right] < \frac{19683}{10} = 1968.3 < 2015\]

✓ III is true.

The sum is bounded by its infinite sum \(\frac{19683}{10}=1968.3\), which is still below 2015.
STEP 8Conclusion.

I is false; II and III are true → the answer is D.

Answer D: II and III only.
Answer: D  (II and III only)
