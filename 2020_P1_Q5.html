HKDSE 2020 · Paper 1 · Q5 Topic: Equations

[4 marks] In a recruitment exercise, the number of male applicants is $28\%$ more than the number of female applicants. The difference of the number of male applicants and the number of female applicants is $91$. Find the number of male applicants in the recruitment exercise.

Solution — step by step

STEP 1Define the unknown
Percentage Increase \(\text{new amount}=\text{original}\times(1+r\%)\) The number of male applicants is \(1.28x\), i.e. \(28\%\) more than the female applicants \(x\).
Let $x$ be the number of female applicants.
Then the number of male applicants is $(1+28\%)x$.
“28% more than” means the original amount plus 28% of it,
i.e. multiply by $1+28\%$.
STEP 2Set up the equation
Difference of the two numbers is $91$:
\[ (1+28\%)x - x = 91 \]
Male minus female gives the difference,
which equals 91.
STEP 3Solve for $x$
Solving a Linear Equation \(ax=b\ \Longrightarrow\ x=\dfrac{b}{a}\) The difference equation \(0.28x=91\) is solved by dividing by \(0.28\).
\[ 0.28x = 91 \]
\[ x = \frac{91}{0.28} = 325 \]
So there are 325 female applicants.
STEP 4Find the number of male applicants
\[ (1+28\%)x = 1.28 \times 325 = 416 \]
Check: $416 - 325 = 91$ ✓
Remember the question asks for the male applicants,
not $x$.
ANSWER The number of male applicants in the recruitment exercise is 416.

Question. In a recruitment exercise, the number of male applicants is \(35\%\) more than the number of female applicants. If the difference between the two numbers is \(126\), find the number of male applicants.

Show the worked solution
Step 1. Let \(x\) be the number of female applicants;
the number of male applicants is \(1.35x\).
Step 2. The difference is \(1.35x-x=0.35x=126\).
Step 3. So \(x=\dfrac{126}{0.35}=360\) female applicants.
Step 4. The number of male applicants is \(1.35\times360=486\). Check: \(486-360=126\) ✓
Answer: \(486\) male applicants
