In a recruitment exercise, the number of male applicants is 28% more than the number of female applicants. The difference of the number of male applicants and the number of female applicants is 91. Find the number of male applicants in the recruitment exercise.

Step-by-step Solution

1 Define the variable +

Let \(x\) be the number of female applicants. This is the unknown we will solve for first.

\[ x = \text{number of female applicants} \]
💡 Hint: Always define the variable clearly. Here we choose the female count as the base because the male count is described relative to it.
2 Express male applicants in terms of \(x\) +

The number of male applicants is 28% more than the female applicants.

\[ \text{Male} = (1 + 28\%)\,x = 1.28x \]
💡 Hint: "28% more than" means multiply the original (female) by \(1 + 0.28 = 1.28\).
3 Set up the equation using the difference +

The difference between the number of male and female applicants is 91.

\[ \text{Male} - \text{Female} = 91 \] \[ 1.28x - x = 91 \]
💡 Hint: Make sure the order of subtraction leads to a positive value. Male is larger, so Male – Female = difference.
4 Solve for \(x\) +

Simplify and solve the equation.

\[ 0.28x = 91 \] \[ x = \frac{91}{0.28} = 325 \]

So the number of female applicants is 325.

💡 Hint: Divide both sides by 0.28. You can also use fractions: \( \frac{91}{0.28} = \frac{9100}{28} = 325\).
5 Find the number of male applicants +

Substitute \(x = 325\) into the expression for male applicants.

\[ \text{Male} = 1.28 \times 325 = 416 \]

Therefore, the number of male applicants is 416.

Answer: 416

💡 Hint: You can also check: \(416 - 325 = 91\), which matches the given difference. ✓
