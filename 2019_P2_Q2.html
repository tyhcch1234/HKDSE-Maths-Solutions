Question

Simplify: \(\; \dfrac{(6x^{7})^{2}}{4x^{5}} = \)

  • A. \(3x^{4}\)
  • B. \(9x^{4}\)
  • C. \(3x^{9}\)
  • D. \(9x^{9}\)
1 Write the given expression. \[ \frac{(6x^{7})^{2}}{4x^{5}} \] Hint: Split the fraction into a numeric part and an algebraic part — this keeps the index laws tidy.
2 Apply “power of a product”: \((ab)^{n}=a^{n}b^{n}\).
Power of a Product \((ab)^{n}=a^{n}b^{n}\) The square hits both the \(6\) and the \(x^{7}\), giving \(36x^{14}\).
\[ (6x^{7})^{2} = 6^{2}\cdot (x^{7})^{2} = 36x^{14} \] Hint: The square hits both the number 6 and the power \(x^{7}\) — a very common trap is squaring only the 6.
3 Deal with the numeric part. \[ \frac{36}{4} = 9 \] Hint: \(36 = 4\times 9\), so the coefficients simplify to \(9\).
4 Apply the quotient law for indices: \(\dfrac{x^{m}}{x^{n}}=x^{m-n}\).
Quotient Law of Indices \(\dfrac{x^{m}}{x^{n}}=x^{m-n}\) With the same base \(x\), subtract the indices: \(14-5=9\).
\[ \frac{x^{14}}{x^{5}} = x^{14-5} = x^{9} \] Hint: Same base \(x\) → subtract the indices: \(14-5=9\).
5 Combine the results. \[ \frac{(6x^{7})^{2}}{4x^{5}} = \frac{36x^{14}}{4x^{5}} = 9x^{9} \] Hint: Coefficient \(9\) (not \(3\)) and index \(9\) (not \(4\)) — only option D matches both.
Answer: \(\;9x^{9}\;\) → option D

Question. Simplify \(\dfrac{(4x^{5})^{3}}{8x^{7}}\).

Show the worked solution
Step 1. By the power of a product, \((4x^{5})^{3}=4^{3}(x^{5})^{3}=64x^{15}\).
Step 2. The fraction becomes \(\dfrac{64x^{15}}{8x^{7}}\), and \(\dfrac{64}{8}=8\).
Step 3. By the quotient law, \(\dfrac{x^{15}}{x^{7}}=x^{15-7}=x^{8}\).
Step 4. So the expression equals \(8x^{8}\).
Answer: \(8x^{8}\)
