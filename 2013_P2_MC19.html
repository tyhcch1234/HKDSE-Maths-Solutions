Circle Geometry — Angles in the Same Segment, Isosceles & Parallel Lines

Cyclic Quadrilateral Angles in Same Segment Isosceles Triangle Alternate Angles Exterior Angle of Δ

Question Full Statement

Refer to the figure (interactive diagram in Part (a) below).

In the figure, \(ABCD\) is a circle. \(AC\) and \(BD\) intersect at \(E\). If \(AB = AD\) and \(AD /\!/ BC\), then \(\angle BAE =\)

  1. 57°
  2. 74°
  3. 69°
  4. 37°

(The angle \(\angle CED = 74^\circ\) is marked on the figure at \(E\).)

1Let the equal angles be \(a\)1M

Since \(AB = AD\), triangle \(ABD\) is isosceles with vertex at \(A\). Let

\[ \angle ABD = a. \]

Then the base angles of the isosceles triangle \(ABD\) are equal:

\[ \angle ADB = \angle ABD = a \quad (\text{base } \angle\text{s, isos. } \triangle). \]
Hint: In an isosceles triangle, the two base angles (the angles opposite the equal sides) are always equal.
2Use the parallel lines \(AD /\!/ BC\)1M

\(BD\) acts as a transversal cutting the parallel lines \(AD\) and \(BC\). The alternate angles are equal:

\[ \angle CBD = \angle ADB = a \quad (\text{alt. } \angle\text{s, } BC /\!/ AD). \]
Hint: Alternate angles (Z-angles) lie on opposite sides of the transversal between the two parallel lines.
3Angles in the same segment1M

\(\angle CAD\) and \(\angle CBD\) both subtend the chord \(CD\) (they sit in the same segment):

\[ \angle CAD = \angle CBD = a \quad (\angle\text{s in the same segment}). \]

Combining with Steps 1–2:

\[ \angle ABD = \angle ADB = \angle CBD = \angle CAD = a. \]
Hint: Angles in the same segment subtended by the same chord are equal.
4Exterior angle of \(\triangle ADE\)1M

In triangle \(ADE\), the exterior angle at \(E\) equals the sum of the two interior opposite angles:

\[ \angle ADE + \angle DAE = \angle CED, \] \[ a + a = 74^\circ \quad\Rightarrow\quad a = 37^\circ. \]
Hint: The exterior angle of a triangle equals the sum of the two opposite interior angles.
So far: \(a = 37^\circ\), i.e. \(\angle ABD = \angle ADB = \angle CAD = 37^\circ\).

0 / 3
1Angle sum of \(\triangle ABD\)1M

In triangle \(ABD\):

\[ \angle ABD + \angle ADB + \angle BAD = 180^\circ \quad (\angle \text{ sum of } \triangle). \]

Substitute the known values:

\[ 37^\circ + 37^\circ + \angle BAD = 180^\circ \quad\Rightarrow\quad \angle BAD = 106^\circ. \]
Hint: The three interior angles of any triangle add up to \(180^\circ\).
2Write \(\angle BAD\) as a sum1M

At vertex \(A\), the ray \(AE\) (which lies along \(AC\)) splits \(\angle BAD\) into two parts:

\[ \angle BAD = \angle BAE + \angle EAD. \]

But \(\angle EAD = \angle CAD = a = 37^\circ\) (from Part (a)). So

\[ 106^\circ = \angle BAE + 37^\circ. \]
Hint: \(E\) lies on \(AC\), so \(\angle EAD\) is exactly the same angle as \(\angle CAD\), which we already know equals \(37^\circ\).
3Solve for \(\angle BAE\)1A
\[ \angle BAE = 106^\circ - 37^\circ = 69^\circ. \]
Answer: \(\angle BAE = 69^\circ\) — option C.

Summary of Answers

  • Let \(a = \angle ABD = \angle ADB\) (isosceles \(\triangle ABD\)).
  • \(\angle CBD = \angle ADB = a\) (alt. \(\angle\)s, \(BC /\!/ AD\)).
  • \(\angle CAD = \angle CBD = a\) (\(\angle\)s in the same segment).
  • In \(\triangle ADE\): \(a + a = 74^\circ \Rightarrow a = 37^\circ\) (ext. \(\angle\) of \(\triangle\)).
  • In \(\triangle ABD\): \(\angle BAD = 180^\circ - 37^\circ - 37^\circ = 106^\circ\).
  • \(\angle BAE = \angle BAD - \angle EAD = 106^\circ - 37^\circ\).
  • \(\displaystyle \angle BAE = \boxed{69^\circ}\)  →  Answer C
