Statistics — Finding the Inter-quartile Range from a Bar Chart
Bar Chart Quartiles Inter-quartile Range Ungrouped Data

Question Multiple Choice

The bar chart below shows the distribution of the numbers of books read by some teachers in a certain month. Find the inter-quartile range of the distribution.

  • A. 1
  • B. 2
  • C. 3
  • D. 4
Reading the chart: the height of each bar gives the number of teachers (the frequency) who read that many books. The label under each bar is the value of the data item.

Step 1 — Read the frequencies from the bar chart

Before any statistics can be computed, the whole data set must be listed from the chart.

1 Record the frequency of each value

Reading the heights of the bars for the numbers of books read:

\[ f(3)=4,\quad f(4)=8,\quad f(5)=6,\quad f(6)=2,\quad f(7)=2 \]
Hint: Always read the vertical axis carefully. Here each grid line represents \(2\) teachers, so a bar reaching the mid-line between \(6\) and \(8\) would represent \(7\). All bars here land exactly on a grid line.
Total number of teachers \(n = 4+8+6+2+2 = 22\)
2 Write the ordered data list

Expanding the tally into an ordered list of all \(22\) data values:

\[ \underbrace{3,3,3,3}_{4},\; \underbrace{4,4,4,4,4,4,4,4}_{8},\; \underbrace{5,5,5,5,5,5}_{6},\; \underbrace{6,6}_{2},\; \underbrace{7,7}_{2} \]

Hint: The data is already sorted because the bar chart is arranged in increasing order of \(x\) — this is essential for locating the quartiles by position.
\(n = 22\) data values in ascending order.

Step 2 — Locate \(Q_1\) and \(Q_3\) by position

The median splits the data into a lower half and an upper half; the quartiles are the medians of those halves.

1 Find the positions of the quartiles

Since \(n=22\) is even, the data splits evenly into two halves of \(11\) items each.

\[ \text{Lower half} = \text{positions } 1 \to 11, \qquad \text{Upper half} = \text{positions } 12 \to 22 \]
Hint: There is no single middle data item when \(n\) is even, so the halves are simply positions \(1\text{–}11\) and \(12\text{–}22\).
Median of lower half = average of the \(6^\text{th}\) and \(6^\text{th}\) positions (the middle of \(11\) items) → position \(6\).
Median of upper half → position \(17\).
2 Read off \(Q_1\) and \(Q_3\)

Counting along the ordered list: positions \(1\text{–}4\) hold the value \(3\); positions \(5\text{–}12\) hold the value \(4\); positions \(13\text{–}18\) hold \(5\); etc.

\[ Q_1 = \text{6}^\text{th}\ \text{value} = 4 \] \[ Q_3 = \text{17}^\text{th}\ \text{value} = 5 \]
Hint: For \(Q_3\), the upper half starts at position \(12\). Its middle (the \(6^\text{th}\) item of that half) is position \(12+6-1 = 17\).
\(Q_1 = 4\) and \(Q_3 = 5\).

Step 3 — Compute the inter-quartile range

The inter-quartile range measures the spread of the middle \(50\%\) of the data.

1 Apply the formula
\[ \text{Inter-quartile range} = Q_3 - Q_1 \] \[ = 5 - 4 = 1 \]
Hint: The inter-quartile range is always non-negative. It describes the spread of the middle half of the distribution, so it is not affected by extreme values (outliers).
Inter-quartile range \(= 1\)  →  the answer is A.

Summary of Answers

  • Frequencies: \(f(3)=4,\;f(4)=8,\;f(5)=6,\;f(6)=2,\;f(7)=2\)  \(\Rightarrow\; n = 22\)
  • Lower half = positions \(1\text{–}11\), upper half = positions \(12\text{–}22\)
  • \(Q_1 = 4\)  (the \(6^\text{th}\) value)
  • \(Q_3 = 5\)  (the \(17^\text{th}\) value)
  • Inter-quartile range \(= Q_3 - Q_1 = 5 - 4 = \mathbf{1}\)
  • Correct option: A
