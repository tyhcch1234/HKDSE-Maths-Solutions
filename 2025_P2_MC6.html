Estimation, Approximation & Error · Finding the range of values from a rounded number

QQuestion

If $x = 5.67$ (correct to 2 decimal places), find the range of values of $x$.
A$5.66 < x \le 5.68$
B$5.66 \le x < 5.68$
C$5.665 < x \le 5.675$
D$5.665 \le x < 5.675$

★Key Concept Tags

Rounding & Approximation Maximum Absolute Error Correct to 2 d.p. Interval Notation Upper / Lower Limits

→Step-by-Step Guided Solution

Saying $x = 5.67$ correct to 2 decimal places means:

All the digits from the first decimal place (tenths) up to the second decimal place (hundredths) are accurate. The next digit — in the thousandths place — may have been changed by rounding.

$5.67 = 5.\,\underbrace{6}_{\text{tenths}}\underbrace{7}_{\text{hundredths}}$

So the true value of $x$ could be a little smaller or a little larger than $5.67$ — but it must still round to $5.67$.

💡 Key idea: the rounding unit is the place value you round to. Here it is the hundredths place, i.e. $0.01$.

We are rounding to 2 decimal places. The corresponding place value is:

$\text{rounding unit} = 0.01$

This single number $0.01$ controls everything: the largest error you can make when rounding is half of this unit.

💡 For 1 d.p. the unit is $0.1$; for 2 d.p. it is $0.01$; for 3 d.p. it is $0.001$. Match the unit to the number of decimal places!

Any value that rounds to $5.67$ must be within half the rounding unit of $5.67$:

$\text{Max absolute error} = \dfrac{0.01}{2} = 0.005$

So the true value $x$ can differ from $5.67$ by at most $0.005$.

💡 Formula (not yet substituted): $\text{Max absolute error} = \dfrac{\text{rounding unit}}{2}$.
Here the rounding unit is $0.01$, which is why we divide by 2 to get $0.005$.

Add and subtract the maximum absolute error from the rounded value:

$\text{Lower limit} = 5.67 - 0.005 = 5.665$ $\text{Upper limit} = 5.67 + 0.005 = 5.675$

So at first glance the range looks like $5.665 \to 5.675$.

💡 This is just the "$5.67 \pm 0.005$" idea. The next step is the one most students get wrong — the endpoints!

Both endpoints are exactly half-way between two values that round differently. Use the standard convention for "correct to $n$ decimal places":

  • The lower limit $5.665$ IS included — it rounds up to $5.67$ (round-half-up), so the interval starts with $\le$.
  • The upper limit $5.675$ is NOT included — it would round up to $5.68$, so the interval ends with $<$.
$5.665 \le x < 5.675$
💡 Memory trick: when rounding to a fixed number of decimal places, the pattern is always $\le$ on the left, $<$ on the right (a "closed-open" interval). The boundary $5.675$ would need a $6$ in the thousandths place — that is $5.68$, not $5.67$.

Comparing with the options:

OptionIntervalVerdict
A$5.66 < x \le 5.68$Wrong: unit is $0.01$, not $0.02$
B$5.66 \le x < 5.68$Wrong: same unit error
C$5.665 < x \le 5.675$Wrong: endpoints swapped
D$5.665 \le x < 5.675$✔ Correct
Answer: D  ·  $5.665 \le x < 5.675$

Exam Tips & Common Traps

  • Wrong unit trap: Options A and B use $5.66$ and $5.68$ — that corresponds to a unit of $0.02$. Remember: 2 d.p. ⇒ unit $0.01$ ⇒ error $0.005$.
  • Endpoint trap: Option C has the inequality signs reversed. For "correct to $n$ d.p.", the shape is always $\le x <$ — closed on the left, open on the right.
  • Quick check: $5.665$ rounds to $5.67$ ✔ (included); $5.675$ rounds to $5.68$ ✘ (excluded).
  • General formula: $a \pm \dfrac{\text{unit}}{2}$, then write it as a closed-open interval.
