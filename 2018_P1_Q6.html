HKDSE Math 2018 Paper 1 Q6

Inequalities Linear Programming Number Line

📋 Question

(a) Find the range of values of \(x\) which satisfy

\[ \frac{3 - x}{2} > 2x + 7 \quad\text{and}\quad x + 8 \ge 0. \]

(b) Write down the greatest integer satisfying both inequalities in (a). [4 marks]

💡 Key concept: Solve each linear inequality separately, then find the overlapping region on the number line. Remember: multiplying or dividing by a negative number flips the inequality sign.

🧩 Step‑by‑Step Solution

Hint: Multiply both sides by 2 to eliminate the denominator.

\[ \frac{3-x}{2} > 2x+7 \]

Multiply both sides by \(2\) (positive, inequality sign stays):

\[ 3-x > 4x + 14 \]

Bring \(x\) terms to one side and constants to the other:

\[ 3 - 14 > 4x + x \]

\[ -11 > 5x \]

Divide both sides by \(5\) (positive, sign unchanged):

\[ x < -\frac{11}{5} \]

⚠️ Careful: Some students forget to reverse the sign when multiplying/dividing by a negative. Here we only divided by positive 5, so the sign remains \(<\). The result is \(x < -2.2\).

\[ x + 8 \ge 0 \]

Subtract \(8\) from both sides:

\[ x \ge -8 \]

This means \(x\) can be \(-8\) or any number greater than \(-8\).

We need \(x\) to satisfy both conditions:

  • \(x < -\frac{11}{5}\) (from Step 1)
  • \(x \ge -8\) (from Step 2)

The overlapping region is:

\[ -8 \le x < -\frac{11}{5} \]

✅ This is the required range for part (a). Note that \(-8\) is included (because of \(\ge\)), while \(-\frac{11}{5}\) is excluded (because of \(<\)).

From part (a), \(x\) must be in the interval \([-8, -2.2)\) (since \(-\frac{11}{5} = -2.2\)).

We want the greatest integer strictly less than \(-2.2\).

Possible integers in the interval: \(-8, -7, -6, -5, -4, -3\).

Among these, the greatest is \(-3\).

Answer to (b): \(-3\)

🏆 Final Answers

(a) The required range is \( -8 \le x < -\frac{11}{5} \).

(b) The greatest integer satisfying both is \( -3 \).

Marks: (a) 1M + 1A for first inequality, 1A for combined range; (b) 1A.
