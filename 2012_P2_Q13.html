HKDSE 2012 Paper 2 — Question 13

Topic 3 · Estimation, Approximation and Error

[2012 MC #13]
$0.0322515 = $ ?
  • A. $0.032$  (correct to 3 significant figures)
  • B. $0.0322$  (correct to 4 decimal places)
  • C. $0.03225$  (correct to 5 significant figures)
  • D. $0.032252$  (correct to 6 decimal places)
Step 1 · Read the digits

Write the given number and mark every digit with its place value:

$0\underset{0}{\underbrace{.}}\,\underset{\text{tenths}}{0}\, \underset{\text{hundredths}}{3}\,\underset{\text{thousandths}}{2}\, \underset{10^{-4}}{2}\,\underset{10^{-5}}{5}\,\underset{10^{-6}}{1}\, \underset{10^{-7}}{5}$

Only the digits after $0.0$ count as significant figures here — the leading zeros are just place holders.
Step 2 · Count the significant figures
Rounding to a Given Number of Decimal Places \(\text{Look at the next digit; round up if it is } 5 \text{ or more}\) The digit after the sixth decimal place decides the rounding of \(0.0322515\).

The first significant figure is the 3 (hundredths place). So the significant figures are:

$3\;(\text{s.f.1}),\;2\;(\text{s.f.2}),\;2\;(\text{s.f.3}),\; 5\;(\text{s.f.4}),\;1\;(\text{s.f.5}),\;5\;(\text{s.f.6})$

There are 6 significant figures in total — this is why option C is suspicious: it claims 5 s.f.
Step 3 · Check option A (3 s.f.)
Significant Figures \(\text{Zeros before the first non-zero digit are not significant}\) In \(0.0322515\) only \(3,2,2,5,1,5\) count, i.e. six significant figures.

Keep the first 3 significant figures $3,2,2$;
the next digit is $5$ so we round up:

$0.032|2515 \;\approx\; 0.0323$  
✗

$0.032$ is wrong for 3 s.f. because the 4th digit (5) forces the 3rd s.f. to become 3, not stay 2.
Step 4 · Check option B (4 d.p.)

The 4th decimal place is the digit $2$;
the next digit is $5$, so round up:

$0.0322|515 \;\approx\; 0.0323$  
✗

Again rounding up gives $0.0323$, not $0.0322$.
Step 5 · Check option C (5 s.f.)
Rounding Rule for 5 \(\text{If the next digit is exactly } 5,\ \text{round the last kept digit up}\) The kept digit \(1\) becomes \(2\), giving \(0.032252\).

Keep the first 5 significant figures $3,2,2,5,1$;
the next digit is $5$, so round up $1 \to 2$:

$0.03225|15 \;\approx\; 0.032252$  
✗

The value $0.032252$ is correct, but it is not 5 s.f. — it has 6 s.f., so the stated reason in C is wrong.
Step 6 · Check option D (6 d.p.)

The 6th decimal place is the digit $1$;
the next digit is $5$, so round up $1 \to 2$:

$0.032251|5 \;\approx\; 0.032252$  
✓

The result $0.032252$ has exactly 6 decimal places, matching the description exactly.

Both the value and the wording must agree — here they do.
Step 7 · Conclusion

Only option D gives a value whose rounding agrees with the stated degree of accuracy.

Answer: D  —  $0.0322515 = 0.032252$ (correct to 6 decimal places)
