HKDSE Math 2015 · Paper 2 · Q37

Geometric Sequence — Which statements must be true?

Sequences Geometric Sequence Common Ratio Sum of GP Reasoning

QThe Question

Let $x_n$ be the $n$th term of a geometric sequence. If $x_6 = 216$ and $x_8 = 96$, which of the following must be true?
I. $\quad x_3 = 729$
II. $\quad \dfrac{x_5}{x_7} > 1$
III. $\quad x_2 + x_4 + x_6 + \cdots + x_{2n} < 2015$
  • A. I only
  • B. II only
  • C. I and III only
  • D. II and III only
Key idea: “Must be true” means true for every possible geometric sequence satisfying the conditions. So we must find all possible common ratios first.

1Step-by-Step Guided Solution

Let the first term be $a$ and the common ratio be $r$. Then

$$x_n = a\,r^{\,n-1}$$

Using the two given terms:

$$x_6 = a r^{5} = 216 \tag{1}$$ $$x_8 = a r^{7} = 96 \tag{2}$$
Formula used: the $n$th term of a geometric sequence $x_n = a r^{\,n-1}$, where $a$ is the first term and $r$ is the common ratio.

Divide equation (2) by equation (1):

$$\frac{a r^{7}}{a r^{5}} = \frac{96}{216} \quad\Longrightarrow\quad r^{2} = \frac{96}{216} = \frac{4}{9}$$

Therefore

$$r = \pm\frac{2}{3}$$
Careful! Dividing gives $r^{2}$, not $r$. Both $r = \frac{2}{3}$ and $r = -\frac{2}{3}$ are possible. Ignoring the negative value is the most common mistake in this question.

Substitute $r^{2} = \frac49$ into (1). Note that $r^{5} = r^{4}\cdot r = (r^{2})^{2}\cdot r$, so

$$a\left(\frac{4}{9}\right)^{2} r = 216 \quad\Longrightarrow\quad a\cdot\frac{16}{81}\cdot r = 216$$

Either way, solving with $r = \frac23$ or $r = -\frac23$ gives the same $a$:

$$a = \frac{2187}{2}$$

So the two possible sequences are:

$$x_n = \frac{2187}{2}\left(\frac{2}{3}\right)^{n-1} \qquad\text{or}\qquad x_n = \frac{2187}{2}\left(-\frac{2}{3}\right)^{n-1}$$
Why is $a$ the same? Because $x_6 = a(r^{2})^{2}\cdot r$ depends on the sign of $r$ through the factor $r$ only — and we solve for $a$ in each case separately, giving the same magnitude. The sign of $r$ flips the signs of alternate terms.

Use $x_3 = x_2 r = x_6 r^{-3}$, i.e. move back 3 steps from $x_6$:

$$x_3 = \frac{x_6}{r^{3}} = x_6 \cdot r^{-3}$$

Case $r = \frac23$:

$$x_3 = \frac{2187}{2}\cdot\frac{2}{3} = 729 \quad ✔$$

Case $r = -\frac23$:

$$x_3 = \frac{2187}{2}\cdot\left(-\frac{2}{3}\right) = -729 \quad ✘$$

Statement I is NOT always true

Why? Since two different sequences satisfy the conditions, a statement about $x_3$ must hold for both. Here the negative ratio gives $-729 \neq 729$.

Recall $x_{n+2} = x_n r^{2}$. Hence

$$x_7 = x_5 r^{2} \quad\Longrightarrow\quad \frac{x_5}{x_7} = \frac{1}{r^{2}}$$

Since $r^{2} = \frac49 < 1$,

$$\frac{x_5}{x_7} = \frac{1}{4/9} = \frac94 = 2.25 > 1$$

Statement II is TRUE — and note it does not depend on whether $r$ is positive or negative!

Key insight: The ratio $\frac{x_5}{x_7}$ only involves $r^{2}$, so both possible sequences give the same value, namely $2.25$.

The terms $x_2, x_4, x_6, \ldots$ themselves form a geometric sequence with first term $x_2$ and common ratio $r^{2} = \frac49$.

$$x_2 = \frac{x_6}{r^{4}} = \frac{216}{16/81} = \frac{2187}{2}$$

Sum of the first $n$ terms:

$$S_n = \frac{x_2\left[1 - (r^{2})^{n}\right]}{1 - r^{2}} = \frac{x_2\left[1 - \left(\frac49\right)^{n}\right]}{1 - \frac49}$$

Substituting $x_2 = \frac{2187}{2}$ and $1 - \frac49 = \frac59$:

$$S_n = \frac{2187}{2}\cdot\frac{9}{5}\left[1 - \left(\frac49\right)^{n}\right] = \frac{19683}{10}\left[1 - \left(\frac49\right)^{n}\right]$$

Since $0 < \left(\frac49\right)^{n} \le \frac49$, the bracket is at most $1$, so

$$S_n < \frac{19683}{10} = 1968.3 < 2015$$

Statement III is TRUE

Formula used: sum of a finite geometric series $S_n = \dfrac{a(1-r^{n})}{1-r}$ with $r \neq 1$. Even the infinite sum here is only $1968.3$, comfortably below $2015$.
  • I Not necessarily true (fails when $r = -\frac23$).
  • II Always true: $\frac{x_5}{x_7} = 2.25 > 1$.
  • III Always true: $S_n < 1968.3 < 2015$.

Therefore the answer is D — II and III only.

3Key Formulas to Memorise

$$\text{General term: } x_n = a r^{\,n-1}$$ $$\text{Finite sum: } S_n = \frac{a(1-r^{n})}{1-r} \quad (r \neq 1)$$ $$\text{Ratio of terms: } \frac{x_{n}}{x_{n+2}} = \frac{1}{r^{2}}$$
Exam tip for “must be true” questions: always check for the negative common ratio when $r^{2}$ is given. Any statement involving an odd-indexed term (like $x_3$) may fail, while statements using only even-indexed terms or $r^{2}$ usually survive.
Final Answer
D
II and III only
