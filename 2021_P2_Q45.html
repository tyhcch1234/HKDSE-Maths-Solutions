Statistics — Median, Range & Variance of Arithmetic Sequences

Arithmetic Sequence Median Range Variance Data Translation

Question Multiple Choice

It is given that \(T(n)\) is the \(n\)th term of an arithmetic sequence. Let \(x_1\), \(y_1\) and \(z_1\) be the median, the range and the variance of the group of numbers \[ \{T(1),\,T(2),\,T(3),\,\dots,\,T(49)\} \] respectively, while \(x_2\), \(y_2\) and \(z_2\) be the median, the range and the variance of the group of numbers \[ \{T(51),\,T(52),\,T(53),\,\dots,\,T(99)\} \] respectively. Which of the following must be true?

  1. \(x_1 < x_2\)
  2. \(y_1 = y_2\)
  3. \(z_1 > z_2\)

A. I only
B. II only
C. I and III only
D. II and III only

Part (a)  Structure of the Arithmetic Sequence Set-up

a = 2 d = 1 x₁ = …, x₂ = …
1 Write the general term.

An arithmetic sequence has the form \(T(n) = a + (n-1)d\), where \(a\) is the first term and \(d\) is the common difference.

Hint: Move the sliders above — the dots move along a straight line, confirming \(T(n)\) is linear in \(n\).
\(T(n) = a + (n-1)d\)
2 Relate set 2 to set 1.

Note that

\[ T(51) = a + 50d = T(1) + 50d \] \[ T(52) = a + 51d = T(2) + 50d \] \[\vdots\] \[ T(99) = a + 98d = T(49) + 50d \]

So every term in the second set is exactly \(50d\) more than the corresponding term in the first set.

Hint: The shift \(51 \to 1\) is \(50\) steps, so each term increases by \(50d\).
Set 2 = Set 1 with \(50d\) added to every number.
0 / 2

Part (b)  Effect of Adding a Constant \(50d\) Analysis

k = 50d
1 Check proposition I: \(x_1 < x_2\)?

Adding \(50d\) to every number adds \(50d\) to the median:

\[ x_2 = x_1 + 50d \]

For \(x_1 < x_2\) we would need \(50d > 0\), i.e. \(d > 0\). But \(d\) can be zero or negative, so \(x_1 < x_2\) is not always true.

Hint: Pull the shift slider \(k\) to 0 or negative — the second median no longer lies to the right.
I is false (only true when \(d>0\)).
2 Check proposition II: \(y_1 = y_2\)?

The range depends only on the gap between the largest and smallest terms:

\[ y_1 = T(49) - T(1) = 48d \] \[ y_2 = T(99) - T(51) = 48d \]

Adding the same constant \(50d\) to every datum does not change the spread, so \(y_1 = y_2\) always.

Hint: Watch the blue range bracket — it keeps the same length while the whole block of dots slides.
II is true.
3 Check proposition III: \(z_1 > z_2\)?

Variance measures the average squared deviation from the mean. Adding the same constant \(50d\) to every datum shifts every value and the mean together, leaving all deviations unchanged:

\[ z_2 = z_1 \]

Hence \(z_1 > z_2\) is false; in fact they are equal.

Hint: The two sets of dots are identical in shape — only translated horizontally — so their spread (variance) matches exactly.
III is false (\(z_1 = z_2\)).
4 Conclude the answer.

Only statement II must be true.

Hint: Match with the options — "II only" corresponds to option B.
Answer: B (II only)
0 / 4

Summary of Results

  • Arithmetic sequence: \(T(n) = a + (n-1)d\).
  • The second group equals the first group plus the constant \(50d\).
  • I. \(x_2 = x_1 + 50d\) → \(x_1 < x_2\) is not always true. False
  • II. \(y_1 = 48d = y_2\) → range unchanged. True
  • III. \(z_2 = z_1\) → variance unchanged, not larger for the first set. False
Correct option: B  (II only)
