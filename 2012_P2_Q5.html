Question. If

\[ m + 2n + 6 = 2m - n = 7 \]

then \[ n = \]

A. \(-4\) B. \(-1\) C. \(3\) D. \(11\)
1Split the double equation

A double equation \(A = B = C\) means \(A=B\) and \(B=C\). Here:

\[ m + 2n + 6 = 2m - n \quad\text{and}\quad 2m - n = 7 \]
Hint: Pick the equation that contains only one unknown if possible.
Method of Substitution \(\text{From one equation write } y \text{ in terms of } x,\ \text{then substitute}\) The first equation already gives \(m\) in terms of \(n\).
2Use the simple equation \(2m - n = 7\)

Rearrange to express \(m\) in terms of \(n\):

\[ 2m = n + 7 \quad\Longrightarrow\quad m = \frac{n+7}{2} \]
Hint: Substitution works well when one letter is easy to isolate.
3Substitute into the other equation

Put \(m = \dfrac{n+7}{2}\) into \(m + 2n + 6 = 2m - n\):

\[ \frac{n+7}{2} + 2n + 6 = 2\cdot\frac{n+7}{2} - n \] \[ \frac{n+7}{2} + 2n + 6 = (n+7) - n = 7 \]
Hint: The right side simplifies nicely because \(2m\) cancels the \(+7\).
Solving Simultaneous Linear Equations \(\text{Two independent equations in } m,n \text{ give one unique pair } (m,n)\) Eliminating \(m\) leaves a single equation in \(n\) only.
4Solve for \(n\)

Multiply the whole equation by 2:

\[ (n+7) + 4n + 12 = 14 \] \[ 5n + 19 = 14 \quad\Longrightarrow\quad 5n = -5 \] \[ n = -1 \]
Hint: Check the arithmetic carefully — the constants add to 19.
Back-Substitution \(\text{Substitute the found value back to get the other unknown}\) With \(n=-1\) known, \(m=\dfrac{n+7}{2}\) gives \(m=3\).
5Check the answer

If \(n=-1\), then \(2m - (-1) = 7 \Rightarrow 2m = 6 \Rightarrow m = 3\).

Test in the first expression: \(\;3 + 2(-1) + 6 = 3 - 2 + 6 = 7\) ✓

Hint: Both conditions \(m+2n+6=7\) and \(2m-n=7\) are satisfied.
Answer: \(n = -1\)  →  Option B

Question. It is given that \(p+3q+4=2p-q=11\). Find \(p\) and \(q\).

Show the worked solution
Step 1. Write \(p+3q+4=11\Rightarrow p=7-3q\), and \(2p-q=11\).
Step 2. Substitute: \(2(7-3q)-q=11\Rightarrow 14-6q-q=11\Rightarrow -7q=-3\).
Step 3. So \(q=\dfrac{3}{7}\), and \(p=7-3\left(\dfrac{3}{7}\right)=\dfrac{49-9}{7}=\dfrac{40}{7}\).
Step 4. Check in \(2p-q=2\left(\dfrac{40}{7}\right)-\dfrac{3}{7}=\dfrac{77}{7}=11\). \(\checkmark\)
Answer: \(p=\dfrac{40}{7},\ q=\dfrac{3}{7}\)
