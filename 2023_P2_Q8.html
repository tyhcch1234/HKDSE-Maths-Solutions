Question
Let $g(x)=13-5x^{2}$. If $\alpha$ is a constant, find $g(1-3\alpha)$.
A. $8-45\alpha^{2}$
B. $8+45\alpha^{2}$
C. $8-30\alpha+45\alpha^{2}$
D. $8+30\alpha-45\alpha^{2}$
Step 1Identify the given function.

The function is defined by the rule

\[ g(x)=13-5x^{2}. \]

The symbol $x$ is only a placeholder — whatever is put inside the brackets must be squared and then subtracted from $13$.

Hint: write the rule with a blank bracket $g(\;\;)=13-5(\;\;)^{2}$ before substituting.

Step 2Substitute the whole input $x=1-3\alpha$.

Treat $1-3\alpha$ as one single block and drop it into the placeholder:

\[ g(1-3\alpha)=13-5(1-3\alpha)^{2}. \]

Common trap: only squaring $\alpha$ or forgetting the bracket, e.g. writing $13-5(1-3\alpha^2)$ — wrong!

Function Notation \(g(\ \ )=\text{rule}\ \Longrightarrow\ g(u)\ \text{replaces every }x\text{ by }u\) The whole block \(1-3\alpha\) replaces \(x\), so it must be squared as a single unit.
Step 3Expand the square $\;(1-3\alpha)^{2}$.

Use $(a-b)^{2}=a^{2}-2ab+b^{2}$ with $a=1,\;b=3\alpha$:

\[ (1-3\alpha)^{2}=1^{2}-2(1)(3\alpha)+(3\alpha)^{2}=1-6\alpha+9\alpha^{2}. \]

Recall $\alpha\cdot\alpha=\alpha^{2}$ and $(3\alpha)^2=9\alpha^2$ — square the number and the variable.

Perfect Square Identity \((a-b)^{2}=a^{2}-2ab+b^{2}\) With \(a=1\) and \(b=3\alpha\), \((1-3\alpha)^{2}=1-6\alpha+9\alpha^{2}\).
Step 4Distribute the $-5$ and simplify. \[ \begin{aligned} g(1-3\alpha)&=13-5(1-6\alpha+9\alpha^{2})\\[2pt] &=13-5+30\alpha-45\alpha^{2}\\[2pt] &=8+30\alpha-45\alpha^{2}. \end{aligned} \]

The result is a quadratic in $\alpha$: constant term $8$, linear term $+30\alpha$, quadratic term $-45\alpha^{2}$.

Multiplying the bracket by $-5$ flips every sign: $-5(1)=-5$, $-5(-6\alpha)=+30\alpha$, $-5(9\alpha^{2})=-45\alpha^{2}$.

Answer:  D  —  $\;g(1-3\alpha)=8+30\alpha-45\alpha^{2}$.
