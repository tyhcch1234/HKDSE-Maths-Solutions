Question

It is given that $\log_8 y$ is a linear function of $\log_4 x$. The intercepts on the vertical axis and on the horizontal axis of the graph of the linear function are 5 and 3 respectively. Which of the following must be true?

A. $x^5 y^2 = 8^{10}$
B. $x^6 y^5 = 8^{20}$
C. $x^{10} y^3 = 8^{20}$
D. $x^9 y^{10} = 8^{30}$

📝 Step-by-Step Solution

The graph is a straight line with:

  • Vertical intercept (where $\log_4 x = 0$): $\log_8 y = 5$ → point $(0, 5)$
  • Horizontal intercept (where $\log_8 y = 0$): $\log_4 x = 3$ → point $(3, 0)$

💡 Hint: The vertical intercept is the value of the dependent variable when the independent variable is zero. The horizontal intercept is the value of the independent variable when the dependent variable is zero.

Using the two points $(0, 5)$ and $(3, 0)$, we find the slope $m$:

$$m = \frac{0 - 5}{3 - 0} = -\frac{5}{3}$$

Using point-slope form with the vertical intercept $(0, 5)$:

$$\log_8 y - 5 = -\frac{5}{3}(\log_4 x - 0)$$
$$\log_8 y = -\frac{5}{3}\log_4 x + 5$$

💡 Hint: The slope is "rise over run" = (change in $y$) / (change in $x$). Here the "variables" are $\log_8 y$ and $\log_4 x$.

We need to express everything in the same base. Using the change of base formula:

$$\log_4 x = \frac{\log_8 x}{\log_8 4}$$

Now, $\log_8 4 = \log_8 (8^{2/3}) = \frac{2}{3}$. So:

$$\log_4 x = \frac{\log_8 x}{2/3} = \frac{3}{2}\log_8 x$$

Substitute this into the line equation:

$$\log_8 y = -\frac{5}{3}\left(\frac{3}{2}\log_8 x\right) + 5$$
$$\log_8 y = -\frac{5}{2}\log_8 x + 5$$

💡 Hint: $\log_a b = \frac{\log_c b}{\log_c a}$. Also, $4 = 8^{2/3}$ because $8^{2/3} = (\sqrt[3]{8})^2 = 2^2 = 4$.

Starting from:

$$\log_8 y = -\frac{5}{2}\log_8 x + 5$$

Multiply every term by 2:

$$2\log_8 y = -5\log_8 x + 10$$

Bring all terms to one side:

$$5\log_8 x + 2\log_8 y = 10$$

💡 Hint: We want to combine the logarithms. Recall the power rule: $n\log_a x = \log_a x^n$.

Using the power rule $n\log_a x = \log_a x^n$:

$$\log_8 x^5 + \log_8 y^2 = 10$$

Using the product rule $\log_a M + \log_a N = \log_a(MN)$:

$$\log_8 (x^5 y^2) = 10$$

💡 Hint: Combining logarithms is the reverse of expanding them. Here we go from sum of logs to log of product.

Recall: if $\log_a M = n$, then $M = a^n$. Here:

$$x^5 y^2 = 8^{10}$$

This matches Option A.

💡 Hint: The base of the logarithm is the base of the exponent. Here base is 8, so $8^{10}$ appears on the right-hand side.

✅ Final Answer

A. $x^5 y^2 = 8^{10}$
