Geometry — Parallelogram, mid-point & equal angles: which statements must be true?
Parallelogram Angle Chasing Mid-point Congruent Triangles Multiple Choice

QUESTION The problem statement

\(ABCD\) is a parallelogram. Let \(E\) be the mid-point of \(AD\).

If \(\angle ABE = \angle CBD = \angle DBE\), which of the following are true?

I. \(AB = BD\)
II. \(\angle ABC = 135^\circ\)
III. \(\triangle ABE \cong \triangle DBE\)

A. I and II only    B. I and III only    C. II and III only    D. I, II and III

Strategy: Let the equal angle be \(\theta\). Use the fact that \(AD /\!/ BC\) and that \(E\) is the mid-point to build a chain of angle equalities, then test each statement.

PART (a) Set up the angles 1A

Let \(\angle ABE = \angle CBD = \angle DBE = \theta\). Chase angles through the parallelogram.

30°
\(\angle ABE=\angle CBD=\angle DBE=\) 30° \(\angle BED=\) — \(\angle ABD=\) — \(\angle ABC=\) —
1 Use \(AD /\!/ BC\) (parallel sides of a parallelogram) 1M

Since \(AD /\!/ BC\) and \(DB\) is a transversal, \[ \angle ADB = \angle DBC = \angle DBE + \angle EBC. \] Also \(AB /\!/ DC\), so \(\angle ABD = \angle BDC\).

Hint: The key is that the two equal angles \(\angle CBD\) and \(\angle DBE\) together form \(\angle CBE\), which equals \(\angle ADB\).
\(\angle ADB = \angle CBD + \angle DBE\), so \(\angle ADB = 2\theta\) if \(\angle EBC=\theta\) … let's be careful: \(\angle DBC = \theta+\theta=2\theta\) only if \(\angle EBC=\theta\).
2 Refine using \(E\) on \(AD\) and \(\angle ABE=\theta\) 1M

In \(\triangle ABE\), \(E\) lies on \(AD\), so \[ \angle BAE = \angle BAD \quad (\text{same angle}). \]

In \(\triangle DBE\), \(E\) lies on \(AD\), so \(\angle BDE = \angle BDA = \angle ADB\).

And \(\angle DBE = \theta\).

Hint: Write down all three angles in \(\triangle ABE\): \(\angle ABE=\theta\), \(\angle BAE\), \(\angle AEB\).
Angles of \(\triangle ABE\): \(\theta,\ \angle BAD,\ \angle AEB\).
3 Deduce \(\angle AEB = 90^\circ\) 1A

Since \(E\) is the mid-point of \(AD\) and \(\angle ABE=\angle DBE\), \(BE\) is the median from \(B\) to \(AD\). Also \(\angle ABE=\angle DBE\), so \(BE\) bisects \(\angle ABD\).

A median that is also an angle bisector in triangle \(ABD\) means \(\triangle ABD\) is isosceles with \(AB=BD\), and \(BE \perp AD\).

Hence \(\angle AEB = 90^\circ\).

Hint: Recognise the "median = angle bisector" condition — it forces an isosceles triangle.
\(\angle AEB = 90^\circ\), and \(AB=BD\).
0 / 3

PART (b) Evaluate statement I: \(AB=BD\) 1A

From part (a), \(BE\) is both the median and the angle bisector from \(B\) in \(\triangle ABD\).

35°
\(AB=\) — \(BD=\) — \(\angle ABE=\) — \(\angle DBE=\) —
1 Consider \(\triangle ABD\) 1M

In \(\triangle ABD\), \(E\) is the mid-point of \(AD\), so \(BE\) is a median.

Given \(\angle ABE = \angle DBE = \theta\), \(BE\) bisects \(\angle ABD\).

Hint: A median that is also an angle bisector occurs only in an isosceles triangle (from the base).
\(BE\) is median + angle bisector \(\angle ABD\).
2 Conclude \(AB = BD\) 1A

By the isosceles triangle property, \(\triangle ABD\) is isosceles with \(AB=BD\).

Hint: The two equal angles at \(B\) plus equal median lengths force the sides opposite those angles to be equal.
Statement I is TRUE. \(AB = BD\).
0 / 2

PART (c) Evaluate statement II: \(\angle ABC = 135^\circ\) 1A

Use the angle sum and the equal angles to find \(\angle ABC\).

30°
\(\angle ABD=\) — \(\angle CBD=\) — \(\angle ABC=\) —
1 Express \(\angle ABD\) in terms of \(\theta\) 1M

\(\angle ABE = \angle DBE = \theta\), so \(\angle ABD = 2\theta\).

From part (b), \(\triangle ABD\) is isosceles with \(AB=BD\), so \(\angle BAD = \angle BDA\).

Angle sum: \(\angle BAD + \angle BDA + 2\theta = 180^\circ\) \[ 2\angle BAD = 180^\circ - 2\theta \quad\Rightarrow\quad \angle BAD = 90^\circ - \theta. \]

Hint: In an isosceles triangle, the base angles are equal. The apex is \(2\theta\).
\(\angle BAD = 90^\circ - \theta\).
2 Find \(\angle ABC\) 1M

\(\angle ABC = \angle ABD + \angle DBC = 2\theta + \angle DBC\).

Since \(AD /\!/ BC\) and \(AB\) is a transversal: \[ \angle DAB + \angle ABC = 180^\circ \] \[ 90^\circ - \theta + \angle ABC = 180^\circ \] \[ \angle ABC = 90^\circ + \theta. \]

Hint: Co-interior angles between parallel lines sum to \(180^\circ\).
\(\angle ABC = 90^\circ + \theta\).
3 Determine \(\theta\) and check \(135^\circ\) 1A

Also \(\angle CBD = \theta\) and \(\angle DBA = 2\theta\); since \(B,D,C\) arrangement in the parallelogram gives \(\angle CBA = \angle ABD + \angle DBC = 2\theta + \theta = 3\theta\)? Careful — that double counts.

Correct approach: At \(B\), the rays \(BA\), \(BE\), \(BD\), \(BC\) appear in that order. We have \(\angle ABE=\theta\), \(\angle EBD=\theta\), \(\angle DBC=\theta\). Hence \[ \angle ABC = \theta + \theta + \theta = 3\theta. \]

But from part (c)(2), \(\angle ABC = 90^\circ + \theta\). Therefore \[ 3\theta = 90^\circ + \theta \;\Rightarrow\; 2\theta = 90^\circ \;\Rightarrow\; \theta = 45^\circ. \] \[ \angle ABC = 3 \times 45^\circ = 135^\circ. \]

Hint: At vertex \(B\) the three equal angles \(\theta\) tile \(\angle ABC\) exactly once each.
Statement II is TRUE. \(\angle ABC = 135^\circ\).
0 / 3

PART (d) Evaluate statement III: \(\triangle ABE \cong \triangle DBE\) 1A

Check whether the two triangles are congruent.

30°
\(\angle AEB=\) — \(\angle DEB=\) — \(AB=\) — \(DB=\) — \(AE=\) — \(DE=\) —
1 List the equal elements 1M

From the given: \(\angle ABE = \angle DBE = \theta\).

From part (a): \(\angle AEB = \angle DEB = 90^\circ\).

And \(BE\) is common.

Hint: Two equal angles and the included side in common — check the order carefully.
\(\angle ABE=\angle DBE\), \(\angle AEB=\angle DEB=90^\circ\), \(BE\) common.
2 Apply the AAS (or ASA) congruence test 1A

In \(\triangle ABE\) and \(\triangle DBE\):

  • \(\angle ABE = \angle DBE\) (given)
  • \(\angle AEB = \angle DEB = 90^\circ\) (from part a)
  • \(BE = BE\) (common side)

By AAS, \(\triangle ABE \cong \triangle DBE\).

Hint: Since two angles and the non-included side match, AAS applies.
Statement III is TRUE. \(\triangle ABE \cong \triangle DBE\).
0 / 2

Summary of Results

  • Part (a): \(\angle ABE = \angle CBD = \angle DBE = \theta\), \(\angle AEB = 90^\circ\), \(\angle ABD = 2\theta\).
  • Statement I: \(AB = BD\) — TRUE (isosceles \(\triangle ABD\)).
  • Statement II: \(\angle ABC = 135^\circ\) — TRUE (with \(\theta = 45^\circ\)).
  • Statement III: \(\triangle ABE \cong \triangle DBE\) — TRUE (AAS).
Answer: D — I, II and III are all true.
