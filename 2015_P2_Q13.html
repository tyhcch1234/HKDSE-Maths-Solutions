Question

[2015 MC #13]

In the figure, the 1st pattern consists of 5 dots. For any positive integer $n$, the $(n+1)$th pattern is formed by adding 4 dots to the $n$th pattern. Find the number of dots in the 6th pattern.

  1. 21
  2. 25
  3. 29
  4. 33
STEP 1 · Given information

The 1st pattern has 5 dots,
so $T(1)=5$.

Each later pattern is made by adding exactly 4 dots:

\[ T(n+1)=T(n)+4 \quad \text{for every positive integer } n \]

This is an arithmetic sequence with first term 5 and common difference 4.
STEP 2 · Start from the first pattern

Pattern 1 (red dots) has $5$ dots:

\[ T(1)=5 \]

The 4 extra dots of pattern 1 form the cross shape around the centre.
STEP 3 · Apply the rule repeatedly
Recurrence Relation \(T(n+1)=T(n)+d\) Each pattern adds exactly \(4\) dots, so \(d=4\) and \(T(6)\) needs five additions of 4 starting from \(T(1)=5\).

Going from one pattern to the next adds 4 dots:

\[ T(2)=T(1)+4,\quad T(3)=T(2)+4,\quad T(4)=T(3)+4,\;\dots \]

So $T(6)$ is $T(1)$ plus 4,
five times.
STEP 4 · Unroll the recurrence

Substituting step by step:

\[ \begin{aligned} T(6)&=T(5)+4\\ &=T(4)+4+4\\ &=T(3)+4+4+4\\ &=T(2)+4+4+4+4\\ &=T(1)+4+4+4+4+4 \end{aligned}\]

Five "＋4" terms appear because we move from pattern 1 to pattern 6.
STEP 5 · Substitute $T(1)=5$
General Term of an Arithmetic Sequence \(T(n)=T(1)+(n-1)d\) With \(T(1)=5\), \(d=4\) and \(n=6\): \(T(6)=5+5\times4=25\), the same as unrolling the recurrence.

\[ \begin{aligned} T(6)&=5+4\times 5\\ &=5+20\\ &=25 \end{aligned}\]

Check with the general term of an arithmetic sequence: $T(n)=T(1)+(n-1)d=5+5\times 4=25$.

Common difference $d=4$,
number of steps $=6-1=5$.
STEP 6 · Choose the answer

The 6th pattern has 25 dots,
which is option B.

A: 21  
| 
B: 25 ✓  
| 
C: 29  
| 
D: 33

Distractors come from using the wrong number of "+4" steps (4 or 6 instead of 5).
Answer: B  (25 dots)

Show the worked solution
Step 1. (a) Each pattern has \(5\) more dots than the previous one,
so \(T(n+1)=T(n)+5\) with \(T(1)=3\).
Step 2. (b) From pattern \(1\) to pattern \(8\) there are \(8-1=7\) additions of \(5\).
Step 3. \(T(8)=3+7\times5=3+35=38\).
Step 4. Check with the general term: \(T(n)=3+(n-1)5=5n-2\), so \(T(8)=40-2=38\) ✓.
