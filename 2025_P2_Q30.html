HKDSE 2025 · Paper 2 · Q30

Consider the following data:

α β −4 −3 1 1 1 4

Denote the mode and the median of the above data by $s$ and $t$ respectively. If the mean and the range of the above data are $0$ and $10$ respectively, which of the following are true?

I.$s = 1$
II.$t = -1$
III.$\alpha + \beta = 0$
A.I and II only
B.I and III only
C.II and III only
D.I, II and III
1Use the mean to relate $\alpha$ and $\beta$
Mean of a Set of Data \(\bar{x}=\dfrac{\sum x}{n}\) The mean being \(0\) forces the sum of all eight values to be zero.

There are $8$ data values. Mean $= 0$:

$$\frac{\alpha+\beta+(-4)+(-3)+1+1+1+4}{8}=0$$

$$\alpha+\beta-4-3+1+1+1+4=0 \;\Rightarrow\; \alpha+\beta-3+1+1+1+4=0$$

$$\alpha+\beta =0$$

✔ Statement III is true.
Add the numbers part: $-4-3+1+1+1+4 = 0$, so the unknowns must also cancel out.
2Use the range to find $\alpha,\beta$
Range of a Set of Data \(\text{range}=\text{largest}-\text{smallest}\) The range fixes the two extreme values, which then determine \(\alpha\) and \(\beta\).

Range $= \text{largest} - \text{smallest} = 10$.

The known values run from $-4$ to $4$. Since $\alpha+\beta=0$, the pair is $(k,-k)$. For the range to be $10$, the largest must be $5$ and the smallest $-5$:

$$\{\alpha,\beta\}=\{5,\,-5\}$$

Also $\alpha \neq \beta$ because a range of $10$ needs two different extreme values.

Check: $\max-\min = 5-(-5)=10$ ✔ and $5+(-5)=0$ ✔
3Find the mode $s$

The full data set is

$$5,\;-5,\;-4,\;-3,\;1,\;1,\;1,\;4$$

The value $1$ appears three times; no other value appears more than once.

$$\therefore s = 1$$

✔ Statement I is true.
Mode = the value with the highest frequency.
4Find the median $t$
Median of a Set of Data \(t=\dfrac{x_{4}+x_{5}}{2}\) With \(8\) values the median is the mean of the \(4\)th and \(5\)th values in order.

Arrange in ascending order:

$$-5,\;-4,\;-3,\;1,\;1,\;1,\;4,\;5$$

With $n=8$ (even), the median is the average of the $4$th and $5$th values:

$$t = \frac{1+1}{2}=1$$

✘ Statement II says $t=-1$, so II is not true.
Middle two values are both $1$, hence the median is $1$, not $-1$.
5Conclude which statements hold

I. $s=1$ — true

II. $t=-1$ — false

III. $\alpha+\beta=0$ — true

Only I and III are true $\Rightarrow$ option B.

Always re-read the question: it asks which statements are true, not which value is the median.
Answer
B  ·  I and III only

Question. Consider the following data: \(\alpha,\ \beta,\ -6,\ -3,\ 1,\ 1,\ 1,\ 4\), where \(\alpha>\beta\). It is given that the mean of the data is \(0\) and the range is \(12\). Find \(\alpha\) and \(\beta\), and find the mode and the median of the data.

Show the worked solution
Step 1. Mean \(=0\): \(\alpha+\beta-6-3+1+1+1+4=0\), so \(\alpha+\beta-2=0\) and \(\alpha+\beta=2\).
Step 2. The known values already include the minimum \(-6\), and a range of \(12\) forces the maximum to be \(6\); so \(\alpha=6\) and \(\beta=2-6=-4\).
Step 3. The data are \(6,-4,-6,-3,1,1,1,4\). The value \(1\) occurs three times and no other value occurs more than once, so the mode is \(1\).
Step 4. In ascending order: \(-6,-4,-3,1,1,1,4,6\). Median \(=\dfrac{1+1}{2}=1\).
Step 5. Check: \(6+(-4)+(-6)+(-3)+1+1+1+4=0\) ✓ and \(6-(-6)=12\) ✓
Answer: \(\alpha=6,\ \beta=-4\); mode \(=1\); median \(=1\)
