Step-by-Step Solution

1

Recognise the structure

The expression has the form \(a^2 - b^2\) where \(a = 4x+y\) and \(b = 4x-y\).

Hint: The identity \(a^2 - b^2 = (a+b)(a-b)\) is the fastest method here.
2

Apply the identity

\[(4x+y)^2-(4x-y)^2 = \big[(4x+y)+(4x-y)\big]\big[(4x+y)-(4x-y)\big]\]

3

Simplify each bracket

\((4x+y)+(4x-y) = 8x\)
\((4x+y)-(4x-y) = 2y\)
Hint: Watch the signs — subtracting a negative \((-y)\) gives \(+y\), so \(-(-y) = +y\).
4

Multiply the results

\[(8x)(2y) = 16xy\]

✓

Answer: D. \(16xy\)

The expression simplifies to \(16xy\), which matches option D.
