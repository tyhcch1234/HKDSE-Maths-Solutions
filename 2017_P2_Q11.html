Map → Real Zoo (scale 1 : 20000)

Map region (4 cm²) Linear scale ×20000 Actual region (m²)

Step 1 — length ratio 1 : 20000, so the area ratio is 1² : 20000².

HKDSE 2017 P2 Q11

Question. The scale of a map is $1:20000$. If the area of a zoo on the map is $4\ \text{cm}^2$, then the actual area of the zoo is

  1. $8\times 10^{4}\ \text{m}^2$
  2. $1.6\times 10^{5}\ \text{m}^2$
  3. $3.2\times 10^{5}\ \text{m}^2$
  4. $1\times 10^{6}\ \text{m}^2$
STEP 1Write the linear scale.

Map length : Actual length $= 1 : 20000$.
So the linear scale factor is $k = 20000$.

Scale gives lengths, not areas directly.

STEP 2Square the scale factor for areas.

Since the two regions are similar,

\[ \frac{\text{area on map}}{\text{actual area}} =\left(\frac{1}{20000}\right)^2 =\frac{1}{20000^2} =\frac{1}{4\times 10^{8}}. \]

Area ratio = (length ratio)².

STEP 3Find the actual area in cm².

\[ \text{Actual area} = 4 \times (4\times 10^{8})\ \text{cm}^2 = 1.6\times 10^{9}\ \text{cm}^2. \]

Multiply map area by $20000^2 = 4\times 10^{8}$.

STEP 4Convert cm² to m².

$1\ \text{m} = 100\ \text{cm}$, so $1\ \text{m}^2 = 100^2 = 10^{4}\ \text{cm}^2$.

\[ \text{Actual area} = \frac{1.6\times 10^{9}}{10^{4}}\ \text{m}^2 = 1.6\times 10^{5}\ \text{m}^2. \]

Divide by $10^4$ (i.e. $100^2$).

Answer: B  —  $1.6\times 10^{5}\ \text{m}^2$
