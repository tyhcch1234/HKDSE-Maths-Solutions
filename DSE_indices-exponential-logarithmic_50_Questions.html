Type 1

Laws of Indices with Integer Exponents · 7 questions

Product, quotient, power and bracket laws

Core idea: When the bases are the same, multiplying adds the indices and dividing subtracts them. A power raised to a power multiplies the indices, and an index written outside a bracket applies to every factor inside, including the number.

\(a^{m}\times a^{n}=a^{m+n}\)\(\frac{a^{m}}{a^{n}}=a^{m-n}\)\((a^{m})^{n}=a^{mn}\)
Q1★☆☆☆2 marks

Simplify \(x^{3}\times x^{5}\div x^{2}\).

Answer\(x^{6}\)
  1. Multiply first, using the product law: \(x^{3}\times x^{5}=x^{3+5}=x^{8}\).
  2. Then divide, using the quotient law: \(x^{8}\div x^{2}=x^{8-2}=x^{6}\).
  3. Check with \(x=2\): \(2^{3}\times 2^{5}\div 2^{2}=8\times 32\div 4=64=2^{6}\). ✓
Common mistake

\(x^{3}\times x^{5}\) is \(x^{8}\), not \(x^{15}\): multiplying powers of the same base adds the indices, it does not multiply them.

Q2★☆☆☆2 marks

Expand and simplify \((3a^{2}b)^{2}\).

Answer\(9a^{4}b^{2}\)
  1. The index 2 outside the bracket applies to every factor inside: \((3a^{2}b)^{2}=3^{2}\times(a^{2})^{2}\times b^{2}\).
  2. \(3^{2}=9\) and \((a^{2})^{2}=a^{2\times 2}=a^{4}\).
  3. So \((3a^{2}b)^{2}=9a^{4}b^{2}\). Check with \(a=b=1\): \((3)^{2}=9\). ✓
Q3★★☆☆3 marks

Simplify \(\frac{12x^{5}y^{2}}{4x^{2}y^{6}}\) and express your answer with positive indices.

Answer\(\frac{3x^{3}}{y^{4}}\)
  1. Deal with the numbers separately: \(\frac{12}{4}=3\).
  2. For \(x\): \(\frac{x^{5}}{x^{2}}=x^{5-2}=x^{3}\).
  3. For \(y\): \(\frac{y^{2}}{y^{6}}=y^{2-6}=y^{-4}=\frac{1}{y^{4}}\).
  4. Hence the expression is \(3x^{3}y^{-4}=\frac{3x^{3}}{y^{4}}\). Check with \(x=2,y=1\): \(\frac{12(32)(1)}{4(4)(1)}=24\) and \(\frac{3(8)}{1}=24\). ✓
Common mistake

Keeping \(y^{-4}\) as the final answer loses the last mark — the question asks for positive indices.

Q4★★☆☆3 marks

Simplify \((2x^{2}y^{3})^{2}\times(3xy^{2})\).

Answer\(12x^{5}y^{8}\)
  1. Expand the bracket first: \((2x^{2}y^{3})^{2}=2^{2}x^{4}y^{6}=4x^{4}y^{6}\).
  2. Multiply by \(3xy^{2}\): \(4\times 3=12\), \(x^{4}\times x=x^{4+1}=x^{5}\), \(y^{6}\times y^{2}=y^{6+2}=y^{8}\).
  3. So the answer is \(12x^{5}y^{8}\). Check with \(x=y=1\): \((2)^{2}\times 3=12\). ✓
Q5★★☆☆3 marks

Simplify \(\frac{(a^{2}b^{-1})^{3}}{a^{-1}b^{2}}\) and express your answer with positive indices.

Answer\(\frac{a^{7}}{b^{5}}\)
  1. Expand the numerator: \((a^{2}b^{-1})^{3}=a^{6}b^{-3}\).
  2. Divide by \(a^{-1}b^{2}\): \(a^{6-(-1)}=a^{7}\) and \(b^{-3-2}=b^{-5}\).
  3. So the expression equals \(a^{7}b^{-5}=\frac{a^{7}}{b^{5}}\).
  4. Check with \(a=b=2\): numerator \((4\times\tfrac12)^{3}=8\), denominator \(\tfrac12\times 4=2\), quotient \(4\); formula gives \(\frac{128}{32}=4\). ✓
Q6★★★☆4 marksPast paper · 2015 Paper 1 Q1 ↗

Simplify \(\frac{p^{7}}{(p^{2}q^{-4})^{3}}\) and express your answer with positive indices.

Answer\(pq^{12}\)
  1. Expand the denominator: \((p^{2}q^{-4})^{3}=p^{6}q^{-12}\).
  2. The expression becomes \(\frac{p^{7}}{p^{6}q^{-12}}=p^{7-6}q^{0-(-12)}\).
  3. \(p^{1}=p\) and \(q^{12}\) is already positive, so the answer is \(pq^{12}\).
  4. Check with \(p=2,q=1\): \(\frac{128}{(4)^{3}}=2\) and \(2\times 1=2\). ✓
Common mistake

A negative index in the denominator moves up as a positive index: \(\frac{1}{q^{-12}}=q^{12}\). Leaving \(q^{-12}\) in the denominator and then writing \(\frac{1}{q^{12}}\) is a sign slip.

Q7★★★☆4 marks

It is given that \(2^{x}=3\) and \(2^{y}=5\).

(a) Find the value of \(2^{2x-y}\).

(b) Find the value of \(4^{x+y}\).

Answer(a) \(\frac{9}{5}\)　(b) \(225\)
  1. (a) \(2^{2x-y}=\frac{2^{2x}}{2^{y}}=\frac{(2^{x})^{2}}{2^{y}}\).
  2. Substitute \(2^{x}=3\) and \(2^{y}=5\): \(\frac{3^{2}}{5}=\frac{9}{5}\).
  3. (b) Write \(4\) as a power of 2: \(4^{x+y}=(2^{2})^{x+y}=2^{2(x+y)}=(2^{x+y})^{2}\).
  4. \(2^{x+y}=2^{x}\times 2^{y}=3\times 5=15\), so \(4^{x+y}=15^{2}=225\).
  5. Check (b) with the definition: if \(2^{x}=3\) then \(x\approx 1.585\) and \(2^{y}=5\) gives \(y\approx 2.322\); \(4^{3.907}\approx 225\). ✓
Common mistake

A common error is writing \(2^{2x}\) as \(2^{x^{2}}\). Squaring a power multiplies the index: \((2^{x})^{2}=2^{2x}\). Also convert a base such as \(4^{x+y}\) to base 2 before combining the two index values.

Type 2

Zero, Negative and Rational Indices · 7 questions

Evaluate powers with 0, negative and fractional indices

Core idea: Anything non-zero to the power 0 is 1; a negative index means reciprocal; and a fractional index \(\frac{m}{n}\) means the \(n\)-th root first, then the \(m\)-th power. Take the root first so that the numbers stay small.

\(a^{0}=1\)\(a^{-n}=\frac{1}{a^{n}}\)\(a^{\frac{m}{n}}=(\sqrt[n]{a})^{m}\)
Q8★☆☆☆2 marks

Evaluate \(3^{0}+2^{-1}+5^{-1}\) without using a calculator.

Answer\(\frac{17}{10}\)
  1. \(3^{0}=1\) (any non-zero number to the power 0 is 1).
  2. \(2^{-1}=\frac{1}{2}\) and \(5^{-1}=\frac{1}{5}\).
  3. \(1+\frac{1}{2}+\frac{1}{5}=1+0.5+0.2=1.7=\frac{17}{10}\).
Q9★☆☆☆2 marks

Evaluate (a) \(4^{-2}\),　(b) \(\left(\frac{2}{3}\right)^{-2}\).

Answer(a) \(\frac{1}{16}\)　(b) \(\frac{9}{4}\)
  1. (a) \(4^{-2}=\frac{1}{4^{2}}=\frac{1}{16}\).
  2. (b) A negative index turns the fraction upside down: \(\left(\frac{2}{3}\right)^{-2}=\left(\frac{3}{2}\right)^{2}\).
  3. \(\left(\frac{3}{2}\right)^{2}=\frac{9}{4}\).
Common mistake

Making the answer negative: \(4^{-2}\) is positive, \(\frac{1}{16}\), because the minus sign only flips the fraction.

Q10★★☆☆3 marks

Evaluate (a) \(27^{\frac{2}{3}}\),　(b) \(16^{-\frac{3}{4}}\).

Answer(a) \(9\)　(b) \(\frac{1}{8}\)
  1. (a) Take the cube root first: \(27^{\frac{1}{3}}=3\), then square: \(27^{\frac{2}{3}}=3^{2}=9\).
  2. (b) Take the fourth root first: \(16^{\frac{1}{4}}=2\), then cube: \(16^{\frac{3}{4}}=2^{3}=8\).
  3. The negative sign gives the reciprocal: \(16^{-\frac{3}{4}}=\frac{1}{8}\).
Q11★★☆☆3 marks

Evaluate \(\left(\frac{8}{27}\right)^{-\frac{2}{3}}\) without using a calculator.

Answer\(\frac{9}{4}\)
  1. Use the negative index to invert the fraction: \(\left(\frac{8}{27}\right)^{-\frac{2}{3}}=\left(\frac{27}{8}\right)^{\frac{2}{3}}\).
  2. Take the cube root: \(\left(\frac{27}{8}\right)^{\frac{1}{3}}=\frac{3}{2}\).
  3. Square it: \(\left(\frac{3}{2}\right)^{2}=\frac{9}{4}\).
  4. Check: \(\left(\frac{8}{27}\right)^{-\frac{2}{3}}\times\left(\frac{8}{27}\right)^{\frac{2}{3}}=1\), and \(\frac{9}{4}\times\frac{4}{9}=1\). ✓
Common mistake

Applying the negative sign to the answer instead of inverting the fraction: the result must be positive.

Q12★★☆☆3 marks

Solve \(x^{\frac{2}{3}}=9\), where \(x>0\).

Answer\(x=27\)
  1. Raise both sides to the power \(\frac{3}{2}\) (the reciprocal of \(\frac{2}{3}\)): \(\left(x^{\frac{2}{3}}\right)^{\frac{3}{2}}=9^{\frac{3}{2}}\).
  2. The left side is \(x^{1}=x\).
  3. For the right side take the square root first, then cube: \(9^{\frac{1}{2}}=3\), so \(9^{\frac{3}{2}}=3^{3}=27\).
  4. Check: \(27^{\frac{2}{3}}=(\sqrt[3]{27})^{2}=3^{2}=9\). ✓
Q13★★★☆4 marksPast paper · 2022 Paper 1 Q1 ↗

Evaluate \(81^{-\frac{3}{4}}\times 32^{\frac{2}{5}}\) without using a calculator.

Answer\(\frac{4}{27}\)
  1. Write each base as a power of a prime: \(81=3^{4}\) and \(32=2^{5}\).
  2. \(81^{-\frac{3}{4}}=(3^{4})^{-\frac{3}{4}}=3^{-3}=\frac{1}{27}\).
  3. \(32^{\frac{2}{5}}=(2^{5})^{\frac{2}{5}}=2^{2}=4\).
  4. Multiply: \(\frac{1}{27}\times 4=\frac{4}{27}\).
  5. Check the exponents: \(4\times(-\frac{3}{4})=-3\) and \(5\times\frac{2}{5}=2\). ✓
Q14★★★☆4 marksPast paper · 2021 Paper 1 Q1 ↗

Simplify \(\frac{(8x^{6})^{\frac{2}{3}}}{(4x^{4})^{\frac{3}{2}}}\), where \(x>0\).

Answer\(\frac{1}{2x^{2}}\)
  1. Numerator: \((8x^{6})^{\frac{2}{3}}=8^{\frac{2}{3}}\,x^{6\times\frac{2}{3}}=4x^{4}\).
  2. Denominator: \((4x^{4})^{\frac{3}{2}}=4^{\frac{3}{2}}\,x^{4\times\frac{3}{2}}=8x^{6}\).
  3. Divide: \(\frac{4x^{4}}{8x^{6}}=\frac{1}{2}x^{4-6}=\frac{1}{2}x^{-2}\).
  4. With positive indices: \(\frac{1}{2x^{2}}\). Check with \(x=2\): numerator \((8\times 64)^{\frac{2}{3}}=512^{\frac{2}{3}}=64\) and denominator \((4\times 16)^{\frac{3}{2}}=64^{\frac{3}{2}}=512\), so the value is \(\frac{64}{512}=\frac{1}{8}=\frac{1}{2(4)}\). ✓
Common mistake

Forgetting that \(8^{\frac{2}{3}}=4\) and \(4^{\frac{3}{2}}=8\): the fractional index must be applied to the number as well as the power of \(x\).

Type 3

Simplifying Index Expressions and Scientific Notation · 7 questions

Mixed index laws; standard form arithmetic

Core idea: Long expressions fall apart once every base is written as a power of a prime (or of the same letter). For standard form \(A\times 10^{n}\) with \(1\le A<10\), handle the numbers and the powers of 10 separately, then re-adjust \(A\) at the end.

\((ab)^{n}=a^{n}b^{n}\)\(A\times 10^{m}\times B\times 10^{n}=AB\times 10^{m+n}\)\(\frac{A\times 10^{m}}{B\times 10^{n}}=\frac{A}{B}\times 10^{m-n}\)
Q15★☆☆☆2 marks

Simplify \(2^{n}\times 2^{n+3}\div 2^{2n}\).

Answer\(8\)
  1. All the bases are 2, so add and subtract the indices: \(n+(n+3)-2n\).
  2. \(n+n+3-2n=3\).
  3. Hence the expression equals \(2^{3}=8\), a constant that does not depend on \(n\).
  4. Check with \(n=1\): \(2\times 2^{4}\div 2^{2}=32\div 4=8\). ✓
Common mistake

Treating \(2^{n+3}\) as \(2^{n}+2^{3}\). An index does not distribute over a sum.

Q16★☆☆☆2 marksPast paper · 2020 Paper 1 Q1 ↗

Express \((4\times 10^{5})\times(2.5\times 10^{3})\) in scientific notation.

Answer\(1\times 10^{9}\)
  1. Multiply the numbers: \(4\times 2.5=10\).
  2. Multiply the powers of 10: \(10^{5}\times 10^{3}=10^{8}\).
  3. So the product is \(10\times 10^{8}=10^{1}\times 10^{8}=10^{9}\).
  4. In scientific notation \(1\le A<10\), so write it as \(1\times 10^{9}\).
Q17★★☆☆3 marks

Simplify \(\frac{6^{n}\times 2^{n+1}}{3^{n}\times 4^{n}}\).

Answer\(2\)
  1. Write every base as a power of 2 or 3: \(6^{n}=2^{n}3^{n}\) and \(4^{n}=2^{2n}\).
  2. Numerator: \(2^{n}3^{n}\times 2^{n+1}=2^{2n+1}3^{n}\).
  3. Denominator: \(3^{n}\times 2^{2n}\).
  4. Divide: \(2^{(2n+1)-2n}\times 3^{n-n}=2^{1}\times 3^{0}=2\).
  5. Check with \(n=1\): \(\frac{6\times 4}{3\times 4}=\frac{24}{12}=2\). ✓
Common mistake

Cancelling \(6^{n}\) with \(3^{n}\) to get \(2^{n}\) works, but then \(\frac{2^{n}\times 2^{n+1}}{4^{n}}=\frac{2^{2n+1}}{2^{2n}}=2\) must still be finished — do not stop at \(2^{2n+1}/4^{n}\).

Q18★★☆☆3 marks

Simplify \(\frac{(2\times 10^{3})^{3}}{8\times 10^{-2}}\) and express your answer in scientific notation.

Answer\(1\times 10^{11}\)
  1. Cube the bracket: \((2\times 10^{3})^{3}=2^{3}\times 10^{9}=8\times 10^{9}\).
  2. Divide the numbers: \(\frac{8}{8}=1\).
  3. Divide the powers: \(10^{9}\div 10^{-2}=10^{9-(-2)}=10^{11}\).
  4. So the value is \(1\times 10^{11}\).
Q19★★☆☆3 marks

Simplify \(\left(\frac{a^{2}b^{3}}{c}\right)^{-2}\times\frac{b^{4}c^{3}}{a^{2}}\) and express your answer with positive indices.

Answer\(\frac{c^{5}}{a^{6}b^{2}}\)
  1. The negative index inverts the bracket: \(\left(\frac{a^{2}b^{3}}{c}\right)^{-2}=\frac{c^{2}}{a^{4}b^{6}}\).
  2. Multiply by \(\frac{b^{4}c^{3}}{a^{2}}\): numbers of \(a\): \(a^{-4}\times a^{-2}=a^{-6}\); \(b\): \(b^{-6}\times b^{4}=b^{-2}\); \(c\): \(c^{2}\times c^{3}=c^{5}\).
  3. So the expression is \(\frac{c^{5}}{a^{6}b^{2}}\).
  4. Check with \(a=b=c=1\): both sides equal 1. ✓
Common mistake

Raising a fraction to a negative power inverts it, but the indices inside are still multiplied by 2: \(\frac{c^{2}}{a^{4}b^{6}}\), not \(\frac{c^{-2}}{a^{-4}b^{-6}}\).

Q20★★★☆4 marksPast paper · 2026 Paper 1 Q2 ↗

Let \(p=2.4\times 10^{5}\) and \(q=8\times 10^{3}\).

(a) Find \(\frac{p}{q}\) in scientific notation.

(b) Find \(p+q\) in scientific notation.

Answer(a) \(3\times 10^{1}\)　(b) \(2.48\times 10^{5}\)
  1. (a) \(\frac{p}{q}=\frac{2.4}{8}\times 10^{5-3}=0.3\times 10^{2}\).
  2. Adjust to scientific notation: \(0.3\times 10^{2}=3\times 10^{1}=30\).
  3. (b) Write both numbers with the same power of 10: \(p=240\,000\) and \(q=8000\).
  4. \(p+q=240\,000+8000=248\,000=2.48\times 10^{5}\).
Q21★★★☆4 marks

The mass of one carbon atom is about \(2\times 10^{-23}\) g. A pencil lead contains 0.05 g of carbon. Estimate the number of carbon atoms in the pencil lead, giving your answer in scientific notation.

Answer\(2.5\times 10^{21}\)
  1. Number of atoms \(=\frac{\text{total mass}}{\text{mass of one atom}}=\frac{0.05}{2\times 10^{-23}}\).
  2. Write \(0.05=5\times 10^{-2}\).
  3. \(\frac{5\times 10^{-2}}{2\times 10^{-23}}=2.5\times 10^{-2-(-23)}=2.5\times 10^{21}\).
  4. Check the size: \(2.5\times 10^{21}\) atoms of mass \(2\times 10^{-23}\) g each have total mass \(5\times 10^{-2}=0.05\) g. ✓
Common mistake

\(10^{-2}\div 10^{-23}=10^{21}\), not \(10^{-25}\): subtract the indices, \(-2-(-23)=21\).

Type 4

Exponential Equations · 7 questions

Same base, substitution, hidden quadratics

Core idea: If \(a^{M}=a^{N}\) with \(a>0\), \(a\neq 1\), then \(M=N\). So the whole game is to write both sides as powers of the same base. When a term like \(a^{2x}\) and \(a^{x}\) both appear, substitute \(u=a^{x}\) to turn the equation into a quadratic.

\(a^{M}=a^{N}\Rightarrow M=N\)\(a^{2x}=(a^{x})^{2}=u^{2}\)\(a^{x+y}=a^{x}a^{y}\)
Q22★☆☆☆2 marks

Solve \(2^{x}=64\).

Answer\(x=6\)
  1. Write 64 as a power of 2: \(64=2^{6}\).
  2. So \(2^{x}=2^{6}\), and since the bases are equal, \(x=6\).
  3. Check: \(2^{6}=64\). ✓
Q23★☆☆☆2 marks

Solve \(9^{x}=27\).

Answer\(x=\frac{3}{2}\)
  1. Use base 3 for both sides: \(9=3^{2}\) and \(27=3^{3}\).
  2. \(9^{x}=(3^{2})^{x}=3^{2x}\), so \(3^{2x}=3^{3}\).
  3. Equate the indices: \(2x=3\), giving \(x=\frac{3}{2}\).
  4. Check: \(9^{\frac{3}{2}}=(\sqrt{9})^{3}=3^{3}=27\). ✓
Q24★★☆☆3 marksPast paper · 2017 Paper 1 Q2 ↗

Solve \(5^{2x-1}=125\).

Answer\(x=2\)
  1. Write 125 as a power of 5: \(125=5^{3}\).
  2. So \(5^{2x-1}=5^{3}\), which forces \(2x-1=3\).
  3. \(2x=4\), hence \(x=2\).
  4. Check: \(5^{2(2)-1}=5^{3}=125\). ✓
Common mistake

Applying the index law wrongly as \(5^{2x-1}=\frac{5^{2x}}{5}\) is correct, but then forgetting the \(-1\) when equating indices gives \(x=1.5\).

Q25★★☆☆3 marks

Solve \(4^{x}=\frac{1}{8}\).

Answer\(x=-\frac{3}{2}\)
  1. Use base 2: \(4^{x}=2^{2x}\) and \(\frac{1}{8}=2^{-3}\).
  2. \(2^{2x}=2^{-3}\), so \(2x=-3\).
  3. \(x=-\frac{3}{2}\).
  4. Check: \(4^{-\frac{3}{2}}=\frac{1}{(\sqrt{4})^{3}}=\frac{1}{8}\). ✓
Common mistake

A negative answer is expected here. Rejecting it, or writing \(x=\frac{3}{2}\), ignores that \(\frac{1}{8}\) is smaller than 1.

Q26★★☆☆3 marksPast paper · 2023 Paper 1 Q2 ↗

Solve \(3^{x+1}=27^{x-1}\).

Answer\(x=2\)
  1. Write the right side with base 3: \(27^{x-1}=(3^{3})^{x-1}=3^{3x-3}\).
  2. So \(3^{x+1}=3^{3x-3}\), which gives \(x+1=3x-3\).
  3. \(4=2x\), so \(x=2\).
  4. Check: left \(3^{3}=27\); right \(27^{1}=27\). ✓
Q27★★★☆4 marks

Solve \(2^{2x}-5(2^{x})+4=0\).

Answer\(x=0\) or \(x=2\)
  1. Notice \(2^{2x}=(2^{x})^{2}\). Let \(u=2^{x}\) (so \(u>0\)); the equation becomes \(u^{2}-5u+4=0\).
  2. Factorise: \((u-1)(u-4)=0\), so \(u=1\) or \(u=4\).
  3. Both are positive, so both are acceptable. Back-substitute: \(2^{x}=1\Rightarrow x=0\); \(2^{x}=4\Rightarrow x=2\).
  4. Check \(x=0\): \(1-5+4=0\) ✓. Check \(x=2\): \(16-20+4=0\) ✓.
Q28★★★☆4 marks

Solve \(4^{x}-3(2^{x+1})+8=0\).

Answer\(x=1\) or \(x=2\)
  1. Rewrite everything in terms of \(2^{x}\): \(4^{x}=(2^{2})^{x}=2^{2x}=(2^{x})^{2}\) and \(2^{x+1}=2\cdot 2^{x}\).
  2. So the equation is \((2^{x})^{2}-6(2^{x})+8=0\). Let \(u=2^{x}\): \(u^{2}-6u+8=0\).
  3. Factorise: \((u-2)(u-4)=0\), so \(u=2\) or \(u=4\).
  4. Then \(2^{x}=2\Rightarrow x=1\) and \(2^{x}=4\Rightarrow x=2\).
  5. Check \(x=1\): \(4-3(4)+8=0\) ✓. Check \(x=2\): \(16-3(8)+8=0\) ✓.
Common mistake

Dropping the factor 2: \(3(2^{x+1})=6(2^{x})\), not \(3(2^{x})\). Getting \(u^{2}-3u+8=0\) gives no real solution and is wrong.

Type 5

Definition of a Logarithm and Evaluating Logs · 7 questions

Convert between index and log form

Core idea: A logarithm answers the question “what power must the base be raised to?”. The statement \(\log_{b}N=k\) is exactly the same as \(b^{k}=N\), so every log question can be turned back into an index question. Here \(b>0\), \(b\neq 1\) and \(N>0\).

\(\log_{b}N=k\Leftrightarrow b^{k}=N\)\(\log_{b}1=0,\ \log_{b}b=1\)\(\log_{b}b^{k}=k\)
Q29★☆☆☆2 marks

Evaluate \(\log_{2}32\) without a calculator.

Answer\(5\)
  1. Ask: 2 to what power gives 32? Write \(32=2^{5}\).
  2. So \(\log_{2}32=\log_{2}2^{5}=5\).
  3. Check: \(2^{5}=32\). ✓
Q30★☆☆☆2 marks

Evaluate \(\log_{5}\frac{1}{25}\).

Answer\(-2\)
  1. Write \(\frac{1}{25}=5^{-2}\).
  2. \(\log_{5}5^{-2}=-2\).
  3. Check: \(5^{-2}=\frac{1}{25}\). ✓
Common mistake

The log of a number between 0 and 1 with base greater than 1 is negative. Answering \(2\) loses the sign.

Q31★★☆☆3 marks

Evaluate \(\log_{3}81+\log_{2}\frac{1}{8}\).

Answer\(1\)
  1. \(81=3^{4}\), so \(\log_{3}81=4\).
  2. \(\frac{1}{8}=2^{-3}\), so \(\log_{2}\frac{1}{8}=-3\).
  3. \(4+(-3)=1\).
  4. Check: \(3^{4}=81\) and \(2^{-3}=\frac{1}{8}\). ✓
Common mistake

Evaluating each log correctly but then subtracting: the second log is already negative, so adding \(-3\) is required.

Q32★★☆☆3 marks

Evaluate \(\log_{4}2+\log_{9}27\).

Answer\(2\)
  1. Write the numbers as powers of the base: \(2=4^{\frac{1}{2}}\), so \(\log_{4}2=\frac{1}{2}\).
  2. \(27=3^{3}=(9)^{\frac{3}{2}}\), so \(\log_{9}27=\frac{3}{2}\).
  3. \(\frac{1}{2}+\frac{3}{2}=2\).
  4. Check: \(4^{\frac{1}{2}}=2\) and \(9^{\frac{3}{2}}=(\sqrt{9})^{3}=27\). ✓
Q33★★☆☆3 marksPast paper · 2014 Paper 1 Q15 ↗

(a) Solve \(\log_{x}64=3\).

(b) Solve \(\log_{2}(x-3)=4\).

Answer(a) \(x=4\)　(b) \(x=19\)
  1. (a) Change to index form: \(x^{3}=64\).
  2. Since \(x\) is a base it must be positive and not 1, so \(x=\sqrt[3]{64}=4\).
  3. (b) Change to index form: \(x-3=2^{4}=16\).
  4. So \(x=19\). Check the domain: \(19-3=16>0\). ✓
Q34★★★☆4 marks

It is given that \(\log 2=a\) and \(\log 3=b\) (both to base 10). Express, in terms of \(a\) and \(b\),

(a) \(\log 72\),　(b) \(\log 1.5\).

Answer(a) \(3a+2b\)　(b) \(b-a\)
  1. (a) Factorise 72 into primes: \(72=8\times 9=2^{3}\times 3^{2}\).
  2. \(\log 72=\log(2^{3}\times 3^{2})=3\log 2+2\log 3=3a+2b\).
  3. (b) Write \(1.5=\frac{3}{2}\).
  4. \(\log 1.5=\log 3-\log 2=b-a\).
Common mistake

\(\log 72\neq (\log 8)(\log 9)\). Logs turn products into sums, not into products.

Q35★★★☆4 marks

Given that \(\log 2=0.3010\) and \(\log 3=0.4771\) (base 10), find

(a) \(\log 48\),　(b) \(\log\sqrt{1.5}\),

giving each answer correct to 4 decimal places where necessary.

Answer(a) \(1.6811\)　(b) \(0.0881\)
  1. (a) \(48=16\times 3=2^{4}\times 3\), so \(\log 48=4\log 2+\log 3\).
  2. \(=4(0.3010)+0.4771=1.2040+0.4771=1.6811\).
  3. (b) \(\log\sqrt{1.5}=\frac{1}{2}\log 1.5=\frac{1}{2}(\log 3-\log 2)\).
  4. \(=\frac{1}{2}(0.4771-0.3010)=\frac{1}{2}(0.1761)=0.08805\approx 0.0881\).
Common mistake

Using \(\log 48=\log 16\times\log 3\). The product law is \(\log(MN)=\log M+\log N\).

Type 6

Laws of Logarithms and Logarithmic Equations · 7 questions

Log laws, solving log equations, change of base

Core idea: Logs turn multiplication into addition, division into subtraction and powers into multipliers. To solve a log equation, first combine everything into a single log, then convert to index form — and always check that the original arguments are positive.

\(\log M+\log N=\log MN\)\(\log M-\log N=\log\frac{M}{N}\)\(\log_{b}a=\frac{\log a}{\log b}\)
Q36★☆☆☆2 marks

Evaluate \(\log 8+\log 125\), where the base is 10.

Answer\(3\)
  1. Use the product law: \(\log 8+\log 125=\log(8\times 125)\).
  2. \(8\times 125=1000=10^{3}\).
  3. So the value is \(\log 10^{3}=3\).
Q37★☆☆☆2 marks

Evaluate \(\log_{2}24-\log_{2}3\).

Answer\(3\)
  1. Use the quotient law: \(\log_{2}24-\log_{2}3=\log_{2}\frac{24}{3}=\log_{2}8\).
  2. \(8=2^{3}\), so \(\log_{2}8=3\).
  3. Check: \(2^{3}=8\). ✓
Q38★★☆☆3 marks

Solve \(\log_{3}x+\log_{3}(x+6)=3\).

Answer\(x=3\)
  1. Combine the left side: \(\log_{3}[x(x+6)]=3\).
  2. Convert to index form: \(x(x+6)=3^{3}=27\).
  3. \(x^{2}+6x-27=0\), so \((x+9)(x-3)=0\), giving \(x=-9\) or \(x=3\).
  4. Check the domain: \(x>0\) and \(x+6>0\), so \(x=-9\) is rejected. Answer \(x=3\).
  5. Check: \(\log_{3}3+\log_{3}9=1+2=3\). ✓
Common mistake

Keeping \(x=-9\): the argument of a logarithm must be positive, so a negative root must always be rejected.

Q39★★☆☆3 marks

Solve \(\log_{2}(x+1)-\log_{2}(x-1)=2\).

Answer\(x=\frac{5}{3}\)
  1. Combine: \(\log_{2}\frac{x+1}{x-1}=2\).
  2. Convert to index form: \(\frac{x+1}{x-1}=2^{2}=4\).
  3. Clear the fraction: \(x+1=4x-4\), so \(5=3x\) and \(x=\frac{5}{3}\).
  4. Check the domain: \(\frac{5}{3}+1>0\) and \(\frac{5}{3}-1=\frac{2}{3}>0\). ✓
  5. Check the value: \(\log_{2}\frac{8/3}{2/3}=\log_{2}4=2\). ✓
Q40★★☆☆3 marksPast paper · 2023 Paper 1 Q18 ↗

Evaluate \(\log_{4}9\times\log_{3}8\).

Answer\(3\)
  1. Change both logs to a common base, say base 2: \(\log_{4}9=\frac{\log_{2}9}{\log_{2}4}=\frac{2\log_{2}3}{2}=\log_{2}3\).
  2. Similarly \(\log_{3}8=\frac{\log_{2}8}{\log_{2}3}=\frac{3}{\log_{2}3}\).
  3. Multiply: \(\log_{2}3\times\frac{3}{\log_{2}3}=3\).
  4. Check numerically: \(\log_{4}9\approx 1.585\) and \(\log_{3}8\approx 1.893\), product \(\approx 3.00\). ✓
Common mistake

Multiplying the logs by multiplying the numbers inside: \(\log_{4}9\times\log_{3}8\neq\log 72\). Use change of base instead.

Q41★★★☆4 marks

Solve \(2\log x=\log 4+\log(x+3)\), where the base is 10.

Answer\(x=6\)
  1. Use the power law on the left: \(2\log x=\log x^{2}\).
  2. Use the product law on the right: \(\log 4+\log(x+3)=\log[4(x+3)]\).
  3. So \(\log x^{2}=\log[4(x+3)]\), which gives \(x^{2}=4x+12\).
  4. \(x^{2}-4x-12=0\), so \((x-6)(x+2)=0\), i.e. \(x=6\) or \(x=-2\).
  5. Reject \(x=-2\) because \(\log x\) needs \(x>0\). Answer \(x=6\).
  6. Check: \(2\log 6=\log 36\) and \(\log 4+\log 9=\log 36\). ✓
Q42★★★☆4 marks

Solve \(\log_{2}x+\log_{4}x=3\).

Answer\(x=4\)
  1. Change \(\log_{4}x\) to base 2: \(\log_{4}x=\frac{\log_{2}x}{\log_{2}4}=\frac{\log_{2}x}{2}\).
  2. The equation becomes \(\log_{2}x+\frac{1}{2}\log_{2}x=3\), i.e. \(\frac{3}{2}\log_{2}x=3\).
  3. So \(\log_{2}x=2\), giving \(x=2^{2}=4\).
  4. Check: \(\log_{2}4+\log_{4}4=2+1=3\). ✓
Common mistake

Adding the two logs directly because the bases look alike: \(\log_{2}x+\log_{4}x\neq\log_{6}x^{2}\). The bases must be the same before any log law applies.

Type 7

Exponential and Logarithmic Graphs and Applications · 8 questions

Growth, decay, half-life, Richter scale

Core idea: \(y=a^{x}\) with \(a>1\) grows without bound and always passes through \((0,1)\); \(y=\log_{a}x\) is its mirror image and always passes through \((1,0)\). In applications, read the model as “starting value × (multiplier)number of periods”, and use logs whenever the unknown sits in the index.

\(y=ka^{t}\)\(A=P(1+r)^{n}\)\(A=P\left(\frac{1}{2}\right)^{\frac{t}{h}}\)
Q43★☆☆☆2 marks

The graph of \(y=2^{x}\) passes through the point \((3,k)\). Find \(k\) and the \(y\)-intercept of the graph.

Answer\(k=8\); \(y\)-intercept \(1\)
  1. Substitute \(x=3\): \(k=2^{3}=8\).
  2. The \(y\)-intercept is the value when \(x=0\): \(y=2^{0}=1\).
  3. So the curve cuts the \(y\)-axis at \((0,1)\) and passes through \((3,8)\).
Q44★☆☆☆2 marks

The graph of \(y=\log_{3}x\) passes through the point \((9,k)\). Find \(k\) and the \(x\)-intercept of the graph.

Answer\(k=2\); \(x\)-intercept \(1\)
  1. Substitute \(x=9\): \(k=\log_{3}9=\log_{3}3^{2}=2\).
  2. The \(x\)-intercept is where \(y=0\): \(\log_{3}x=0\Rightarrow x=3^{0}=1\).
  3. So the curve cuts the \(x\)-axis at \((1,0)\) and passes through \((9,2)\).
Q45★★☆☆3 marks

A bacteria culture starts with 500 bacteria and doubles every 3 hours. Let \(N\) be the number of bacteria after \(t\) hours.

(a) Write down an expression for \(N\) in terms of \(t\).

(b) Find the number of bacteria after 12 hours.

Answer(a) \(N=500\times 2^{\frac{t}{3}}\)　(b) \(8000\)
  1. (a) The number of doubling periods in \(t\) hours is \(\frac{t}{3}\), so \(N=500\times 2^{\frac{t}{3}}\).
  2. (b) Put \(t=12\): \(N=500\times 2^{\frac{12}{3}}=500\times 2^{4}\).
  3. \(500\times 16=8000\).
  4. Check: 500 → 1000 (3 h) → 2000 (6 h) → 4000 (9 h) → 8000 (12 h). ✓
Q46★★☆☆3 marks

A radioactive isotope has a half-life of 20 years. A sample has mass 640 g.

(a) Find the mass remaining after 60 years.

(b) What fraction of the original mass remains after 60 years?

Answer(a) \(80\) g　(b) \(\frac{1}{8}\)
  1. 60 years is \(\frac{60}{20}=3\) half-lives.
  2. (a) Mass \(=640\times\left(\frac{1}{2}\right)^{3}=640\times\frac{1}{8}=80\) g.
  3. (b) The fraction is \(\left(\frac{1}{2}\right)^{3}=\frac{1}{8}\).
  4. Check: 640 → 320 → 160 → 80. ✓
Common mistake

Halving three times and reporting 320 g (one half-life only). Count the number of half-lives first.

Q47★★☆☆3 marks

The magnitude \(M\) of an earthquake on the Richter scale is given by \(M=\log_{10}\frac{A}{A_{0}}\), where \(A\) is the amplitude recorded and \(A_{0}\) is a fixed reference amplitude. An earthquake P has magnitude 4. An earthquake Q has an amplitude 1000 times that of P.

Find the magnitude of Q.

Answer\(7\)
  1. For P: \(4=\log_{10}\frac{A_{P}}{A_{0}}\), so \(\frac{A_{P}}{A_{0}}=10^{4}\).
  2. For Q: \(\frac{A_{Q}}{A_{0}}=1000\times 10^{4}=10^{3}\times 10^{4}=10^{7}\).
  3. \(M_{Q}=\log_{10}10^{7}=7\).
  4. Short cut: a 1000-fold amplitude adds \(\log_{10}1000=3\) to the magnitude, so \(4+3=7\).
Common mistake

Multiplying the magnitude by 1000 gives 4000. The Richter scale is logarithmic: multiplying the amplitude adds to the magnitude.

Q48★★★☆4 marks

A machine is bought for $200 000. Its value after \(n\) years is modelled by \(V=200\,000(0.85)^{n}\) dollars.

(a) Find its value after 3 years, correct to the nearest dollar.

(b) Find the first year at the end of which the value drops below $100\,000.

Answer(a) $122 825　(b) 5 years
  1. (a) Put \(n=3\): \(V=200\,000(0.85)^{3}=200\,000\times 0.614125=122\,825\).
  2. (b) Try successive years: \(0.85^{4}=0.5220\), so \(V=104\,401.25\) (still above 100\,000).
  3. \(0.85^{5}=0.4437\), so \(V=88\,741.06\), which is below 100\,000.
  4. The value first drops below $100\,000 at the end of the 5th year.
Q49★★★☆4 marksPast paper · 2017 Paper 1 Q15 ↗

Let \(a\) and \(b\) be constants. The graph of \(y=a+\log_{b}x\) cuts the \(x\)-axis at 8 and passes through the point \((32,2)\).

(a) Find \(a\) and \(b\).

(b) Hence express \(x\) in terms of \(y\).

Answer(a) \(a=-3,\ b=2\)　(b) \(x=2^{y+3}\)
  1. The \(x\)-intercept gives \(0=a+\log_{b}8\).
  2. The point \((32,2)\) gives \(2=a+\log_{b}32\).
  3. Subtract: \(\log_{b}32-\log_{b}8=2\), so \(\log_{b}\frac{32}{8}=\log_{b}4=2\).
  4. Hence \(b^{2}=4\) and (as a base must be positive) \(b=2\).
  5. Then \(0=a+\log_{2}8=a+3\), so \(a=-3\), i.e. \(y=-3+\log_{2}x\).
  6. (b) Rearrange: \(\log_{2}x=y+3\), so \(x=2^{y+3}\).
  7. Check with \(x=32\): \(y=-3+\log_{2}32=-3+5=2\), and \(2^{2+3}=32\). ✓
Common mistake

Subtracting the two equations in the wrong order gives \(\log_{b}\frac{1}{4}=2\), which has no valid base. Keep the larger logarithm first.

Q50★★★★6 marks

A patient is given 200 mg of a drug. The amount \(A\) mg remaining in the blood \(t\) hours later is modelled by \(A=200\left(\frac{1}{2}\right)^{\frac{t}{4}}\).

(a) Find the amount remaining after 6 hours, correct to 1 decimal place.

(b) Find the time needed for the amount to fall to 25 mg.

(c) Explain whether the amount can ever become exactly 0 mg.

Answer(a) 70.7 mg　(b) 12 hours　(c) No — \(\left(\frac{1}{2}\right)^{\frac{t}{4}}>0\) for every \(t\), so the amount only approaches 0.
  1. (a) Put \(t=6\): \(A=200\left(\frac{1}{2}\right)^{\frac{6}{4}}=200\left(\frac{1}{2}\right)^{1.5}\).
  2. \(\left(\frac{1}{2}\right)^{1.5}=\frac{1}{2\sqrt{2}}\approx 0.35355\), so \(A\approx 200\times 0.35355=70.7\) mg.
  3. (b) Set \(A=25\): \(200\left(\frac{1}{2}\right)^{\frac{t}{4}}=25\), so \(\left(\frac{1}{2}\right)^{\frac{t}{4}}=\frac{25}{200}=\frac{1}{8}\).
  4. Since \(\frac{1}{8}=\left(\frac{1}{2}\right)^{3}\), the indices are equal: \(\frac{t}{4}=3\), giving \(t=12\).
  5. Check: after 4 h → 100 mg, 8 h → 50 mg, 12 h → 25 mg. ✓
  6. (c) A power of a positive number is always positive, so \(A>0\) for all \(t\); the model describes a quantity that decays towards 0 but never reaches it.
Common mistake

In (a), using \(\frac{1}{2}\times 6=3\) as the index instead of \(\frac{6}{4}=1.5\); the index counts the number of 4-hour half-lives.
