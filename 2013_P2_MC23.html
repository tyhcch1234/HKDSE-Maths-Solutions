Trigonometric identities & signs in the first quadrant

Complementary Angles tan x · tan(90°−x) = 1 Sign Analysis 0° < x < 90°

Question Multiple Choice · 5 marks

If \(0^\circ < x < 90^\circ\), which of the following must be true?

  1. \(\tan x\,\tan(90^\circ - x) = 1\)
  2. \(\sin x - \sin(90^\circ - x) < 0\)
  3. \(\cos x + \cos(90^\circ - x) > 0\)
A. I and II only
B. I and III only
C. II and III only
D. I, II and III

Summary — Final Answer

  • Statement I: \(\tan x\tan(90^\circ-x)=\tan x\cdot\frac{1}{\tan x}=1\) → true
  • Statement II: \(\sin x-\cos x<0\) fails for \(x>45^\circ\) → false
  • Statement III: \(\cos x+\sin x>0\) since both are positive → true
  • Therefore only I and III are correct.

Correct option: B
