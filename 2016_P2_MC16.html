Geometry on a straight line — collinear points & segment lengths
Collinear Points Segment Addition Surds Multiple Choice

Question The figure

In the figure, \(ABCD\) is a straight line. If \(AB = \sqrt{5}\), \(AD = \sqrt{45}\), \(BD = \sqrt{20}\) and \(CD = \sqrt{5}\), then \(BC =\)
A. \(\sqrt{5}\)
B. \(\sqrt{20}\)  ✓
C. \(\sqrt{45}\)
D. \(\sqrt{80}\)

Drag the sliders in the diagram below to see how the four lengths fit together on the same straight line.

Part (a) Read the picture: which pieces touch which?

Points \(A, B, C, D\) all lie on one straight line. We must decide the correct order of the points. Two given facts fix it:

  • \(BD = \sqrt{20}\) and \(AD = \sqrt{45}\) — so \(D\) is on the far side of \(B\) from \(A\).
  • \(CD = \sqrt{5}\) is small, so \(C\) sits close to \(D\).
AB = √5 ≈ 2.236 BD = √20 ≈ 4.472 AD = √45 ≈ 6.708 BC = 2√5 ≈ 4.472
11M
Order the four collinear points using the two distances from \(A\):
Hint: A smaller distance from \(A\) means the point is nearer to \(A\).
\[ AD=\sqrt{45}\approx 6.71 > AB=\sqrt{5}\approx 2.24 \] so \(B\) is between \(A\) and \(D\). Also \(BD=\sqrt{20}\) places \(B\) between \(A\) and \(D\).
Order: \(A \;-\; B \;-\; C \;-\; D\)
21A
Check against the given \(CD = \sqrt{5}\):
\[ CD = \sqrt{5} \quad \text{(small)} \;\Rightarrow\; C \text{ is between } B \text{ and } D. \]
Hint: \(BC = BD - CD\), not \(BD + CD\), because \(C\) lies between \(B\) and \(D\).
Confirmed order: \(A,\;B,\;C,\;D\) (with \(C\) between \(B\) and \(D\))

Part (b) Compute \(BC\) using the segment relation

Because \(A - B - C - D\) lie in that order, the lengths satisfy:

\[ BC = BD - CD \]

The slider lets you verify numerically that only one value of \(BC\) makes \(AD = AB + BC + CD\).

AB = √5 ≈ 2.236 BD = √20 ≈ 4.472 AD = √45 ≈ 6.708
11M
Use the straight-line relation \(BD = BC + CD\), so:
\[ BC = BD - CD \]
Hint: All four points are collinear, so lengths add and subtract along the same line.
21A
Substitute the surds and simplify:
\[ BC = \sqrt{20} - \sqrt{5} \] \[ \sqrt{20} = \sqrt{4 \times 5} = 2\sqrt{5} \] \[ BC = 2\sqrt{5} - \sqrt{5} = \sqrt{5} \]
Hint: Simplify \(\sqrt{20}\) to \(2\sqrt{5}\) first — then the subtraction is easy.
\[ BC = \sqrt{5} \]

Part (c) Check the whole line: why only \(\sqrt{5}\) works

We can also verify by adding up the three small pieces from \(A\) to \(D\): \[ AB + BC + CD = \sqrt{5} + \sqrt{5} + \sqrt{5} = 3\sqrt{5} = \sqrt{45} = AD \;\checkmark \]

11M
Option A is \(\sqrt{5}\), option B is \(\sqrt{20}\), option C is \(\sqrt{45}\), option D is \(\sqrt{80}=4\sqrt{5}\).
We need \(BC\) such that \(AB + BC + CD = AD\), i.e. \(\sqrt{5} + BC + \sqrt{5} = \sqrt{45}\).
Hint: Try each option in the equation — only one makes it true.
21A
Solve for \(BC\):
\[ BC = \sqrt{45} - 2\sqrt{5} = 3\sqrt{5} - 2\sqrt{5} = \sqrt{5} \]
\(\sqrt{5} \approx 2.236 \;\Rightarrow\;\) Option A

Summary Answers at a glance

  • Order of collinear points: \(A - B - C - D\)
  • Piece relation: \(BC = BD - CD\)
  • Simplification: \(\sqrt{20} = 2\sqrt{5}\), \(\sqrt{45} = 3\sqrt{5}\)
  • Key numeric check: \(\sqrt{5} + \sqrt{5} + \sqrt{5} = \sqrt{45} = AD\) ✓
  • Answer: \(\boxed{BC = \sqrt{5}}\) — Option A
