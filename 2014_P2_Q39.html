Q39Question

For \(0^\circ \le x \le 360^\circ\), how many roots does the equation \[ 7\sin^2 x = \sin x \] have?
A. 2
B. 3
C. 4
D. 5

Full marks for this multiple-choice question:

(a)Rearranging & Factorising the Equation

Bring all terms to one side and factorise — this is the key to separating the problem into two simple cases.

x₀ = 0.00°, sin x₀ = 0.000, 7sin²x₀ − sin x₀ = 0.000
Step 1
Move all terms to one side: \[ 7\sin^2 x - \sin x = 0 \]
Hint: Never divide by \(\sin x\) — you would lose the \(\sin x = 0\) solution!
Step 2
Factorise out the common factor \(\sin x\): \[ \sin x\,(7\sin x - 1) = 0 \]
Hint: A product is zero exactly when one of its factors is zero. This gives two independent cases.
Step 3
Therefore: \[ \sin x = 0 \quad \text{or} \quad \sin x = \tfrac17 \]
Two separate cases to solve: \(\sin x = 0\) and \(\sin x = \tfrac{1}{7}\).
0 / 3

(b)Solving Each Case in \(0^\circ \le x \le 360^\circ\)

Now count the roots of each case over one full revolution. Use the sine curve and the unit-circle idea to see exactly how many solutions appear.

k = 0.00  |  intersections in [0°, 360°]: 3
Step 1
Case 1: \(\sin x = 0\).
Within \(0^\circ \le x \le 360^\circ\): \[ x = 0^\circ,\ 180^\circ,\ 360^\circ \]
Hint: The endpoints \(0^\circ\) and \(360^\circ\) are included, so they both count.
3 roots from this case.
Step 2
Case 2: \(\sin x = \tfrac{1}{7}\).
Since \(0 < \tfrac{1}{7} < 1\), the reference angle is: \[ \alpha = \sin^{-1}\!\left(\tfrac17\right) \approx 8.2132^\circ \]
Hint: \(\sin x > 0\) in Quadrants I and II, so there are two solutions.
Step 3
\[ x \approx 8.2132^\circ \quad \text{or} \quad x = 180^\circ - 8.2132^\circ \approx 171.7868^\circ \]
2 roots from this case.
Step 4
Total number of roots: \[ 3 + 2 = 5 \]
Hint: The two cases give distinct values — no overlap, so simply add.
The equation has 5 roots.  ⇒  Answer: D
0 / 4

Summary of Answers

  • Factorisation: \(\sin x\,(7\sin x - 1) = 0\)
  • Case 1: \(\sin x = 0 \Rightarrow x = 0^\circ,\ 180^\circ,\ 360^\circ\)  →  3 roots
  • Case 2: \(\sin x = \tfrac17 \Rightarrow x \approx 8.2132^\circ,\ 171.7868^\circ\)  →  2 roots
  • Total roots: \(3 + 2 = 5\)
  • Correct option: D
Final answer: D. 5
