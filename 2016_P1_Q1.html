HKDSE Math 2016 Paper 1 Q1

3 marks
Q1

Simplify and express your answer with positive indices.

\[ \frac{(x^8 y^7)^2}{x^5 y^{-6}} \]
Laws of Indices Positive Indices Power of a Product Quotient Rule

Core Concepts

  • Power of a Product: \((ab)^n = a^n b^n\)
  • Power of a Power: \((a^m)^n = a^{m \times n}\)
  • Quotient Rule: \(\frac{a^m}{a^n} = a^{m-n}\)
  • Negative Indices: \(a^{-n} = \frac{1}{a^n}\) (but here we need positive indices only)

Step-by-Step Solution

Hint: Raise each factor inside the bracket to the power of 2.

\[ (x^8 y^7)^2 = (x^8)^2 \cdot (y^7)^2 \]

Using the rule \((ab)^n = a^n b^n\).

Hint: Multiply the exponents: \( (a^m)^n = a^{m \times n} \).

\[ (x^8)^2 = x^{8 \times 2} = x^{16}, \quad (y^7)^2 = y^{7 \times 2} = y^{14} \]

So the numerator becomes: \(x^{16} y^{14}\)

Now rewrite the whole fraction.

\[ \frac{x^{16} y^{14}}{x^5 y^{-6}} \]

Next, apply the Quotient Rule for each variable separately.

Hint: \(\frac{a^m}{a^n} = a^{m-n}\). Subtract the exponents.

\[ \frac{x^{16}}{x^5} = x^{16-5} = x^{11} \] \[ \frac{y^{14}}{y^{-6}} = y^{14 - (-6)} = y^{14 + 6} = y^{20} \]

Remember: subtracting a negative is the same as adding.

Answer with positive indices

\[ x^{11} y^{20} \]

No negative exponents remain.

Exam Tip

Always check that all indices are positive. If a negative index remains, rewrite it as a reciprocal to make it positive. For example, \(x^{-3} = \frac{1}{x^3}\).
