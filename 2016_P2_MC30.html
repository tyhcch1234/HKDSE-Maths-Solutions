Statistics — Mean, Mode and Median of a Data Set

Mean Mode Median Unknowns \(a,b,c\) Ordered Data

Question Multiple Choice

Consider the following data:

32 68 79 86 88 98 98 a b c

If the mean and the mode of the above data are \(77\) and \(68\) respectively, then the median of the above data is

A. \(76\)     B. \(82\)     C. \(85\)     D. \(93\)

Part (a) — Use the Mean to Relate \(a,b,c\) Step-by-step

There are \(10\) data values. The mean is \(77\), so the sum of all ten values must be \(10\times 77 = 770\).

Total count
\(10\) values
Target sum
\(10 \times 77 = 770\)
Known sum
\(32+68+79+86+88+98+98\)
Sum of \(a+b+c\) = 221  |  Condition: \(a+b+c = 221\)
0 / 3
Step 1
Set up the mean equation:
\[ \frac{32+68+79+86+88+98+98+a+b+c}{10} = 77 \]
Hint: Mean \(= \dfrac{\text{sum of all data}}{\text{number of data}}\). There are \(7\) known values plus \(a,b,c\), so \(10\) values in total.
Step 2
Multiply both sides by \(10\) and simplify the known values:
\[ 32+68+79+86+88+98+98+a+b+c = 770 \] \[ (32+68+79+86+88+98+98)+a+b+c = 770 \] \[ 549 + a + b + c = 770 \]
Hint: Check the known sum: \(32+68=100\), \(100+79=179\), \(179+86=265\), \(265+88=353\), \(353+98=451\), \(451+98=549\).
Step 3
Subtract \(549\) from both sides:
\[ a + b + c = 770 - 549 = 221 \]
Result: \(\;a+b+c = 221\)

Part (b) — Use the Mode to Identify \(a,b,c\) Step-by-step

The mode is \(68\). In the known data, \(98\) appears twice. For \(68\) to be the mode, \(68\) must appear more times than any other value.

0 / 3
Step 1
The number \(98\) already occurs twice among the known values:
\[ 32,\;68,\;79,\;86,\;88,\;\mathbf{98},\;\mathbf{98},\;a,\;b,\;c \]
Hint: For \(68\) to be the mode, it must occur strictly more than twice — i.e. at least \(3\) times. Since there is one known \(68\), at least \(2\) of \(a,b,c\) must equal \(68\).
Step 2
So \(68\) occurs \(3\) times, and to keep \(68\) the unique mode, the third unknown cannot be \(98\) (otherwise \(98\) would also occur \(3\) times). Using \(a+b+c=221\):
\[ 68 + 68 + c = 221 \] \[ c = 221 - 136 = 85 \]
Hint: "The mode is \(68\)" means \(68\) is the only most frequent value. If \(c=98\), then \(98\) also occurs \(3\) times — that would give two modes, not a unique mode of \(68\).
Step 3
Therefore two of \(a,b,c\) are \(68\) and the remaining one is \(85\). The full data set is:
\[ 32,\;68,\;68,\;68,\;79,\;85,\;86,\;88,\;98,\;98 \]
So: \(\{a,b,c\} = \{68,\,68,\,85\}\), and the sorted data set is\ \(32,\,68,\,68,\,\mathbf{68},\,\mathbf{79},\,\mathbf{85},\,\mathbf{86},\,88,\,98,\,98\).

Part (c) — Find the Median Step-by-step

With \(10\) ordered values, the median is the average of the \(5\)th and \(6\)th values.

Median = \(\dfrac{79+85}{2}\) = 82
0 / 3
Step 1
Arrange all \(10\) values in ascending order:
\[ 32,\;68,\;68,\;68,\;79,\;85,\;86,\;88,\;98,\;98 \]
Hint: Median requires the data to be ordered first. \(n=10\) is even, so the median is the mean of the \(\frac{n}{2}=5\)th and the \(\left(\frac{n}{2}+1\right)=6\)th values.
Step 2
The 5th value is \(79\) and the 6th value is \(85\).
\[ \text{Median} = \frac{79 + 85}{2} \]
Hint: Count carefully: position \(1\!-\!4\) are \(32,68,68,68\); position \(5\) is \(79\); position \(6\) is \(85\).
Step 3
Compute the average:
\[ \text{Median} = \frac{79+85}{2} = \frac{164}{2} = 82 \]
Median = 82  →  Answer: B

Summary of Answers

  • From the mean: \(\;a+b+c = 221\)  (since the total sum is \(10 \times 77 = 770\))
  • From the mode: \(\;\)two of \(a,b,c\) equal \(68\), and the remaining one equals \(85\)  →  \(\{a,b,c\}=\{68,68,85\}\)
  • Ordered data: \(\;32,\,68,\,68,\,68,\,79,\,\mathbf{85},\,86,\,88,\,98,\,98\)
  • \(\text{Median} = \dfrac{79+85}{2} = \mathbf{82}\)  →  Answer: B
