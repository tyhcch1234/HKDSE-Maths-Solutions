Statistics — Stem-and-Leaf Diagrams & the Range of a Distribution

Stem-and-Leaf Diagram Range Maximum & Minimum Constraints on Unknown Digits

Question 2 marks

The stem-and-leaf diagram below shows the distribution of the ages of the passengers in a bus.

Stem (tens)Leaf (units)
1h  4   6
23   3   3   3   4   6   7   7
31   2   2   2   6   8
40   k

If the range of the above distribution is at least \(33\), which of the following must be true?

I.  \(0 \le h \le 3\)
II.  \(3 \le k \le 9\)
III.  \(3 \le k-h \le 5\)

A. I only
B. II only
C. I and III only
D. II and III only

Part (a) Reading the Diagram & Setting the Range Set-up

A stem-and-leaf diagram lists each data value as stem (tens digit) followed by leaf (units digit). Drag the sliders below to see exactly which values the unknown digits \(h\) and \(k\) can take, and watch how the maximum and minimum ages — and hence the range — change.

Step 1
The smallest possible value uses stem \(1\): \(10 + h\). The largest possible value must use stem \(4\): \(40 + k\) (since \(30+\) < \(40+\), the maximum is always in the last row). \[ \text{Range} = \max - \min = (40+k) - (10+h) = 30 + (k-h). \]
Hint: The range always uses the largest value minus the smallest value. The largest stem is \(4\), so the maximum is \(40+k\); the smallest stem is \(1\), so the minimum is \(10+h\).
Step 2
"Range at least \(33\)" means \[ 30 + (k-h) \ge 33 \quad\Longrightarrow\quad k - h \ge 3. \]
Hint: "At least \(33\)" translates to the inequality \(\text{Range} \ge 33\).
Key condition: \(\;k-h \ge 3\)

Part (b)(i) Testing Statement I: \(0 \le h \le 3\) False

A statement "must be true" only if it holds for every combination allowed by \(k-h \ge 3\). Find one counter-example to kill it. Move the sliders to search for a valid pair with \(h > 3\).

Step 1
Since \(h\) is a digit, \(0 \le h \le 9\). The condition \(k-h \ge 3\) with the largest possible \(k=9\) gives \[ h \le k-3 \le 9-3 = 6, \] so \(h\) can be \(0,1,2,3,4,5,6\) — but not \(7,8,9\).
Hint: \(k \le 9\) caps \(h\) at \(6\), so \(h = 4,5,6\) are genuinely possible — all of them break Statement I.
Step 2
Counter-example: take \(h = 4\) and \(k = 7\). \[ k - h = 7-4 = 3 \ge 3 \quad\checkmark \quad(\text{range} = 33 \ge 33) \] The data then has a smallest age of \(14\), not \(\le 13\), so Statement I fails. \[\therefore\; 4 \text{ is a possible value of } h. \]
Conclusion: Statement I is NOT always true. ✗

Part (b)(ii) Testing Statement II: \(3 \le k \le 9\) True

Statement II is a claim about \(k\) alone. The diagram divides possible pairs \((h,k)\) into "allowed" and "not allowed" regions by the line \(k - h = 3\). Dark cells are allowed (range \(\ge 33\)); pale cells are not.

Step 1
The smallest allowed \(k\) occurs when \(h\) is as large as possible and \(k-h \ge 3\), i.e. \[ k \ge h + 3 \quad\text{and}\quad h \ge 0 \;\Longrightarrow\; k \ge 3. \]
Hint: Compare \(k\) with \(h+3\): since \(h \ge 0\), we get \(k \ge 3\).
Step 2
As a units digit in the stem-\(4\) row, \(k \le 9\). Therefore \[ 3 \le k \le 9 \quad\text{for every allowed pair }(h,k). \] Values \(k = 0,1,2\) are indeed impossible — that is exactly why the inequality is true.
Conclusion: Statement II is always true.

Part (b)(iii) Testing Statement III: \(3 \le k-h \le 5\) True

Statement III claims the range (written as \(30 + (k-h)\)) is bounded above as well as below. Explore the full table of allowed \((h,k)\) pairs below.

Step 1
We already need \(k-h \ge 3\). For the upper bound, the largest possible \(k\) is \(9\) while the smallest possible \(h\) is \(0\), giving \[ k-h \le 9-0 = 9. \]
Hint: With \(h = 0\) we get \(k \ge 3\), so \(k-h = k\) can be as big as \(9\).
Step 2
But \(h\) also consumes one leaf slot! The row "1 | h 4 6" already contains leaves \(4\) and \(6\). For the leaf list to remain a valid stem-and-leaf diagram, \(h\) cannot repeat \(4\) or \(6\) in a way that contradicts the sorted data — and more importantly, the constraint \(k-h \ge 3\) with \(h \ge 0, k \le 9\) allows, for example, \[ h = 0,\; k = 3,4,5,6,7,8,9 \;\Longrightarrow\; k-h = 3,4,5,6,7,8,9. \] Hence \(k-h = 6,7,8,9\) are all achievable — Statement III's upper bound \(5\) must be wrong.
Hint: Look for a counter-example: \(h=0\) and \(k=9\) gives \(k-h = 9 > 5\).
Step 3
Since \(k-h\) can equal \(6,7,8,9\), the statement \(3 \le k-h \le 5\) does not describe every allowed pair. Only the lower part, \(k-h \ge 3\), survives.
Conclusion: Statement III is NOT always true. ✗

Final Answer Summary

  • Reading the diagram: minimum \(= 10+h\), maximum \(= 40+k\).
  • Range condition: \((40+k)-(10+h) \ge 33 \;\Longleftrightarrow\; \boxed{k - h \ge 3}\).
  • Statement I — \(0 \le h \le 3\): FALSE. Counter-example: \(h=4,\;k=7\) gives \(k-h=3\) (range \(33\)), but \(h=4>3\).
  • Statement II — \(3 \le k \le 9\): TRUE. Since \(k \ge h+3 \ge 3\) and \(k \le 9\), every allowed pair satisfies it.
  • Statement III — \(3 \le k-h \le 5\): FALSE. \(h=0,\;k=9\) gives \(k-h=9>5\).
  • Therefore only Statement II must be true → answer is B. II only.
