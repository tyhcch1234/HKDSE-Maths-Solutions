2019 Paper 2 · Question 18

Isosceles Triangle · Similar Triangles · Pythagoras' Theorem

Isosceles Triangle Similar Triangles (AAA) Parallel Lines Pythagoras' Theorem Ratios of Segments

Question Full Statement MC

In the figure, \(ABC\) is an isosceles triangle with \(AB=AC\). \(D\) and \(E\) are points lying on \(AB\) such that \(AD = DE = 2\,EB\), while \(F\) is a point lying on \(AC\) such that \(DF /\!/ EC\). If \(\angle ADF = 90^\circ\) and \(CE = 60\text{ cm}\), then \(EF =\)

  1. \(45\text{ cm}\)
  2. \(48\text{ cm}\)
  3. \(50\text{ cm}\)
  4. \(52\text{ cm}\)
Key strategy: Let one small unit be \(a\) cm. Because \(AD = DE = 2\,EB\), every segment on \(AB\) can be written in terms of \(a\), and \(AB = AC\) gives \(AC = 5a\). Since \(DF /\!/ EC\), right angle \(\angle ADF\) forces \(\angle AEC = 90^\circ\), so Pythagoras in \(\triangle ACE\) finds \(a\), and then similar triangles \(\triangle ADF \sim \triangle AEC\) give \(DF\). Finally \(\triangle DEF\) is right-angled at \(D\).

Part (a) Setting up the lengths along \(AB\) and finding \(a\)

Unit a = 20 cm AB = AC = 100 cm AD = DE = 40 cm EB = 20 cm AE = 80 cm

Place the unit \(a\) so that \(AD = DE = 2a\) and \(EB = a\). Then \(AE = 4a\) and \(AB = 5a = AC\).

Step 11M

Let \(AB = 5a\) cm. Since \(AB = AC\), \(AC = 5a\) cm.

From \(AD = DE = 2\,EB\), write \(EB = a\), \(AD = DE = 2a\). Then

\[ AE = AD + DE = 2a + 2a = 4a,\qquad AB = AE + EB = 4a + a = 5a. \]
Hint: Introducing a single unknown \(a\) converts the ratio problem into an algebraic one.
Step 21M

Because \(DF /\!/ EC\) and \(A\), \(D\), \(E\) lie on \(AB\) while \(F\) lies on \(AC\), \(\angle ADF\) and \(\angle AEC\) are corresponding angles:

\[ \angle AEC = \angle ADF = 90^\circ. \]

So \(\triangle ACE\) is right-angled at \(E\).

Hint: Parallel lines \((\,DF /\!/ EC\,)\) cut by the transversal \(AB\) give equal corresponding angles.
Step 31M

Apply Pythagoras' theorem in \(\triangle ACE\):

\[ AE^2 + CE^2 = AC^2 \] \[ (4a)^2 + 60^2 = (5a)^2 \] \[ 16a^2 + 3600 = 25a^2 \] \[ 9a^2 = 3600 \quad\Longrightarrow\quad a^2 = 400 \] \[ a = 20. \]
Answer: \(a = 20\), so \(AE = 4(20) = 80\) cm and \(AD = 40\) cm.
Hint: Note \(AE^2 + CE^2 = AC^2\) works exactly because \(\angle AEC = 90^\circ\).

Part (b) Similar triangles \(\triangle ADF \sim \triangle AEC\) → find \(DF\)

AD = 40 cm AE = 80 cm CE = 60 cm DF = 30 cm Ratio \(\frac{AD}{AE}=\frac{1}{2}\)

We compare the small triangle \(\triangle ADF\) with the large triangle \(\triangle AEC\).

Step 11M

List the equal angles:

\[ \angle DAF = \angle EAC \quad (\text{common angle}) \] \[ \angle ADF = \angle AEC = 90^\circ \] \[ \angle AFD = \angle ACE \quad (\text{corresponding } \angle\text{s},\ DF /\!/ EC) \]

Therefore \(\triangle ADF \sim \triangle AEC\) (AAA).

Hint: Once two triangles share one angle and have a pair of parallel sides, the third angle is automatically equal.
Step 21M

Corresponding sides of similar triangles are proportional:

\[ \frac{DF}{EC} = \frac{AD}{AE} \] \[ \frac{DF}{60} = \frac{40}{80} = \frac{1}{2} \] \[ DF = 30\text{ cm}. \]
Answer: \(DF = 30\) cm.
Hint: Match vertices carefully: \(D \leftrightarrow E\) and \(F \leftrightarrow C\) in the similarity.

Part (c) Find \(EF\) using right-angled \(\triangle DEF\)

DE = 40 cm DF = 30 cm \(\angle EDF = \mathbf{90^\circ}\) EF = 50 cm

Because \(\angle ADF = 90^\circ\) and \(E\) lies on ray \(DA\), the angle \(\angle EDF\) is also \(90^\circ\).

Step 11M

\(D\), \(E\), \(A\) are collinear with \(E\) between \(D\) and \(A\), so the straight line \(DE\) is perpendicular to \(DF\):

\[ \angle EDF = 180^\circ - \angle ADF = 90^\circ. \]
Hint: Angles on a straight line sum to \(180^\circ\); here \(DE\) is the straight line through \(D\) containing \(A\).
Step 21M

Apply Pythagoras' theorem in the right-angled \(\triangle DEF\):

\[ EF^2 = DE^2 + DF^2 \] \[ EF^2 = 40^2 + 30^2 = 1600 + 900 = 2500 \] \[ EF = \sqrt{2500} = 50\text{ cm}. \]
Answer: \(EF = 50\text{ cm}\) → correct choice is C.
Hint: \(\triangle DEF\) is a \(3\text{-}4\text{-}5\) right triangle scaled by \(10\): \(30, 40, 50\).

Summary of Answers

  • \(AB = AC = 5a\), \(AD = DE = 2a\), \(EB = a\), \(AE = 4a\)
  • \(\angle AEC = \angle ADF = 90^\circ\) (corresponding angles, \(DF /\!/ EC\))
  • Pythagoras in \(\triangle ACE\): \((4a)^2 + 60^2 = (5a)^2 \Rightarrow 9a^2 = 3600 \Rightarrow \boxed{a = 20}\)
  • Similar triangles \(\triangle ADF \sim \triangle AEC\) (AAA) \(\Rightarrow \dfrac{DF}{60} = \dfrac{40}{80} \Rightarrow \boxed{DF = 30}\) cm
  • Right-angled \(\triangle DEF\): \(EF^2 = 40^2 + 30^2 = 2500\)
\(\boxed{EF = 50\text{ cm}}\) — the correct choice is C.
