Step 1 — 5 red balls and 4 black balls in the box (9 balls total).

HKDSE 2023 Paper 1 Q15

Probability

In a box, there are 5 red balls and 4 black balls. From the box, 2 balls are randomly chosen at the same time.

(a) Find the probability that the 2 balls chosen are red. [2 marks]

(b) In a bag, there are 8 red balls. The 2 balls chosen from the box are put into the bag and then 3 balls are randomly chosen at the same time from the bag. Find the probability that the 3 balls chosen are of the same colour. [2 marks]

1Part (a) — Set up the total number of ways

The box contains $5$ red and $4$ black balls, so there are $9$ balls in total. Choosing $2$ balls at the same time from the box can be done in ${}^{9}C_{2}$ ways.

Choosing $2$ red balls can be done in ${}^{5}C_{2}$ ways.

Hint: "at the same time" means order does not matter — use combinations, not permutations.
2Part (a) — Compute the probability

$$P(\text{both red}) = \frac{{}^{5}C_{2}}{{}^{9}C_{2}} = \frac{10}{36} = \frac{5}{18}$$

Hint: ${}^{5}C_{2}=\frac{5\times4}{2}=10$ and ${}^{9}C_{2}=\frac{9\times8}{2}=36$.
3Part (b) — Describe the bag after transferring

The bag initially has $8$ red balls. The $2$ balls taken from the box are added to the bag, so the bag ends up with $10$ balls: $8$ red plus whatever colour was transferred. Then $3$ balls are chosen from the bag in ${}^{10}C_{3}$ ways.

Hint: split into cases according to what was transferred — RR, RB, or BB.
4Part (b) — Case 1: 2 red balls transferred

Probability of transferring $2$ red balls is $\dfrac{5}{18}$ (from part (a)). The bag then has $10$ red balls, so $3$ same-colour balls means choosing $3$ red:

$$\frac{{}^{10}C_{3}}{{}^{10}C_{3}} = 1$$

Contribution: $\dfrac{5}{18}\times 1 = \dfrac{5}{18}$.

Hint: if all 10 balls are red, any 3 chosen are automatically the same colour.
5Part (b) — Case 2: 1 red + 1 black transferred

Probability of transferring $1$ red and $1$ black is $\dfrac{{}^{5}C_{1}{}^{4}C_{1}}{{}^{9}C_{2}} = \dfrac{20}{36} = \dfrac{5}{9}$.

The bag then has $9$ red and $1$ black balls. To choose $3$ same-colour balls, we choose $3$ red: $\dfrac{{}^{9}C_{3}}{{}^{10}C_{3}} = \dfrac{84}{120} = \dfrac{7}{10}$.

Contribution: $\dfrac{5}{9}\times\dfrac{7}{10} = \dfrac{35}{90}$.

Hint: $1$ black ball is not enough to make 3 same-colour balls, so only the all-red choice counts.
6Part (b) — Case 3: 2 black balls transferred

Probability of transferring $2$ black balls is $\dfrac{{}^{4}C_{2}}{{}^{9}C_{2}} = \dfrac{6}{36} = \dfrac{1}{6}$.

The bag then has $8$ red and $2$ black balls. To choose $3$ same-colour balls, we choose $3$ red: $\dfrac{{}^{8}C_{3}}{{}^{10}C_{3}} = \dfrac{56}{120} = \dfrac{7}{15}$.

Contribution: $\dfrac{1}{6}\times\dfrac{7}{15} = \dfrac{7}{90}$.

Hint: with only 2 black balls, 3 same-colour means all red again.
7Part (b) — Add the three cases

$$\frac{5}{18} + \frac{35}{90} + \frac{7}{90} = \frac{25}{90} + \frac{35}{90} + \frac{7}{90} = \frac{67}{90}$$

Hint: convert to a common denominator of 90 before adding.
Answer: (a) $\dfrac{5}{18}$     (b) $\dfrac{67}{90}$
