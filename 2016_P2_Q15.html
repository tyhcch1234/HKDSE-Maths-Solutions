Question & Solution

2016 MC #15

According to the figure, which of the following must be true?

  1. $a + c = 180^\circ$
  2. $a + b - c = 180^\circ$
  3. $b + c = 360^\circ$
A. I only
B. II only
C. I and III only
D. II and III only

STEP 1Understand the figure & label the angles

Draw line $ST$ parallel to line $PQ$. The broken path goes $P \to Q \to R \to S \to T$.

$a = \angle PQR$,   $b = \text{reflex } \angle QRS$,   $c = \angle RST$.

Hint: The question asks which relations must hold for all such figures — testing one special case that breaks a relation is enough to reject it.

STEP 2Test statement I :   $a + c = 180^\circ$

Move $Q$ only so that $PQ$ gets longer. Then $a$ decreases while $c$ stays the same.

So the L.H.S. of $a + c = 180^\circ$ changes, but the R.H.S. is fixed.

✗ Not always true  (only true when the two rays $PQ$ & $ST$ are parallel)

STEP 3Prove statement II :   $a + b - c = 180^\circ$

Method 1 — auxiliary parallel line through $R$

Let $U$ be a point on the line through $R$ with $QU \parallel PQ \parallel ST$.

$\angle QRU = 180^\circ - \angle PQR = 180^\circ - a$   (int. $\angle$s, $UR \parallel PQ$)

$\angle SRU = \angle RST = c$   (alt. $\angle$s, $UR \parallel ST$)

$\text{reflex } \angle QRS = \angle QRU + \angle SRU$

$b = (180^\circ - a) + c$

$\Rightarrow \; a + b - c = 180^\circ$

✓ Must be true

Alternate Angles (Parallel Lines) \(a\parallel b\ \Longrightarrow\ \text{alternate angles are equal}\) \(UR\parallel ST\) makes \(\angle SRU\) and \(\angle RST=c\) alternate angles.
Co-Interior Angles (Parallel Lines) \(\text{co-interior angles are supplementary}:\quad a+b=180^{\circ}\) \(UR\parallel PQ\), so \(\angle QRU=180^{\circ}-a\) are interior angles on the same side.

STEP 4Statement II — a second check (ΔVQR)

Let $V$ be the point where $PQ$ extended meets a line through $R$ such that $VRS$ is a straight line.

$\angle QVS = 180^\circ - c$   (int. $\angle$s, $PQ \parallel ST$)

$\angle QRV = \text{reflex } \angle QRS - 180^\circ = b - 180^\circ$

In $\Delta VQR$ :

$\angle QVR + \angle VQR + \angle QRV = 180^\circ$   ($\angle$ sum of $\Delta$)

$(180^\circ - c) + a + (b - 180^\circ) = 180^\circ$

$\Rightarrow \; a + b - c = 180^\circ$   ✓ confirms statement II.

Angle Sum of a Triangle \(\angle A+\angle B+\angle C=180^{\circ}\) Applied to \(\triangle VQR\) it gives \((180^{\circ}-c)+a+(b-180^{\circ})=180^{\circ}\).

STEP 5Test statement III :   $b + c = 360^\circ$

Again move $Q$ only so that $PQ$ gets longer. Then $b$ increases while $c$ stays the same.

The L.H.S. of $b + c = 360^\circ$ increases but the R.H.S. is unchanged.

✗ Not always true

STEP 6Conclusion

Only statement II must be true.

Therefore the answer is B.

Key idea: at $Q$ the reflex angle is $360^\circ - a$, and turning along the path the total turn must balance, forcing the relation $a + b - c = 180^\circ$.
Final Answer
B  —  II only   ($a + b - c = 180^\circ$)
PRACTICESimilar question — try it yourself

Question. In the figure, \(PQ\parallel ST\). The broken line goes \(P\to Q\to R\to S\to T\), where \(\angle PQR=70^{\circ}\) and \(\angle RST=25^{\circ}\). The reflex angle \(\angle QRS\) is A. \(95^{\circ}\) B. \(110^{\circ}\) C. \(135^{\circ}\) D. \(155^{\circ}\) [1 mark]

Show the worked solution
Step 1. Draw the line \(UR\) through \(R\) parallel to \(PQ\) and \(ST\).
Step 2. Co-interior angles (\(UR\parallel PQ\)): \(\angle QRU=180^{\circ}-70^{\circ}=110^{\circ}\).
Step 3. Alternate angles (\(UR\parallel ST\)): \(\angle SRU=\angle RST=25^{\circ}\).
Step 4. The reflex angle is the whole angle round the far side of \(R\): \(b=\angle QRU+\angle SRU=110^{\circ}+25^{\circ}=135^{\circ}\).
Step 5. Check with the relation \(a+b-c=180^{\circ}\): \(70^{\circ}+135^{\circ}-25^{\circ}=180^{\circ}\) \u2713.
Answer: C. \(135^{\circ}\)
