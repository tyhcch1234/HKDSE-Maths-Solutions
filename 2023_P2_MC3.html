Laws of Indices — Simplifying $4^{n+2}\,3^{2n+4}$

A guided, interactive walkthrough of a classic HKDSE MCQ on index laws.

QQuestion

$$4^{n+2}\,3^{2n+4} \;=\; ?$$
  • A$6^{\,2n+4}$
  • B$6^{\,4n+8}$
  • C$12^{\,2n+4}$
  • D$12^{\,3n+6}$

Tap an option above to test your intuition — the correct choice is revealed at the end of Step 4.

Law of Indices $(a^m)^n = a^{mn}$ $a^n b^n = (ab)^n$ Index Addition Prime Factorisation

1Step-by-Step Solution

Reveal each step only when you are ready. Read the Hint first if you are stuck.

We start with the expression

$$4^{n+2}\;3^{2n+4}$$

The two bases are 4 and 3 — they are different, so we cannot directly combine them yet.

  • 4 is a power of 2  →  $4 = 2^{2}$
  • 3 is already prime  →  stays as $3$

So 2 is the common base, and 3 stays as it is. This is the key observation for the whole question.

Hint Look at the answer choices. Options A and B have base 6, while C and D have base 12. A common base will appear after rewriting — so we should aim to factorise both numbers into primes.

Replace the base 4 with $2^2$:

$$4^{n+2} \;=\; \left(2^{2}\right)^{n+2}$$

Now we use the power law of indices:

Formula $$\left(a^{m}\right)^{n} = a^{\,m\times n}$$ Here $a = 2$, $m = 2$, $n = n+2$.

So the exponent is $2\times(n+2)$:

$$\left(2^{2}\right)^{n+2} \;=\; 2^{\,2(n+2)} \;=\; 2^{\,2n+4}$$

The whole expression becomes:

$$2^{\,2n+4}\;3^{\,2n+4}$$

We have:

$$2^{\,2n+4}\;3^{\,2n+4}$$

Both powers share the same exponent, $2n+4$. That is exactly the condition needed for the reverse power law:

Formula $$a^{\,k}\,b^{\,k} = (a\,b)^{k}$$ This is the "power of a product" rule used in reverse — same exponent means we can merge the bases.

Here $a = 2$, $b = 3$ and $k = 2n+4$, so:

$$2^{\,2n+4}\;3^{\,2n+4} \;=\; (2\times 3)^{\,2n+4}$$

Since $2\times 3 = 6$:

$$(2\times 3)^{\,2n+4} \;=\; 6^{\,2n+4}$$

Therefore the entire expression simplifies in one clean chain:

$$4^{\,n+2}\,3^{\,2n+4} \;=\; \left(2^{2}\right)^{n+2}3^{\,2n+4} \;=\; 2^{\,2n+4}\,3^{\,2n+4} \;=\; (2\cdot 3)^{\,2n+4} \;=\; \boxed{6^{\,2n+4}}$$
Watch out A common trap is writing $2^{\,2n+4}\,3^{\,2n+4} = 6^{\,4n+8}$ — that incorrectly adds the exponents. The rule merges the bases, not the exponents: the exponent $2n+4$ stays the same.

✓Answer & Key Idea

A $6^{\,2n+4}$
$$4^{\,n+2}3^{\,2n+4}=(2^{2})^{n+2}3^{\,2n+4} =2^{\,2n+4}3^{\,2n+4}=(2\cdot 3)^{2n+4}=6^{\,2n+4}$$

The one-line idea: convert every base into primes, make the exponents identical, then merge the bases with $a^k b^k=(ab)^k$.
