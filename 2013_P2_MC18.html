Mensuration – Area of a Trapezium from Similar Triangles
Trapezium Area Similar Triangles (AAA) Area Ratio Mid-point

QQuestion

In the figure, \(ABCD\) is a trapezium with \(AD /\!/ BC\) and \(AD : BC = 2 : 3\). Let \(E\) be the mid-point of \(BC\). \(AC\) and \(DE\) intersect at \(F\). If the area of \(\triangle CEF\) is \(36\ \text{cm}^2\), then the area of the trapezium \(ABCD\) is
A. \(216\ \text{cm}^2\)    B. \(264\ \text{cm}^2\)    C. \(280\ \text{cm}^2\)    D. \(324\ \text{cm}^2\)
( for the correct option)
Key fact: \(AD : BC = 2 : 3\) and \(E\) is the mid-point of \(BC\), so if \(AD = 4a\) then \(BC = 6a\) and \(EC = 3a\).

Original Figure

APart (a) – Set Up Lengths & Find Similar Triangles

Introduce a parameter \(a\) to express all lengths, then prove \(\triangle ADF \sim \triangle CEF\).

AD = 4a
BC = 6a
EC = 3a
DF : EF = 4 : 3
4
0 / 4
Step 1 1M

Let \(AD = 4a\ \text{cm}\). Since \(AD : BC = 2 : 3\), we have \(BC = 6a\ \text{cm}\).

Since \(E\) is the mid-point of \(BC\):

\[ EC = \frac{BC}{2} = \frac{6a}{2} = 3a\ \text{cm} \]
Choose the parameter \(a\) so every length is a simple multiple. This avoids fractions later.
\(AD = 4a\), \(BC = 6a\), \(EC = 3a\)
Step 2 1M

In \(\triangle ADF\) and \(\triangle CEF\):

\[ \angle AFD = \angle CFE \quad (\text{vert. opp. } \angle\text{s}) \] \[ \angle ADF = \angle CEF \quad (\text{alt. } \angle\text{s},\ AD /\!/ EC) \] \[ \angle DAF = \angle ECF \quad (\text{alt. } \angle\text{s},\ AD /\!/ EC) \]

Therefore, \(\triangle ADF \sim \triangle CEF\) (AAA).

The parallel sides \(AD /\!/ BC\) give two pairs of alternate angles; the intersection \(F\) gives the vertically opposite pair.
\(\triangle ADF \sim \triangle CEF\) (AAA)
Step 3 1A

From the similarity, corresponding sides are in the same ratio:

\[ \frac{DF}{EF} = \frac{AD}{CE} = \frac{4a}{3a} = \frac{4}{3} \]
Match the corresponding sides carefully: \(AD\) (in the big triangle) corresponds to \(CE\) (in the small triangle).
\(DF : EF = 4 : 3\)
Step 4 1A

Also from the similarity, \(AF : FC = AD : CE = 4 : 3\).

These ratios are the key to linking the area of \(\triangle CEF\) to the rest of the figure.

We now have enough information to compare areas of triangles sharing a common height.
\(AF : FC = 4 : 3\) and \(DF : EF = 4 : 3\)

BPart (b) – Find the Area of \(\triangle CDE\)

Use the ratio \(DF : EF = 4 : 3\) and a common height to compare areas.

Area \(\triangle CEF = 36\ \text{cm}^2\)
Area \(\triangle CDE = 84\ \text{cm}^2\)
1.0
0 / 3
Step 1 1M

\(\triangle CDE\) and \(\triangle CEF\) share the same height from \(C\) to the line \(DE\).

Therefore their areas are in the same ratio as their bases along \(DE\):

\[ \frac{[\triangle CDE]}{[\triangle CEF]} = \frac{DE}{EF} \]
Both triangles have the same altitude from \(C\), so area is proportional to the base on line \(DE\).
Step 2 1M

Now \(DE = DF + EF\), and we know \(DF : EF = 4 : 3\). So:

\[ DE = 4k + 3k = 7k \quad\text{and}\quad EF = 3k \] \[ \frac{DE}{EF} = \frac{7k}{3k} = \frac{7}{3} \]
Write \(DF = 4k\) and \(EF = 3k\), then \(DE = DF + EF = 7k\).
\(\dfrac{DE}{EF} = \dfrac{7}{3}\)
Step 3 1A

Given \([\triangle CEF] = 36\ \text{cm}^2\):

\[ [\triangle CDE] = 36 \times \frac{7}{3} = 84\ \text{cm}^2 \]
Multiply the known area by the ratio \(\frac{DE}{EF} = \frac{7}{3}\).
\([\triangle CDE] = 84\ \text{cm}^2\)

CPart (c) – Find the Area of the Trapezium \(ABCD\)

Compare \(\triangle CDE\) with the whole trapezium \(ABCD\) using the same height.

Area \(\triangle CDE = 84\ \text{cm}^2\)
Area \(ABCD = 280\ \text{cm}^2\)
4.0
0 / 3
Step 1 1M

Let \(h\ \text{cm}\) be the perpendicular distance between the parallel sides \(AD\) and \(BC\).

The trapezium and \(\triangle CDE\) share this same height \(h\).

\[ [ABCD] = \frac{(AD + BC) \cdot h}{2} = \frac{(4a + 6a)h}{2} = 5ah \] \[ [\triangle CDE] = \frac{EC \cdot h}{2} = \frac{3a \cdot h}{2} = \frac{3ah}{2} \]
Both figures sit between the same parallel lines, so they have the same perpendicular height \(h\).
Step 2 1M

Form the ratio of the two areas:

\[ \frac{[ABCD]}{[\triangle CDE]} = \frac{5ah}{\frac{3ah}{2}} = \frac{5ah \times 2}{3ah} = \frac{10}{3} \]
The parameter \(a\) and the height \(h\) both cancel — the ratio depends only on the lengths along the parallel sides.
\(\dfrac{[ABCD]}{[\triangle CDE]} = \dfrac{10}{3}\)
Step 3 1A

Using \([\triangle CDE] = 84\ \text{cm}^2\):

\[ [ABCD] = 84 \times \frac{10}{3} = 280\ \text{cm}^2 \]
Multiply the known area by \(\frac{10}{3}\). So the answer is C.
\([ABCD] = 280\ \text{cm}^2\)  →  Option C

★Summary of Answers

  • Part (a)\(AD : BC = 2 : 3 \Rightarrow AD = 4a,\ BC = 6a,\ EC = 3a\); \(\triangle ADF \sim \triangle CEF\) (AAA) so \(DF : EF = 4 : 3\).
  • Part (b)\(\dfrac{DE}{EF} = \dfrac{7}{3}\), so \([\triangle CDE] = 36 \times \dfrac{7}{3} = 84\ \text{cm}^2\).
  • Part (c)\(\dfrac{[ABCD]}{[\triangle CDE]} = \dfrac{10}{3}\), so \([ABCD] = 84 \times \dfrac{10}{3} = 280\ \text{cm}^2\).
