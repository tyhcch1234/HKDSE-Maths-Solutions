Formulas and Sequences — Arithmetic & Geometric Sequences

Multiple Choice · Topic 5: Formulas and Sequences
Arithmetic Sequence Geometric Sequence Indices · \(3^d\) Reciprocals Common Ratio Proof

QQuestion

Let \(p, q\) and \(r\) be non-zero real numbers. If \(p, q, r\) is an arithmetic sequence, which of the following must be true?
  1. I. \(3^p, 3^q, 3^r\) is a geometric sequence.
  2. II. \(\dfrac{5}{p}, \dfrac{5}{q}, \dfrac{5}{r}\) is a geometric sequence.
  3. III. \(p-q,\; q-r,\; r-p\) is an arithmetic sequence.
A. I only
B. II only
C. I and III only
D. II and III only

KThe one substitution that cracks it

Every "must be true" sequence question starts the same way: write the middle and last terms in terms of the first term and the common difference \(d\).

$$q = p + d, \qquad r = p + 2d$$

Then test each statement with the definition of a geometric sequence ($\text{common ratio} = \dfrac{T_2}{T_1} = \dfrac{T_3}{T_2}$) or an arithmetic sequence ($T_2 - T_1 = T_3 - T_2$).

Step-by-step solution

Because \(p, q, r\) is an arithmetic sequence, the difference between consecutive terms is a constant \(d\).

$$q - p = d \quad\text{and}\quad r - q = d$$ $$\therefore\; q = p + d, \qquad r = p + 2d$$
Hint — notation: \(d\) is the common difference (not a digit). Once \(q\) and \(r\) are expressed via \(p\) and \(d\), every statement becomes a statement about \(p\) and \(d\) only.

A geometric sequence needs a constant ratio \(\dfrac{T_2}{T_1} = \dfrac{T_3}{T_2}\). Compute using index laws:

$$\frac{3^q}{3^p} = 3^{\,q-p} = 3^{\,d}$$ $$\frac{3^r}{3^q} = 3^{\,r-q} = 3^{\,d}$$

Both ratios equal \(3^{d}\), a constant.

✔ Statement I is TRUE — common ratio \(3^{d}\).
Hint — index law: \(\dfrac{a^{m}}{a^{n}} = a^{\,m-n}\). The exponent is the difference of consecutive terms, which is constant exactly because \(p,q,r\) is arithmetic.

Compute the two consecutive ratios:

$$\frac{5}{q} \div \frac{5}{p} \;=\; \frac{5}{q}\times\frac{p}{5} \;=\; \frac{p}{q} \;=\; \frac{p}{p+d}$$ $$\frac{5}{r} \div \frac{5}{q} \;=\; \frac{5}{r}\times\frac{q}{5} \;=\; \frac{q}{r} \;=\; \frac{p+d}{p+2d}$$

In general, \(\dfrac{p}{p+d} \ne \dfrac{p+d}{p+2d}\) — for example take \(p=1,\ d=1\):

$$\frac{p}{p+d} = \frac{1}{2}, \qquad \frac{p+d}{p+2d} = \frac{2}{3} \;\ne\; \frac{1}{2}$$
✘ Statement II is NOT true in general.
Hint — rule of reciprocals: The reciprocals of an arithmetic sequence form a harmonic sequence, not a geometric one. Only the "opposite" works in general: \(3^p, 3^q, 3^r\) (exponentials) become geometric, because the exponent difference \(d\) is constant.

Substitute \(q=p+d\) and \(r=p+2d\):

$$p-q = p-(p+d) = -d$$ $$q-r = (p+d)-(p+2d) = -d$$ $$r-p = (p+2d)-p = 2d$$

Check the differences:

$$(q-r)-(p-q) = (-d)-(-d) = 0$$ $$(r-p)-(q-r) = (2d)-(-d) = 3d \;\ne\; 0 \quad (d\ne 0 \text{ is not required; the mismatch breaks it})$$

In fact \(2d - (-d) = 3d \ne 0\) whenever \(d\ne 0\), so the gaps are unequal.

✘ Statement III is NOT true.
Hint — arithmetic test: An arithmetic sequence requires \(T_2 - T_1 = T_3 - T_2\), i.e. \(2T_2 = T_1 + T_3\). Here \(2(q-r) = -2d\) while \((p-q)+(r-p) = d\), so the condition fails.
  • I — True (geometric, ratio \(3^d\))
  • II — Not true (reciprocals give a harmonic sequence)
  • III — Not true (differences are \(0\) then \(3d\))

Only statement I must be true.

Answer: A — I only
