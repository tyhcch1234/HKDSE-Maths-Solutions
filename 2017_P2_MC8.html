Polynomials · Identity Comparison

📘 Paper 2 — Multiple Choice ⚡ Topic 4: Polynomials
Q8
If \(m\) and \(n\) are constants such that \[ 4x^2 + m(x+1) + 28 \equiv mx(x+3) + n(x-4), \] then \(n =\)
Polynomial Identity Coefficient Comparison Simultaneous Equations
A. \(-8\)
B. \(-7\)
C. \(4\)
D. \(16\)
1 Expand the Left Hand Side

Start by expanding \(4x^2 + m(x+1) + 28\):

\[ 4x^2 + mx + m + 28 \]

Group the \(x\) terms and constants.

Distributive Law: \(m(x+1) = mx + m\).

Then combine like terms: \(4x^2\) (only \(x^2\) term), \(mx\) (\(x\) term), \(m+28\) (constant).

2 Expand the Right Hand Side

Expand \(mx(x+3) + n(x-4)\):

\[ mx^2 + 3mx + nx - 4n \]

Collect \(x\) terms: \(3mx + nx = (3m + n)x\).

\[ mx^2 + (3m+n)x - 4n \]

Distributive: \(mx(x+3) = mx^2 + 3mx\),   \(n(x-4) = nx - 4n\).

Combine middle terms: \(3mx + nx = (3m+n)x\).

3 Compare Coefficients

The identity holds for all \(x\), so the coefficients of corresponding powers must be equal.

Left Side Coefficients

\(x^2 : 4\)
\(x : m\)
constant : \(m + 28\)

Right Side Coefficients

\(x^2 : m\)
\(x : 3m + n\)
constant : \(-4n\)
\(x^2\) coefficient: \(4 = m\)   …… (1)
Constant term: \(m + 28 = -4n\)   …… (2)

Identity principle: If two polynomials are identically equal, their corresponding coefficients must match.

We compare \(x^2\) and constant terms to find \(m\) and \(n\) easily. (We could also compare \(x\) terms, but it would introduce the same variables.)

4 Solve the Equations

From (1): \(m = 4\).

Substitute \(m = 4\) into (2):

\[ 4 + 28 = -4n \] \[ 32 = -4n \] \[ n = \frac{32}{-4} = -8 \]

Alternative approach: You could also compare the \(x\) coefficients: \(m = 3m + n\). With \(m = 4\), we get \(4 = 12 + n \Rightarrow n = -8\). Both methods give the same result.

✅ Final Answer n = −8   (Option A)
Option A is correct.
