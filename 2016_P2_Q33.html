Place Value in Base 16

Question

\(BC000DE000000_{16} =\)

  1. \(188\times16^{11} + 222\times16^{6}\)
  2. \(205\times16^{11} + 239\times16^{6}\)
  3. \(188\times16^{12} + 222\times16^{7}\)
  4. \(205\times16^{12} + 239\times16^{7}\)

Solution

Step 1 · Values of the hex digits
Hexadecimal Digit Values \(A=10,\ B=11,\ C=12,\ D=13,\ E=14,\ F=15\) \(B=11\), \(C=12\), \(D=13\) and \(E=14\) are the values used in \(BC000DE000000_{16}\).

In base 16, \(B = 11\), \(C = 12\), \(D = 13\), \(E = 14\). The number \(BC000DE000000_{16}\) has 13 digits.

Step 2 · Identify the place values
Place Value in Base b \(\overline{d_{n}\dots d_{1}d_{0}}_{\,b}=\sum_{i=0}^{n} d_{i}\,b^{i}\) Counting from the right, \(E\) sits in the \(16^{6}\) place and \(B\) in the \(16^{12}\) place.

Counting places from the right (rightmost digit = \(16^{0}\)):

  • \(E\) is in the \(16^{6}\) place,
  • \(D\) is in the \(16^{7}\) place,
  • \(C\) is in the \(16^{11}\) place,
  • \(B\) is in the \(16^{12}\) place.
Step 3 · Expand \[ BC000DE000000_{16} = 11\times16^{12} + 12\times16^{11} + 13\times16^{7} + 14\times16^{6}. \]
Step 4 · Factor in pairs
Common Factor Law \(ab+ac=a(b+c)\) Pairs sharing a power of \(16\): \(11\times16^{12}+12\times16^{11}=16^{11}(11\times16+12)\).
\[ 11\times16^{12} + 12\times16^{11} = 16^{11}\,(11\times16 + 12) = 16^{11}(176+12) = 188\times16^{11}, \] \[ 13\times16^{7} + 14\times16^{6} = 16^{6}\,(13\times16 + 14) = 16^{6}(208+14) = 222\times16^{6}. \]
Step 5 · Conclusion \[ BC000DE000000_{16} = 188\times16^{11} + 222\times16^{6}. \]
Final Answer: A. \(188\times16^{11} + 222\times16^{6}\)

Question. \(3D000B00_{16}=\)
A. \(61\times16^{6}+11\times16^{2}\)    B. \(61\times16^{7}+11\times16^{3}\)    C. \(48\times16^{6}+11\times16^{2}\)    D. \(61\times16^{6}+11\times16^{3}\)  (1 mark)

Show the worked solution
Step 1. \(3D000B00_{16}\) has \(8\) digits, so the place values run from \(16^{0}\) to \(16^{7}\); \(D=13\) and \(B=11\).
Step 2. Expand by place value: \(3\times16^{7}+13\times16^{6}+11\times16^{2}\).
Step 3. Factor out \(16^{6}\) from the first two terms: \(3\times16^{7}+13\times16^{6}=16^{6}(3\times16+13)=61\times16^{6}\).
Step 4. Hence \(3D000B00_{16}=61\times16^{6}+11\times16^{2}\), which is option A.
Answer: A. \(61\times16^{6}+11\times16^{2}\)
