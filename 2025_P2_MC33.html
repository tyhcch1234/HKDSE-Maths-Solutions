Logarithms Indices

It is given that $\log_5 y$ is a linear function of $\log_{25} x$.

The intercepts on the vertical axis and on the horizontal axis of the graph of the linear function are $12$ and $2$ respectively. If $y = m x^n$, then $n = $

A. \(-12\)
B. \(-4\)
C. \(-3\)
D. \(-1\)

Correct answer: C

Step-by-Step Solution

Step 1 of 5

The graph is a straight line with:

  • Vertical intercept = $12$ (point $(0,12)$)
  • Horizontal intercept = $2$ (point $(2,0)$)
📌 Hint: In a linear graph, the vertical intercept is the value of the dependent variable when the independent variable is zero. Here the dependent variable is $\log_5 y$ and the independent variable is $\log_{25} x$.

Using the two intercept points $(0,12)$ and $(2,0)$:

\[ \text{Slope} = \frac{0 - 12}{2 - 0} = -6 \]

So the equation of the line is:

\[ \log_5 y = -6\log_{25} x + 12 \]
📌 Hint: Slope formula: \(m = \frac{y_2-y_1}{x_2-x_1}\). Here the variables are \(\log_5 y\) and \(\log_{25} x\).

The term \(-6\log_{25} x\) can be rewritten as \(\log_{25} x^{-6}\).

Also, \(12 = 12 \times \log_{25} 25 = \log_{25} 25^{12}\).

\[ \begin{aligned} \log_5 y &= \log_{25} x^{-6} + \log_{25} 25^{12} \\ &= \log_{25} (25^{12}x^{-6}) \end{aligned} \]
📌 Hint: Power law: \(a\log_b c = \log_b c^a\)  |  Product law: \(\log_b P + \log_b Q = \log_b PQ\).

Since \(25 = 5^2\), by the change-of-base formula:

\[ \log_5 y = \frac{\log_{25} y}{\log_{25} 5} = \frac{\log_{25} y}{\frac{1}{2}} = 2\log_{25} y \]

Substitute this into our equation:

\[ 2\log_{25} y = \log_{25} (25^{12}x^{-6}) \]
📌 Hint: In particular, \(\log_{25}5 = \frac{1}{2}\) because \(25^{1/2}=5\).

Divide both sides by \(2\):

\[ \log_{25} y = \frac{1}{2}\log_{25}(25^{12}x^{-6}) = \log_{25}(25^{12}x^{-6})^{1/2} \]

Since the logarithms have the same base, we equate the arguments:

\[ \begin{aligned} y &= (25^{12}x^{-6})^{1/2} \\ &= 25^{6} x^{-3} \end{aligned} \]

Compare with \(y = m x^n\):

\[ m = 25^6,\quad n = -3 \]

Therefore, the answer is C. \(-3\).

📌 Hint: If \(\log_b A = \log_b B\), then \(A = B\). Also, \((a^p q^r)^k = a^{pk} q^{rk}\).

Key Takeaway

  • A linear relationship between \(\log_5 y\) and \(\log_{25} x\) can be written as \(\log_5 y = a \log_{25} x + b\).
  • Use the given intercepts to find the slope and equation.
  • Change all logarithms to the same base (here base \(25\)) using \(\log_5 y = 2\log_{25} y\).
  • Combine log terms and equate arguments to express \(y\) in the form \(m x^n\).
