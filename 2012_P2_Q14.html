2012 P2 Q14Estimation, Approximation and Error

The length of a piece of thin string is measured as $\text{24.5 m}$ correct to the nearest $\text{m}$ (i.e. a given length $L$ metres correct to the nearest metre). If the string is cut into $n$ pieces such that the length of each piece is measured as $\text{4.5 cm}$ correct to the nearest $\text{cm}$, find the greatest possible value of $n$.

A. 445
B. 566
C. 567
D. 650

Step-by-step solution

Step 1 Find the range of the total length $L$.
Maximum Absolute Error \(\text{Max absolute error}=\dfrac{1}{2}\times\text{unit of measurement}\) Measured to the nearest metre, the error is at most \(0.5 ext{ m}\).
The string is measured as $24.5\ \text{m}$ correct to the nearest metre,
so $$24.5\ \text{m} \le L < 25.5\ \text{m}$$ Converting to centimetres ($1\ \text{m}=100\ \text{cm}$): $$2450\ \text{cm} \le L < 2550\ \text{cm}$$

Maximum error for rounding to the nearest metre is $0.5\ \text{m}=50\ \text{cm}$;
the lower bound is included, the upper bound is not.

Step 2 Find the range of each piece $l_i$.
Error Bounds of a Measurement \(m-\dfrac{u}{2}\le x So \(2450\le L<2550 ext{ cm}\) for the measured \(25 ext{ m}\).
Each piece is measured as $4.5\ \text{cm}$ correct to the nearest centimetre,
so $$4.5\ \text{cm} \le l_i < 5.5\ \text{cm}\qquad (i=1,2,\dots,n)$$

This is the smallest possible length each piece can have — the key to maximising $n$.

Step 3 Set up the total-length condition.
Since $L = l_1 + l_2 + \dots + l_n$ and each $l_i \ge 4.5\ \text{cm}$: $$4.5 \times n \;\le\; l_1 + l_2 + \dots + l_n = L < 2550\ \text{cm}$$

To fit as many pieces as possible,
use the minimum piece length $4.5$ cm and the maximum total $L < 2550$ cm.

Step 4 Solve the inequality for $n$.
Greatest Number of Pieces \(n<\dfrac{\text{upper bound of }L}{\text{minimum piece length}}\) Dividing \(2550\) by \(4.5\) and taking the integer below gives \(566\).
$$4.5n < 2550$$ $$n < \frac{2550}{4.5} = 566.666\ldots$$

Strict inequality: $n$ must be strictly less than $566.67$.

Step 5 Interpret the result.
Since $n$ is an integer,
the greatest possible value is $$n = 566$$

$n = 567$ would force $L \ge 567 \times 4.5 = 2551.5\ \text{cm} > 2550$ cm,
which is impossible.

Answer: B. 566

Question. A ribbon is measured as \(18\text{ m}\) correct to the nearest metre. It is cut into pieces each at least \(7\text{ cm}\) long. Find the greatest possible number of pieces.

Show the worked solution
Step 1. Max absolute error \(=\dfrac{1}{2}\times 1=0.5\text{ m}\), so \(17.5\le L<18.5\text{ m}\).
Step 2. In centimetres: \(1750\le L<1850\).
Step 3. Number of pieces \(n<\dfrac{1850}{7}=264.28\ldots\)
Step 4. So the greatest possible number of whole pieces is \(264\).
Answer: \(264\) pieces
