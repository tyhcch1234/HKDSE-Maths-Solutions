Number Line: Rounding Down to 3 S.F.

Step 1 — the given rounded-down result is 345.

345 (rounded value) 346 (next 3 s.f. value) admissible interval for $x$
HKDSE 2022 · Paper 2 · Q6

It is given that $x$ is a real number. If $x$ is rounded down to 3 significant figures, then the result is $345$. Find the range of values of $x$.

A.   $345 < x \le 345.5$

B.   $345 \le x < 346$

C.   $344.5 < x \le 345$

D.   $344.5 \le x < 345.5$

Step 1Interpret the wording.
Rounding Down (Truncation) \(\text{truncate at the }k\text{th significant figure}\) The 4th digit is never inspected, so every number starting \(3,4,5\) gives \(345\).

“Rounded down to 3 significant figures” means we truncate at the 3rd significant figure — we do not look at the 4th digit and round up.
So every real number whose first three significant figures are $3,\,4,\,5$ gives the result $345$.

Key difference from ordinary rounding: nothing ever rounds up.

Step 2Find the smallest admissible value of $x$.

For the truncated value to be exactly $345$,
the three leading significant figures must be $3,4,5$ (the digit $5$ is in the units place). The smallest number with these leading digits is $345$ itself,
so

$$x \ge 345.$$

Including equality: $x = 345$ trivially truncates to $345$.

Step 3Find the largest admissible value of $x$.
Upper Bound of a Truncated Value \(x<\text{next }3\text{ s.f. number}\) At \(x=346\) the leading digits become \(3,4,6\), so \(346\) is excluded and \(x<346\).

As $x$ increases, the leading three digits stay $3,4,5$ until the value reaches the next 3-significant-figure number, $346$. At $x = 346$ the leading digits change,
so $346$ must be excluded:

$$x < 346.$$

This is why the upper end is an open bound — the value $346$ would give $346$,
not $345$.

Step 4Combine to obtain the range.

$$345 \le x < 346$$

Checking the options: A uses $345.5$ (that is the bound for rounding to nearest),
C and D have the wrong order of digits — none of them fit.
Option B matches exactly.

Compare with “round to nearest 3 s.f.” which would give $344.5 \le x < 345.5$ (Option D).

Answer: B  —  $345 \le x < 346$

Question. It is given that \(x\) is a real number. If \(x\) is rounded down to 3 significant figures, the result is \(20.6\). Find the range of values of \(x\).

Show the worked solution
Step 1. Rounding down means truncating at the 3rd significant figure;
the 4th digit is ignored.
Step 2. The smallest value giving \(20.6\) is \(20.6\) itself, so \(x\ge20.6\).
Step 3. The next 3-significant-figure number is \(20.7\), which already truncates to \(20.7\),
so \(x<20.7\).
Step 4. Hence \(20.6\le x<20.7\).
Answer: \(20.6\le x<20.7\)
