HKDSE Math 2012 Paper 2 Q12 Formulas & Sequences

In the figure, the 1st pattern consists of 1 dot. For any positive integer $n$, the $(n+1)$th pattern is formed by adding $n$ dots to the $n$th pattern. Find the number of dots in the 8th pattern.

A22
B29
C36
D37

Step-by-step Solution

Let $T(m)$ be the number of dots in the $m$th pattern.

STEP 1Translate the given information.
Recurrence Relation \(T(n+1)=T(n)+n,\quad T(1)=1\) Each new term adds the previous index, so the sequence builds up term by term.

Given: $T(1) = 1$.

For every positive integer $n$,
the $(n+1)$th pattern has $n$ more dots than the $n$th pattern:

$T(n+1) = T(n) + n$

Hint: read the rule as “\(+n\) to get from the \(n\)th to the \((n+1)\)th pattern”.
STEP 2Write out the recurrences up to $n=7$.
Sum of the First n Integers \(1+2+\cdots+n=\dfrac{n(n+1)}{2}\) Adding \(1+2+\cdots+7\) gives \(T(8)-T(1)\).

Put $n = 7, 6, 5, \ldots, 1$ into the rule:

  • $T(8) = T(7) + 7$
  • $T(7) = T(6) + 6$
  • $T(6) = T(5) + 5$  $\cdots$  $T(2) = T(1) + 1$
Hint: the added amounts are $1, 2, 3, \ldots, 7$.
STEP 3Substitute backwards (telescoping sum).

Replacing each term by the one before it:

$T(8) = T(7) + 7 = \bigl(T(6)+6\bigr)+7 = \cdots = T(1) + 1 + 2 + \cdots + 6 + 7$

And since $T(1) = 1$:

$T(8) = 1 + 1 + 2 + 3 + 4 + 5 + 6 + 7$

Hint: each line “unwinds” one more recurrence — the same idea as the marking scheme’s line-by-line substitution.
STEP 4Evaluate the sum.
Telescoping Sum \(T(n)=T(1)+\sum_{k=1}^{n-1} k\) Only the first term and the accumulated sum survive.

Use $1+2+\cdots+7 = \dfrac{7 \times 8}{2} = 28$.

$T(8) = 1 + 28 = 29$

Check with the totals: $1, 2, 4, 7, 11, 16, 22, 29$ — adding $1,2,3,4,5,6,7$ gives $29$. ✓

Hint: $T(8) = 29$ corresponds to option B.
ANSWER B  ·  The 8th pattern has $\;29\;$ dots.

Question. A sequence satisfies \(T(n+1)=T(n)+2n\) with \(T(1)=3\). Find \(T(6)\).

Show the worked solution
Step 1. \(T(6)-T(1)=2(1)+2(2)+2(3)+2(4)+2(5)\).
Step 2. Sum the bracket: \(1+2+3+4+5=15\), so the total added is \(2\times 15=30\).
Step 3. Hence \(T(6)=3+30=33\).
Step 4. Check directly: \(T(2)=5,\ T(3)=9,\ T(4)=15,\ T(5)=23,\ T(6)=33\). \(\checkmark\)
Answer: \(T(6)=33\)
