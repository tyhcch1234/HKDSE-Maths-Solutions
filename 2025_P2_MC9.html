# Polynomials # Factor Theorem # Substitution
Q9

Let \(p(x) = n x^3 - 3n x + 36\), where \(n\) is a constant. If \(x + 3\) is a factor of \(p(x)\), then \(p(3) =\)

A. \(-2\)
B. \(0\)
C. \(2\)
D. \(72\)

Visual insight: The graph of \(p(x)\)

Move the slider to change \(n\). Notice: when \(x+3\) is a factor, the curve passes through \((-3, 0)\). The correct \(n\) makes the curve touch the x-axis at \(x=-3\).

When \(n=2\), \(p(-3)=0\) (correct factor condition). The point \((3, p(3))\) is highlighted in red.

Step-by-step solution

1 Use the Factor Theorem

Factor Theorem: If \((x - a)\) is a factor of \(p(x)\), then \(p(a) = 0\).

Here \(x + 3 = x - (-3)\), so \(a = -3\). Therefore:

\(p(-3) = 0\)
2 Substitute \(x = -3\) into \(p(x)\)

\(p(-3) = n(-3)^3 - 3n(-3) + 36\)

Simplify the powers and signs:

\((-3)^3 = -27\)
\(n(-27) = -27n\)
\(-3n(-3) = +9n\)

So the equation becomes:

\(-27n + 9n + 36 = 0\)
3 Solve for \(n\)

Combine like terms:

\(-18n + 36 = 0\)

Subtract 36 from both sides:

\(-18n = -36\)

Divide by -18:

\(n = 2\)
4 Find \(p(3)\)

Now \(n = 2\), so the polynomial is:

\(p(x) = 2x^3 - 6x + 36\)

Substitute \(x = 3\):

\(p(3) = 2(3)^3 - 6(3) + 36\)
\(= 2(27) - 18 + 36\)
\(= 54 - 18 + 36\)
\(p(3) = 72\)

Therefore, the answer is D. 72.

Key concept: Factor Theorem

Statement

If \((x - a)\) is a factor of \(p(x)\), then \(p(a) = 0\).

Reverse

If \(p(a) = 0\), then \((x - a)\) is a factor of \(p(x)\).

Use this to find unknown coefficients when a factor is given.
