Ferry Passengers Problem

Question: On a ferry, the number of female passengers is 40% more than the number of male passengers. If 24 female passengers leave the ferry, then the number of male passengers is 40% more than the number of female passengers. Find the number of male passengers on the ferry. [4 marks]

Let x be the number of male passengers and y be the original number of female passengers.

Step-by-step Solution

Let x be the number of male passengers and y be the original number of female passengers.

Hint: Clearly stating what each variable represents helps build the equations later.

"Female passengers is 40% more than male passengers" means:

\[ y = (1 + 40\%)x = 1.4x \]
Hint: "40% more" is equivalent to multiplying by \(1 + 0.4 = 1.4\).

After 24 females leave, remaining females \(= y - 24\).
Then "male passengers is 40% more than female passengers" gives:

\[ x = (1 + 40\%)(y - 24) = 1.4(y - 24) \]
Hint: Be careful: the comparison now is with the new number of females, not the original.

Substitute \(y = 1.4x\) into \(x = 1.4(y - 24)\):

\[ x = 1.4(1.4x - 24) \]

Expand and solve:

\[ \begin{aligned} x &= 1.96x - 33.6 \\ 33.6 &= 0.96x \\ x &= \frac{33.6}{0.96} = 35 \end{aligned} \]
Hint: Keep decimals exact or use fractions to avoid rounding errors.

We have found \(x = 35\).

Thus, the number of male passengers on the ferry is 35.

Check: originally 35 males and \(1.4\times35=49\) females. After 24 females leave, 25 females remain, and \(1.4\times25=35\) males, which matches.

Exam tip: When you see "A is p% more than B", write \(A = (1 + p\%)B\). Always define variables clearly and double-check the substitution step.
