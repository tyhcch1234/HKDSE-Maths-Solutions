If the inter-quartile range of the above distribution is at most \(25\), which of the following must be true?

I.  \(5 \le a \le 9\)
II.  \(0 \le b \le 4\)
III.  \(1 \le a - b \le 6\)

A.  I and II only
B.  I and III only
C.  II and III only
D.  I, II and III

aPart (a) — Read off \(Q_1\) and \(Q_3\)

There are \(20\) students, so each quartile group wraps around the 5th and 6th, and 15th and 16th ordered values.

Q₁\( \frac{32 + (30+a)}{2} \) = —
Q₃\( \frac{(60+b)+(60+b)}{2} \) = —
IQR—
1Count & order the data

Arrange all \(20\) values in ascending order and note the positions of the quartiles:

\[Q_1 = \frac{5^{\text{th}} + 6^{\text{th}}}{2}, \qquad Q_3 = \frac{15^{\text{th}} + 16^{\text{th}}}{2}\]
For \(n=20\), the lower quartile sits between the 5th and 6th values, and the upper quartile between the 15th and 16th values.
2Locate the 5th, 6th, 15th, 16th values

Reading from the ordered list (stems \(2,3,4,5,6,7\)):

\[ \underbrace{21,22,22,28}_{1\text{–}4},\; \underbrace{3a}_{5},\; \underbrace{3a}_{6},\; \dots,\; \underbrace{60+b}_{15},\; \underbrace{60+b}_{16},\; \underbrace{70,78}_{19\text{–}20} \]

So the 5th and 6th values are both \(30+a\), and the 15th and 16th values are both \(60+b\).

3Write \(Q_1\) and \(Q_3\)
\[ Q_1 = \frac{(30+a)+(30+a)}{2} = 30 + a \] \[ Q_3 = \frac{(60+b)+(60+b)}{2} = 60 + b \]
\(Q_1 = 30 + a \qquad Q_3 = 60 + b\)
4Form the IQR condition
\[ \text{IQR} = Q_3 - Q_1 = (60 + b) - (30 + a) = 30 + b - a \]

Given \(\text{IQR} \le 25\):

\[ 30 + b - a \le 25 \] \[ \boxed{a - b \ge 5} \]
This single inequality is the key that unlocks all three statements — everything else follows by squeezing \(a\) and \(b\) into their allowed digits \(0\) to \(9\).
\(\text{IQR} = 30 + b - a \le 25 \;\Longrightarrow\; a - b \ge 5\)

iPart (b)(i) — Is \(5 \le a \le 9\) a must?

Explore the feasible region of \((a,b)\) implied by \(a-b\ge 5\), with \(a,b\in\{0,1,\dots,9\}\).

(a, b) feasible?—
a − b—
Smallest possible a5
1Use \(b \ge 0\)

Since \(b\) is a digit and \(b \ge 0\), from \(a - b \ge 5\):

\[ a \ge b + 5 \ge 5 \]
Adding \(b\) to both sides of \(a - b \ge 5\) gives \(a \ge b + 5\); the smallest \(b\) can be is \(0\).
2Bound above by a digit

Also, \(a\) is a single digit, so \(a \le 9\). Combining:

\[ 5 \le a \le 9 \]
Statement I is TRUE \( \checkmark \)
3Which values of \(a\) are impossible?

If \(a \le 4\), then \(b \le a - 5 \le -1\), which is impossible since \(b \ge 0\). Hence \(a = 0,1,2,3,4\) are impossible, confirming \(a \ge 5\).

The diagram shows the lemon-yellow cells: they are exactly the impossible \((a,b)\) pairs. No yellow cell has \(a \le 4\) in a feasible spot.

iiPart (b)(ii) — Is \(0 \le b \le 4\) a must?

Drag the sliders to sweep through \(a\) and watch the maximum allowed value of \(b\).

Max allowed b\(= a - 5 =\) 4
Always b ≤ 4?YES
1Rearrange the key inequality

From Part (a):

\[ a - b \ge 5 \;\Longrightarrow\; b \le a - 5 \]
The larger \(a\) is, the larger \(b\) may be — so we must look at the worst case \(a = 9\).
2Use \(a \le 9\)

Since \(a\) is a digit, \(a \le 9\), hence:

\[ b \le a - 5 \le 9 - 5 = 4 \] \[ \therefore 0 \le b \le 4 \]
Statement II is TRUE \( \checkmark \)
3Why values \(5\)–\(9\) are impossible for \(b\)

If \(b \ge 5\), then \(a \ge b + 5 \ge 10\), which is not a single digit. So \(b = 5,6,7,8,9\) are impossible for \(b\).

The horizontal dashed line in the diagram marks \(b = 4\): no feasible (blue) cell ever lies above it.

iiiPart (b)(iii) — Is \(1 \le a - b \le 6\) a must?

We know \(a-b \ge 5\). The question is the upper bound: must \(a-b \le 6\)?

a − b—
Feasible & a−b ≤ 6?—
Possible values of a−b—
1Test the extreme case \(a = 9,\; b = 0\)

Take \(a = 9\) (max) and \(b = 0\) (min). Then \(a\) and \(b\) are legal digits and:

\[ a - b = 9 - 0 = 9 \]

But \(9 > 6\), which would violate statement III.

Statements with "must be true" fail as soon as ONE valid example breaks them. Here \(a=9,\ b=0\) also satisfies \(\text{IQR} = 30 + 0 - 9 = 21 \le 25\).
2Find all possible values of \(a-b\)

With \(a \in \{5,\dots,9\}\), \(b \in \{0,\dots,4\}\) and \(a - b \ge 5\):

  • Largest: \(a = 9,\; b = 0 \Rightarrow a - b = 9\)
  • Smallest allowed: \(a - b = 5\) (i.e. \(b = a - 5\))

So \(a - b\) can take values \(5, 6, 7, 8, 9\).

3Conclude

Since \(a - b = 9\) is possible, \(a - b \le 6\) is not guaranteed.

Statement III is FALSE \( \times \)  (counter-example: \(a = 9,\ b = 0\))

Summary & Final Answer

  • \(Q_1 = 30 + a,\quad Q_3 = 60 + b,\quad \text{IQR} = 30 + b - a\)
  • Condition: \(\text{IQR} \le 25 \;\Longrightarrow\; a - b \ge 5\)
  • Statement I: \(5 \le a \le 9\) TRUE
  • Statement II: \(0 \le b \le 4\) TRUE
  • Statement III: \(1 \le a - b \le 6\) FALSE  — counter-example \(a=9,\ b=0\) gives \(a-b=9\)
  • Only I and II are always true \(\;\Rightarrow\;\) Answer: A
