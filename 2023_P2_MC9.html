Question

Let \( h(x) = ax^{6} + 16x^{3} + b \), where \(a\) and \(b\) are constants.

If \( h(x) \) is divisible by \( 2x - 3 \), find the remainder when \( h(x) \) is divided by \( 2x + 3 \).

A.  −108
B.  −54
C.   54
D.   108

Click "Reveal Answer" at the bottom of the steps to check.

Step-by-Step Guided Solution

Hint — Factor Theorem

If a polynomial \(P(x)\) is divisible by \((x - c)\), then \(P(c) = 0\). Here, \(2x - 3 = 2\left(x - \frac{3}{2}\right)\), so the root is \(x = \frac{3}{2}\).

Divisible by \(2x - 3\) means: \(h\!\left(\frac{3}{2}\right) = 0\).

So \(h\!\left(\frac{3}{2}\right) = a\left(\frac{3}{2}\right)^6 + 16\left(\frac{3}{2}\right)^3 + b = 0\)  … (1)

Hint — Remainder Theorem

When \(P(x)\) is divided by \((x - c)\), the remainder is \(P(c)\). Here \(2x + 3 = 2\left(x + \frac{3}{2}\right)\), so the root is \(x = -\frac{3}{2}\).

Let \(r\) be the required remainder. Then:

\(r = h\!\left(-\frac{3}{2}\right) = a\left(-\frac{3}{2}\right)^6 + 16\left(-\frac{3}{2}\right)^3 + b\)

Notice the powers: \(x^6\) is even, \(x^3\) is odd, and the constant \(b\) is even. So:

\(h(x) - h(-x) = \big(ax^6 + 16x^3 + b\big) - \big(a(-x)^6 + 16(-x)^3 + b\big)\)

Since \((-x)^6 = x^6\) and \((-x)^3 = -x^3\):

\(h(x) - h(-x) = 32x^3\)

This eliminates the unknown constants \(a\) and \(b\) — perfect!

We know \(h\!\left(\frac{3}{2}\right) = 0\) and \(h\!\left(-\frac{3}{2}\right) = r\). Using \(h(x) - h(-x) = 32x^3\):

\(h\!\left(\frac{3}{2}\right) - h\!\left(-\frac{3}{2}\right) = 32\left(\frac{3}{2}\right)^3\)

\(0 - r = 32 \cdot \frac{27}{8} = 108\)

Therefore, \(\;r = -108\).

Answer: A. −108
