Scale of a Map — from Area Ratio to Linear Ratio

Rate & Ratio Variations Similar Figures Unit Conversion Scale Drawing

QUESTION The Problem

The actual area of a golf course is \(0.75\ \text{km}^2\). If the area of the course on a map is \(300\ \text{cm}^2\), then the scale of the map is

  • A. \(1:250\)
  • B. \(1:5\,000\)
  • C. \(1:62\,500\)
  • D. \(1:25\,000\,000\)
Big idea: the map and the real ground are similar figures. Areas scale with the square of the linear scale — so we must take a square root at the end.

SOLUTION Step-by-Step Guided Walkthrough

1 What exactly is "the scale of a map"? ›

The scale of a map is a ratio

\[ \text{scale} = \frac{\text{length on map}}{\text{corresponding actual length}} = 1:n \]

It compares lengths, not areas. The answer choices \(1:250\), \(1:5\,000\) , … are all of this form, so we must produce a length ratio.

Hint — dangerous spot: the question gives you two areas. Using them directly gives the area ratio \(\frac{1}{25\,000\,000}\), which is option D — the classic trap!
2 Convert the actual area to \(\text{cm}^2\) ›

Both areas must be in the same unit before comparing. Convert the real area into \(\text{cm}^2\).

Hint — unit facts you need: \(1\ \text{km} = 1000\ \text{m}\) and \(1\ \text{m} = 100\ \text{cm}\), so \(1\ \text{km} = 1000\times100 = 100\,000\ \text{cm}\).
For areas we square the conversion factor: \(1\ \text{km}^2 = (100\,000)^2\ \text{cm}^2 = 10^{10}\ \text{cm}^2\).
\[ 0.75\ \text{km}^2 = 0.75 \times (1000\times100)^2\ \text{cm}^2 = 0.75\times 10^{10}\ \text{cm}^2 \]

So the true area is \(7.5\times10^{9}\ \text{cm}^2\). That is a huge number — which is why the map scale must be very large.

3 Form the ratio of areas (map : ground) ›
\[ \frac{\text{area on map}}{\text{actual area}} = \frac{300\ \text{cm}^2}{0.75\times(1000\times100)^2\ \text{cm}^2} = \frac{300}{7.5\times10^{9}} = \frac{1}{25\,000\,000} \]

So the area ratio is \(1:25\,000\,000\).

Hint — meaning of each number: \(300\ \text{cm}^2\) is the area of the picture of the course on the paper; \(0.75\times10^{10}\ \text{cm}^2\) is the area of the real land. Same shape, different size → similar figures, so the ratio of areas equals the square of the ratio of lengths.
Stop here and you would answer D. But D is an area ratio, not a map scale. Keep going.
4 Square root: from area ratio to length ratio ›

For similar figures, if the linear scale is \(1:n\), then

\[ \frac{\text{area on map}}{\text{actual area}} = \left(\frac{1}{n}\right)^{2} \]

Therefore the linear scale is the square root of the area ratio:

\[ \text{scale} = \sqrt{\frac{1}{25\,000\,000}} = \frac{\sqrt{1}}{\sqrt{25\,000\,000}} = \frac{1}{5000} \]
Hint: \(\sqrt{25\,000\,000} = 5000\) because \(5000^2 = 25\,000\,000\). Break it as \(25\times10^{6}\), so \(\sqrt{25}\times\sqrt{10^{6}} = 5\times1000 = 5000\).

Answer: \(1:5000\) — option B.

5 Common mistake checklist ›

A (1:250): comes from wrongly using \(\sqrt{\frac{300}{0.75}}\) without converting \(\text{km}^2\to\text{cm}^2\).

C (1:62 500): comes from forgetting to take the square root of the area ratio in the other direction (or treating \(\sqrt{300}\) step-by-step incorrectly).

D (1:25 000 000): is exactly the area ratio \(\frac{300}{0.75\times10^{10}}\) — correct arithmetic but the wrong quantity for a map scale.

B (1:5000): convert units → form area ratio → take square root. ✅
