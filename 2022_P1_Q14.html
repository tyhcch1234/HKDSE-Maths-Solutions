4. Polynomials
Polynomial division Remainder theorem Factor theorem Discriminant Irrational roots

Let \( P(x) = 2x^3 + ax^2 + bx - 20 \), where \(a\) and \(b\) are constants. When \(P(x)\) is divided by \(x^2 - 2x + 3\), the remainder is \(x + 13\).

(a) Find \(a\) and \(b\). [3 marks]
(b) Is \(x-5\) a factor of \(P(x)\)? Explain. [2 marks]
(c) Claim: \(P(x)=0\) has two irrational roots. Do you agree? Explain. [3 marks]

Given that \(P(x)\) divided by \(x^2 - 2x + 3\) gives remainder \(x+13\), we can write:

\[ P(x) = (mx + n)(x^2 - 2x + 3) + (x + 13) \]

Hint: The divisor is quadratic, so the remainder is at most linear: \(mx + n\). Actually, we can compare with the given \(P(x)\).

Expand the right side:

\[ P(x) = mx^3 + (n - 2m)x^2 + (3m - 2n + 1)x + (3n + 13) \]

Compare coefficients with \(P(x) = 2x^3 + ax^2 + bx - 20\).

Equate coefficients:

  • \(x^3\): \(m = 2\)
  • constant: \(3n + 13 = -20 \Rightarrow 3n = -33 \Rightarrow n = -11\)

Now substitute \(m=2\) and \(n=-11\):

\(a = n - 2m = -11 - 4 = -15\)

\(b = 3m - 2n + 1 = 6 + 22 + 1 = 29\)

✅ \(a = -15,\quad b = 29\)

Hint: double-check with constant term: \(3n+13 = -33+13 = -20\) ✓

We have \(P(x) = 2x^3 -15x^2 + 29x -20\).

By the Factor Theorem, \(x-5\) is a factor if and only if \(P(5) = 0\).

Evaluate \(P(5)\):

\[ \begin{aligned} P(5) &= 2(5)^3 - 15(5)^2 + 29(5) - 20 \\ &= 250 - 375 + 145 - 20 \\ &= 0 \end{aligned} \]

✅ Since \(P(5) = 0\), \(x-5\) is indeed a factor of \(P(x)\).

Since \(x-5\) is a factor, divide \(P(x)\) by \(x-5\) (or perform synthetic division).

We get: \[ P(x) = (x-5)(2x^2 - 5x + 4) \]

You can verify by expansion: \((x-5)(2x^2 - 5x + 4) = 2x^3 -5x^2 +4x -10x^2 +25x -20 = 2x^3 -15x^2 +29x -20\) ✓

Set \(P(x)=0\):

\[ (x-5)(2x^2 - 5x + 4) = 0 \]

So either \(x-5=0\) or \(2x^2 - 5x + 4 = 0\).

For \(2x^2 - 5x + 4 = 0\), compute the discriminant:

\[ \begin{aligned} \Delta &= (-5)^2 - 4(2)(4) \\ &= 25 - 32 \\ &= -7 \end{aligned} \]

Since \(\Delta < 0\), the quadratic equation has no real roots.

Therefore the only real root of \(P(x)=0\) is \(x=5\), which is rational.

📌 Hence \(P(x)=0\) does not have any irrational roots. The claim is disagreed.
