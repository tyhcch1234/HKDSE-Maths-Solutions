Q38 The Question

For \(0^\circ \le x < 360^\circ\), how many roots does the equation \[\cos^{2}x - \sin x = 1\] have?

A. 2    B. 3    C. 4    D. 5

Key idea: all terms must be in the same trigonometric function. Use the Pythagorean identity \(\sin^{2}x + \cos^{2}x = 1\) to replace \(\cos^{2}x\) by \(1-\sin^{2}x\), then factorise (or solve as a quadratic).

Step A Convert to a single trig function

Drag the slider to see how \(\cos^2 x\) is rewritten: the shaded heights of \(\cos^2 x\) and \(1-\sin^2 x\) coincide for every \(x\).
1Use the Pythagorean identity

Begin from the given equation:

\[\cos^{2}x - \sin x = 1\]
Hint: \(\cos^{2}x = 1 - \sin^{2}x\). Substituting removes every cosine and leaves a single unknown, \(\sin x\).
\[\Rightarrow\ (1-\sin^{2}x) - \sin x = 1\]
2Move everything to one side

Subtract 1 from both sides:

\[1-\sin^{2}x-\sin x-1 = 0\] \[\Rightarrow\ -\sin^{2}x-\sin x = 0\]
Hint: The constant \(1\) and the substituted \(1\) cancel — this is why the equation becomes especially simple.
0 / 2

Step B Factorise and solve

The graph of \(y=\cos^2 x-\sin x-1\) on \(0^\circ \le x < 360^\circ\). The curve touches or crosses \(y=0\) at exactly the root angles.
1Factorise out \(-\sin x\)
\[-\sin^{2}x-\sin x = 0\] \[\Rightarrow\ -\sin x\,(\sin x + 1) = 0\]
Hint: Both terms share the factor \(\sin x\). Factorising gives a product equal to zero, so each factor can be solved separately.
2Solve each factor — careful with the domain
\[\sin x = 0 \quad\text{or}\quad \sin x = -1\]

Within \(0^\circ \le x < 360^\circ\):

\[\sin x = 0 \;\Rightarrow\; x = 0^\circ,\ 180^\circ\] \[\sin x = -1 \;\Rightarrow\; x = 270^\circ\]
Hint: \(x=360^\circ\) is excluded because the domain is \(0^\circ \le x < 360^\circ\). Also \(x=0^\circ\) is included since the lower bound is \(\le\).
Roots: \(x = 0^\circ,\ 180^\circ,\ 270^\circ\) — that is 3 roots, so the answer is B.

Summary of Answers

  • Working\(\cos^{2}x-\sin x=1 \;\Rightarrow\; (1-\sin^{2}x)-\sin x=1 \;\Rightarrow\; -\sin x(\sin x+1)=0\)
  • Factor 1\(\sin x = 0 \;\Rightarrow\; x = 0^\circ,\ 180^\circ\) (2 roots)
  • Factor 2\(\sin x = -1 \;\Rightarrow\; x = 270^\circ\) (1 root)
  • Total\(0^\circ,\ 180^\circ,\ 270^\circ\) — the equation has 3 roots. Answer: B
