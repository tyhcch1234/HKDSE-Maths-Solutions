[2015 MC #38]
For $0^\circ \le x < 360^\circ$, how many roots does the equation $$\cos^2 x - \sin x = 1$$ have?
A. 2
B. 3
C. 4
D. 5
💡 Key idea: the equation mixes $\cos^2 x$ and $\sin x$. Use the identity $\cos^2 x = 1-\sin^2 x$ to write everything in terms of $\sin x$ alone, then solve for $\sin x$ and count the angles in $[0^\circ,360^\circ)$.
Step 1 · Use the Pythagorean identity Replace $\cos^2 x$ by $1-\sin^2 x$ so the equation contains only $\sin x$: $$\cos^2 x - \sin x = 1$$ $$(1-\sin^2 x) - \sin x = 1$$
Step 2 · Rearrange & simplify Subtract $1$ from both sides and collect terms: $$-\sin^2 x - \sin x = 0$$ Multiply both sides by $-1$: $$\sin^2 x + \sin x = 0$$
Step 3 · Factorise Take out the common factor $\sin x$ (equivalently $-\sin x(\sin x+1)=0$): $$\sin x\,(\sin x + 1) = 0$$ So either $$\sin x = 0 \qquad \text{or} \qquad \sin x = -1.$$
Step 4 · Solve each case on $0^\circ \le x < 360^\circ$

Case 1: $\sin x = 0$

$$x = 0^\circ,\ 180^\circ$$

Case 2: $\sin x = -1$

$$x = 270^\circ$$ Check that all three values lie in the required interval ✔
Step 5 · Count the roots The solutions are $$x = 0^\circ,\quad 180^\circ,\quad 270^\circ.$$ That is $3$ distinct roots in $[0^\circ, 360^\circ)$.
✅ Answer: B — the equation has 3 roots.
