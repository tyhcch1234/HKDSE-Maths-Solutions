Question. The table below shows the distribution of the numbers of pens owned by some students.

Number of pens56789
Number of students9132$s$11

The median of the distribution is $7$.

(a) Find the least possible value of $s$.
(b) Write down the greatest possible value of $s$.
(c) Find the greatest possible standard deviation of the distribution.

(5 marks)

Step-by-step Solution

STEP 1 — Understand the data

Total number of students $=9+13+2+s+11=35+s$.

The median is the $\dfrac{35+s+1}{2}$-th value. Since the median is $7$, the $7$ column must contain the middle value(s).

Sort the data by number of pens. Values 5 and 6 come before 7; we need to locate the middle position.
Median of a Data Set \(\text{median}=\text{middle value of the ordered data}\) With \(5\) values the median is the 3rd value once the data are arranged in order; this fixes the possible values of the unknown.
STEP 2 — Part (a): least possible $s$

We need the median to be $7$. Let the total be $n=35+s$.

Even/odd: if $n$ is odd, the median is the $\frac{n+1}{2}$-th value. If $n$ is even, median $=$ average of the $\frac{n}{2}$-th and $(\frac{n}{2}+1)$-th values.

The cumulative counts: $5$'s: $9$; $6$'s: $9+13=22$; $7$'s: $22+2=24$.

For the least $s$, we want the $7$ column to just barely contain the middle position.

If $s=10$, then $n=45$, median is the $23$rd value. The $22$nd is the last $6$, so the $23$rd is the first $7$. ✔

If $s=9$, then $n=44$, median is average of $22$nd and $23$rd values $=6$ and $7$ → median $=6.5 \neq 7$. ✘

Therefore $s \ge 10$.

Check the boundary: $s=9$ gives median $6.5$; $s=10$ gives median exactly $7$.
Range of a Data Set \(\text{range}=\text{largest value}-\text{smallest value}\) The range gives an upper bound for the unknown and so limits the choices.
STEP 3 — Part (b): greatest possible $s$

To keep the median at $7$, the $7$ column must still contain the middle position.

The last $7$ occurs at cumulative position $24$. The largest $s$ before the $8$'s push the middle out of the $7$'s:

For $s=12$, $n=47$, median is the $24$th value $=7$. ✔

For $s=13$, $n=48$, median is avg of $24$th and $25$th values $=7$ and $8$ → median $=7.5 \neq 7$. ✘

Thus $s \le 12$, and the greatest possible value is $s=12$.

The $7$'s run from position $23$ to $24$. With $s=12$, the $24$th value is still $7$.
Standard Deviation (Population) \(\sigma=\sqrt{\frac{\sum(x-\bar x)^2}{n}}\) Compute the standard deviation for each allowed value of the unknown and compare.
STEP 4 — Part (c): greatest standard deviation

Possible $s$ values: $10,11,12$. Compute the standard deviation for each.

Case $s=10$: total $n=45$.
$\sum x = 9(5)+13(6)+2(7)+10(8)+11(9)=45+78+14+80+99=316$.
$\sum x^2 = 9(25)+13(36)+2(49)+10(64)+11(81)=225+468+98+640+891=2322$.
$\sigma^2 = \dfrac{2322}{45} - \left(\dfrac{316}{45}\right)^2 = 51.6 - 49.310123\ldots = 2.2898765\ldots$
$\sigma \approx 1.5132$.

Case $s=11$: $n=46$.
$\sum x = 316+8=324$; $\sum x^2 = 2322+64=2386$.
$\sigma^2 = \dfrac{2386}{46}-\left(\dfrac{324}{46}\right)^2 = 51.869565 - 49.606238\ldots = 2.263327\ldots$
$\sigma \approx 1.5044$.

Case $s=12$: $n=47$.
$\sum x = 324+8=332$; $\sum x^2 = 2386+64=2450$.
$\sigma^2 = \dfrac{2450}{47}-\left(\dfrac{332}{47}\right)^2 = 52.127660 - 49.891789\ldots = 2.235871\ldots$
$\sigma \approx 1.4953$.

The greatest standard deviation occurs at $s=10$: $\sigma \approx 1.5132 \approx 1.51$.

Less spread near the ends gives a smaller $\sigma$; $s=10$ (fewer students at $8$ pens) gives the largest $\sigma$.
Answers:
(a) Least possible $s = 10$
(b) Greatest possible $s = 12$
(c) Greatest possible standard deviation $\approx 1.51$

Question. The five numbers \(4,\ 6,\ 8,\ 9,\ t\), where \(t\) is a positive integer, have median \(8\) and range at most \(8\). (a) Find all possible values of \(t\). (b) Find the greatest possible standard deviation, correct to 3 significant figures.

Show the worked solution
1. Since \(4\) and \(6\) are already below \(8\), the median is \(8\) only when \(t\ge8\).
2. Range at most \(8\): \(t-4\le8\), so \(t\le12\). Hence \(t=8,9,10,11,12\).
3. For these values \(\sigma\approx1.79,\ 1.94,\ 2.15,\ 2.42,\ 2.71\) respectively, so \(\sigma\) increases with \(t\).
4. The greatest standard deviation occurs at \(t=12\): \(\sigma\approx2.71\).
Answer: (a) \(t=8,9,10,11,12\) (b) \(2.71\)
