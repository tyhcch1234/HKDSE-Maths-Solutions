HKDSE 2013 · Paper 2 · Q4

Which of the following is true?

$0.0504545 = \;?$

  • A. $0.0504545 = 0.051$  (correct to 2 significant figures)
  • B. $0.0504545 = 0.0505$  (correct to 3 decimal places)
  • C. $0.0504545 = 0.05045$  (correct to 4 significant figures)
  • D. $0.0504545 = 0.05046$  (correct to 5 decimal places)

Step-by-step Solution

1Locate the significant figures
Significant Figures Rule\(0.0\underbrace{5}_{1^{\text{st}}}\underbrace{0}_{2^{\text{nd}}}\underbrace{4}_{3^{\text{rd}}}\underbrace{5}_{4^{\text{th}}}\)Counting starts at the first non-zero digit of \(0.0504545\), so the two leading zeros are not significant.

Write the number in a place-value frame.
The first non-zero digit starts the significant figures — here the leading zeros are not significant.

\(0.\,\underbrace{0}_{\text{not sig.}}\,\underbrace{0}_{\text{not sig.}}\,\underbrace{5}_{1^{\text{st}}}\,\underbrace{0}_{2^{\text{nd}}}\,\underbrace{4}_{3^{\text{rd}}}\,\underbrace{5}_{4^{\text{th}}}\,\underbrace{4}_{5^{\text{th}}}\,\underbrace{5}_{6^{\text{th}}}\)

Hint: count significant figures from the first non-zero digit onward.
2Test option A — 2 significant figures
Rounding Rule\(d<5\ \Rightarrow\ \text{round down},\qquad d\geq 5\ \Rightarrow\ \text{round up}\)For 2 s.f. the kept digits are \(5\) and \(0\); the next digit \(4<5\), so nothing rounds up and \(0.051\) is wrong.

Keep 2 sig. figs: the digit after the kept part is the 3rd sig. fig. = \(4\),
which is \(<5\), so we round down.

\(0.050\lvert 4\ldots \;\rightarrow\; 0.050\)

But option A claims \(0.051\). That is false.

Hint: \(4.5\) is not \(\ge 5\) — the value \(0.0504545\) lies closer to \(0.050\) than to \(0.051\).
3Test option B — 3 decimal places
Decimal Places\(\text{3 d.p.}=\text{keep the first 3 digits after the decimal point}\)Option B claims \(3\) d.p. but quotes \(0.0505\), which has four decimal places.

Keep 3 decimal places;
look at the 4th decimal digit = \(4\) (again \(<5\)), so round down.

\(0.050\lvert 4\ldots \;\rightarrow\; 0.050\)

Option B claims \(0.0505\). That is false.

Hint: the correct value to 3 d.p. is \(0.050\), not \(0.0505\).
4Test option C — 4 significant figures

Keep 4 sig. figs: \(5,\,0,\,4,\,5\). The next digit is \(4\) (\(<5\)),
so round down.

\(0.05045\lvert 4\ldots \;\rightarrow\; 0.05045\)

Option C claims \(0.05045\). That is true.

KeptNext digitRuleResult
\(0.05045\)\(4\)\(4<5\) → round down\(0.05045\)
Hint: because the following digit is \(4\), no increase is applied to the last kept digit.
5Test option D — 5 decimal places

Keep 5 decimal places;
look at the 6th decimal digit = \(5\). With the next digit also non-zero,
we round up.

\(0.05045\lvert 45 \;\rightarrow\; 0.05046\)

Option D claims \(0.05046\). That is actually also for 5 d.p. but the question asks which statement is true — let's check: \(0.0504545\) to 5 d.p. is indeed \(0.05046\) (since the 5th decimal \(4\) is followed by \(5\),
round up the 5th place).

However, only one option is correct.
Re-examine: to 5 d.p. the 6th decimal digit is \(4\), not \(5\).

\(0.05045\lvert 4\,5\ldots \;\rightarrow\; 0.05045\) (not \(0.05046\))

So option D is false.

Hint: the 6th decimal digit is \(4\), so we round down to \(0.05045\), not up.
6Conclusion

Only C is a correct statement:

\(0.0504545 = 0.05045\)  
(correct to 4 significant figures).

Hint: check the digit immediately after the last kept digit — it decides rounding up or down.
Answer: C \(0.0504545 = 0.05045\) (correct to 4 significant figures)
