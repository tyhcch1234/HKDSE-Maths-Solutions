HKDSE Math 2014 Paper 2 Q37

Topic 5 — Formulas and Sequences

Geometric Sequences Indices Logarithms Ratio Test

If \(m > 1\), which of the following are geometric sequences?

I. \(2^m,\; 2^{2m},\; 2^{3m},\; 2^{4m}\)
II. \(m,\; 2m^2,\; 3m^4,\; 4m^8\)
III. \(\log m,\; \log m^2,\; \log m^4,\; \log m^8\)

🔑 Key Concept

A sequence is geometric if the ratio between consecutive terms is constant: \[ \frac{T_{n+1}}{T_n} = r \quad \text{for all } n \]

📘 Step-by-Step Solution

A sequence \(a_1, a_2, a_3, \ldots\) is geometric if:

\[ \frac{a_2}{a_1} = \frac{a_3}{a_2} = \frac{a_4}{a_3} = r \quad (r \text{ constant}) \]

So we need to check that the ratio between consecutive terms is the same throughout.

Ratio 1 → 2

\[ \frac{2^{2m}}{2^m} = 2^{2m - m} = 2^m \]

Ratio 2 → 3

\[ \frac{2^{3m}}{2^{2m}} = 2^{3m - 2m} = 2^m \]

Ratio 3 → 4

\[ \frac{2^{4m}}{2^{3m}} = 2^{4m - 3m} = 2^m \]
✓ All ratios equal \(2^m\) → Geometric sequence

Ratio 1 → 2

\[ \frac{2m^2}{m} = 2m \]

Ratio 2 → 3

\[ \frac{3m^4}{2m^2} = \frac{3}{2}m^{4-2} = \frac{3}{2}m^2 \]

Ratio 3 → 4

\[ \frac{4m^8}{3m^4} = \frac{4}{3}m^{8-4} = \frac{4}{3}m^4 \]
✗ Ratios are \(2m,\; \frac{3}{2}m^2,\; \frac{4}{3}m^4\) — not equal (since \(m > 1\)) → Not geometric

Why not equal? \(2m \neq \frac{3}{2}m^2\) because \(m > 1\) makes the powers of \(m\) different.

Use log law: \(\log m^k = k \log m\)

Ratio 1 → 2

\[ \frac{\log m^2}{\log m} = \frac{2\log m}{\log m} = 2 \]

Ratio 2 → 3

\[ \frac{\log m^4}{\log m^2} = \frac{4\log m}{2\log m} = 2 \]

Ratio 3 → 4

\[ \frac{\log m^8}{\log m^4} = \frac{8\log m}{4\log m} = 2 \]
✓ All ratios equal \(2\) → Geometric sequence

Note: Since \(m > 1\), \(\log m \neq 0\), so division is valid.

✓ Sequence I is geometric
✗ Sequence II is not geometric
✓ Sequence III is geometric

Therefore, the answer is

B. I and III only
