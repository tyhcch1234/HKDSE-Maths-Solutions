HKDSE Math 2021 Paper 2 Q5

Estimation, Approximation & Error

Rounding Error Bounds Inequalities

It is given that \( x = 6.24 \) (correct to 2 decimal places). Find the range of values of \( x \).

A. \( 6.235 < x \le 6.245 \)
B. \( 6.23 \le x < 6.25 \)
C. \( 6.235 \le x < 6.245 \)
D. (Correct) \( 6.235 \le x < 6.245 \)
1

Understand the rounding instruction

The value \( x = 6.24 \) is correct to 2 decimal places. This means when we round the original value of \( x \) to the nearest hundredth, we get \( 6.24 \).

💡 Hint: The "rounding unit" is \( 0.01 \) (the last digit is in the hundredths place).

2

Find the maximum possible error

The maximum error is half of the rounding unit.

\[ \text{Max error} = \frac{0.01}{2} = 0.005 \]

This means the original value of \( x \) can be at most \( 0.005 \) away from \( 6.24 \).

3

Construct the error bounds

We know \( x \) can be as low as \( 6.24 - 0.005 = 6.235 \) and as high as \( 6.24 + 0.005 = 6.245 \).

\[ 6.24 - \frac{0.01}{2} \le x < 6.24 + \frac{0.01}{2} \]

4

Determine the inequality signs

The lower bound \( 6.235 \) is included because \( 6.235 \) itself rounds to \( 6.24 \) (0.5 rounds up). So we use \( \le \).

The upper bound \( 6.245 \) is not included because \( 6.245 \) would round up to \( 6.25 \), not \( 6.24 \). So we use \( < \).

⚠️ Common mistake: Many students forget that the lower bound is included when the original number rounds up.

5

Write the final range

Combining the bounds and inequality signs, the range of values of \( x \) is:

\[ 6.235 \le x < 6.245 \]

This matches option D.

✅ Correct Answer

D

\( 6.235 \le x < 6.245 \)
