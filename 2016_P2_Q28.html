HKDSE Math 2016 Paper 2 Q28 Probability

Coin Selection Probability

Christine selects 3 coins from her pocket. Find the probability she gets at least $13.

Question

Christine has one $1 coin, one $2 coin, one $5 coin and one $10 coin in her pocket. If Christine takes out three coins randomly from her pocket, find the probability that she gets at least $13.

A 1/2
B 1/4
C 3/4
D 23/24

Step-by-step Solution

Christine picks 3 coins from a set of 4 distinct coins ($1, $2, $5, $10). Since order does not matter, the number of possible combinations is: \[ C^{4}_{3} = 4 \] The four possible outcomes are:
  • {1, 2, 5} — sum = $8
  • {1, 2, 10} — sum = $13
  • {1, 5, 10} — sum = $16
  • {2, 5, 10} — sum = $17
We need the total value ≥ $13. Check each outcome:
  • ✗ {1, 2, 5} = $8 (too low)
  • {1, 2, 10} = $13
  • {1, 5, 10} = $16
  • {2, 5, 10} = $17
There are 3 favourable outcomes.
For equally likely outcomes: \[ P(\text{at least } \$13) = \frac{\text{number of favourable outcomes}}{\text{total number of outcomes}} = \frac{3}{4} \]
Answer: C (3/4)
