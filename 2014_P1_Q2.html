HKDSE Math 2014 Paper 1 Q2

Factorization by Grouping

Polynomials Factorization Grouping Terms Common Factor

📋 Question

Factorize:

(a)
$a^2 - 2a - 3$
(b)
$ab^2 + b^2 + a^2 - 2a - 3$  [3 marks]

🧭 Step-by-Step Solution

1

Part (a): Factorize $a^2 - 2a - 3$

Find two numbers that multiply to $-3$ and add to $-2$.

The numbers are $+1$ and $-3$ because:

$1 \times (-3) = -3$   and   $1 + (-3) = -2$

Therefore: $$a^2 - 2a - 3 = (a + 1)(a - 3)$$

✓ Correct (1A)

2

Part (b): Rewrite the expression

Start with the full expression:

$ab^2 + b^2 + a^2 - 2a - 3$

Notice the last three terms are exactly part (a)!

$a^2 - 2a - 3 = (a + 1)(a - 3)$

So we can write:

$ab^2 + b^2 + (a + 1)(a - 3)$   (1M for substitution)

3

Factor by grouping: Take out $b^2$

The first two terms share a common factor $b^2$:

$ab^2 + b^2 = b^2(a + 1)$

Now the expression becomes:

$b^2(a + 1) + (a + 1)(a - 3)$

Both terms now have a common factor $(a + 1)$.

4

Final factorization

Take out the common factor $(a + 1)$:

$b^2(a + 1) + (a + 1)(a - 3)$

$= (a + 1)(b^2 + a - 3)$

Final answer:

$(a + 1)(b^2 + a - 3)$

✓ Correct (1A)
