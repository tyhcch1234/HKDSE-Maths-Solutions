Inequalities and Linear Programming (46) · Sub-Topic: Compound Inequalities

T9 Q26

Solve the compound inequality $-1 < 2x-3 \le 3$.

Solution

Add $3$ to all three parts: $-1+3 < 2x-3+3 \le 3+3$, so $2 < 2x \le 6$.
Divide all three parts by $2$: $1 < x \le 3$.
Check: $x=2$ gives $-1 < 1 \le 3$; the lower bound $1$ is excluded and the upper bound $3$ is included, so the solution is consistent.
The solution is $1 < x \le 3$, i.e. $x \in (1,3]$.
