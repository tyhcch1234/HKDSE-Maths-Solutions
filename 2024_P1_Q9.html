QUESTION The Distribution of Keys Owned

The table below shows the distribution of the numbers of keys owned by a group of housewives.

Number of keys 345678
Number of housewives 109434\(k\)

If a housewife is randomly selected from the group, then the probability that she owns more than 6 keys is \(\dfrac{5}{18}\).

(a) Find \(k\).

(b) Write down the mean, the mode and the median of the distribution.

(5 marks)

PART (a) Find \(k\)

\(k\) = 6
Total number of housewives \(N = \) 36 Number owning > 6 keys = 10 P(>6 keys) = 0.2778 ≠ 5/18
1
Translate the probability condition
1M

"Owns more than 6 keys" means \(7\) or \(8\) keys.

\[ P(\text{more than }6) = \frac{\text{(No. with 7)} + \text{(No. with 8)}}{\text{Total}} \]

Total number of housewives:

\[ N = 10+9+4+3+4+k = 30+k \]

Number owning more than 6 keys: \(4 + k\).

Hint: The total must include the unknown \(k\), otherwise the fractions won't match.
2
Set up the equation given \(P = \frac{5}{18}\)
1M
\[ \frac{4+k}{10+9+4+3+4+k} = \frac{5}{18} \] \[ \frac{4+k}{30+k} = \frac{5}{18} \]
Hint: A single fraction equals a single fraction — cross-multiply to clear it.
3
Solve for \(k\)
1A
\[ 18(4+k) = 5(30+k) \] \[ 72 + 18k = 150 + 5k \] \[ 13k = 78 \] \[ k = 6 \]
\(k = 6\), so there are \(8\) housewives owning \(8\) keys, and \(N = 36\) in total.
Check: \(\dfrac{4+6}{36} = \dfrac{10}{36} = \dfrac{5}{18}\) ✓
0 / 3

PART (b) Mean, Mode and Median

Mean = 5 Mode = 3 Median = 4 Mean key-count sum = 180
1
Mean (using the frequency table)
1A

With \(k=6\), the full frequency table is \(10,\ 9,\ 4,\ 3,\ 4,\ 6\) for keys \(3,4,5,6,7,8\).

\[ \text{Mean} = \frac{\sum (\text{keys}\times\text{frequency})}{\sum \text{frequency}} \] \[ = \frac{3(10)+4(9)+5(4)+6(3)+7(4)+8(6)}{36} \] \[ = \frac{30+36+20+18+28+48}{36} = \frac{180}{36} = 5 \]
Mean \(= 5\)
Tip: Use the symmetric structure — the counts \(10,9,4,3,4,6\) produce a mean exactly at the mid-value \(5\).
2
Mode
1A

The mode is the value with the largest frequency.

Keys345678
Frequency1094346

The largest frequency is \(10\), which corresponds to \(3\) keys.

Mode \(= 3\)
Hint: Mode = the data value that appears most often (highest bar), not the highest frequency itself.
3
Median (locate the \(\frac{36}{2}=18\)th position)
1A

There are \(36\) data values (even), so the median is the average of the \(18\)th and \(19\)th values in order.

Build cumulative frequencies:

\[ \underbrace{10}_{3},\quad \underbrace{10+9=19}_{4},\quad \underbrace{19+4=23}_{5},\ \dots \]
  • Keys \(3\): positions \(1\) to \(10\)
  • Keys \(4\): positions \(11\) to \(19\)

Both the \(18\)th and \(19\)th values lie in the "keys \(4\)" group.

\[ \text{Median} = \frac{4+4}{2} = 4 \]
Median \(= 4\)
Hint: Cumulative frequency \(19\) first reaches/passes \(18\) at key value \(4\) — that pins the median down instantly.
0 / 3

📌 Final Answers at a Glance

  • (a) \(k = 6\)  (total housewives \(N = 36\))
  • (b) Mean \(= 5\)
  • (b) Mode \(= 3\)
  • (b) Median \(= 4\)
