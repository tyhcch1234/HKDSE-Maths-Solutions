Question — HKDSE 2025 Paper 2 Q6

MC

If $x = 5.67$ (correct to 2 decimal places), find the range of values of $x$.

  • A. $5.665 \le x < 5.675$
  • B. $5.665 < x \le 5.675$
  • C. $5.665 \le x \le 5.675$
  • D. $5.665 \le x < 5.675$

Step-by-step Solution

Step 1 · Understand what “correct to 2 d.p.” means

$x = 5.67$ means $x$ has been rounded to the nearest $0.01$.

Rounding to 2 decimal places keeps the hundredths digit; the next digit decides whether to round up or down.

Hint: the result $5.67$ is only a rounded value — many exact values of $x$ could give $5.67$.

Step 2 · Find the maximum absolute error

For rounding to 2 d.p. (i.e. to the nearest $0.01$):

\[ \text{max absolute error} \;=\; \frac{0.01}{2} \;=\; 0.005 \]

Hint: maximum absolute error $= \dfrac{\text{rounding unit}}{2}$. Here the rounding unit is $0.01$.

Maximum Absolute Error \(\text{max. abs. error}=\dfrac{\text{rounding unit}}{2}\) Correct to \(1\) decimal place the rounding unit is \(0.1\), so the error is at most \(0.05\).

Step 3 · Build the valid interval

The exact value must lie within $5.67 \pm 0.005$:

\[ 5.67 - 0.005 \;\le\; x \;<\; 5.67 + 0.005 \]

\[ 5.665 \;\le\; x \;<\; 5.675 \]

Hint: the lower bound is included ($\le$) because $5.665$ itself rounds up to $5.67$; the upper bound is not included ($<$) because $5.675$ would round up to $5.68$.

Rounding Interval \(x_{0}-e\le x Thus \(8.6-0.05\le m<8.6+0.05\), i.e. \(8.55\le m<8.65\).

Step 4 · Check the endpoints

  • $x = 5.665$ → rounds to $5.67$ ✓ (included)
  • $x = 5.675$ → rounds to $5.68$ ✗ (excluded)
  • $x = 5.6651$ → rounds to $5.67$ ✓
  • $x = 5.6749$ → rounds to $5.67$ ✓

Hint: always test the two endpoints of the interval to confirm whether they are included or excluded.

Answer: Option D  —  $5.665 \le x < 5.675$
