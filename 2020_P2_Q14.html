Step 1 — measurements read to the nearest cm.

[HKDSE 2020 Paper 2 Q14] In the figure, $PQRST$ is a pentagon, where all the measurements are correct to the nearest cm. Let $A$ cm$^2$ be the actual area of the pentagon. Find the range of values of $A$.

  • A. $48.25 \le A < 64.75$
  • B. $44.75 \le A < 60.75$
  • C. $27.83 \le A < 31.83$
  • D. $48.25 \le A < 60.75$
1

Read the given measurements

From the figure (right angles at $Q$ and $S$): $$PQ = 5\text{ cm},\quad QR = 5\text{ cm},\quad RS = 4\text{ cm},\quad ST = 4\text{ cm}$$ $$PT \perp \text{horizontal}, \quad QT = 8\text{ cm (overall width)},\quad TS = 4\text{ cm}$$ All measurements are correct to the nearest cm, so each value $m$ satisfies $$m-0.5 < \text{true} < m+0.5.$$
Hint: “correct to the nearest cm” ⇒ maximum absolute error $=0.5$ cm.
2

Split the pentagon into two triangles

Draw diagonal $QT$: it divides $PQRST$ into $$\triangle PQT \quad\text{and}\quad \triangle QST.$$ Since the figures are right-angled, the area is a product of two linear measurements, so we can bound each part separately. $$[PQT] = \tfrac12 \,QT \cdot PQ,\qquad [QST]=\tfrac12\,QT\cdot ST.$$
Hint: a diagonal turns a pentagon into two triangles whose areas use simple base × height.
3

Lower bound of the area

Use the smallest possible values: $QT_{\min}=7.5$, $PQ_{\min}=4.5$, $ST_{\min}=3.5$. $$A_{\min}=\tfrac12(7.5)(4.5)+\tfrac12(7.5)(3.5)$$ $$A_{\min}=\tfrac12(33.75)+\tfrac12(26.25)=16.875+13.125=27.83\text{ (2 d.p.)}$$
Hint: $\frac12(7.5)(4.5)=16.875$ and $\frac12(7.5)(3.5)=13.125$.
4

Upper bound of the area

Use the largest possible values: $QT_{\max}=8.5$, $PQ_{\max}=5.5$, $ST_{\max}=4.5$. $$A_{\max}=\tfrac12(8.5)(5.5)+\tfrac12(8.5)(4.5)$$ $$A_{\max}=\tfrac12(46.75)+\tfrac12(38.25)=23.375+19.125=31.83\text{ (2 d.p.)}$$
Hint: $\frac12(8.5)(5.5)=23.375$ and $\frac12(8.5)(4.5)=19.125$.
5

Write the range of $A$

The actual area always lies strictly between the two bounds: $$27.83 \le A < 31.83$$ (rounded to 2 d.p.), which matches option C.
Hint: the lower bound is inclusive when the rounded value reaches the boundary; the upper bound is strictly less.
Answer: C —  $27.83 \le A < 31.83$
