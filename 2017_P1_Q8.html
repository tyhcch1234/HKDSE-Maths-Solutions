Inverse Variation with a Square Root

Topic 2 — Rate, Ratio and Variations  |  5 marks

Inverse Variation Proportionality Constant \(k\) Surds & Roots Change in Value

Question

It is given that \(y\) varies inversely as \(\sqrt{x}\). When \(x = 144\), \(y = 81\).

  1. Express \(y\) in terms of \(x\).
  2. If the value of \(x\) is increased from \(144\) to \(324\), find the change in the value of \(y\).

5 marks

Step-by-Step Guided Solution

Step 0 / 5
1 Translate "varies inversely as \(\sqrt{x}\)" into an equation

When \(y\) varies inversely as \(\sqrt{x}\), \(y\) is equal to a constant divided by \(\sqrt{x}\):

\[ y = \frac{k}{\sqrt{x}} \]

where \(k\) is a non-zero constant (the variation constant).

Hint — form of variation: "varies inversely as" means the variable goes in the denominator. So \(y \propto \dfrac{1}{\sqrt{x}}\), which becomes \(y = \dfrac{k}{\sqrt{x}}\). Here \(k\) is the fixed number we must find from the given data.
2 Substitute the given values to find the constant \(k\)

Substitute \(x = 144\) and \(y = 81\) into \(y = \dfrac{k}{\sqrt{x}}\):

\[ 81 = \frac{k}{\sqrt{144}} \]
Hint — evaluate the root first: \(\sqrt{144} = 12\), so the equation becomes \(81 = \dfrac{k}{12}\). Multiply both sides by \(12\) to isolate \(k\).
3 Solve for \(k\) and write down the answer for (a)
\[ k = 81 \times \sqrt{144} = 81 \times 12 = 972 \]

Therefore, expressing \(y\) in terms of \(x\):

(a)   \( y = \dfrac{972}{\sqrt{x}} \)
Hint — why this is worth full marks: An "express in terms of \(x\)" answer must contain only the variable \(x\). Leaving \(k\) in the formula would lose the mark.
4 Part (b): find the new value of \(y\) when \(x = 324\)

Use the result from part (a) with \(x = 324\):

\[ y = \frac{972}{\sqrt{324}} = \frac{972}{18} = 54 \]
Hint: \(324 = 18^2\), so \(\sqrt{324} = 18\). (Check: \(18^2 = 324\). ✓)
5 Find the change in \(y\)

The initial value of \(y\) (when \(x = 144\)) is \(81\). The new value (when \(x = 324\)) is \(54\).

\[ \text{Change} = 81 - 54 = 27 \]

Since the value has gone down, \(y\) decreases by \(27\).

(b)   The value of \(y\) decreases by \(27\).
Hint — sign matters: The question asks for the change. State the direction ("decrease by") or give \(-27\); a bare "27" without direction is ambiguous.
