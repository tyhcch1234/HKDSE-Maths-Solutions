Regular pentagon, intersecting diagonals and angle chasing — deciding which of three statements must be true.

QQuestion Multiple Choice

In the figure, \(ABCDE\) is a regular pentagon. \(AD\) and \(CE\) intersect at the point \(F\). Which of the following are true?

I. \(\angle DAE = \angle AFE\)
II. \(AE = EC\)
III. \(\angle AFB + \angle EAF = 90^\circ\)

A. I and II only    B. I and III only    C. II and III only    D. I, II and III

Step 11M

For a regular pentagon with \(n=5\) sides, each interior angle is

\[ \angle ABC = \frac{(5-2)\times 180^\circ}{5} = 108^\circ .\]

In the isosceles triangle \(\triangle AED\), \(AE = ED\), so

\[ \angle DAE = \angle ADE = \frac{180^\circ - 108^\circ}{2} = 36^\circ .\]
Hint: Every regular pentagon has interior angles \(108^\circ\) — this never changes, so \(\angle DAE = 36^\circ\) always.
Step 21M

In triangle \(\triangle ECF\), by symmetry of the pentagon \(CE = CD\), so

\[ \angle CEF = \angle CED = 36^\circ,\qquad \angle ECF = 72^\circ .\]

Hence

\[ \angle EFC = 180^\circ - 36^\circ - 72^\circ = 72^\circ .\]

Since \(\angle AFE\) and \(\angle EFC\) are vertically opposite at \(F\),

\[ \angle AFE = 72^\circ - 36^\circ ? \qquad\text{No — check carefully: } \angle AFE = 72^\circ .\]
Hint: \(\angle AFE = \angle CFD = 72^\circ\) because they are vertically opposite. So \(\angle DAE = 36^\circ \neq 72^\circ = \angle AFE\).
Step 31A

Therefore \(\angle DAE = 36^\circ\) while \(\angle AFE = 72^\circ\), so

\[ \angle DAE \neq \angle AFE .\]
Conclusion: Statement I is false.

Step 11M

All five sides of a regular pentagon are equal, so

\[ AB = BC = CD = DE = EA .\]

In particular, \(AE\) is a side, while \(EC\) is a diagonal.

Hint: In any regular pentagon a diagonal is always longer than a side — \(AE\) is a side of the pentagon.
Step 21M

Since \(EC\) is a diagonal and \(AE\) is a side of the same regular pentagon,

\[ EC > AE .\]

(Equivalently, \(EC = 2R\sin 72^\circ\) while \(AE = 2R\sin 36^\circ\), where \(R\) is the circumradius.)

Hint: Try the slider: the ratio \(EC/AE\) stays at the golden ratio \(\varphi \approx 1.618\) no matter the size.
Step 31A

Because \(EC > AE\),

\[ AE \neq EC .\]
Conclusion: Statement II is false.

Step 11M

Let \(G\) be the point of intersection of \(AC\) and \(BF\).

Since \(AB = BC = CD = DE = EA\) and \(AC /\!/ DE\), \(BC /\!/ AE\), the quadrilateral \(ABCE\) is a rhombus.

The diagonals of a rhombus are perpendicular, so

\[ \angle AGF = 90^\circ .\]
Hint: All four sides of \(ABCE\) equal the side of the pentagon, so it is a rhombus. Its diagonals \(AC\) and \(BE\) meet at \(90^\circ\).
Step 21M

In \(\triangle AFG\), by the angle sum of a triangle,

\[ \angle AFG + \angle FAG = 180^\circ - \angle AGF = 180^\circ - 90^\circ = 90^\circ .\]

But \(\angle AFG = \angle AFB\) and \(\angle FAG = \angle EAF\) (same angle, different names).

Hint: \(\angle AFB\) is the same as \(\angle AFG\), and \(\angle EAF\) is the same as \(\angle FAG\).
Step 31A

Therefore

\[ \angle AFB + \angle EAF = \angle AFG + \angle FAG = 90^\circ .\]
Conclusion: Statement III is true.

Summary of Answers

  • I\(\angle DAE = 36^\circ\) but \(\angle AFE = 72^\circ\), so \(\angle DAE \neq \angle AFE\) → FALSE
  • II\(AE\) is a side and \(EC\) is a diagonal, so \(EC > AE\) → \(AE \neq EC\) → FALSE
  • IIIIn rhombus \(ABCE\), the diagonals are perpendicular, giving \(\angle AFB + \angle EAF = 90^\circ\) → TRUE
Only statement III is true  ⟹  the correct choice is B.
