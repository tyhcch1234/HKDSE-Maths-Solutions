Question 28 · Expected Value

Probability Expected Value Discrete Random Variable

Q Question

A box contains six cards numbered 2, 2, 2, 3, 4 and 5 respectively. In a game, a number is randomly drawn from the box and a certain number of tokens will be got according to the following table:

Number drawn 2 3 4 5
Number of tokens got 10 15 25 50

Find the expected number of tokens got in the game.

A. 3
B. 4
C. 20
D. 25

2 Step-by-Step Solution

Let \(X\) be the number of tokens obtained. The possible values of \(X\) are \(10,\ 15,\ 25,\ 50\), each corresponding to the drawn number \(2,\ 3,\ 4,\ 5\).
💡 Hint: Expected value \(E(X)=\sum x\,P(X=x)\), so we need the probability of drawing each number first.

Six cards exist, so the denominator is always 6. Count how many cards carry each number:

Number 2 3 4 5
Frequency 3 1 1 1
Probability \(\frac{3}{6}\) \(\frac{1}{6}\) \(\frac{1}{6}\) \(\frac{1}{6}\)
⚠️ Common trap: The probability of drawing 2 is \(\frac{3}{6}\), not \(\frac{1}{6}\), because there are three identical “2” cards.
\[ \begin{aligned} E(X) &= P(2)\times 10 + P(3)\times 15 + P(4)\times 25 + P(5)\times 50 \\[4pt] &= \frac{3}{6}\times 10 + \frac{1}{6}\times 15 + \frac{1}{6}\times 25 + \frac{1}{6}\times 50 \end{aligned} \]
💡 Hint: Multiply each outcome by its probability, then sum. Each term is a “weighted” contribution of the tokens.
\[ \begin{aligned} E(X) &= 5 + 2.5 + \frac{25}{6} + \frac{50}{6} \\[4pt] &= 5 + 2.5 + \frac{75}{6} \\[4pt] &= 5 + 2.5 + 12.5 = 20 \end{aligned} \] Alternatively, keep the common denominator 6: \[ E(X)=\frac{1}{6}(30+15+25+50)=\frac{120}{6}=20 \]
The expected number of tokens got in the game is \[ \boxed{E(X) = 20} \] Therefore the correct option is C.

📌 Quick Recap

  • Expected value of a discrete random variable: \(E(X)=\sum x\,P(X=x)\).
  • Probability = (# favourable cards) ÷ (total cards) — repeated numbers increase the probability.
  • Always check the total: \(3+1+1+1=6\), so the probabilities sum to 1.
