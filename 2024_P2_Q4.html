HKDSE 2024 Paper 2 — Q4

Topic 3: Estimation, Approximation and Error

Question. Which of the following is correct?

  • A.  $18$ (correct to the nearest integer).
  • B.  $18.25$ (correct to 2 decimal places).
  • C.  $18.2$ (correct to 3 significant figures).
  • D.  $18.2482$ (correct to 4 decimal places).

The left-hand figure shows the exact value $\sqrt{333}=18.24828759\ldots$ on a number line, together with the rounding boundaries used in each option.

Step-by-step solution

1 Write down the exact value of $\sqrt{333}$.

Using a calculator,

$$\sqrt{333}=18.248287590\ldots$$

So the digits after the point are 2, 4, 8, 2, 8, 7, 5, 9, …

Hint: all four options are different roundings of this same number — we just need to apply the correct rounding rule at each accuracy.
2 Option A — nearest integer.

Look at the first decimal place: $18.\underline{2}48287\ldots$

The digit $2<5$, so round down:

$$\sqrt{333}\approx 18 \quad(\text{nearest integer})$$

Option A is correct.

Hint: rounding to the nearest integer means checking the 1st decimal place — if it is 5 or more, round up; otherwise round down.
3 Option B — 2 decimal places.

Keep 2 digits after the point and look at the 3rd decimal place: $18.24\underline{8}287\ldots$

The digit $8\ge 5$, so we must round the $4$ up:

$$18.24 \;\longrightarrow\; 18.25$$

So $18.25$ is a correct rounding of $\sqrt{333}$ to 2 d.p.

Option B is also correct.

Hint: do not be tempted to say "B is wrong" because it differs from A — the two options round to different accuracies, so both can be correct.
4 Option C — 3 significant figures.

The first 3 significant figures are $1,8,2$ (the leading $1$ counts, then $8$, then $2$):

$$1\underline{8}.2\,\big|\,\underline{4}8287\ldots$$

The next digit is $4<5$, so round down and keep $18.2$:

$$18.2 \quad(\text{3 s.f.})$$

So $18.2$ is a correct rounding of $\sqrt{333}$ to 3 s.f.

Option C is also correct.

Hint: for 3 s.f. of $18.248\ldots$, the cut-off is after the '2' in the tenths place; the following digit 4 tells us to round down.
5 Option D — 4 decimal places.

Keep 4 digits after the point and look at the 5th decimal place: $18.2482\underline{8}759\ldots$

The digit $8\ge 5$, so we round the $2$ up to $3$:

$$18.2482 \;\longrightarrow\; 18.2483$$

But the option states $18.2482$, which is not the correct 4-d.p. rounding. It should be $18.2483$.

Option D is incorrect.

Key trap: option D "drops" the remaining digits instead of rounding up, so it is wrong.
6 Compare all four options.
OptionAccuracyCorrect rounding of $\sqrt{333}$Verdict
Anearest integer$18$correct
B2 d.p.$18.25$correct
C3 s.f.$18.2$correct
D4 d.p.$18.2483$ (not $18.2482$)incorrect

Since the question asks which statement is correct, options A, B and C all hold.

Hint: whenever a multiple-choice question has several true statements, the exam is testing whether you notice that different accuracies give different (all valid) rounded values.
Answer: A, B and C — i.e. $18$ (nearest integer), $18.25$ (2 d.p.) and $18.2$ (3 s.f.) are all correct roundings of $\sqrt{333}$.
(D is wrong: the correct value to 4 d.p. is $18.2483$, not $18.2482$.)
