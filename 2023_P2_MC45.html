Statistics — Standard Deviation, Median & Range of a Linear Family
Standard Deviation Median Range Linear Shift Multiple Choice

Q The Question

It is given that \(n\) is an integer. Let \(u\), \(v\) and \(w\) be the standard deviation, the median and the range of the group of numbers \[ \{\,1-9n,\; 3-9n,\; 4-9n,\; 5-9n,\; 7-9n\,\} \] respectively. Which of the following must be true?

\(\text{I. } u = 2\)

\(\text{II. } v < 4\)

\(\text{III. } w > 6\)

  • A. I only
  • B. II only
  • C. I and III only
  • D. II and III only

Note: the five values are exactly \(\{1,3,4,5,7\}\) each shifted by \(-9n\). This shift is the key to the whole question.

Step 11MFactor out the shift

Write each term with the common shift factored out:

\[ 1-9n=(1)+(-9n),\quad 3-9n=(3)+(-9n),\;\dots \]

So the set equals \(\{1,3,4,5,7\}\) with \(-9n\) added to every value.

Hint: Adding (or subtracting) the same number to every datum is a translation — it moves the whole graph but does not stretch it, so the spread (standard deviation, variance, range) is unchanged.
Step 21MCompute the SD of the base set \(\{1,3,4,5,7\}\)

Mean of base set:

\[ \bar{x}=\frac{1+3+4+5+7}{5}=\frac{20}{5}=4 \]

Sum of squared deviations:

\[ (1-4)^2+(3-4)^2+(4-4)^2+(5-4)^2+(7-4)^2 \] \[ =9+1+0+1+9=20 \]

Variance and standard deviation:

\[ \sigma^2=\frac{20}{5}=4 \qquad\Rightarrow\qquad \sigma=\sqrt{4}=2 \]
Hint: In this paper, the standard deviation is the population one, dividing by \(N=5\) (not \(N-1\)). Check that \(20/5=4\), hence \(\sqrt{4}=2\).
Step 31AConclude

Since the shift \(-9n\) does not change the spread,

\[ u = \sigma_{\{1,3,4,5,7\}} = 2 \]
✓ Statement I is TRUE. \(u=2\) for every integer \(n\).

Step 11MOrder the data

The five base values in increasing order are \(1<3<4<5<7\). Adding \(-9n\) keeps the same order, so the ordered list is

\[ 1-9n,\;3-9n,\;4-9n,\;5-9n,\;7-9n \]
Hint: Since there are \(5\) data values (odd), the median is the middle one — the 3rd ordered datum.
Step 21AFind \(v\)

The 3rd ordered value is \(4-9n\), hence

\[ v = 4 - 9n \]
Hint: The median follows the shift: \(\text{median}(x_i+c)=\text{median}(x_i)+c\).
Step 31ATest the inequality

We need \(v<4\) for every integer \(n\):

\[ 4-9n<4 \iff -9n<0 \iff n>0 \]

So \(v<4\) holds only when \(n\) is a positive integer. For example, with \(n=-1\):

\[ v = 4-9(-1)=13 \not< 4 \]
Hint: The word “must” is strong — a single counter-example is enough to kill the statement. Take \(n=0\): \(v=4\), not less than 4.
✗ Statement II is FALSE. \(v=4-9n\), which is not always less than 4 (e.g. \(n=0\) gives \(v=4\); \(n=-1\) gives \(v=13\)).

Step 11MIdentify min and max

From the ordered list, the smallest value is \(1-9n\) and the largest is \(7-9n\).

Hint: The shift \(-9n\) moves both ends by the same amount, so the gap is preserved.
Step 21ACompute the range
\[ w = (7-9n)-(1-9n) = 7-1 = 6 \]

The \(-9n\) terms cancel — the range is a constant \(6\).

Hint: Watch the signs: \(7-9n-1+9n=6\). The range does not depend on \(n\).
Step 31ATest the inequality

The statement claims \(w>6\), but we found \(w=6\) exactly. Hence \(w>6\) is never true — it is false for every integer \(n\).

✗ Statement III is FALSE. \(w=6\), which is not greater than 6.

📋 Summary — Answers at a Glance

  • Base set: \(\{1,3,4,5,7\}\), each shifted by \(-9n\).
  • I. \(u=\sqrt{\dfrac{(1-4)^2+(3-4)^2+(4-4)^2+(5-4)^2+(7-4)^2}{5}}=\sqrt{\dfrac{20}{5}}=2\) → TRUE
  • II. \(v=4-9n\); \(v<4 \iff n>0\), not true for all integers (e.g. \(n=0\)) → FALSE
  • III. \(w=(7-9n)-(1-9n)=6\), but the claim is \(w>6\) → FALSE
  • Only statement I must be true.
  • ✅ Answer: A (I only)
