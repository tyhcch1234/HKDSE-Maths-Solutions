Inequalities Quadratic Inequality OR / AND solution sets

Question

The solution of \((x-a)(x-b) \le 0\)  or  \((x-b)(x-c) \ge 0\)  is

Interactive Number Line

Adjust the positions of \(a, b, c\) (with \(a < b < c\)) and see how the two inequalities behave on the real number line.

\((x-a)(x-b) \le 0\)

True for \(a \le x \le b\) (between \(a\) and \(b\)).

\((x-b)(x-c) \ge 0\)

True for \(x \le b\) or \(x \ge c\) (outside \([b,c]\)).

Combined solution (union):

\( (a \le x \le b) \cup (x \le b) \cup (x \ge c) \)

Since \(x \le b\) already covers the whole interval \([a, b]\), the union simplifies to \(x \le b \;\; \text{or} \;\; x \ge c\) .

Guided Solution

For a quadratic factorised as \((x-p)(x-q)\) with \(p < q\):

  • \((x-p)(x-q) < 0\) between \(p\) and \(q\).
  • \((x-p)(x-q) > 0\) outside the interval.
  • Equality holds at \(x=p\) or \(x=q\).

Hence here, where the roots are \(a\) and \(b\) with \(a < b\): \[ (x-a)(x-b) \le 0 \quad\Longleftrightarrow\quad a \le x \le b \]

By the same reasoning, with roots \(b\) and \(c\) and \(b < c\):

\[ (x-b)(x-c) \ge 0 \quad\Longleftrightarrow\quad x \le b \;\; \text{or} \;\; x \ge c \]

(The product is positive on the two outer intervals and equals zero at the endpoints \(b\) and \(c\).)

The original condition is “or”, so we take the union:

\[ \underbrace{a \le x \le b}_{\text{set 1}} \;\;\cup\;\; \underbrace{x \le b \;\text{ or }\; x \ge c}_{\text{set 2}} \]

Observe that \([a,b] \subseteq (-\infty, b]\). So the whole union collapses to

\[ x \le b \quad \text{or} \quad x \ge c \]
  • A. \(x \ge a\) – too wide, includes values in \((b, c)\).
  • B. \(x \le b\) – only half of the union.
  • C. all real numbers – false; e.g. \(x\) in \((b, c)\) fails.
  • D. \(x \le a\) or \(x \ge c\) – misses \((a, b)\cup\{b\}\).

None of the given options matches exactly. (In the actual paper, the correct answer as per the official key is “\(x \le b\) or \(x \ge c\)”, which is not listed among A – D.)
