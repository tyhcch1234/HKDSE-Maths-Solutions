HKDSE Math 2014 Paper 2 · Q14

Recurrence Relation: Finding \(a_5\) from a Fibonacci-type Rule

Formulas and Sequences — nth term of a sequence defined recursively.

Sequences Recurrence Relation Substitution MC

Q The Question

Let \(a_n\) be the \(n\)th term of a sequence. If \(a_2 = 7\), \(a_4 = 63\) and \[a_{n+2} = a_{n+1} + a_n\] for any positive integer \(n\), then \(a_5 =\)
A 56
B 70
C 91
D 119
Key idea: A recurrence relation expresses each term in terms of the previous terms. To reach \(a_5\) we must "walk forward" from the known values \(a_2\) and \(a_4\), one term at a time.

1 Step-by-Step Guided Solution

Tap each step to reveal it. Try to guess the next move before you open it!

1
Understand what the rule means
▼

The given rule is:

\[a_{n+2} = a_{n+1} + a_n\]

It says: any term equals the sum of the two terms immediately before it. (This is the famous Fibonacci-type rule.)

Hint · Meaning of the rule:
  • \(a_{n+2}\) = the term we are finding,
  • \(a_{n+1}\) = the term just before it,
  • \(a_n\) = the term two places before it.
Each new term needs the two previous ones.

So to find \(a_5\), we need \(a_4\) and \(a_3\). We already know \(a_4 = 63\), but \(a_3\) is missing — that's our first job.

2
Which value of \(n\) lets us use \(a_4 = 63\)?
▼

We want the rule to contain \(a_4\). The rule uses \(a_{n+2}\) as its highest index, so set:

\[n + 2 = 4 \quad\Longrightarrow\quad n = 2\]

Substituting \(n = 2\) into the rule:

\[a_{4} = a_{3} + a_{2}\]

Hint · Choosing \(n\): Want to involve \(a_k\)? Set \(n+2 = k\), i.e. \(n = k - 2\). Here \(k = 4\), so \(n = 2\).
3
Solve for the missing term \(a_3\)
▼

Now substitute the known values \(a_4 = 63\) and \(a_2 = 7\):

\[63 = a_3 + 7\]

Subtract \(7\) from both sides:

\[a_3 = 63 - 7 = 56\]

Check: \(7 + 56 = 63\) ✓ — so \(a_3 = 56\) fits the rule \(a_4 = a_3 + a_2\).
4
Now use the rule again for \(a_5\)
▼

To get \(a_5\), set \(n+2 = 5\), i.e. \(n = 3\):

\[a_{5} = a_{4} + a_{3}\]

Substitute \(a_4 = 63\) and \(a_3 = 56\):

\[a_5 = 63 + 56 = 119\]

Hint · Order matters: We could not jump straight to \(a_5 = a_4 + a_3\) without first finding \(a_3\). Recurrence problems are solved sequentially: fill the gap first, then move forward.
5
Conclusion and MCQ answer
▼

So \(a_5 = 119\), which corresponds to option D.

Therefore
\(a_5 = 119\)
Answer: D

3 Exam Tips & Common Traps

Tip 1 — Work backwards from the index you know.
To use a known \(a_k\), set \(n + 2 = k\) and solve for \(n\) before substituting.
Tip 2 — Fill gaps in order.
Recurrence relations are "chain" problems. You cannot skip a missing term; find \(a_3\) first, then \(a_5\).
Common trap: Writing \(a_5 = a_4 + a_2 = 63 + 7 = 70\) (option B).
The rule uses the two immediately preceding terms (\(a_4\) and \(a_3\)), not \(a_4\) and \(a_2\).
Common trap: Thinking \(a_3 = a_4 - a_2\) is a different "formula". It is just the same rule \(a_4 = a_3 + a_2\) rearranged — and it works because we are allowed to solve for the unknown.
