HKDSE Math 2022 Paper 2 Q36

Inequalities Linear Programming Feasible Region

Find the least value of \(7x + 6y\) subject to the given constraints.

The Problem

Consider the following system of inequalities:

\[ \begin{cases} 2x + y \ge 8 \\ 2x + 3y \ge 16 \\ 4x + 3y \le 22 \end{cases} \]

Let \(R\) be the region representing the solution of the above system. If \((x, y)\) is a point lying in \(R\), then the least value of \(7x + 6y\) is:

A. 32
B. 38
C. 41
D. 43

Step-by-Step Guided Solution

1

Understand the objective

We need to find the minimum value of the linear expression \(7x + 6y\) over all points \((x,y)\) in the feasible region \(R\).

💡 Hint: For a linear function over a polygonal region, the extreme values always occur at one of the corner points (vertices) of the feasible region.
2

Identify the boundary lines

Rewrite the inequalities as equations to find the lines that form the boundaries of \(R\):

  • \(L_1: 2x + y = 8\)
  • \(L_2: 2x + 3y = 16\)
  • \(L_3: 4x + 3y = 22\)
3

Find the intersection points (corner points)

Solve the pairs of equations to get the vertices:

Intersection of \(L_1\) and \(L_2\):

\(2x + y = 8\) and \(2x + 3y = 16\)

Subtracting: \(2y = 8 \Rightarrow y = 4\), then \(2x + 4 = 8 \Rightarrow x = 2\).

Point A = \((2, 4)\)

Intersection of \(L_2\) and \(L_3\):

\(2x + 3y = 16\) and \(4x + 3y = 22\)

Subtracting: \(2x = 6 \Rightarrow x = 3\), then \(6 + 3y = 16 \Rightarrow 3y = 10 \Rightarrow y = \frac{10}{3}\).

Point B = \(\left(3, \frac{10}{3}\right)\)

Intersection of \(L_3\) and \(L_1\):

\(4x + 3y = 22\) and \(2x + y = 8\)

From \(2x + y = 8 \Rightarrow y = 8 - 2x\). Substitute: \(4x + 3(8 - 2x) = 22 \Rightarrow 4x + 24 - 6x = 22 \Rightarrow -2x = -2 \Rightarrow x = 1\), then \(y = 8 - 2 = 6\).

Point C = \((1, 6)\)

4

Evaluate \(7x + 6y\) at each corner point

Point \((x, y)\) \(7x + 6y\)
A \((2, 4)\) \(7(2) + 6(4) = 14 + 24 = 38\)
B \(\left(3, \frac{10}{3}\right)\) \(7(3) + 6\left(\frac{10}{3}\right) = 21 + 20 = 41\)
C \((1, 6)\) \(7(1) + 6(6) = 7 + 36 = 43\)
5

Determine the least value

Comparing the three values \(38, 41, 43\), the smallest is \(38\).

✅ Least value of \(7x + 6y\) is \(38\), attained at \((2, 4)\).

Therefore, the correct option is B.
