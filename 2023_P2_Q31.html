Step 0 — The binary number $1011001011001011_2$ and its place-value (index) table.

2023 MC #31

$1011001011001011_2 =$

  • A.  $11\times 2^{11} + 11\times 2^{5} + 11$
  • B.  $11\times 2^{12} + 11\times 2^{6} + 11$
  • C.  $11\times 2^{13} + 11\times 2^{7} + 11$
  • D.  $11\times 2^{14} + 11\times 2^{8} + 11$
1Read the binary number &
number the bit positions
Write the 16 bits with their place values (indices from 15 down to 0): $$1011001011001011_2$$ Count positions from the right,
starting at index $0$.
There are 16 bits,
so the highest index is $15$.
2Expand as a sum of powers of 2
Binary Place Values \(2^{15},\ 2^{14},\ \ldots,\ 2^{1},\ 2^{0}\) Every bit is worth a power of 2, counting positions from 0 at the right-hand end.
Keep only the positions where the bit is $1$: $$=2^{15}+2^{13}+2^{12}+2^{9}+2^{7}+2^{6}+2^{3}+2^{1}+2^{0}$$
Each "1" bit contributes $2^{(\text{index})}$;
each "0" bit contributes nothing.
3Group the terms into blocks of three
Law of Indices \(2^{a}\times 2^{b}=2^{a+b}\) Using the law in reverse splits the sum into three identical blocks multiplied by powers of 2.
Group from the highest power downward in triples: $$=\underbrace{(2^{3}+2^{1}+2^{0})}_{\text{top block}}\times 2^{12} +\underbrace{(2^{3}+2^{1}+2^{0})}_{\text{middle}}\times 2^{6} +\underbrace{(2^{3}+2^{1}+2^{0})}_{\text{bottom}}$$
This is just the Law of Indices: $2^{a}\times 2^{b}=2^{a+b}$ used in reverse.
4Check the gap pattern (the key trap)
The three blocks sit at indices $12$, $6$ and $0$ — the gaps are $6$ and $6$.
For option A the gaps would be $6$ and $6$ too,
but the block starts at $11$, i.e. $2^{11},2^{5},2^{-1}$ — impossible since $2^{0}$ is the lowest term.
Options C and D shift the block up, changing the bit pattern.
$2^{12}=4096$, $2^{6}=64$, $2^{0}=1$ — the block multipliers.
5Simplify each block
$$2^{3}+2^{1}+2^{0}=8+2+1=11$$ So $$=11\times 2^{12}+11\times 2^{6}+11$$
Verify: $11\times4096=45056$, $11\times64=704$, $11\times1=11$;
sum $=45771$.
Answer B.   $11\times 2^{12}+11\times 2^{6}+11$

Question. Express \(1101001101001101_{2}\) in the form \(a\times 2^{12}+a\times 2^{6}+a\), where \(a\) is a positive integer.

Show the worked solution
Step 1. The \(16\) bits occupy positions \(15\) down to \(0\);
the \(1\)-bits are at positions \(15,14,12,9,8,6,3,2,0\).
Step 2. So the number is \(2^{15}+2^{14}+2^{12}+2^{9}+2^{8}+2^{6}+2^{3}+2^{2}+2^{0}\).
Step 3. The bits group into the block \(1101_{2}\) at positions \(12\), \(6\) and \(0\),
with two zeros between consecutive blocks: \(\left(2^{3}+2^{2}+2^{0}\right)2^{12}+\left(2^{3}+2^{2}+2^{0}\right)2^{6}+\left(2^{3}+2^{2}+2^{0}\right)\).
Step 4. Each block equals \(8+4+1=13\), so the number is \(13\times 2^{12}+13\times 2^{6}+13\).
Step 5. Check: \(53248+832+13=54\,093\), and \(1101001101001101_{2}=54\,093\) ✓
Answer: \(13\times 2^{12}+13\times 2^{6}+13\ \ (=54\,093)\)
