Number of dots in the 8th pattern

Formulas and Sequences — Recurrence relations & summation

Sequences Recurrence Relation Arithmetic Series Summation

Question

In the figure, the 1st pattern consists of 3 dots. For any positive integer $n$, the $(n+1)$th pattern is formed by adding $(2n+3)$ dots to the $n$th pattern.

Find the number of dots in the 8th pattern.

Key relation: $\;T(1)=3\;$ and $\;T(n+1)=T(n)+(2n+3)\;$ for all positive integers $n$.

Step-by-Step Guided Solution

Tap each step to reveal the reasoning. Try to predict the next line before opening it!

1
Name the unknown & restate the given information
▶

Let $T(m)$ be the number of dots in the $m$th pattern.

We are told:

(1) $\;T(1)=3$
(2) $\;T(n+1)=T(n)+(2n+3)\;$ for any positive integer $n$
Hint — What is a recurrence relation?
It does not give a formula for $T(m)$ directly. Instead it tells us how to move from one term to the next term by adding a known amount $(2n+3)$. So we must "climb" from $T(1)$ up to $T(8)$, one step at a time.

Goal: find $T(8)$, the number of dots in the 8th pattern.

2
Work out the "extra dots added" at each step
▶

The extra dots added from the $n$th to the $(n+1)$th pattern is $(2n+3)$. Substitute $n=1,2,\dots,7$:

$n$Extra added to reach next pattern: $2n+3$
1$2(1)+3=5$
2$2(2)+3=7$
3$2(3)+3=9$
4$2(4)+3=11$
5$2(5)+3=13$
6$2(6)+3=15$
7$2(7)+3=17$

The extra dots form an arithmetic sequence: $5,7,9,11,13,15,17$ with common difference $2$.

3
Build the chain of equations
▶

Start from $T(1)=3$ and apply relation (2) repeatedly:

$T(2)=T(1)+5$
$T(3)=T(2)+7$
$T(4)=T(3)+9$
$T(5)=T(4)+11$
$T(6)=T(5)+13$
$T(7)=T(6)+15$
$T(8)=T(7)+17$

Substituting each equation into the next one (a chain substitution) gives:

$T(8)=T(1)+5+7+9+11+13+15+17$
4
Evaluate the sum
▶

Now $T(1)=3$, so

$T(8)=3+5+7+9+11+13+15+17$

Add the terms:

$3+5=8,\;8+7=15,\;15+9=24,\;24+11=35,$
$35+13=48,\;48+15=63,\;63+17=\mathbf{80}$

Or cleverly rearrange: the eight numbers $3,5,7,9,11,13,15,17$ are an arithmetic series, so

$S=\dfrac{8}{2}\big(3+17\big)=4\times20=80$
Hint — Arithmetic series formula: $S_n=\dfrac{n}{2}\big(a+\ell\big)$, where $a$ is the first term and $\ell$ is the last term. Here $n=8$, $a=3$, $\ell=17$. This is much faster than adding one by one!
5
Conclusion & trap to avoid
▶

Therefore the number of dots in the 8th pattern is $80$, answer C.

Common mistake: Using the formula with the wrong $n$. For example, $T(8)=T(7)+(2\times8+3)=T(7)+19$ would be incorrect, because the relation is defined for $n$ going from the $n$th pattern. To reach the 8th pattern we use $n=7$, so the added amount is $2(7)+3=17$, not $19$.
