Let $g(x)=ax^{3}+4ax^{2}-24$, where $a$ is a constant. If $x+2$ is a factor of $g(x)$, then $g(2)=$

A. $-96$
B. $0$
C. $3$
D. $48$

Step-by-step solution

1

Use the Factor Theorem to set up an equation

Since $x+2$ is a factor of $g(x)$, we have

$$g(-2)=0.$$

That is, substituting $x=-2$ into $g(x)=ax^{3}+4ax^{2}-24$ gives zero.

Hint: factor $x-k$ ⇒ $g(k)=0$. Here $x+2=x-(-2)$, so the root is $-2$.
2

Solve for the constant $a$

$$a(-2)^{3}+4a(-2)^{2}-24=0$$

$$-8a+16a-24=0$$

$$8a-24=0$$

$$a=3.$$

Careful: $(-2)^3=-8$ and $(-2)^2=4$, so $4a\cdot4=16a$.
3

Write down the polynomial

With $a=3$,

$$g(x)=3x^{3}+12x^{2}-24.$$

Now the polynomial is fully determined — substitute $x=2$.
4

Evaluate $g(2)$

$$g(2)=3(2)^{3}+12(2)^{2}-24$$

$$=3(8)+12(4)-24$$

$$=24+48-24=48.$$

$2^3=8$, $2^2=4$ — compute each term before combining.
5

Conclusion

Therefore $g(2)=48$, which corresponds to option D.

Answer: D. 48
