Counting the number of roots of a trigonometric equation on \(0^\circ \le \theta \le 360^\circ\)

For \(0^\circ \le \theta \le 360^\circ\), how many roots does the equation \[5\sin^2\theta + \sin\theta - 4 = 0\] have?

A. 2     B. 3     C. 4     D. 5

Part (a) Factorise the quadratic

Discriminant \(\Delta\)—
Root 1—
Root 2—
Valid for \(\sin\theta\)?—
1
Substitute \(x = \sin\theta\)

Let \(x = \sin\theta\). Then \(\sin^2\theta = x^2\) and the equation becomes a quadratic in \(x\):

\[5x^2 + x - 4 = 0\]
Hint: Because only \(\sin\theta\) appears (and no \(\cos\theta\), etc.), the equation is a quadratic in \(\sin\theta\).
2
Factorise

Find two numbers whose product is \(5 \times (-4) = -20\) and whose sum is \(1\): these are \(+5\) and \(-4\). Split the middle term:

\[5x^2 + 5x - 4x - 4 = 0\] \[5x(x+1) - 4(x+1) = 0\] \[(5x - 4)(x + 1) = 0\]
Hint: You can also use the quadratic formula \(x = \dfrac{-b \pm \sqrt{b^2 - 4ac}}{2a}\) to get the same roots.
Factorised form: \((5\sin\theta - 4)(\sin\theta + 1) = 0\)
0 / 2

Part (b)(i) Solve the two factors

Root: \(\sin\theta = 4/5\)—
Root: \(\sin\theta = -1\)—
Angles from \(4/5\)—
Angles from \(-1\)—
1
Set each factor equal to zero

From \((5\sin\theta - 4)(\sin\theta + 1) = 0\), we get:

\[5\sin\theta - 4 = 0 \quad \text{or} \quad \sin\theta + 1 = 0\] \[\sin\theta = \frac{4}{5} \quad \text{or} \quad \sin\theta = -1\]
Hint: A product is zero only when at least one factor is zero — this is the zero-product property.
2
Check the range of sine

Since \(-1 \le \sin\theta \le 1\) for all real \(\theta\):

  • \(\sin\theta = 0.8\)  → valid (\(\theta\) lies in the first or second quadrant)
  • \(\sin\theta = -1\)  → valid, and on \(0^\circ \le \theta \le 360^\circ\) this happens at \(\theta = 270^\circ\) only.
Hint: If a root were outside \([-1,1]\) it would be rejected. Here both roots are acceptable.
Candidate values: \(\sin\theta = \dfrac{4}{5}\)  or  \(\sin\theta = -1\)
0 / 2

Part (b)(ii) Find all angles in \(0^\circ \le \theta \le 360^\circ\)

1
Solve \(\sin\theta = \dfrac{4}{5}\)

The reference angle is

\[\theta_{\text{ref}} = \sin^{-1}\!\left(\frac{4}{5}\right) \approx 53.1301^\circ\]

Since sine is positive in quadrants I and II:

\[\theta_1 = 53.1301^\circ, \qquad \theta_2 = 180^\circ - 53.1301^\circ = 126.8699^\circ\]
Hint: The CAST rule — in quadrant II, \(\theta = 180^\circ - \theta_{\text{ref}}\); in quadrant I, \(\theta = \theta_{\text{ref}}\).
2
Solve \(\sin\theta = -1\)

Sine attains its minimum \(-1\) only at the bottom of the unit circle:

\[\theta_3 = 270^\circ\]
Hint: \(\sin\theta = -1\) has exactly one solution per full revolution, not two like \(\sin\theta = k\) with \(-1 < k < 1\).
3
Collect and count the roots

Listing all solutions in \(0^\circ \le \theta \le 360^\circ\):

\[\theta \approx 53.13^\circ,\; 126.87^\circ,\; 270^\circ\]

These are three distinct angles, so the equation has 3 roots.

Hint: Check that \(\theta = 360^\circ\) is not one of the solutions — here it is not, so no double counting with \(0^\circ\).
Roots: \(53.13^\circ,\ 126.87^\circ,\ 270^\circ\) → Answer: B (3 roots)
0 / 3

Summary Final Answers at a Glance

  • Let \(x = \sin\theta\). The equation is a quadratic: \(\;5x^2 + x - 4 = 0\).
  • Factorising: \(\;(5x - 4)(x + 1) = 0 \;\Rightarrow\; \sin\theta = \dfrac{4}{5}\) or \(\sin\theta = -1\).
  • \(\sin\theta = \dfrac{4}{5}\) gives two angles: \(\;\theta \approx 53.13^\circ\) and \(\theta \approx 126.87^\circ\).
  • \(\sin\theta = -1\) gives one angle: \(\;\theta = 270^\circ\).
  • Total number of roots on \(0^\circ \le \theta \le 360^\circ\): \(\;\boxed{3}\).
  • Correct option: B.
