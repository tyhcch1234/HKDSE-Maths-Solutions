Functions and Graphs (40) · Sub-Topic: Max/Min Value

T7 Q35

Write the function \(y = 2x^2 - 8x + 5\) in the form \(y = a(x-h)^2 + k\), and hence state its minimum value.

Solution

Factor $2$ from the $x^2$ and $x$ terms: $y=2(x^2-4x)+5$.
Complete the square inside the bracket: $x^2-4x=(x-2)^2-4$.
Substitute back: $y=2[(x-2)^2-4]+5$.
Simplify: $y=2(x-2)^2-8+5=2(x-2)^2-3$.
Since $2(x-2)^2\ge 0$ for all real $x$, the minimum occurs when $(x-2)^2=0$.
Thus the minimum value is $-3$, attained at $x=2$.
The function is $y=2(x-2)^2-3$, so its minimum value is $-3$.
